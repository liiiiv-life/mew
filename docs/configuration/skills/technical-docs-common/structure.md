# Structure specialist adaptation

Read and apply [documentation](../.vendor/documentation/SKILL.md) for reader-purpose classification and type-specific information order. Do not replace it with this short adaptation.

Use existing context to establish audience and goals; ask only about material missing information. Existing project rules determine folders, document ownership, navigation, and mandatory sections. Use Diátaxis to improve a user guide's purpose and reading order without forcing its four categories into the folder tree.

For internal specifications, shared contracts, runbooks, work records, and ADRs, retain project-required formats and current/history ownership. Split a file only when independent retrieval and maintenance justify it. Preserve historical rationale and raw sources. Once the source structure is finalized, target-language editors refine prose within that structure.

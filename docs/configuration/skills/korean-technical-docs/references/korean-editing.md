# 한국어 교정 스킬 연결

[korean-writing-reviewer](../../.vendor/korean-writing-reviewer/SKILL.md)의 원문과 필요한 기술 문서 프로필을 읽고 적용한다. 작업 범위·독자·말투·보호 구문을 전달하며, 요청에 맞는 `review` 또는 `improve` 모드를 선택한다. 이 파일은 이전 참조를 보존하는 연결 안내다.

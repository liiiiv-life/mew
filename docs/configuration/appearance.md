# 화면·알림·Dock·단축키 설정

헤더 메뉴의 **설정**에서 개인 작업 화면을 바꾼다. 계정과 권한은 [계정 설정](accounts.md), 호스트 환경변수는 [서버 설정](environment.md)을 따른다.

## 화면 설정

테마는 같은 Mew 인스턴스의 로그인 계정에 저장한다. 다른 기기에서 바꾸면 열려 있는 화면에도 반영되며, 화면 복귀·재연결 때 최신 값을 다시 확인한다. 계정에 테마가 없으면 처음 연결한 브라우저의 기존 선택을 가져오고, 기존 설정도 없으면 **미드나이트**로 시작한다.

설정 창은 메모·태스크 팝업을 포함한 앱의 모든 작업 레이어 위에 표시된다. 내부 언어·글꼴 선택 목록도 설정 창 위에서 동작한다.

PC 메모·태스크의 팝업/패널 전환은 각 탭 오른쪽 아이콘을 누른다. 현재 방식에 따라 **팝업으로 전환** 또는 **패널로 전환** 툴팁을 표시하고 브라우저에 선택을 기억한다. 화면 설정에서는 이 항목을 제공하지 않는다. 모바일은 패널로 표시하고 PC 선택값은 그대로 유지한다.

언어와 글꼴 목록은 앱 테마를 따르는 자체 드롭다운으로 표시한다. 글꼴은 추천 목록에서 고르거나 이름을 직접 입력할 수 있다. 방향키·Enter로 목록을 선택하고 Esc·뒤로가기는 목록만 닫는다.

언어를 바꾸면 에이전트의 히스토리·로딩·새로고침, 편집기·검색·파일·Git·예약·원격 데스크톱과 공용 확인창의 문구에도 바로 적용된다. 열린 편집기·터미널과 작성 중인 초안을 유지한다. 문서·대화·파일명과 외부 명령의 출력 원문은 그대로 표시한다. 구현·누락 방지 검사는 [UI 번역 계약](../development/ui-contracts.md#ui-번역)을 따른다.

헤더 메뉴 → **설정 → 화면**에서 **배경색·글씨색·주요색**을 묶은 테마를 고른다. 각 버튼은 테마 배경 위에 글씨색 `A`와 주요색 `a`를 보여 준다. 기본 다크·라이트와 미드나이트·포레스트·페이퍼·로즈·오션 프리셋을 누르면 즉시 적용한다. 미드나이트·로즈·오션은 두 색이 부드럽게 섞이고 천천히 움직이는 그라데이션 배경을 사용한다. 선택한 테마와 커스텀 목록은 같은 계정의 기기들이 공유한다.

마지막 **+** 버튼으로 현재 테마를 복사해 커스터마이징한다. 세 색을 각각 색상 영역 드래그(마우스·터치), 색조·채도·밝기 슬라이더 또는 6자리 HEX 코드로 바꾼다. 초기화는 해당 색을 편집 시작 때의 값으로 되돌린다. **테마 추가**를 누르면 미리보기의 조합이 그리드에 추가되고 화면에 적용된다. 같은 조합은 중복 저장하지 않는다. 저장한 커스텀 테마 카드를 누르면 해당 테마가 적용되고 그리드 아래에 편집 영역이 바로 열린다. **테마 저장**은 해당 항목을 교체한다. 편집 영역 안의 **커스텀 테마 삭제**를 누르면 해당 항목을 삭제하고 기본 다크 테마로 돌아간다.

커스텀 편집에서 **그라데이션**을 켜면 두 그라데이션 색과 방향을 바꿀 수 있다. **배경 애니메이션**으로 움직임을 켜거나 끈다. 미리보기와 테마 버튼에 같은 배경을 표시하며, 단색·그라데이션 여부와 두 색·방향·애니메이션까지 같은 조합만 중복으로 판단한다. 기기의 모션 감소 설정이 켜져 있으면 저장한 애니메이션 설정과 관계없이 배경 움직임을 멈춘다. 그라데이션을 꺼도 선택한 배경색은 유지한다.

편집 영역의 취소 버튼은 수정 내용을 버리고 편집 영역을 닫는다. Esc·뒤로가기는 열린 색 선택기와 커스텀 편집 영역을 차례로 접는다. 저장 전 편집 영역을 닫으면 초안을 버리고 기존 테마를 유지한다. 배경색과 그라데이션의 여러 지점에서 글씨 대비가 낮은 초안에는 안내를 표시한다.

선택한 테마와 커스텀 목록은 서버의 계정 상태에 저장하며, 브라우저에는 계정별 사본과 초기 화면용 `mew:themes`를 남긴다. 서버에 이미 저장된 테마는 오래된 브라우저 사본으로 덮어쓰지 않는다. 저장에 실패하면 현재 선택을 유지하고 오류를 알리며, 재연결·화면 복귀·다음 변경 때 다시 저장한다. 기존 `mew:theme` 모드와 `mew:theme-color` 또는 `mew:accent-color`는 실제 표시 색을 유지해 이관한다. 이전 미드나이트·로즈·오션의 세 색과 정확히 같은 테마가 선택되어 있으면 새 그라데이션 프리셋으로 이어받는다. 같은 단색 조합을 커스텀 목록에 저장한 경우에는 그 선택을 유지한다. 패널·테두리·보조 글씨·링크·버튼 hover 색은 자동 계산하며, 밝은/어두운 모드는 기본 배경색의 밝기를 따른다. 그라데이션 테마에서는 버블·일반 버튼·컴포넌트의 배경색을 진하게 섞되 반투명하게 표시해 전체 배경이 비치게 한다.

라이트·페이퍼·로즈·오션과 밝은 커스텀 테마의 팝업·드롭다운·메뉴·대화상자·부유창은 그라데이션 유무와 관계없이 배경을 75% 불투명도로 표시하고 6px 배경 블러를 적용한다. 테마 배경색 70%와 기존 팝업 표면색 30%를 섞어 밝은 색조를 유지한다. 대화상자의 검은 덮개는 둥근 패널 바깥에만 표시해 반투명 패널 아래로 비치지 않게 한다. 바깥 누름·Esc·뒤로가기와 창의 앞뒤 순서는 유지한다. 어두운 모드에서는 그라데이션 팝업의 75% 배경·6px 블러와 단색 테마의 불투명 배경을 유지한다. 사이드바의 명령어 버튼 추가·수정 창도 같은 규칙을 따른다. 글씨와 아이콘은 선명하게, 안쪽 입력 요소·트리 고정 행·터미널은 단색 배경으로 유지한다. 저장한 테마 색·그라데이션 설정은 바뀌지 않으며 삭제·경고 색은 모드별 의미를 유지한다. 자세한 저장·색 계산은 [테마 계약](../development/ui-contracts.md#테마색과-파생-액센트)을 따른다.

헤더의 계정/설정 메뉴에서 여는 `설정 > 화면`은 언어와 글꼴 세 벌을 브라우저별로 기억한다. 테마는 계정별로 공유한다. 전역 UI 텍스트, Markdown 핫뷰 본문, Mono(코드 편집기·터미널·인라인/블록 코드·`font-mono` UI)는 서로 독립이며, 입력한 글꼴이 웹폰트로 로드되지 않고 이 기기에도 없으면 각 범주의 시스템 폴백 글꼴을 쓴다. 값은 `localStorage`의 `mew:fonts`에 저장되고 각 항목을 기본값으로 되돌릴 수 있다.

기본 UI·Markdown 글꼴은 IBM Plex Sans KR, Mono는 IBM Plex Mono다. 두 글꼴은 일반체(400)·굵은체(700) WOFF2를 mew에 포함해 같은 서버에서 제공하므로, 인터넷 연결이나 기기별 폰트 설치 없이 사용할 수 있다. `index.html`이 `/fonts/ibm-plex/fonts.css`를 로드하며, `public/fonts/ibm-plex/`는 개발 서버와 Vite 배포 결과에 그대로 포함된다. IBM 공식 배포본 `@ibm/plex-sans-kr` 1.1.0·`@ibm/plex-mono` 2.5.0의 원본 파일을 사용한다. [SIL OFL 원문](../../public/fonts/ibm-plex/LICENSE.txt)과 [출처·버전·파일 해시](../../public/fonts/ibm-plex/sources.json)를 함께 배포한다.

Noto Serif KR은 저장된 글꼴 설정에 포함되거나 사용자가 선택했을 때만 Google Fonts에서 한 번 불러온다. 기본 화면의 최초 HTML에서는 외부 글꼴 CSS를 요청하지 않는다. 프로덕션 CSP는 스타일시트에 `https://fonts.googleapis.com`, 폰트 파일에 `https://fonts.gstatic.com`만 외부 출처로 허용한다. 외부 스크립트 허용 범위는 넓히지 않는다. Google Fonts에 연결할 수 없는 환경에서는 Noto Serif KR의 설치된 글꼴 또는 시스템 폴백을 사용한다. 글꼴 이름을 직접 입력해도 임의의 웹폰트를 자동으로 다운로드하지는 않는다.

## 알림 설정

**설정 → 알림**에서 앱 내 알림·데스크톱 알림·소리·서버 자원 감시와 테스트 알림을 설정한다. 기존 뮤펫 탭에서 이 설정을 옮겼으며 설정값은 유지한다. 미확인 알림이 있으면 상단 활성 세션 왼쪽의 종 아이콘으로 목록을 열어 확인하고 해당 작업 화면으로 이동할 수 있다. 뮤펫이 꺼져 있어도 헤더·OS 알림·소리는 각 설정을 따른다.

**승인 요청 시 에이전트 탭 열기**는 기본으로 켜져 있다. 새 승인 요청을 받으면 다른 작업 중에도 해당 에이전트 탭으로 이동한다. 현재 화면에서 계속 작업하려면 이 옵션을 끈다. 자동 전환을 꺼도 주황색 대기 표시와 알림은 유지되며 뮤펫의 **승인 요청 보기**로 직접 이동할 수 있다. 설정은 브라우저에 저장되며 기존 저장값에 이 항목이 없으면 켜짐으로 읽는다.

뮤펫 스킨을 활성화하면 알림 탭에 **뮤펫으로도 알림 표시**가 나타난다. 이 옵션은 고양이의 자동 말풍선·알림 동작만 제어한다. 기존 사용자에게 기본 켜짐으로 이어받으며 뮤펫을 끄거나 옵션을 해제해도 다른 알림 채널은 유지된다. [알림 기능 계약](../features/화면·계정·운영/Mewpet%20마스코트·알림·휴식.md#알림-설정과-pc-데스크톱-알림)을 따른다.

## Dock 설정

헤더 메뉴 → **설정 → Dock**에서 현재 사용할 수 있는 항목의 표시 여부와 순서를 바꾼다. 미리보기와 실제 독에 즉시 반영하며, 초기화는 모든 표시 설정과 순서를 기본값으로 되돌린다. 모바일 하단 독과 PC 왼쪽 수직 독에 같은 설정이 적용된다. 원격 데스크톱은 헤더 메뉴에서 연다. localhost 앱은 현재 Mew 주소 뒤에 `/포트번호`를 붙여 연다.

아이콘을 숨겨도 열린 패널이나 작업 세션은 닫지 않는다. 모든 항목을 숨기면 독을 표시하지 않으며 헤더 메뉴에서 설정을 다시 열 수 있다. 권한·로그인·프로젝트 조건으로 사용할 수 없는 항목은 설정 목록과 독에서 제외한다. 숨김 설정은 `mew:mobile-dock-hidden`, 순서는 기존 `mew:mobile-dock-order`에 브라우저별로 저장하며, 권한으로 제외된 항목의 설정도 보존한다. 저장을 사용할 수 없으면 현재 페이지에서 계속 적용한다. 같은 페이지의 설정·독과 다른 창의 저장 변경을 함께 반영한다. 독의 기존 길게 누르기·키보드 재정렬은 유지한다.

## 단축키 설정

헤더 메뉴 → **설정 → 단축키**에서 기능별 현재 키 조합을 확인한다. 기본 `Alt+F`는 기능 패널을 열고 닫는다. 기본 `Alt+T`는 태스크 패널을 열고 닫으며 터미널은 `Ctrl+백틱`으로 연다. 변경 가능한 항목을 선택한 뒤 사용할 조합을 입력한다. 각 항목의 초기화 버튼은 그 항목만, 전체 초기화는 모든 사용자 지정 조합을 기본값으로 되돌린다. 편집기의 실행 취소·다시 실행·링크·문서 검색처럼 고정된 항목은 변경할 수 없다.

단축키는 포커스된 창을 대상으로 한다. `Ctrl/Cmd+N`·`Ctrl/Cmd+T`는 현재 패널의 새 탭을 열고 에디터·사이드바에서는 새 파일 이름 입력을 연다. `Ctrl/Cmd+Shift+N`은 새 폴더 이름 입력을 연다(문서 트리에서는 새 문서). `Ctrl/Cmd+W`·`Ctrl/Cmd+Shift+W`는 현재 내부 탭 하나를 닫으며 터미널·에이전트 탭을 닫으면 해당 세션도 끝난다. `Ctrl/Cmd+1…9`는 표시 순서의 탭을 선택하고 `Ctrl/Cmd+Tab`·`Ctrl/Cmd+Shift+Tab`·`Ctrl/Cmd+PageUp/PageDown`은 이전·다음 탭으로 순환한다. 없는 번호는 무시하며 분할 패널마다 별도로 적용한다. 사이드바와 태스크의 보기 전환도 같은 번호를 사용한다. 이 표준 조합은 고정 별칭이고 기존 `Alt+N/W/Q/E`와 재지정 가능한 단축키도 사용할 수 있다. `Alt+1…9`는 포커스된 패널과 관계없이 프로젝트 선택기의 목록 순서로 프로젝트를 전환한다. 없는 번호·현재 프로젝트·모달·키 반복은 전환하지 않는다. 원격 화면 포커스에서는 원격으로 전달한다. 에이전트 입력의 CLI 전환은 `Ctrl+Alt+M`이다.

Chrome의 예약키를 사용하려면 **mew 헤더의 전체화면 버튼 또는 Alt+Enter**로 전체화면을 켠다. HTTPS/localhost의 지원 브라우저에서 생성·닫기·전환 예약키 잠금을 요청한다. F11 전체화면은 대신할 수 없다. 일반 Chrome 창에서는 일부 예약키가 mew에 전달되지 않으므로 기존 Alt 조합을 사용하거나 Chrome 메뉴의 **이 페이지를 앱으로 설치**로 앱 창을 열어 Ctrl+W를 사용할 수 있다. 원격 화면에 포커스가 있으면 모든 전달 가능한 키를 원격으로 보내고 원격 포커스를 벗어나면 앱 단축키 잠금을 복원한다. 상세는 [포커스 계약](../development/ui-contracts.md#포커스-기반-탭-단축키)을 따른다.

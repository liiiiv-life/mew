# 뮤캣 도우미

상위: [제품 스펙](MOC.md) · [기능](../features/%ED%99%94%EB%A9%B4%C2%B7%EA%B3%84%EC%A0%95%C2%B7%EC%9A%B4%EC%98%81/%EB%AE%A4%EC%BA%A3%20%EB%8F%84%EC%9A%B0%EB%AF%B8%C2%B7%EB%8C%80%ED%99%94%C2%B7Mew%20%EC%A1%B0%EC%9E%91.md). 결정: [ADR 0184](../../../.mew/docs/decisions/0184-mewcat-assistant-session-mcp.md).

## 목적과 진입

여러 프로젝트를 진행하려는 초보 개발자·일반인이 Mew 설정을 공부하지 않고, 궁금한 점을 묻고 요청한 기능을 실행하도록 돕는다. 뮤캣을 누르면 기존 최근 알림과 하단 시스템 리소스 사이에 대화 영역을 표시한다. agent 권한이 없는 계정은 기존 알림·리소스만 사용한다. 리소스는 기존 system 권한을 따른다.

- 미선택 상태: **에이전트 연결**이 에이전트 패널의 런타임 목록을 연다. 사용자가 런타임을 선택하고 필요한 설치·로그인을 진행한다. 선택한 런타임을 도우미에도 사용한다.
- 이미 연결된 작업용 에이전트가 있고 도우미 선택값이 없으면 처음 준비된 런타임을 사용한다. 뮤캣을 처음 열기 전에는 도우미 프로세스를 시작하지 않는다.
- 선택 후: 에이전트 이름, 대화 기록 지우기 버튼과 톱니 버튼을 표시한다. 톱니 안의 자체 선택 목록에서 설치된 ACP 런타임을 바꾸거나 기존 에이전트 패널에서 다른 런타임을 준비한다. 대화 기록 지우기는 기존 새 대화 동작으로 표시 기록과 현재 에이전트 대화 맥락을 초기화한다. 기록이 없거나 연결 준비 전·진행 중에는 지우기를 비활성화하며 진행 중에는 런타임 변경도 비활성화한다.
- 로그인 필요 상태는 에이전트 패널로 안내한다. 작업용 대화가 인증 후 준비되면 같은 런타임의 도우미 인증도 다시 확인한다.
- 질문 입력의 힌트는 “메모 앱을 만들고 싶어”다. 전송 버튼 또는 Enter로 보내며 Shift+Enter는 줄바꿈, IME 조합 중 Enter는 전송하지 않는다.
- 답변은 말풍선으로 스트리밍하고 최근 알림·대화·입력·리소스는 팝업 전체의 단일 스크롤로 탐색한다. 알림 목록과 대화 영역에 별도 높이 제한·스크롤을 두지 않는다. 하단을 보고 있을 때 새 답변을 따라가며 위쪽 기록을 읽는 동안에는 스크롤 위치를 유지한다. 진행 상태, 중지, 승인·거절, 실패 후 재연결을 제공한다. 팝업을 닫아도 대화와 작업은 유지된다.

## 대화 소유권과 복원

계정·브라우저 탭 식별자·런타임별 전용 감독과 ACP 대화를 사용한다. 감독의 작업 폴더는 `DATA_DIR/mewcat/<digest>`로 고정된다. 현재 화면의 프로젝트와 UI 언어를 매 요청에 별도로 전달하므로 프로젝트 전환이 도우미 대화를 재생성하지 않는다. 일반 프로젝트용 세션을 도우미 대화로 재사용하지 않는다.

런타임 선택은 계정별 브라우저 localStorage, 브라우저 탭 식별자는 sessionStorage, ACP 세션 포인터는 계정·탭·런타임별 localStorage에 저장한다. 새로고침·재연결과 런타임 변경 후 복귀는 기존 감독 또는 지원 런타임의 session/load를 사용한다. 다른 브라우저 탭은 별도 도우미 대화다. 저장소가 제한되면 저장·복원 편의가 제한된다. 런타임의 load 지원이나 기록 복원 실패는 연결 오류로 확인할 수 있다.

대화 전사는 기존 [저장 계약](../development/conversation-storage.md)을 사용한다. 현재 화면에는 최근 대화 최대 200개를 표시한다. 기존 대화·프로젝트 이름은 언어 변경 시 그대로 유지한다.

## 자동 MCP

Mew 자체의 stdio MCP 브리지를 session/new·session/load에 주입한다. 사용자에게 MCP 주소·토큰·설치·설정 파일 편집을 요구하지 않는다. 전역·프로젝트 MCP 원본 설정과 기존 [MCP 관리창](../configuration/agent-harness.md)은 변경하지 않는다. 인증 재시도·새 대화·복원용 ACP 재시작도 같은 MCP 정보를 사용한다.

브리지는 도우미 전용 Unix socket으로 서버에 요청한다. 폴더는 0700, 소켓은 0600이며 브라우저에 별도 인증 비밀을 전달하지 않는다. 서버는 각 호출과 화면 작업 결과 수신 때 원래 웹 세션의 인증·agent 권한을 재검사한다. 프로젝트 생성·열기·문서 초기화는 owner 전용이다. 화면별 기능 권한·파일 접근은 기존 UI/API를 따른다.

| 도구 | 동작 |
| --- | --- |
| `mew_get_context` | 현재 프로젝트·UI 언어·프로젝트 관리 권한·새 프로젝트의 기본 상위 위치 조회 |
| `mew_get_help` | 시작·프로젝트·Documents·에이전트·Git·뮤캣 중 한 주제의 현재 제품 문서 조회 |
| `mew_create_project` | 기존 상위 폴더 안에 새 프로젝트 폴더 생성; 기존 폴더를 덮어쓰지 않음 |
| `mew_open_project` | 요청한 프로젝트를 위쪽 탭으로 열고 활성화 |
| `mew_setup_documents` | 지정 프로젝트의 기존 설정·문서를 보존하며 없는 기본 문서 생성 |
| `mew_open_file` | 지정 프로젝트의 기존 파일을 일반 편집기로 열기 |
| `mew_open_panel` | 에이전트·Documents·Git·브라우저·설정·프로젝트 선택 화면 열기 |
| `mew_start_project_session` | 별도 프로젝트용 대화를 열고 작업 요청 초안을 입력칸에 준비 |

화면 이동은 요청한 브라우저에 작업 ID로 전달한다. 프로젝트 탭 복원과 파일 탭 선택, 작업용 대화의 요청 접수가 실제 UI 상태에 반영됐는지 확인한다. Documents 파일은 기존 `docs` API·탭 스코프로 연다. 브라우저에서 기존 프로젝트 전환·파일 열기·패널 동작을 처리하고 결과를 응답한다. 다른 작업 ID의 응답은 무시하며 실패·연결 종료·권한 회수·60초 시간 초과를 성공으로 처리하지 않는다. 이미 완료한 파일 생성은 이후 화면 전환 실패 시 자동 삭제하지 않는다. 서버가 재시작되면 살아 있는 감독은 브라우저 재연결 후 같은 로컬 소켓 경로로 도구 호출을 재개한다.

삭제·배포·Mew 빌드·업데이트·시크릿 수정 도구는 제공하지 않는다. 에이전트 자체의 셸·파일 접근은 기존 실행 권한을 따르며 이 MCP는 OS 샌드박스가 아니다.

## 프로젝트 시작 흐름

“메모 앱을 만들고 싶어” 같은 요청은 현재 맥락 확인 → 프로젝트 생성·열기 → Documents 준비 → 별도 프로젝트용 대화 열기로 연결한다. 이름·위치 등 필수 정보만 필요에 따라 묻는다. 실제 작업 요청은 입력 초안으로 준비하고 사용자가 확인·전송한다. 도구 결과 전에 완료를 주장하지 않도록 매 요청에서 안내한다. AI의 도구 선택과 답변 품질은 연결한 런타임에 의존한다.

## 번역

한국어·영어·일본어·중국어 간체의 제목·버튼·힌트·상태·오류·접근성 문구를 `mewcat.assistant.*` 키로 제공한다. 언어 변경은 열린 팝업과 이후 요청에 즉시 반영한다. AI는 매 요청에 현재 UI 언어로 답하도록 안내받으며 기존 응답을 재번역하지 않는다. 공급자 오류 원문과 도구 작업 제목은 외부 생성 내용으로 보존하며 Mew의 오류 안내·승인 버튼은 번역한다.

도우미가 생성하는 새 Documents 문서는 UI 언어를 사용한다. 기존 초기화 GUI·CLI의 기본 영어 템플릿은 유지한다. 생성 미리보기 revision에는 템플릿 언어도 포함한다.

## 구현과 검증

서버: `mewcat-assistant.ts`(권한·MCP·도구·화면 왕복), `mewcat-mcp-stdio.ts`(stdio), 기존 `agentWs.ts`·`agentHost.ts`·`agentAcp.ts`(독립 감독·주입·대화).
화면: `use-mewcat-assistant.ts`(세션), `mewcat-assistant.tsx`(대화), `Mewcat.tsx`·`mewcat-resources.tsx`(기존 팝업 통합), `App.tsx`·`AgentPanel.tsx`(실제 화면 동작·런타임 연결).

격리 MCP/ACP 테스트로 세션 생성·새 대화·복원 시 자동 주입, 프로젝트 생성·문서 보존·언어별 생성, 권한 회수·계정 분리·브라우저 응답 대기를 검사한다. 인증된 격리 WebSocket→독립 감독→실제 stdio MCP→프로젝트 생성·문서 준비→브라우저 이동 응답까지 왕복한다. 실제 App의 프로젝트 전환·Documents 탭·작업용 대화 초안과 전환 실패도 격리 Chromium에서 검사한다. Chromium fixture로 데스크톱·모바일, 양 테마, 네 언어, Enter/IME, 팝업 재열기·프로젝트 전환 후 세션 유지, 런타임 변경·대화 복원·오류 안내를 확인한다. 실제 공급자 계정 요청·앱 빌드·서버 재시작은 수행하지 않는다.

에이전트 창의 입력칸은 토큰 앞글자를 입력하면 자동완성 목록을 보여 준다. 선택하면 뒤에 공백 하나를 붙여 계속 쓸 수 있다.

| 입력 | 목록 | 선택 결과 |
| --- | --- | --- |
| `@` | 역할에 맞는 워크스페이스 하위 프로젝트, 현재 프로젝트의 폴더·파일 | 프로젝트는 `[프로젝트명]` 뒤 줄바꿈, 폴더·파일은 멘션 토큰(프로젝트·상대경로) 뒤 공백 |
| `/` | 로컬 스킬 | `/스킬명` |

에이전트 자동완성은 후보를 8개에서 자르지 않고 스크롤로 모두 보여 준다. 하위 프로젝트가 많아도 그 아래 폴더·파일을 선택할 수 있으며, 방향키로 이동하면 선택 항목이 보이도록 목록이 스크롤된다. 폴더는 경로 끝의 `/`로 파일과 구분한다. 폴더·파일 후보의 범위는 현재 프로젝트에서 로드된 트리이며, 접힌 폴더의 하위 경로를 추가로 읽지는 않는다.

`@` 결과는 입력한 문자열로 **시작하는** 항목만 보인다. 마지막으로 포커스한 편집기 파일이 있으면 그것을 가장 먼저 보이고, 없을 때는 **하위 프로젝트 → 폴더 → 파일** 우선순위이며 각 종류 안에서는 가나다 오름차순이다. 하위 프로젝트는 `GET /api/projects`의 역할별 목록과 현재 트리에서 발견한 하위 프로젝트를 합친다. 따라서 게스트에게는 그 역할이 볼 수 있는 프로젝트만 보이고, 에이전트 창을 쓸 수 있는 manager·owner에게는 워크스페이스의 프로젝트 전체가 보인다. 프로젝트를 선택하면 `[프로젝트명]`을 넣은 뒤 다음 줄에 커서를 놓고, 현재 에이전트 탭 이름은 대괄호 없는 `프로젝트명`으로 바꾼다. 이미 같은 이름의 탭이 있으면 `프로젝트명 (1)`처럼 가장 작은 빈 번호를 붙인다. 폴더·파일을 직접 참조할 때는 `@`를 쓴다.

입력 영역은 두 열이다. 왼쪽 열은 모델·추론 정도·권한 드롭다운과 입력칸을 쌓고, 오른쪽 열은 저장 버튼 위와 첨부·예약·전송 버튼 아래를 둔다. 아래 버튼은 `gap-1.5` 간격으로 모은다. 드롭다운의 기본 화살표는 위쪽을 향하고, 모델 드롭다운만 화살표를 맨 오른쪽에 둔다. 모델 드롭다운만 왼쪽 설정 줄의 남는 폭을 채우며, 추론 정도·권한 드롭다운은 내용 폭을 유지한다. 높이 조절의 최소값은 이 요소들을 막힘없이 담는 hug 높이이고, 최대값은 에이전트 창의 90%다. 모바일 소프트 키보드나 브라우저 UI가 화면 아래를 덮으면 `visualViewport`에서 실제로 가려진 높이를 구해 입력 영역 전체를 그만큼 위로 띄우고, 표시 높이의 상한에서도 같은 값을 뺀다. 모바일에서는 측정 경계보다 8px 더 위를 하단 한계로 삼아 최대 높이에서도 키보드와 겹치지 않게 한다. 키보드가 닫히면 사용자가 정한 높이로 되돌린다. 고른 파일, OS에서 입력칸으로 끌어놓은 파일, 또는 이미지 클립보드를 붙여넣은 파일은 현재 프로젝트의 `.mew/files/`에 원본 바이트 그대로 저장되고, 이름이 겹치면 서버가 비켜 쓴다. 저장하는 동안 입력칸 위에는 회전 표시와 `첨부 중…` 태그가 보이고 전송은 완료될 때까지 비활성화된다. 저장을 마치면 입력칸 위에 확장자만 보이는 태그가 생기며, 각 태그의 ×로 전송 전 첨부를 뺄 수 있다. 사진 태그 본문을 누르면 큰 미리보기 팝업이 열리고, ×와 팝업 바깥 클릭 또는 Escape로 닫는다. 실제 프로젝트·`.mew/files/` 경로 참조 토큰은 입력칸에 노출하지 않고 전송할 때만 프롬프트에 넣는다.

전송에 성공한 입력은 탭별로 브라우저에 최근 100개까지 보관한다. 입력칸의 첫 줄에서 ↑를 누르면 이전 입력, 마지막 줄에서 ↓를 누르면 다음 입력을 불러온다. 여러 줄 안에서의 방향키는 커서 이동을 유지한다.

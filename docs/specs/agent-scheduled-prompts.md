에이전트 창 입력줄의 시계 버튼은 **예약 메시지** 팝업을 연다. 팝업은 미래의 날짜·시간만 고르며, 등록하면 입력줄에 이미 적힌 내용(첨부 파일 참조 포함)을 그 시각에 보낸다. 등록이 끝나면 그 입력 초안과 첨부 표시는 비운다.

미실행 예약은 입력줄 바로 위의 **대기 큐 목록**에서 본다. 일반 대기 메시지 뒤에만 나타나며, 예약끼리는 전송 시각 오름차순이다. 메시지 본문을 한 번 누르면 그 자리에서 내용을 고친다. 대기·예약 메시지 수정칸은 입력칸처럼 위 경계선을 위아래로 끌어 높이를 조절하며, 경계선에 키보드 포커스를 두면 위·아래 화살표로도 조절한다. 날짜·시간 텍스트를 누르면 같은 시간 선택기를 다시 열어 시각을 바꾼다. 예약끼리 순서를 바꾸지는 않으며 삭제도 가능하다. 일반 대기 메시지는 편집을 완료하거나 취소할 때까지 큐 실행을 잠근다([ADR 0118](../../../.mew/docs/decisions/0118-mew-agent-queue-edit-lock.md)).

예약은 서버 데이터 폴더에 남는다. 시각이 되면 원래 ACP 세션을 다시 연결해 메시지를 보내며, 그 세션이 작업 중이면 서버 큐의 끝에서 실행된다. 별도 cron 기반 [예약 작업](../guides/commands.md)은 독립 에이전트 작업이라 이 목록에 섞이지 않는다. 저장·세션 복원 계약은 [ADR 0091](../../../.mew/docs/decisions/0091-mew-agent-tab-scheduled-prompts.md)을 따른다.

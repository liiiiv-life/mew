기능 항목: [예약 메시지](../features/%ED%84%B0%EB%AF%B8%EB%84%90%C2%B7%EC%97%90%EC%9D%B4%EC%A0%84%ED%8A%B8%C2%B7%EC%9E%90%EB%8F%99%ED%99%94/%EC%97%90%EC%9D%B4%EC%A0%84%ED%8A%B8%20%EC%98%88%EC%95%BD%20%EB%A9%94%EC%8B%9C%EC%A7%80.md). 이 문서는 해당 기능의 세부 동작·표시 계약을 소유한다.

에이전트 창 입력줄의 시계 버튼은 **예약 메시지** 팝업을 연다. 팝업은 미래의 날짜·시간만 고르며, 등록하면 입력줄에 이미 적힌 내용(첨부 파일 참조 포함)을 그 시각에 보낸다. 등록이 끝나면 그 입력 초안과 첨부 표시는 비운다.

미실행 예약은 입력줄 바로 위의 **대기 큐 목록**에서 본다. 일반 대기 메시지 뒤에만 나타나며, 예약끼리는 전송 시각 오름차순이다. 메시지 본문을 한 번 누르면 그 자리에서 내용을 고친다. 대기·예약 메시지 수정칸은 입력칸처럼 위 경계선을 위아래로 끌어 높이를 조절하며, 경계선에 키보드 포커스를 두면 위·아래 화살표로도 조절한다. 날짜·시간 텍스트를 누르면 같은 시간 선택기를 다시 열어 시각을 바꾼다. 예약끼리 순서를 바꾸지는 않으며 삭제도 가능하다. 일반 대기 메시지는 편집을 완료하거나 취소할 때까지 큐 실행을 잠근다([ADR 0118](../../../.mew/docs/decisions/0118-mew-agent-queue-edit-lock.md)).

예약은 서버 데이터 폴더에 남는다. 시각이 되면 원래 ACP 세션을 다시 연결해 메시지를 보내며, 그 세션이 작업 중이면 서버 큐의 끝에서 실행된다. 별도 cron 기반 [예약 작업](../guides/commands.md)은 독립 에이전트 작업이라 이 목록에 섞이지 않는다. 저장·세션 복원 계약은 [ADR 0091](../../../.mew/docs/decisions/0091-mew-agent-tab-scheduled-prompts.md)을 따른다.

## 브라우저 목록 복원

- 대화 내역과 같이 IndexedDB에 표시용 목록을 비동기 저장한다. `mew-agent-scheduled-prompts` 데이터베이스의 `lists` 저장소를 계정·런타임·탭 ID·cwd로 격리하며, 서버 탭 원장 확인 뒤 해당 탭의 목록을 먼저 표시한다. 대화 전사의 저장소·예산과는 독립적이다.
- 서버 목록 조회는 캐시 읽기와 동시에 시작한다. 서버 확인 전에는 마지막 기기 목록을 표시하고, 성공 응답으로 전체 목록을 교체한다. 실행·취소로 서버 목록이 비었으면 로컬에도 빈 목록을 저장한다. 조회 실패는 마지막 표시·저장 목록을 유지한다.
- 등록·내용/시각 수정·취소 API가 성공하면 응답을 즉시 화면과 캐시에 반영한다. 후속 조회 실패를 변경 실패로 표시하지 않으며, 이전 조회나 늦은 캐시 읽기가 변경 결과를 되돌리지 못한다. 다른 계정·탭·런타임·cwd로 전환하거나 화면을 닫으면 이전 요청은 새 화면에 반영하지 않는다.
- WebSocket 접속·재접속, 브라우저 창 포커스 복귀, 온라인 복귀 시 서버 목록을 다시 조회한다. 로컬 목록은 조회 전 표시용으로만 쓰며 실행 시각 경과를 예약 취소로 판단하거나 로컬에서 예약을 실행하지 않는다.
- 표시 필드만 저장하며 ACP 세션 ID·skill payload는 보관하지 않는다. 최대 7일·128개 범위·합계 약 4MiB로 제한하며 오래된 범위부터 정리한다. 저장 불가·용량 초과는 서버 조회·예약 조작을 막지 않는다. 캐시가 없거나 만료되면 서버 조회 뒤 표시한다.

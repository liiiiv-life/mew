Mewcat은 화면 **맨 아래**에서만 움직이며, 벽·천장을 타지 않는다. 기본 행동은 idle, walk,
run 중 하나를 무작위로 골라 수행한다. 레포 안의 단순 벡터 마크를 좌우 반전·CSS 모션으로 표현한다.

짧게 클릭하면 이동을 멈추고 love 모션을 한 번 재생한다. 고양이를 누른 뒤 곧바로 움직이면
플로팅 핸들처럼 끌 수 있고, 그동안 struggle 모션을 반복한다.
놓으면 마지막 포인터 이동의 수평·수직 속도를 운동량으로 이어 받아 중력이 적용된 궤적으로 날아간다.
공중에 떠 있는 중에도 다시 눌러 붙잡을 수 있으며, 이때 기존 운동량은 멈춘다.
낙하 중에는 run 모션을 반복하며, 양쪽 벽에 닿으면 진행 방향을 반대로 바꾸고 속도는
50%로 줄어든다. 바닥에 닿을 때는 run의 마지막 두 프레임을 한 번 재생한 뒤 다시 기본 행동을 무작위로
고른다.

공개 레포에는 외부 마스코트 원본·가공본을 넣지 않는다. 재배포 권한이 불명확한 Oreo Cat 계열 자산은
재도입하지 않는다.

## 스킨 선택

설정 창의 **뮤캣** 카테고리에서 화면별 스킨을 고른다. 첫 카드는 **없음**이며, 선택하면 Mewcat을
렌더링하지 않는다. 나머지 카드는 해당 스킨의 RUN 중간 프레임을 정적 미리보기로 쓴다. 현재 기본
Oreo Cat 스킨 하나만 제공하고, 새 스킨은 클라이언트의 `MEWCAT_SKINS` 등록표에 추가해 같은 그리드에
자동으로 나타난다. 선택은 브라우저 localStorage에만 저장된다. 이전의 `oreo` 저장값은 자체 기본
스킨으로 이관한다.

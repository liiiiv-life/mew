## 상태버블

**에이전트**와 **터미널**은 별도 패널이다. 에이전트에는 ACP 채팅과 공식 에이전트 TUI를, 터미널에는 일반 셸 탭을 둔다. 에이전트의 `+`는 런타임 선택기를 열고 터미널의 `+`는 셸을 추가한다. 기존 `tmux` 탭은 ID·cwd를 유지한 채 터미널에 표시한다.

패널 이동과 탭 분리는 [ADR 0134](../../../.mew/docs/decisions/0134-mew-dockable-workspace-panels.md)와 [UI 계약](../development/ui-contracts.md#작업-패널-배치)을 따른다. 패널을 접거나 이동해도 세션은 종료하지 않는다. 패널의 닫기 버튼은 누른 칸만 닫고 탭을 같은 종류의 남은 패널로 모은다. 마지막 패널의 탭은 다시 열 때를 위해 보존한다. 남은 패널은 빈자리를 채우며 닫은 분할은 복원하지 않는다. 탭의 `×`만 해당 세션을 끝낸다.

## 로그인 화면

제목은 `<에이전트 이름> 로그인`으로 표시한다. 로그인 방식은 설명 카드 대신 행 전체를 누르는 버튼으로 제공하며, Kimi의 `.com`·`.ai`처럼 선택에 필요한 구분은 이름에 남긴다. API 키는 이름이 연결된 입력란과 `연결` 버튼을 사용한다.

서버 실행 위치, CLI 자격증명 관리, 세션 재연결, 인증 코드 저장 방식 같은 내부 동작 설명은 화면에 표시하지 않는다. 인증 브라우저의 `SERVER OAUTH` 배지와 반복되는 하단 안내도 제거한다. 이 설명 문구는 다시 추가하지 않는다. 구현 정보는 [런타임 설정](../configuration/agent-runtimes.md)에서 관리한다.

진행 상태, 승인 코드·복사, `로그인 계속하기`, 코드 입력, 오류와 재시도 안내는 필요한 상태에서만 표시한다. 로그인 사이트의 호스트와 공급자가 요청한 안내는 유지하며, 긴 OAuth URL은 본문에 나열하지 않는다. Prime의 `/login` 입력처럼 사용자가 직접 해야 하는 단계는 짧게 안내한다. 로그인 방식·인증 작업·브라우저 연결 계약은 유지한다.

내용은 최대 24rem 폭으로 배치하고, 짧은 패널에서는 위쪽으로 스크롤해 뒤로가기와 입력란에 접근할 수 있어야 한다. 버튼과 입력란은 키보드 포커스를 표시하며, 진행 상태는 `status`, 오류는 `alert`로 알린다.

## 연결 계정·구독·사용량 제한

로그인에 성공해도 구독 권한이나 남은 사용량이 없을 수 있다. Claude·Kimi·Codex·Cursor의 ACP 채팅에서는
로그인 안내가 없는 상태에서 에이전트창의 **i(세션 정보)** 팝업을 열면 `연결 계정 · 구독`의 계정과 공급자 플랜을 바로 보여 준다. 화면의 항목명은 `계정`이며, 조회 방식에 대한 설명은 붙이지 않는다. 계정 조회는 팝업을 열 때 수행하며, 별도의 본문 카드와 추가 펼치기 단계는 두지 않는다. 지원 런타임 설정에서도 같은 계정 정보를 확인할 수 있다. Antigravity는 ACP 채팅·공식 Google 인증을 제공하지만 계정·플랜 정보 카드에는 포함하지 않는다. 공식 서버가 반환하지 않는 계정 정보는 추정하지 않는다.

구독 필요·사용량 소진·크레딧 부족은 인증 만료와 구분한다. 공급자가 Authentication required로 감싸 보내더라도
명시적 한도 오류이면 기존 대화와 로그인 상태를 유지한다. 대기 메시지를 보존하고 자동 전송은 멈춘다.
계정 재조회·패널 재연결·대기 메시지 편집은 실행 재개 신호가 아니다. 사용자가 새 메시지를 보내면 대기 순서대로 재개한다.

무료·미구독과 현재 요청 불가를 같은 상태로 보지 않는다. 무료 한도를 쓸 수 있는 상품은 구독 없이도 사용할 수 있다.
플랜 코드나 조회 실패만으로 미구독을 추정하지 않으며, Kimi의 VIP10처럼 유료 여부를 확인하지 못한 값은 그대로 표시하고 판단을 유보한다.

사용량 확인은 i 팝업의 기존 컨텍스트·입출력·캐시·전체 토큰·API 환산 비용 표시를 사용한다. 중복된 `구독 · 사용량 확인` 동선은 제거하고 `구독 관리`(무료 플랜 또는 구독 필요 시 `구독하기`) 버튼으로 내부 DOM 브라우저의 공식 페이지를 연다. 이 UI 통합은 재시도 금지 결정이 아니다. 팝업은 좁은 패널 폭에 맞추고 내용이 길면 내부에서 스크롤한다. 서버 CLI 계정과 웹 구독 페이지의 계정은 별개로 로그인되어 있을 수 있으므로
구독 창 안에서 같은 계정인지 확인하도록 안내한다. 계정 요약에는 무료 플랜 설명과 공급자 조회 메모를 반복 표시하지 않으며, API 키 연결은 별도 요금임을 표시한다. 구독 창을 닫으면 상태만 재조회하고 결제나 프롬프트 전송은 자동 수행하지 않는다.
계정 정보는 잠시 표시하며 대화 전사·브라우저 저장소에 남기지 않는다. 결정은 [ADR 0130](../../../.mew/docs/decisions/0130-mew-agent-account-entitlement.md),
공급자별 조회 기능·실행 계약·API는 [런타임 설정](../configuration/agent-runtimes.md)에 둔다.

## 새 탭 생성

런타임이나 에이전트셋의 `사용`을 누르면 현재 루트 프로젝트 경로를 서버의 `agent-cwd` 검증에 통과시킨 뒤 탭을 만든다. 검증 중에는 선택기를 그대로 두고 `여는 중…`을 표시한다. 검증 실패 시 이유를 같은 화면에 표시하고 탭은 만들지 않는다. 복원 호환 데이터의 cwd는 비어 있을 수 있지만 새 탭 생성 함수는 빈 cwd를 허용하지 않는다.

탭 목록의 SSoT는 계정 서버 원장이고 `localStorage`는 첫 화면용 fallback이다. 따라서 전사·본문 캐시가 브라우저 저장 한도를 채워 fallback 갱신이 `QuotaExceededError`로 실패해도 새 탭 렌더와 서버 원장 저장을 계속한다. 활성 탭과 최근 런타임·선택기 보기 저장도 같은 원칙으로 best effort 처리한다.

[브라우저 저장 계약](../development/browser-storage.md)에 따라 로컬 전사 캐시는 탭당 512KiB, 다른 재생성 캐시와 합쳐 전체 2MiB를 넘기지 않는다. 긴 대화는 상한 안에 들어가는 최근 이벤트 꼬리를 로컬에 남겨 먼저 보여 주고, 서버 transcript/replay가 도착하면 원본으로 보정한다. 캐시 저장 전에 오래된 캐시부터 정리해 공간을 확보한다. 이벤트 하나 자체가 상한을 넘으면 그 이벤트는 로컬에 담지 않고 서버 복원을 기다린다. 계정 탭 원장 동기화가 끝나면 원장에 없는 닫힌 탭의 `mew:agent-events:*`와 `mew:agent-controls:*`도 제거한다. 2026-09-08 실제 계측에서는 전체 약 10.49MB 중 닫힌 Codex 탭 세 개의 전사 캐시가 6.41MB·1.91MB·1.05MB로 약 89%를 차지해 quota를 소진했다.

서버 탭 원장 조회 중에도 활성 ACP 탭의 최근 대화 텍스트를 읽기 전용 미리보기로 표시한다. 미리보기는 세션을 연결하거나 서버 원장을 갱신하지 않으며, 원장 확인 뒤 실제 대화 화면으로 전환한다. 캐시가 없는 첫 방문은 서버 조회가 필요하다.

ACP 에이전트 대화에서 사용자 메시지 바로 위에 보이는 `모델 · 노력 · 권한` 구분선을 **상태버블**이라 부른다.

- 첫 사용자 메시지에는 항상 보인다.
- 이후에는 직전 사용자 메시지와 모델·노력·권한 중 하나라도 달라진 경우에만 다시 보인다.
- 같은 대화를 한 시간 뒤 이어 가거나 유휴 종료 후 복원해도 조합이 같으면 새 상태버블을 추가하지 않는다. 복원된 답변의 표현·청크가 달라져도 같은 질문에 저장된 설정은 유지한다.
- 전송 시점의 값을 대화 전사에 남기므로, 재접속·세션 복원 뒤에도 당시 상태버블을 보인다.
- 상태버블은 사용자 메시지가 아니라 작업 버블과 같은 전체 폭을 쓴다. 사용자 메시지만 오른쪽으로 들여쓴다.

## 작업 버블 상태

작업 버블의 점 색은 실행 상태를 뜻한다: 파랑은 진행 중, 초록은 완료, 회색은 중단, 빨강은 실패다. ACP 히스토리에 마지막 종료 이벤트가 없더라도 현재 세션이 유휴면 마지막 작업은 완료로 본다.

완료된 작업은 종료 순간의 전체 전사를 보존한다. 따라서 감독 프로세스가 유휴 종료된 뒤에도 다시 불러온 화면에는 사용자 질문, 답변과 작업 내역 전체, 완료 상태와 경과 시간이 남는다. 이벤트 수가 많다는 이유로 한 턴의 앞부분을 자르지 않는다.

# 원격 데스크톱

[사용법 지도](MOC.md) · [아키텍처·검증 범위](../development/remote-desktop.md)

PC·모바일 독의 **원격 데스크톱**을 누른다. 독에서는 기본 맨 오른쪽에 표시되며 좌우 스와이프로 해당 항목에 도달해도 열린다. manager·owner만 사용할 수 있으며, 작업 패널과 독립적으로 화면 전체를 채운다. 서버가 Mac/Linux면 로그인한 데스크톱을, WSL이면 Windows 데스크톱을 공유한다. 서버 전체에 한 연결만 사용할 수 있다.

## 처음 연결

`./mew setup`은 필요한 보조앱 구성 요소를 미리 설치한다. Mac/Linux는 해당 OS용, WSL은 Windows용으로 준비하며, 별도 앱이나 npm 명령을 직접 실행할 필요가 없다. 최초 다운로드는 몇 분 걸릴 수 있고 진행 상황은 setup 터미널에 표시한다. 이 단계에서는 화면 캡처나 입력 제어를 시작하지 않는다. 설치 파일 준비와 아래 표의 OS 로그인·라이브러리·권한 승인은 별개다.

Mac은 설치 후 아래의 [권한 준비](#mac-권한-준비)까지 진행한다. setup에서 보조앱 설치·권한 준비에 실패해도 경고를 표시하고 Mew 설치는 계속한다(Ctrl+C는 setup도 중단). 이전 설치이거나 구성 요소가 없거나 업데이트가 필요하면 독에서 **원격 데스크톱**을 열 때 자동으로 설치한 뒤 연결한다. 이때 **준비 내역 보기**를 누르면 내부 tmux의 진행 상황을 확인할 수 있다. Mac 권한이 부족하면 `./mew desktop-setup`으로 준비한 뒤 다시 연결한다.

내역 창의 **닫기**는 준비를 계속 진행하며, **종료**는 준비 작업도 중단한다. 원격 데스크톱을 닫아도 준비 작업은 남는다. 다시 열면 진행 중인 작업에 이어서 기다린다. 실패하면 내역의 오류를 확인하고 **다시 연결**을 누른다. 실패한 작업을 무한히 재시도하지 않는다.

설치된 환경에서는 준비 상태 확인과 연결 시작에 필요한 실행 경로를 짧게 재사용하고, Windows 방화벽 진단은 화면 시작과 함께 진행한다. 전용 Windows Node가 있으면 추가 탐색을 생략하며, Windows 화면 캡처가 시작되지 않을 때 대체 방식으로 넘어가는 대기도 줄였다. 짧은 구성 요소 업데이트는 완료를 더 빠르게 확인한다. 직접 연결이 막힌 경우의 대기도 줄였다. 최초 설치·OS 권한 승인·로그인 세션의 보조 앱 실행·네트워크 시간은 여전히 필요하므로 모든 환경의 즉시 연결을 보장하지 않는다.

Mew 코드가 업데이트되면 구성 요소의 버전도 자동으로 확인한다. 의존성이 그대로면 설치된 런타임을 재사용한다. 준비가 끝나면 자동으로 연결하므로 터미널을 닫고 재연결 버튼을 누르는 단계는 필요 없다.

화면 공유 승인 후 직접 연결을 먼저 시도한다. 직접 연결이 실패하거나 약 1.2초 안에 영상이 들어오지 않으면 **Mew 서버를 통해 화면을 연결하고 있습니다…**라는 안내와 함께 자동으로 서버 전송으로 바뀐다. 같은 화면 공유를 유지하므로 OS 승인을 다시 할 필요가 없다. 상단의 **직접 연결**·**서버 연결**로 현재 경로를 확인할 수 있다.

| 서버 환경 | 필요한 OS 준비 |
| --- | --- |
| Mac | macOS 12.3 이상·Apple Command Line Tools가 필요하다(`xcode-select --install`). 준비 중 자체 캡처 모듈을 컴파일한다. 데스크톱에 로그인한다. setup 또는 desktop-setup이 연 서버 Mac의 시스템 설정에서 **손쉬운 사용**과 **화면 기록**을 Electron에 허용한다. 승인 감지 후 원격 데스크톱을 연결한다 |
| Linux X11 | 로그인한 사용자 환경의 DISPLAY/Xauthority, Electron GUI 라이브러리와 libXtst가 필요하다. Debian/Ubuntu 입력 라이브러리는 `libxtst6` |
| Linux Wayland | 로그인한 사용자 D-Bus·PipeWire·xdg-desktop-portal과 compositor의 RemoteDesktop 지원이 필요하다. 화면 공유와 원격 입력 요청을 승인한다 |
| WSL | Windows에 같은 사용자로 로그인하고 WSL interop를 켠다. Windows Node/npm이 없으면 Mew가 전용 런타임을 자동으로 다운로드한다. Windows 작업 스케줄러에서 현재 사용자 작업 실행을 허용해야 한다 |

WSL에서는 Mew를 **내부 tmux에서 시작하거나 재시작해도 된다**. Windows 세션 0에서 시작했더라도 연결할 때 임시 작업을 통해 현재 Windows 계정의 로그인 데스크톱에서 캡처를 실행한다. 로그인 비밀번호를 저장하거나 상주 앱·로그인 자동 실행을 등록하지 않는다. 로그아웃·로그인 전·잠금·UAC 화면은 지원 범위 밖이다.

직접 연결의 방화벽 설정은 **Mew 서버가 실행 중인 컴퓨터의 Windows에서** 한다. WSL에서 서버를 실행한 경우에도 해당 컴퓨터의 Windows 보안을 연다. Electron의 네트워크 접근을 묻는다면 원격 연결에 사용할 네트워크에 허용한다. **Windows 방화벽 차단** 안내가 나오면 해당 앱의 차단 규칙을 확인한다. 서버 전송은 기존 Mew 접속을 사용하므로 Electron의 직접 영상 연결이 차단되어도 사용할 수 있다. 재설치는 해결 방법이 아니며 Mew가 기존 차단 규칙을 자동으로 바꾸지 않는다.

Windows 파일은 `%LOCALAPPDATA%\Mew\remote-desktop`에 준비한다. PATH에 PowerShell이 없어도 마운트된 Windows 드라이브에서 찾는다. Windows 드라이브·interop가 끊긴 경우에는 연결 오류 안내를 따른다. Linux GUI가 없는 서버/컨테이너에는 공유할 데스크톱이 없으며 WSLg 화면을 Windows 전체 화면으로 대신 보여주지 않는다.

진단용 수동 준비도 유지한다. Mew 저장소에서 `npm run desktop:install`을 실행할 수 있다. 앱 빌드·서버 재시작은 [README](../../README.md#development)에 따라 사용자가 한다.

### Mac 권한 준비

`./mew setup`에 포함되며, Mew 서버가 이미 실행 중이면 **Mew 설치 폴더**의 Mew 터미널 또는 같은 Mac의 로컬 터미널에서 다음 명령만 실행한다. 현재 프로젝트 폴더가 다른 곳이면 먼저 Mew 설치 폴더로 이동한다.

```bash
./mew desktop-setup
```

보조앱 설치 → 권한 확인 → 필요한 설정 열기 → 승인 감지 순서로 진행한다. **승인창은 접속 중인 폰·PC나 터미널 안이 아니라 Mew 서버 Mac의 데스크톱에 뜬다.** 데스크톱에 로그인한 동일 OS 사용자로 실행하고 `sudo`는 붙이지 않는다.

- 이미 허용된 권한은 다시 요청하지 않는다. 부족하면 **손쉬운 사용 → 화면 기록** 순서로 설정을 열고, Electron 보조앱을 사용자가 허용한다.
- 터미널에서 각 권한 상태를 표시하고 최대 5분 동안 기다린다. 승인 감지 후 자동으로 완료하며, Mac이 **종료 및 다시 열기**를 요구하는 경우도 새 보조 프로세스로 다시 확인한다. Mew 서버는 재시작하지 않는다.
- 완료 메시지가 나오면 Mew에서 원격 데스크톱을 열거나 다시 연결한다. 이 명령 자체는 화면 캡처·원격 입력을 시작하지 않는다.
- 거부·시간 초과·로그인 사용자 불일치·관리 정책 제한은 미완료로 표시한다. Ctrl+C로 중단해도 설치 파일은 남으며 같은 명령으로 재시도한다. `desktop-setup`은 미완료 시 실패 코드로 종료한다.

설치 완료 마커는 파일 준비 상태만 뜻한다. 권한은 매번 OS에서 확인하며, 명령어로 사용자의 승인을 대신하거나 권한 DB를 수정하지 않는다. 터미널이 설정을 열 수 없는 로그인 환경에서는 서버 Mac의 시스템 설정에서 Electron 권한을 직접 확인한 뒤 다시 실행한다. Mac 실기 검증 범위는 [개발 계약](../development/remote-desktop.md#mac-터미널-권한-준비)을 따른다.

## 조작

모바일 원격 화면에서도 하단 독으로 다른 패널을 선택하거나 좌우로 스와이프할 수 있다. 다른 패널로 이동하면 원격 연결은 종료된다. **전체화면**을 켜면 독이 숨고, 전체화면을 해제하면 다시 나타난다. 키보드가 열린 동안에도 독은 숨긴다.

### 화면과 설정

상단 도구는 **맞춤 → 입력 → 도움말 → 회전 → 전체화면 → 설정 → 닫기** 순서다. 전체화면 버튼은 브라우저의 주소창·탭 영역까지 숨긴다. 해제 버튼으로 돌아오며, 지원하지 않거나 전환이 거절되면 안내가 나온다. 회전 버튼은 원격 영상을 시계 방향으로 90도씩 돌린다(0·90·180·270도). 호스트 모니터 설정은 바꾸지 않고, 회전할 때 확대·이동을 맞춤으로 초기화한다. 회전한 영상에서도 직접 클릭 위치·커서·드래그 방향이 일치한다.

**설정**에서 마우스 커서 감도(0.5–6배), 공유 화면, 핫키 보조키(Ctrl 또는 Mac의 Cmd)를 선택한다. 커서 감도 기본값은 **3배**이며 커서 이동 패드·세 버튼 드래그·방향키 이동에 즉시 적용한다. 터치/마우스로 패드를 빠르게 밀수록 커서가 더 멀리 움직이는 **속도 비례 가속**을 적용한다. 같은 100px을 0.05초에 밀면 0.5초에 밀 때보다 커서 이동량이 10배다(화면 가장자리에 도달하기 전 기준). 천천히 움직이면 정밀하게 조절할 수 있고, 멈추면 커서도 멈춘다. 슬라이더 배율은 가속된 이동량에 곱한다. 방향키는 반복 속도에 따른 가속 없이 감도 배율만 적용한다. 직접 마우스로 화면을 가리키는 좌표·휠·화면 이동·확대 속도는 바꾸지 않는다. 감도만 이 브라우저에 저장한다. **감도 초기화**는 3배, **버튼 위치 초기화**는 마우스와 핫키를 처음 위치로 돌린다. **다시 연결**도 설정 안에 있다.

왼쪽 세로 **핫키** 바에는 Esc·Tab·Enter·Backspace·복사·붙여넣기·실행 취소·앱 전환이 있다. 설정의 보조키에 따라 Ctrl 또는 Cmd 조합을 전송한다. 핫키의 붙여넣기는 **원격 컴퓨터의 클립보드**를 사용한다. 내 기기의 텍스트를 보내려면 상단 입력 창을 사용한다. 바 아래 핸들을 끌거나 포커스 후 방향키를 눌러 위치를 옮긴다. 화면 크기가 바뀌면 바를 화면 안에 제한하고, 가로로 낮은 화면에서는 핫키 목록을 스크롤한다.

설정·입력·도움말이 열려 있으면 Esc·뒤로가기는 그 창부터 닫는다. 전체화면 상태에서는 전체화면을 먼저 해제하며, 일반 상태에서는 원격 연결을 닫는다. 왼쪽 **원격 Esc**는 뷰어를 닫지 않고 원격 컴퓨터에 Escape를 보낸다.

### 마우스와 터치

오른쪽 아래 컨트롤은 마우스 모양이다. 위쪽에 좌클릭(1)·휠(2)·우클릭(3), 아래쪽에 세 칸을 합친 커서 이동(0)이 있다. 화면 이동(4)·확대(5)는 옆에 따로 배치한다.

```text
┌────┬────┬────┐
│ 1  │ 2  │ 3  │   4
├────┴────┴────┤
│      0      │   5
└─────────────┘
```

터치패드처럼 손가락 이동 거리와 속도에 따라 커서가 움직인다. 손가락을 멈추면 커서도 멈추며, 가운데로 돌아올 필요가 없다. 손을 떼었다 다시 대서 이어 움직일 수 있다. 좌·우 버튼 드래그와 휠을 길게 눌러 하는 중간 버튼 드래그도 움직인 만큼만 반응한다.

**휠·화면 이동·확대는 속도 조이스틱**이다. 밀기 시작한 뒤에는 컨트롤 중앙에서 멀리 떨어질수록 완만하게 빨라지고, 그 위치에 유지하면 계속 작동한다. 멀리 밀 때의 속도 증가폭과 최대 속도를 낮춰 과도하게 빨라지지 않도록 한다. 중앙 부근으로 돌아오거나 손을 떼면 멈춘다. 휠·확대는 위아래 방향만 사용한다. 마우스 컨트롤과 왼쪽 핫키 바는 반투명 배경으로 원격 화면을 비춰 보이며 글자와 아이콘은 선명하게 유지한다.

| 조이스틱 | 짧게 탭 | 바로 밀기 | 잠깐 꾹 누른 뒤 밀기 |
| --- | --- | --- | --- |
| 1 좌클릭 | 왼쪽 클릭 | 왼쪽 버튼을 누른 채 이동 | 동일 |
| 2 휠 | 중간 버튼 클릭 | 위아래로 밀어 유지: 연속 스크롤 | 중간 버튼을 누른 채 모든 방향 이동 |
| 3 우클릭 | 오른쪽 클릭 | 오른쪽 버튼을 누른 채 이동 | 동일 |
| 0 커서 이동 | 클릭하지 않음 | 커서만 이동 | 동일 |
| 4 화면 이동 | — | 밀어 유지: 확대된 화면에서 보는 위치 연속 이동 | 동일 |
| 5 확대·축소 | — | 위로 밀어 유지: 확대, 아래로 유지: 축소 | 동일 |

좌·우 조이스틱은 이동을 시작하면 즉시 버튼을 누른다. 휠의 중간 버튼 드래그는 약 0.32초 꾹 누른 뒤 시작한다. 버튼을 잡으면 색이 바뀌고, 손을 떼거나 취소하면 해제한다. 마지막 **핸들**을 끌면 컨트롤 묶음이 함께 움직이며 화면 바깥으로 넘어가지 않는다. 조이스틱·핸들에 포커스를 두고 방향키로도 조작할 수 있다. 좌·우 조이스틱에서는 방향키를 누르는 동안 드래그하고 모든 방향키를 떼거나 포커스를 옮기면 해제한다.

휴대폰에서 원격 화면 자체를 밀면 보는 위치를 옮기고, 두 손가락으로 확대한다. 원격 클릭은 조이스틱으로 한다. **맞춤**은 확대·이동을 초기화한다. 확대는 1–6배이며 원격 해상도는 바꾸지 않는다.

마우스가 있으면 화면에서 직접 커서를 움직이고 클릭할 수 있다. Wayland는 조이스틱 상대 이동을 사용한다. 키보드는 화면을 선택한 뒤 입력한다. F6은 상단 도구로 포커스를 옮긴다. **입력 → 붙여넣기**는 작성한 텍스트로 원격 클립보드를 덮어쓰고 붙여넣는다. 같은 창의 **원격 Esc**는 원격 컴퓨터에 Escape 키를 보낸다.

Windows/WSL과 macOS의 지원되는 화면에서는 커서를 내 기기에서 즉시 표시하므로 영상 갱신을 기다리지 않는다. Windows는 기본 캡처가 준비되지 않으면 커서를 분리하는 보조 캡처를 자동으로 시도한다. 연결 후 **도움말 → 커서 표시**에서 실제로 적용됐는지 확인한다. **이 기기에서 즉시 표시**는 로컬 커서, **영상에 포함됨**은 기존 영상 커서다. 호버·클릭·드래그는 원격 컴퓨터에 전달한다. 화면 변화가 없으면 영상 전송을 쉬고, 화면이 바뀌면 재개한다. Mac은 ScreenCaptureKit으로 화면과 커서를 분리한다. 지원되지 않거나 초기 캡처가 실패한 화면 및 Linux는 기존 영상 커서를 사용한다.

공유 화면이 여러 개면 설정의 **공유 화면** 선택기로 바꾼다. 이전 연결을 종료하고 새 화면에 연결한다. 열린 보조 창과 전체화면이 없는 상태에서 로컬 Esc·모바일 뒤로가기는 연결을 종료한다. 상단 닫기는 바로 연결을 종료한다. 백그라운드가 되면 연결을 종료하고, 돌아왔을 때 **다시 연결**을 누른다.

## 네트워크와 설정

**TURN 서비스·계정·API 키 없이 사용할 수 있다.** 외부 네트워크에서 직접 연결이 막히면 기존 Mew WebSocket으로 VP8 압축 영상과 입력을 전달한다. 영상은 Mew 서버를 통과하며 별도 공개 포트를 열지 않는다. 외부 접속에는 HTTPS와 WebSocket을 지원하는 기존 배포 경로가 필요하다. 브라우저는 보안 컨텍스트에서 VP8 WebCodecs 디코딩을 지원해야 하며 지원하지 않으면 업데이트 안내가 나온다.

서버 전송은 최대 1080p·30fps, 직접 연결은 최대 1080p·60fps를 목표로 한다. 실제 성능은 서버·브라우저·네트워크에 따라 달라지며 서버 전송은 TCP 손실과 왕복 지연의 영향을 더 받는다. 기존 HTTPS 터널이 외부 서비스를 쓴다면 그 경로는 그대로 이용한다. 추가 영상 중계 서비스는 사용하지 않는다.

`MEW_DESKTOP_ICE_SERVERS`는 기존 운영자를 위한 선택 설정으로 유지한다. 기본은 `[]`이고 공개 STUN/TURN을 자동으로 호출하지 않는다. 값을 지정한다면 해당 서버의 `urls`, `username`, `credential`을 서버 비밀 설정에만 저장한다. 필요하지 않으면 비워 둔다.

`MEW_DESKTOP_HELPER_DIR`은 설치 경로를 바꾸는 선택 설정이다. Mac/Linux는 절대 경로, WSL은 `C:\…` 같은 Windows 절대 경로다. 설치 버튼과 수동 설치 모두 이 위치에 보조 앱을 복사·설치하며, 연결도 같은 위치를 사용한다.

HTTPS 프록시/터널은 로그인·연결 협상과 서버 전송 영상을 전달한다. 직접 WebRTC 경로는 별개다. [환경변수](../configuration/environment.md), [검증 범위·지원하지 않는 화면](../development/remote-desktop.md), [배포 라이선스](../development/remote-desktop-distribution.md)를 참고한다.

서버 연결의 **표시 응답**은 영상 전송·디코딩·표시 후 응답이 돌아오는 시간이다. 클릭 결과가 화면에 나타나는 전체 지연은 아니다. **화면 정지**는 연결을 유지하며 영상 변화가 없는 상태다.

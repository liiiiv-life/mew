# 원격 데스크톱

[사용법 지도](MOC.md) · [아키텍처·검증 범위](../development/remote-desktop.md)

헤더 메뉴의 **원격 데스크톱**을 누른다. manager·owner만 사용할 수 있으며, 작업 패널과 독립적으로 화면 전체를 채운다. 서버가 Mac/Linux면 로그인한 데스크톱을, WSL이면 Windows 데스크톱을 공유한다. 서버 전체에 한 연결만 사용할 수 있다.

## 처음 연결

메뉴에서 **원격 데스크톱**을 열면 필요한 구성 요소를 자동으로 준비한 뒤 연결한다. 별도 앱이나 npm 명령을 직접 실행할 필요가 없다. 최초 다운로드는 몇 분 걸릴 수 있다. **준비 내역 보기**를 누르면 내부 tmux의 진행 상황을 확인할 수 있다.

내역 창의 **닫기**는 준비를 계속 진행하며, **종료**는 준비 작업도 중단한다. 원격 데스크톱을 닫아도 준비 작업은 남는다. 다시 열면 진행 중인 작업에 이어서 기다린다. 실패하면 내역의 오류를 확인하고 **다시 연결**을 누른다. 실패한 작업을 무한히 재시도하지 않는다.

Mew 코드가 업데이트되면 구성 요소의 버전도 자동으로 확인한다. 의존성이 그대로면 설치된 런타임을 재사용한다. 준비가 끝나면 자동으로 연결하므로 터미널을 닫고 재연결 버튼을 누르는 단계는 필요 없다.

화면 공유 승인 후 직접 연결을 먼저 시도한다. 직접 연결이 실패하거나 약 4초 안에 영상이 들어오지 않으면 **Mew 서버를 통해 화면을 연결하고 있습니다…**라는 안내와 함께 자동으로 서버 전송으로 바뀐다. 같은 화면 공유를 유지하므로 OS 승인을 다시 할 필요가 없다. 상단의 **직접 연결**·**서버 연결**로 현재 경로를 확인할 수 있다.

| 서버 환경 | 필요한 OS 준비 |
| --- | --- |
| Mac | macOS 12.3 이상·Apple Command Line Tools가 필요하다(`xcode-select --install`). 준비 중 자체 캡처 모듈을 컴파일한다. 데스크톱에 로그인한다. 최초 연결에서 시스템 설정의 **손쉬운 사용**과 **화면 기록**을 Electron에 허용한다. OS가 요구하면 다시 연결한다 |
| Linux X11 | 로그인한 사용자 환경의 DISPLAY/Xauthority, Electron GUI 라이브러리와 libXtst가 필요하다. Debian/Ubuntu 입력 라이브러리는 `libxtst6` |
| Linux Wayland | 로그인한 사용자 D-Bus·PipeWire·xdg-desktop-portal과 compositor의 RemoteDesktop 지원이 필요하다. 화면 공유와 원격 입력 요청을 승인한다 |
| WSL | Windows에 같은 사용자로 로그인하고 WSL interop를 켠다. Windows Node/npm이 없으면 Mew가 전용 런타임을 자동으로 다운로드한다. Windows 작업 스케줄러에서 현재 사용자 작업 실행을 허용해야 한다 |

WSL에서는 Mew를 **내부 tmux에서 시작하거나 재시작해도 된다**. Windows 세션 0에서 시작했더라도 연결할 때 임시 작업을 통해 현재 Windows 계정의 로그인 데스크톱에서 캡처를 실행한다. 로그인 비밀번호를 저장하거나 상주 앱·로그인 자동 실행을 등록하지 않는다. 로그아웃·로그인 전·잠금·UAC 화면은 지원 범위 밖이다.

직접 연결의 방화벽 설정은 **Mew 서버가 실행 중인 컴퓨터의 Windows에서** 한다. WSL에서 서버를 실행한 경우에도 해당 컴퓨터의 Windows 보안을 연다. Electron의 네트워크 접근을 묻는다면 원격 연결에 사용할 네트워크에 허용한다. **Windows 방화벽 차단** 안내가 나오면 해당 앱의 차단 규칙을 확인한다. 서버 전송은 기존 Mew 접속을 사용하므로 Electron의 직접 영상 연결이 차단되어도 사용할 수 있다. 재설치는 해결 방법이 아니며 Mew가 기존 차단 규칙을 자동으로 바꾸지 않는다.

Windows 파일은 `%LOCALAPPDATA%\Mew\remote-desktop`에 준비한다. PATH에 PowerShell이 없어도 마운트된 Windows 드라이브에서 찾는다. Windows 드라이브·interop가 끊긴 경우에는 연결 오류 안내를 따른다. Linux GUI가 없는 서버/컨테이너에는 공유할 데스크톱이 없으며 WSLg 화면을 Windows 전체 화면으로 대신 보여주지 않는다.

진단용 수동 준비도 유지한다. Mew 저장소에서 `npm run desktop:install`을 실행할 수 있다. 앱 빌드·서버 재시작은 [README](../../README.md#개발-실행과-검증)에 따라 사용자가 한다.

## 조작

오른쪽 아래 컨트롤은 마우스 모양이다. 위쪽에 좌클릭(1)·휠(2)·우클릭(3), 아래쪽에 세 칸을 합친 커서 이동(0)이 있다. 화면 이동(4)·확대(5)는 옆에 따로 배치한다.

```text
┌────┬────┬────┐
│ 1  │ 2  │ 3  │   4
├────┴────┴────┤
│      0      │   5
└─────────────┘
```

터치패드처럼 손가락을 움직인 거리만큼 커서가 움직인다. 손가락을 멈추면 커서도 멈추며, 가운데로 돌아올 필요가 없다. 손을 떼었다 다시 대서 이어 움직일 수 있다. 드래그·휠·화면 이동·확대도 움직인 만큼만 반응한다.

| 조이스틱 | 짧게 탭 | 바로 밀기 | 잠깐 꾹 누른 뒤 밀기 |
| --- | --- | --- | --- |
| 1 좌클릭 | 왼쪽 클릭 | 왼쪽 버튼을 누른 채 이동 | 동일 |
| 2 휠 | 중간 버튼 클릭 | 세로 스크롤 | 중간 버튼을 누른 채 모든 방향 이동 |
| 3 우클릭 | 오른쪽 클릭 | 오른쪽 버튼을 누른 채 이동 | 동일 |
| 0 커서 이동 | 클릭하지 않음 | 커서만 이동 | 동일 |
| 4 화면 이동 | — | 확대된 화면에서 보는 위치 이동 | 동일 |
| 5 확대·축소 | — | 위로 확대, 아래로 축소 | 동일 |

좌·우 조이스틱은 이동을 시작하면 즉시 버튼을 누른다. 휠의 중간 버튼 드래그는 약 0.32초 꾹 누른 뒤 시작한다. 버튼을 잡으면 색이 바뀌고, 손을 떼거나 취소하면 해제한다. 마지막 **핸들**을 끌면 컨트롤 묶음이 함께 움직이며 화면 바깥으로 넘어가지 않는다. 조이스틱·핸들에 포커스를 두고 방향키로도 조작할 수 있다. 좌·우 조이스틱에서는 방향키를 누르는 동안 드래그하고 모든 방향키를 떼거나 포커스를 옮기면 해제한다.

휴대폰에서 원격 화면 자체를 밀면 보는 위치를 옮기고, 두 손가락으로 확대한다. 원격 클릭은 조이스틱으로 한다. **맞춤**은 확대·이동을 초기화한다. 확대는 1–6배이며 원격 해상도는 바꾸지 않는다.

마우스가 있으면 화면에서 직접 커서를 움직이고 클릭할 수 있다. Wayland는 조이스틱 상대 이동을 사용한다. 키보드는 화면을 선택한 뒤 입력한다. F6은 상단 도구로 포커스를 옮긴다. **입력 → 붙여넣기**는 작성한 텍스트로 원격 클립보드를 덮어쓰고 붙여넣는다. 같은 창의 **원격 Esc**는 원격 컴퓨터에 Escape 키를 보낸다.

Windows/WSL과 macOS의 지원되는 화면에서는 커서를 내 기기에서 즉시 표시하므로 영상 갱신을 기다리지 않는다. Windows는 기본 캡처가 준비되지 않으면 커서를 분리하는 보조 캡처를 자동으로 시도한다. 연결 후 **도움말 → 커서 표시**에서 실제로 적용됐는지 확인한다. **이 기기에서 즉시 표시**는 로컬 커서, **영상에 포함됨**은 기존 영상 커서다. 호버·클릭·드래그는 원격 컴퓨터에 전달한다. 화면 변화가 없으면 영상 전송을 쉬고, 화면이 바뀌면 재개한다. Mac은 ScreenCaptureKit으로 화면과 커서를 분리한다. 지원되지 않거나 초기 캡처가 실패한 화면 및 Linux는 기존 영상 커서를 사용한다.

공유 화면이 여러 개면 상단 선택기로 바꾼다. 이전 연결을 종료하고 새 화면에 연결한다. 로컬 Esc·모바일 뒤로가기·닫기는 팝업과 영상/입력을 종료한다. 백그라운드가 되면 연결을 종료하고, 돌아왔을 때 **다시 연결**을 누른다.

## 네트워크와 설정

**TURN 서비스·계정·API 키 없이 사용할 수 있다.** 외부 네트워크에서 직접 연결이 막히면 기존 Mew WebSocket으로 VP8 압축 영상과 입력을 전달한다. 영상은 Mew 서버를 통과하며 별도 공개 포트를 열지 않는다. 외부 접속에는 HTTPS와 WebSocket을 지원하는 기존 배포 경로가 필요하다. 브라우저는 보안 컨텍스트에서 VP8 WebCodecs 디코딩을 지원해야 하며 지원하지 않으면 업데이트 안내가 나온다.

서버 전송은 최대 1080p·30fps, 직접 연결은 최대 1080p·60fps를 목표로 한다. 실제 성능은 서버·브라우저·네트워크에 따라 달라지며 서버 전송은 TCP 손실과 왕복 지연의 영향을 더 받는다. 기존 HTTPS 터널이 외부 서비스를 쓴다면 그 경로는 그대로 이용한다. 추가 영상 중계 서비스는 사용하지 않는다.

`MEW_DESKTOP_ICE_SERVERS`는 기존 운영자를 위한 선택 설정으로 유지한다. 기본은 `[]`이고 공개 STUN/TURN을 자동으로 호출하지 않는다. 값을 지정한다면 해당 서버의 `urls`, `username`, `credential`을 서버 비밀 설정에만 저장한다. 필요하지 않으면 비워 둔다.

`MEW_DESKTOP_HELPER_DIR`은 설치 경로를 바꾸는 선택 설정이다. Mac/Linux는 절대 경로, WSL은 `C:\…` 같은 Windows 절대 경로다. 설치 버튼과 수동 설치 모두 이 위치에 보조 앱을 복사·설치하며, 연결도 같은 위치를 사용한다.

HTTPS 프록시/터널은 로그인·연결 협상과 서버 전송 영상을 전달한다. 직접 WebRTC 경로는 별개다. [환경변수](../configuration/environment.md), [검증 범위·지원하지 않는 화면](../development/remote-desktop.md), [배포 라이선스](../development/remote-desktop-distribution.md)를 참고한다.

서버 연결의 **표시 응답**은 영상 전송·디코딩·표시 후 응답이 돌아오는 시간이다. 클릭 결과가 화면에 나타나는 전체 지연은 아니다. **화면 정지**는 연결을 유지하며 영상 변화가 없는 상태다.

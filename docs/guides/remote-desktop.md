# 원격 데스크톱

[사용법 지도](MOC.md) · [아키텍처·검증 범위](../development/remote-desktop.md)

헤더 메뉴의 **원격 데스크톱**을 누른다. manager·owner만 사용할 수 있으며, 작업 패널과 독립적으로 화면 전체를 채운다. 서버가 Mac/Linux면 로그인한 데스크톱을, WSL이면 Windows 데스크톱을 공유한다. 서버 전체에 한 연결만 사용할 수 있다.

## 처음 설치

메뉴에서 원격 데스크톱을 열고 **보조 앱 설치**를 누른다. 내부 tmux 터미널이 열리며 서버의 mew 설치 경로에서 설치가 시작된다. 현재 선택한 프로젝트나 터미널의 작업 폴더는 영향을 주지 않는다. 앱의 일반 설치와 별개인 선택 기능이다.

**닫기**는 터미널 창만 닫으며 설치는 계속된다. **설치 터미널 열기**로 출력을 다시 확인할 수 있다. 실패하면 터미널에 표시된 오류를 확인하고 창을 닫은 뒤 **다시 설치**를 누른다. 재시도는 이전 설치 터미널을 교체한다. **종료**는 tmux 세션도 종료한다. 설치 완료 후에는 **닫기 → 다시 연결**을 누른다.

수동 설치도 가능하다. 서버의 mew 저장소에서 실행한다.

```bash
npm run desktop:install
```

의존성은 `native/remote-desktop/`의 별도 lockfile로 설치한다. Electron 다운로드가 필요하다. 앱 빌드·반영은 [README](../../README.md)의 절차대로 사용자가 한다.

| 서버 환경 | 준비 |
| --- | --- |
| Mac | 데스크톱에 로그인한다. 최초 연결에서 시스템 설정의 **손쉬운 사용**과 **화면 기록**을 보조 앱(Electron)에 허용하고 다시 연결한다. OS가 요구하면 보조 앱을 재실행한다 |
| Linux X11 | 로그인한 사용자 환경에서 Mew를 실행한다. DISPLAY/Xauthority, Electron GUI 라이브러리와 libXtst가 필요하다. Debian/Ubuntu 입력 라이브러리는 `libxtst6` |
| Linux Wayland | 로그인한 사용자 D-Bus·PipeWire·xdg-desktop-portal과 compositor의 RemoteDesktop 지원이 필요하다. 서버에서 화면 공유와 원격 입력 요청을 승인한다 |
| WSL | **Windows에도 Node.js 22.12 이상**과 npm을 설치한다. Windows 로그인과 WSL interop를 켠 뒤 설치 버튼을 누른다. PowerShell을 통해 `%LOCALAPPDATA%\Mew\remote-desktop`에 복사하고 해당 Windows 폴더에서 npm을 실행한다. Windows npm을 찾지 못하면 터미널에 안내가 표시된다 |

WSL 보조 앱 코드가 바뀌면 설치 명령을 다시 실행해 Windows 복사본도 갱신한다. GUI 세션에 접근할 수 없는 서비스/컨테이너에는 표시할 데스크톱이 없다. WSLg 창을 Windows 전체 화면으로 대신 보여주지 않는다.

## 조작

오른쪽 아래에 다음 순서로 배치된다. 보이는 원은 작고, 손가락을 조금 밀어 유지하면 빠르게 움직인다. 가운데로 돌아오면 멈춘다.

| 조이스틱 | 짧게 탭 | 바로 밀기 | 잠깐 꾹 누른 뒤 밀기 |
| --- | --- | --- | --- |
| 좌클릭 | 왼쪽 클릭 | 커서 이동 | 왼쪽 버튼을 누른 채 이동 |
| 휠 | 중간 버튼 클릭 | 세로 스크롤 | 중간 버튼을 누른 채 모든 방향 이동 |
| 우클릭 | 오른쪽 클릭 | 커서 이동 | 오른쪽 버튼을 누른 채 이동 |
| 화면 이동 | — | 확대된 화면에서 보는 위치 이동 | 동일 |
| 확대·축소 | — | 위로 확대, 아래로 축소 | 동일 |

꾹 누르기는 약 0.32초이며 버튼을 잡으면 원의 색이 바뀐다. 마지막 **핸들**을 끌면 조이스틱 묶음이 함께 움직인다. 화면 바깥으로 넘어가지 않는다. 조이스틱·핸들에 포커스를 두고 방향키로도 조작할 수 있다.

휴대폰에서 원격 화면 자체를 밀면 보는 위치를 옮기고, 두 손가락으로 확대한다. 원격 클릭은 조이스틱으로 한다. **맞춤**은 확대·이동을 초기화한다. 확대는 1–6배이며 원격 해상도는 바꾸지 않는다.

마우스가 있으면 화면에서 직접 커서를 움직이고 클릭할 수 있다. Wayland는 조이스틱 상대 이동을 사용한다. 키보드는 화면을 선택한 뒤 입력한다. F6은 상단 도구로 포커스를 옮긴다. **입력 → 붙여넣기**는 작성한 텍스트로 원격 클립보드를 덮어쓰고 붙여넣는다. 같은 창의 **원격 Esc**는 원격 컴퓨터에 Escape 키를 보낸다.

공유 화면이 여러 개면 상단 선택기로 바꾼다. 이전 연결을 종료하고 새 화면에 연결한다. 로컬 Esc·모바일 뒤로가기·닫기는 팝업과 영상/입력을 종료한다. 백그라운드가 되면 연결을 종료하고, 돌아왔을 때 **다시 연결**을 누른다.

## 네트워크와 설정

직접 연결이 가능한 망에서는 영상 중계가 필요 없다. 외부 망에서 직접 연결이 막히면 `MEW_DESKTOP_ICE_SERVERS`에 운영자의 STUN/TURN JSON 배열을 지정한다. 기본은 `[]`이며 내장 공개 중계 서버는 없다. TURN의 `urls`, `username`, `credential`은 사용하는 서비스의 값으로 서버 설정에만 저장한다. 자격증명은 연결한 관리자 뷰어에도 전달되므로 원격 데스크톱 전용·제한된 자격증명을 사용한다.

`MEW_DESKTOP_HELPER_DIR`은 설치 경로를 바꾸는 선택 설정이다. Mac/Linux는 절대 경로, WSL은 `C:\…` 같은 Windows 절대 경로다. 설치 버튼과 수동 설치 모두 이 위치에 보조 앱을 복사·설치하며, 연결도 같은 위치를 사용한다.

HTTPS 프록시/터널은 로그인과 연결 협상을 전달한다. 영상 경로는 별개이므로 HTTPS 접속만으로 WebRTC 연결이 보장되지는 않는다. [환경변수](../configuration/environment.md)와 [검증 범위·지원하지 않는 화면](../development/remote-desktop.md)을 참고한다.

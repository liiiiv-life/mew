## 공동 편집과 참여자

로그인한 사용자끼리 같은 프로젝트의 같은 파일을 열면 실시간으로 내용을 함께 편집한다. Markdown은 Hotview에서, 다른 텍스트 파일은 Plain에서 협업한다. 문서·사이드바에 표시되는 색 점으로 작업 중인 사람을 확인하고 편집기에서 다른 사용자의 커서를 볼 수 있다.

여러 칸에 파일을 열어도 다른 사람에게 보고 있는 파일로 알리는 것은 마지막으로 클릭한 편집 칸의 파일 하나다. 터미널이나 에이전트가 디스크에서 수정한 Markdown도 열린 협업 문서에 반영된다. 게스트와 서버 파일 탐색기의 프로젝트 밖 파일에는 실시간 공동 편집을 제공하지 않는다. 동기화 상세는 [협업 계약](../development/collaboration.md)을 따른다.

## 공통 메모

하단 독의 **메모** 아이콘 또는 `Ctrl+M`·`Cmd+M`으로 **메모** 팝업을 연다. 아이콘은 PC·모바일 모두 RAG 왼쪽에 기본 배치되며 로그인·협업 권한이 있을 때 표시한다. PC에서는 다시 누르면 닫고, 모바일에서는 열린 메모로 포커스를 옮긴다. 모바일에서 다른 독 항목을 고르면 메모를 숨기며 작성 내용은 유지한다. 이미 열려 있고 다른 곳에 포커스가 있으면 메모 입력칸으로 이동하며, 메모 안에 포커스가 있으면 닫는다. 키를 누르고 있어도 열림·닫힘을 반복하지 않는다. 단축키 설정에서 조합을 바꿀 수 있다.

제목과 오른쪽 닫기 버튼 아래에 기존 Markdown Hotview 입력칸만 표시한다. 글자 수 상태줄은 없다. 제목 부분을 끌어서 이동하며, 제목에 키보드 초점을 두면 방향키로도 옮긴다. 네 변과 네 모서리를 마우스나 손가락으로 끌면 상하좌우·대각선으로 크기를 조절한다. Tab으로 가장자리 조절 영역에 초점을 두고 방향키로도 조절할 수 있다. 같은 페이지에서 닫았다 열면 크기를 유지하고, 화면 크기·모바일 키보드가 바뀌면 창 크기와 위치를 화면 안으로 맞춘다. 외부를 눌러도 계속 열려 있으며 메모에서 Esc, 뒤로가기 또는 닫기 버튼으로 닫는다.

메모는 같은 Mew 서버의 로그인 사용자들이 함께 쓰는 하나의 공간이다. 프로젝트·루트 프로젝트 전환과 무관하게 실시간 공동 편집되며, 서버에 자동 저장되어 모두 닫거나 서버를 재시작한 뒤에도 남는다. 제목 옆 색 점은 현재 메모를 열어 둔 사용자 수를 나타내고 같은 계정의 여러 창은 하나로 센다. 협업 권한이 없는 계정과 게스트에게는 제공하지 않는다. 연결 중에는 상태를 표시하고 편집을 잠시 막으며, 창을 닫아도 현재 페이지 안의 미전송 변경은 재연결 시 병합한다.

## 접속 중인 mew 세션

로그인 후 프로젝트 탭 줄의 **햄버거 버튼 왼쪽 원형 숫자 버튼**을 누르면 접속 중인 세션 목록을 연다. 사용자별로 브라우저·기기, 보고 있는 프로젝트와 파일, 접속 시각을 볼 수 있다. 지금 사용하는 탭에는 **현재 세션**, 다른 화면 뒤에 있는 탭에는 **백그라운드**를 표시한다.

숫자 원은 모바일 20px·데스크톱 22px로 표시하고, 배경에 글자색·숫자에 화면 배경색을 써 색을 반전한다. 누르는 영역은 기존 크기를 유지한다. 숫자는 브라우저 탭·창 기준이다. 같은 사람이 두 탭을 열면 2개이며, 게스트 접속도 포함한다. 접속·종료에 따라 자동으로 갱신되고 네트워크 연결이 끊기면 숫자 대신 `—`가 나타난다. 게스트에게는 이 숫자와 목록을 공개하지 않는다.

각 세션 아래의 **작업 중 에이전트 N개**는 해당 브라우저의 현재 프로젝트에서 연결된 에이전트 탭 중 작업 중인 수다. 대기 중인 탭·일반 터미널은 제외하며 에이전트 탭에서 실행 중인 CLI 명령은 작업으로 센다. 작업 상태 변경 시 바로 갱신하고 30초마다 다시 보고한다. 구버전 클라이언트나 90초 넘게 갱신되지 않은 값은 다음 목록 갱신에서 `—`로 표시한다.

같은 에이전트를 여러 브라우저에서 보면 각 세션에 표시될 수 있으므로 합산하지 않는다. 브라우저 연결을 떠나 서버에서 계속 실행 중인 작업 전체의 수는 아니다. 기존 JS 메모리 표시·측정·전송은 작업 현황을 보여 달라는 요청에 따라 제거했다. 사용자 요청 전에는 다시 도입하지 않는다.

## 댓글과 답글

1. 문서에서 의견을 남길 부분을 선택하고 `Alt+Shift+C`를 누른다.
2. 내용을 입력해 등록한다. 입력창에서 멤버 멘션을 사용할 수 있다.
3. 본문의 하이라이트를 누르거나 편집기의 **댓글 목록**에서 스레드를 골라 답글을 남긴다. 원문이 바뀌어 하이라이트를 찾을 수 없는 댓글도 목록에서 확인한다.
4. 본인 댓글은 수정·삭제할 수 있고 owner는 다른 사람의 댓글도 관리할 수 있다.

댓글은 본문에 텍스트로 삽입되지 않고 별도로 관리된다. 코드·텍스트에도 선택 위치에 댓글을 달 수 있다.

## 단체 채팅과 DM

헤더 메뉴 → **채팅** 또는 `Alt+C`로 연다. 대화 목록에서 단체방을 고르면 전체 멤버와, 사람을 고르면 그 사람과 1:1로 대화한다. 읽지 않은 대화 수와 메시지별 미확인 수신자 수를 표시한다.

입력창에서 파일 참조를 넣어 보내면 수신자가 그 참조를 눌러 mew 편집기로 열 수 있다. 채팅을 연 뒤 편집기에서 `Ctrl+L`을 누르면 [참조 전달 규칙](editor.md#ctrll-참조-경로줄)에 따라 파일 멘션을 입력창에 넣는다. 다른 보조창을 마지막으로 열었다면 그 창이 참조를 받을 수 있다.

채팅은 채팅 기능이 허용된 로그인 사용자 전용이다. DM은 앱에서 당사자에게만 전달하지만 서버 파일에 저장되므로 서버 관리자에게 숨기는 비밀 대화는 아니다. 저장·읽음 처리 범위는 [채팅 계약](../development/collaboration.md), 권한 정책은 [SECURITY](../../SECURITY.md)를 따른다.

## 게스트 공유

로그인하지 않은 방문자는 guest다. owner는 **계정 관리 → 파일·폴더 권한**에서 경로를 선택하고 guest 행의 상속·차단·열람·수정을 설정한다. 수정은 열람을 포함한다. 사이드바의 눈·연필 설정은 사용하지 않는다. 설정 후 mew 접속 주소를 전달하면 방문자가 허용된 경로를 탐색할 수 있다.

이 권한은 특정 수신자에게만 발급하는 초대가 아니라 **로그인하지 않은 방문자 전체에 적용되는 경로 규칙**이다. 폴더를 허용하면 하위 경로에도 적용되고 더 구체적인 경로 규칙이 우선한다. 공유를 중단하려면 해당 규칙을 해제하고 하위 항목의 별도 허용도 확인한다.

게스트는 허용된 파일의 열람·본문 편집만 할 수 있고 생성·삭제·개명·터미널·에이전트·DB·공동 편집은 사용할 수 없다. 차단 경로·시크릿 파일과 알려진 예외의 기준본은 [게스트 경계](../../SECURITY.md#게스트-경계)다.

공동 편집·댓글은 해당 기능과 대상 파일 권한을 함께 확인한다. 접속 세션 팝업도 보는 계정이 열람할 수 없는 프로젝트·파일 경로는 표시하지 않는다. 기능 기본값과 계정별 변경은 [권한 설정](../configuration/environment.md#내-계정과-계정-관리)을 따른다.

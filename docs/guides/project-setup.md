# 프로젝트 문서 연결과 에이전트 자동 안내

상위: [사용법](MOC.md). 결정: [ADR 0155](../../../.mew/docs/decisions/0155-mew-project-agent-context.md).

## 자동으로 전달되는 내용

mew의 채팅형(ACP) 에이전트는 매 요청마다 프로젝트 루트, 작업 폴더, Documents 위치와 짧은 문서 탐색·갱신 안내를 받는다. 별도 AGENTS.md 생성 없이 기본으로 켜진다. 추가 문서 진입점과 프로젝트 지침은 설정할 수 있다.

안내는 프로젝트 README와 기존 지침을 따르고, 문서 지도에서 관련 current 문서만 읽고, 기능·코드·운영 변경을 소유 문서에 되돌려 쓰도록 요청한다. 문서 본문 전체, 회사 고유 정책, 브랜드 규칙을 자동으로 복사하지 않는다. 시스템 역할의 강제 지침이나 문서 열람 검증 기능은 아니다.

사용자 입력·대화 표시에는 이 안내를 덧붙이지 않는다. ACP 런타임의 원본 대화 기록에는 실제 전달 내용이 남을 수 있다. 설정의 **전달할 안내 보기**에서 현재 루트 기준 내용을 확인한다. 하위 폴더에서 시작한 에이전트는 실제 작업 폴더의 진입점도 함께 받는다.

## 공통 안내 파일 편집

사이드바 파일 목록 맨 위, **Documents 위의 공통 에이전트 안내**를 누르면 `agent-guidance.txt`가 기존 파일 편집기에서 열린다. 서버 파일 탐색기 권한이 있는 계정(manager·owner 기본)이 사용할 수 있다. 저장된 내용은 같은 mew 서버의 모든 프로젝트·세션에 다음 실제 ACP 요청부터 적용된다. 프로젝트 하나에만 필요한 규칙은 Documents 설정의 추가 지침에 쓴다.

실제 기준본은 `DATA_DIR/agent-guidance.txt`이며 기본 설치 위치는 `~/.local/share/mew/agent-guidance.txt`다. `MEW_DATA_DIR` 또는 기존 `.data`를 쓰는 설치는 그 데이터 폴더를 따른다. 처음 요청하거나 파일을 열 때 `server/prompts/agent-guidance.txt`의 기본 내용으로 생성한다. 앱 업데이트·재시작은 기존 파일을 덮어쓰지 않는다. 미리보기만 실행하면 파일을 생성하지 않고 기본 내용을 보여 준다.

파일에는 공통 안내 문구만 쓴다. 프로젝트·작업·Documents 경로와 문서 진입점, 프로젝트별 추가 지침은 mew가 자동으로 뒤에 붙인다. 빈 파일을 저장하면 공통 문구만 빠지고 이 경로 정보는 유지된다. 파일 삭제 후 다음 요청·열기는 기본 안내를 다시 생성한다. 읽기 오류는 요청 오류로 알린다. 프로젝트의 자동 안내를 끄면 공통 파일과 자동 경로 정보 모두 전달하지 않는다. 결정은 [ADR 0165](../../../.mew/docs/decisions/0165-mew-common-agent-guidance-file.md)를 따른다.

## GUI로 설정하기

1. 프로젝트를 열거나 새 폴더를 만든 뒤, 사이드바 **Documents**를 우클릭한다. 모바일에서는 길게 눌러 항목 메뉴를 연다.
2. **에이전트 안내와 문서 설정**을 연다(owner 전용).
3. Documents 상대 경로, 자동 전달 여부, 추가 문서 진입점(한 줄에 하나), 추가 지침을 설정한다. 진입점은 프로젝트 안의 기존 Markdown 파일이다.
4. 새 프로젝트에는 **없는 문서 기본 구조 만들기**를 선택한다. 기존 프로젝트에는 현재 문서 폴더를 연결하고 필요한 진입점만 지정해도 된다.
5. 외부 도구에서도 문서 안내를 쓰려면 **외부 도구용 AGENTS.md 만들기**를 선택한다.
6. **미리보기**에서 생성·갱신·기존 유지 파일과 전달 안내를 확인한 뒤 **적용**한다. 입력을 바꾸면 다시 미리보기해야 한다. 적용 후 화면을 다시 불러온다.

초기화 대상은 Documents의 `AGENT.md`, `README.md`, `MOC.md`와 프로젝트 `README.md`다. 없는 파일만 생성하며 기존 문서 내용·지도·AGENTS.md를 덮어쓰거나 이동하지 않는다. 생성 템플릿은 영어다. 기존 MOC에 이미 문서가 있다면 그 지도를 계속 사용한다. 추가 폴더와 ADR 저장 위치는 프로젝트 정책에 맡긴다.

AGENTS.md 내보내기는 해당 파일이 없을 때만 짧은 Documents 연결 파일을 만든다. 기존 파일은 미리보기에 **기존 유지**로 표시되며 자동 병합하지 않는다. 이 경우 기존 지침에 Documents 진입점 링크가 필요한지는 사용자가 판단한다.

## CLI로 설정하기

mew 저장소에서 실행한다. 기본은 읽기 전용 미리보기이고 `--apply`를 붙여야 기록한다.

```bash
# 기존 프로젝트의 문서 폴더 연결·미리보기
npm run project:setup -- --project /absolute/path/to/project --docs docs

# 문서가 없는 기존 프로젝트의 기본 구조 생성
npm run project:setup -- --project /absolute/path/to/project --init-docs --apply

# 새 프로젝트와 기본 문서, 외부 도구용 연결 파일 생성
npm run project:setup -- --project /absolute/path/to/new-project --create --init-docs --export-agents --apply

# 기존 Markdown 진입점과 프로젝트 지침 지정
npm run project:setup -- --project /absolute/path/to/project --entry docs/MOC.md --instructions "Follow the existing project decisions." --apply

# 자동 안내 끄기 / 도움말
npm run project:setup -- --project /absolute/path/to/project --disable --apply
npm run project:setup -- --help
```

`--entry`는 반복할 수 있으며 저장된 추가 진입점 목록을 대체한다. `--instructions ""`는 추가 지침을 지운다. `--enable`은 자동 안내를 다시 켠다. CLI는 프로젝트 파일만 설정하며 mew 서버를 실행·빌드·재시작하거나 프로젝트 탭을 열지 않는다. CLI로 현재 열린 프로젝트의 Documents 경로를 바꿨다면 그 프로젝트를 다시 열어 화면의 경로도 갱신한다.

## 저장과 세션 수명

프로젝트별 설정은 `<프로젝트>/.mew/agent-context.json`에 저장한다.

```json
{
  "version": 1,
  "enabled": true,
  "docsDir": "docs",
  "entrypoints": [],
  "instructions": ""
}
```

Documents 경로 선택 우선순위는 프로젝트 설정 → 해당 폴더가 실제 존재하는 기존 `MEW_DOCS` → `docs` 또는 기존 `.mew/docs`다. 기존 **폴더 바꾸기**도 같은 프로젝트 설정을 기록한다. 상대 경로만 허용하며 설정·생성 경로에서 심볼릭 링크를 따라가지 않는다. 잘못된 JSON은 덮어쓰지 않고 오류를 알린다.

세션이 시작되면 프로젝트 루트와 Documents 연결을 세션 ID에 귀속한다. 프로젝트 화면을 전환하거나 오래된 기록을 복원해도 다른 프로젝트의 연결로 바뀌지 않는다. Documents 경로를 바꾼 뒤에는 **새 대화**(`/clear`)부터 새 경로를 쓴다. 자동 안내 켜기/끄기와 추가 지침은 다음 실제 요청에서 읽는다. 큐 메시지도 실행 시점의 지침을 받는다.

명시적으로 설정된 하위 프로젝트에서 시작하면 그 프로젝트 설정을 사용한다. 설정이 없는 하위 폴더는 현재 워크스페이스 연결을 상속한다. 워크스페이스 밖에서 시작한 세션은 자기 경로의 설정·기본 Documents를 사용하며 다른 화면의 문서 경로를 빌리지 않는다.

## 지원 범위와 업데이트

- 채팅 입력, 에이전트셋, 큐 수정 후 실행, 예약 메시지, 반복 예약 작업은 공통 ACP 전송 지점에서 안내를 받는다. 반복 예약 명령에는 작업의 프로젝트·Documents 연결을 명시한다.
- 일반 터미널·터미널형 에이전트에 직접 입력한 내용에는 자동 주입하지 않는다. 외부 도구의 AGENTS.md 지원에 따라 선택적으로 내보낸 연결 파일을 사용한다.
- 이미 실행 중인 이전 버전의 독립 에이전트 감독은 서버 재시작만으로 교체되지 않는다. 작업이 끝난 뒤 기존 에이전트 탭을 닫고 다시 열어 업데이트된 전달 경로를 사용한다.
- 이 기능을 배포하려면 사용자가 mew를 빌드·재시작한다. 에이전트는 실행 중인 서버에 반영하는 명령을 실행하지 않는다.

공통 [RAG 설정](../configuration/search.md#공통-설정과-에이전트)이 켜져 있으면 같은 자동 안내에 세션 프로젝트용 로컬 검색 명령을 함께 전달한다. 프로젝트 자동 안내를 끄면 이 RAG 안내도 전달하지 않는다.

# 첫 프로젝트와 문서 열기

설치를 마치고 mew에 로그인한 상태에서 시작합니다. 이 안내를 마치면 작업 폴더에 `notes.md`를 만들고 변경 내용을 확인할 수 있습니다. 아직 설치하지 않았다면 [한국어 시작 안내](getting-started-ko.md)를 따르세요.

## 1. 작업 폴더 열기

헤더 왼쪽의 **현재 프로젝트 아이콘·이름**을 누르고 목록 마지막의 **프로젝트 추가**를 선택합니다. 서버 컴퓨터의 작업 폴더로 이동한 뒤 **현재 폴더 열기**를 누릅니다(owner). 여기서 보이는 것은 **mew 서버의 파일**입니다. 처음에는 폴더 선택 창에서 `hello-mew` 같은 예제 폴더를 만들어 시작해도 됩니다. 선택한 폴더로 전환하면 헤더에 해당 프로젝트의 아이콘과 이름이 표시됩니다.

다른 프로젝트로 가려면 헤더의 현재 프로젝트를 누른 뒤 목록에서 선택합니다. 계정 역할에 따라 폴더 열기와 기능 접근 권한이 다릅니다. [프로젝트 관리](projects.md#프로젝트-탭).

## 2. 파일과 Documents 구분하기

왼쪽 **파일**에서 프로젝트 폴더의 파일을 선택합니다. **문서**는 그 프로젝트에 연결된 Documents 폴더를 보여줍니다. 둘 다 같은 에디터로 열리며, 보기 전환만으로 파일이 복사되지는 않습니다.

Markdown 파일이 없다면 **파일** 보기의 **새 파일** 버튼을 누릅니다. `notes.md`처럼 확장자까지 입력한 뒤 Enter를 누르면 파일이 생깁니다. 폴더가 선택돼 있으면 그 폴더 안에, 파일이 선택돼 있으면 그 파일과 같은 폴더에 만듭니다. 선택이 없으면 프로젝트 루트에 만듭니다. 기존 문서 폴더를 연결하려면 [Documents 설정](project-setup.md)을 따릅니다.

## 3. Markdown 편집하기

![예제 프로젝트 노트를 Hotview로 편집하는 화면](../assets/screenshots/desktop.png)

다음과 같이 제목과 체크리스트를 적어 보세요.

```markdown
# 프로젝트 노트

## 할 일

- [ ] 요구사항 정리
- [ ] 첫 변경 검토
```

**Hotview**에서 렌더링된 내용을 편집하고, **Plain** 버튼으로 Markdown 원문을 확인합니다. 저장 상태가 완료되면 다른 파일을 열었다가 `notes.md`로 돌아와 내용이 남아 있는지 확인합니다. 본문은 자동저장되며, `Ctrl+S`는 현재 파일을 Git에 커밋하는 조작입니다. 변경 이력을 남기거나 파일을 되돌리기 전에는 [저장·복원 동작](editor.md#자동저장커밋파일-이력)을 확인하세요.

## 4. 필요한 도구 열기

PC 왼쪽 독에서 **에이전트**, **터미널**, **Git** 등을 누릅니다. 도구를 닫거나 배치를 바꿀 수 있으며, 문서 탭을 편집 칸 가장자리로 끌면 화면을 나눕니다. 원하는 아이콘이 보이지 않으면 **설정 → Dock**의 표시 설정과 계정의 기능 권한을 확인합니다.

AI 에이전트는 먼저 [런타임 설치·인증](../configuration/agent-runtimes.md)을 준비해야 합니다. 터미널과 에이전트는 서버의 OS 계정 권한으로 실행됩니다. [터미널 사용법](terminal-agents.md) · [보안과 역할](../operations/security.md).

휴대폰에서는 아래 독으로 전면 패널을 바꿉니다. 화면이 좁을 때는 파일 목록에서 문서를 선택해 편집 화면으로 이동하세요.

## 5. 변경 확인하기

Git 저장소인 프로젝트라면 **Git** 패널에서 `notes.md`를 눌러 diff를 검토합니다. 이력으로 남기려면 파일의 체크박스를 선택하고 커밋 아이콘으로 제목을 작성해 커밋합니다. 처음 커밋할 때는 Mew 계정에 GitHub를 연결합니다. Git 저장소가 아닌 폴더도 문서 편집에 사용할 수 있습니다. [Git 작업 패널](projects.md#git-작업-패널).

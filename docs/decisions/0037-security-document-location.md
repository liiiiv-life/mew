## 상태

대체됨. 보안 문서를 `docs/`에 두는 원칙은 유지하며, `docs/SECURITY.md` 배치는 [후속 결정 0040](0040-document-gardening.md)의 운영 문서 분류로 대체한다.

## 배경

보안 기준본은 역할·인증·실행 권한·데이터 보관을 설명하는 상세 문서지만 저장소 루트에 있어 Documents의 문서 탐색 대상에서 빠져 있었다.

## 결정

보안 기준본을 [docs/SECURITY.md](../operations/security.md)에 둔다. [문서 규칙](../README.md)의 루트 배치 예외에서 SECURITY.md를 제거하고, 들어오는 링크와 문서 내부 상대 링크·데모 초기 사본의 경로를 함께 바꾼다.

## 근거와 영향

보안 기준본에 description을 두어 다른 기준 문서와 같은 방식으로 탐색·검사한다. 보안 정책과 취약점 신고 절차는 유지한다. 이력의 옛 경로 서술과 고정 커밋으로 만든 데모 생성물은 보존하고, 실제로 열리는 문서 링크만 새 위치로 맞춘다.

## 배경

인증 화면은 이미 분리됐지만, 작업 화면은 닫힌 패널과 편집기·터미널·브라우저 재생 코드까지 정적으로 가져왔다. 인증과 모듈 다운로드를 기다리는 동안에는 빈 화면만 보였다. 작업 화면의 필수 JS 의존 청크는 격리 메모리 번들에서 gzip 합계 약 1.36MB였다.

## 결정

저장된 글꼴·테마를 적용한 시작 화면을 인증·경로 모듈 대기 전에 표시한다. 작업 화면의 기본 구조와 편집기·도구의 로딩 경계를 나누고, 순수 검색·세션 함수와 전체 아이콘 목록을 무거운 renderer에서 분리한다. 업데이트 검사는 첫 화면 표시 이후로 미룬다. 현재 계약과 회귀 검사는 [앱 시작 구조](../development/architecture.md)가 소유한다.

## 근거와 영향

필수 다운로드가 줄고 도구 하나의 지연이 헤더·사이드바 조작을 막지 않는다. 첫 사용 시 도구 다운로드 대기가 생기므로 패널별 로딩 상태와 지연 마운트 후 포커스를 제공한다. 기존 에이전트 백그라운드 복원·알림과 계정별 상태는 보존한다.

P2P 저장소 범위와 인증·권한 검사는 작업 상태를 읽기 전에 완료한다. 협업 문서의 동기화·쓰기 순서는 바꾸지 않는다. 격리 번들·브라우저 결과는 실제 설치·원격망의 시작 시간과 구분하며, 운영 적용은 사용자가 빌드·재시작한다.

상태: 승인

## 배경

사용자가 에디터 DB에 통합한 간트 보기는 유지하고 독립 태스크 패널을 다시 제공하도록 요청했다. 기존 태스크 Markdown의 완료·태그·담당자·기간 관리와 문서 DB의 행·날짜 열 기반 일정 편집을 함께 사용할 수 있어야 한다.

## 결정

- [0051](0051-database-gantt.md)의 태스크 패널·독·모바일·단축키 제거와 저장 배치 제외를 대체한다. 기존 목록·달력·간트, 도킹·팝업·모바일 전면, 저장된 그룹·탭 할당·열림 상태와 레이아웃 프리셋을 복원한다.
- 기본 `Alt+T`는 태스크 패널을 열고 닫는다. 기능 패널의 기본 `Alt+F`와 터미널의 `Ctrl+백틱`은 유지한다. 태스크에 포커스가 있으면 기존 새 항목·보기 전환 단축키를 사용한다.
- 에디터 DB 간트와 기존 날짜 열·표시 설정·항목 상세 편집은 유지한다. 태스크는 기존 Markdown과 저장 API를 사용하며 DB 행과 자동 이관하거나 동기화하지 않는다.

## 근거와 영향

기존 태스크를 계속 관리하면서 같은 문서 DB의 다른 보기와 공유하는 간트도 사용할 수 있다. DB의 Postgres·권한 준비는 기존 계약을 유지하며 태스크 패널 복원 때문에 변경하지 않는다. 제거 기간에 이미 저장에서 빠진 배치는 임의로 추정하지 않고 패널을 열 때 기본 위치에 추가한다.

현재 조작은 [태스크 사용법](../guides/projects.md#태스크)과 [DB 안내](../guides/database.md#뷰-바꾸기), 저장·입력은 [태스크 계약](../development/task-list.md), 공통 배치·포커스는 [UI 계약](../development/ui-contracts.md)을 따른다.

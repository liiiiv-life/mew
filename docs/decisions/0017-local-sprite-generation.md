# 0017 — 로컬 영상 모델과 독립 MCP로 Mewpet 생성

상태: [결정 0021](0021-external-local-sprites.md)로 소스·설치·배포 경계 대체

## 배경

Mew 에이전트 채팅에서 캐릭터 설명과 선택적인 참조 이미지로 애니메이션 스프라이트를 만들 필요가 있다. 기존 Mewpet은 전역 폴더의 PNG·WebP 스트립을 빌드 없이 읽지만 생성 모델은 제공하지 않는다. 생성에 필요한 GPU·Python 의존성과 장시간 실행을 앱 서버의 수명에 묶지 않는다.

## 결정

1. `tools/local-sprites`의 독립 stdio MCP를 선택한 런타임의 기존 전역 설정에 등록한다. Mew 내장 MCP나 앱 서버 API에 모델 실행을 추가하지 않는다. 다른 MCP와 런타임 설정은 보존한다.
2. Apache-2.0의 Wan2.1 VACE 1.3B와 ComfyUI용 가중치를 사용한다. ComfyUI는 GPL-3.0의 별도 실행 도구로 설치하며 기본 노드만 사용한다. 배경 제거는 MIT의 rembg와 Apache-2.0의 U²-Net으로 수행한다. [구성 출처](../configuration/local-sprites.md#구성출처와-검증-범위)에 라이선스를 연결한다.
3. 최초 설치 때 모델을 다운로드하고 생성 모델과 배경 제거 모델은 호스트에서 추론한다. ComfyUI는 loopback에서 작업 동안만 실행하고 외부 API·추가 노드를 끈다. 미리보기 응답은 선택한 채팅 에이전트에 전달되며 채팅 런타임의 전송 범위는 별도다.
4. 생성 요청은 즉시 작업 ID를 돌려주고 별도 작업자가 GPU 대기열에서 실행한다. 상태 조회·취소·전체 프레임과 GIF 미리보기를 제공한다. 모델이 만든 연속 프레임을 사용하고 정지 그림의 단순 변형을 애니메이션 대체물로 사용하지 않는다.
5. 생성 결과와 스킨 등록을 구분한다. 사용자가 등록·사용을 요청했을 때만 지정한 `<DATA_DIR>/mewpet/skins`에 새 ID로 등록한다. 브라우저의 현재 스킨은 자동 변경하지 않으며 설정에서 고른다.
6. ComfyUI 커밋과 Wan 모델 세 파일의 저장소 revision·크기·SHA-256을 고정한다. 설치기는 검증을 통과한 가중치만 사용하고 실제 Python 패키지 목록을 기록한다. 모델·가상환경·작업 결과는 Git에 넣지 않는다.

## 근거와 영향

영상 모델은 시간에 따른 동작을 생성하고 VACE의 이미지 참조로 동작 사이 캐릭터를 맞출 수 있다. 결과는 기존 Mewpet 스트립 계약으로 정규화하므로 렌더러를 바꾸지 않는다. 독립 MCP는 선택한 런타임의 새 채팅에 적용되며 Mew 빌드·재시작을 요구하지 않는다.

이 선택은 CUDA GPU와 별도 모델 저장 공간을 요구한다. 동작 생성은 시간이 걸리며 참조와 프롬프트만으로 정확한 정체성·해부학·동작·반복을 보장하지 않는다. 패킹·파일 등록 검증과 GPU 추론·시각 품질 확인은 구분한다. 구체적인 설치·사용·운영 계약은 [로컬 스프라이트 설정](../configuration/local-sprites.md)이 소유한다.

## 후속 정정

최초 결정의 `tools/local-sprites` 위치와 Mew가 설치·운영 문서를 소유하는 범위는 [결정 0021](0021-external-local-sprites.md)이 대체한다. 생성기는 별도 저장소에서 설치·재사용하고 Mew에는 선택적인 MCP 연결과 스킨 형식 안내만 둔다. 위 본문은 당시 선택의 이력으로 보존한다.

Mewlink 원격 접속 기능을 만드는 작업이다. 상세 설계·구현 단계·당시 검증 결과와 출시 확인 조건은 [작업 기록](../work/remote-access.md)에서 관리한다.

현재 동작과 검증 범위는 [P2P 원격 접속 계약](../development/remote-access.md), 적용 절차와 운영 확인은 [중앙 서비스 배포](../deployment/remote-central.md)를 따른다. 이 문서의 완료·태그·기간·담당자는 태스크 패널의 작업 상태다.

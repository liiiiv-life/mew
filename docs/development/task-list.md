# 태스크 패널

[개발 지도](MOC.md) · [기능](../features/projects/tasks.md) · [사용법](../guides/projects.md#태스크)

## 입력과 패널

- 메모와 독립된 `tasks` 도킹 패널이며 현재 루트 프로젝트의 태스크를 관리한다. 항목은 `{id, text, done, parentId?, startDate?, date?}` 객체다. `parentId`는 부모 ID이며 생략/null은 최상위다. 날짜는 선택 속성이다. 우선순위·그 외 속성은 제공하지 않는다.
- 마지막 입력칸은 새 항목 초안이다. Enter 또는 포커스 이동으로 객체를 만들며 Enter 이후 같은 입력칸에서 다음 항목을 이어 쓴다. 기존 항목의 Enter는 커서/선택 위치에서 내용을 나누고 원래 항목 ID를 유지한다. 오른쪽 내용에는 새 ID를 부여한다. Shift+Enter는 같은 항목 안의 줄바꿈이다.
- 여러 줄 붙여넣기는 줄마다 객체를 만든다. 기존 항목에 붙이면 첫 줄은 원래 ID를 유지한다. 빈 항목의 Backspace는 해당 객체를 삭제하고 앞 항목에 포커스한다. 첫 항목은 삭제 버튼으로 지울 수 있다. 커서가 처음/끝에 있을 때 위/아래 화살표로 인접 항목을 이동한다. IME 조합 중 Enter는 태스크를 만들거나 나누지 않는다.
- 체크박스는 해당 객체의 완료만 바꾸며 완료 항목도 위치를 유지한다. 완료 내용은 취소선으로 표시하고 바로 수정할 수 있다. 삭제 버튼은 hover·포커스와 터치 환경에서 표시한다.
- 체크박스 영역을 6px 이상 끌면 순서 이동으로 전환하며 짧은 클릭/탭은 완료 체크를 유지한다. 포인터를 따라가는 항목 복사본과 삽입선을 표시하고 가장자리에서 본문을 자동 스크롤한다. 다른 형제 항목의 중앙을 넘을 때마다 하위 항목을 포함한 블록의 화면 순서를 즉시 바꾸며 주변 행은 탭·독과 같은 재배열 애니메이션으로 이동한다. 미리보기 순서는 패널 내부에만 유지하고 드롭 때 최신 객체에 최종 위치를 적용해 자동 저장한다. 취소하면 원래 순서로 돌아가며, 외부에서 구조가 바뀌면 이동을 취소한다. 체크 상태·본문·ID는 유지하며 드래그 뒤 합성 클릭을 차단한다. Esc·pointercancel·capture 해제·창 크기 변경·blur·화면 숨김은 이동을 취소하며 Esc가 패널 닫기로 전달되지 않는다. 입력칸과 일반 본문에서는 기존 스크롤·텍스트 선택을 유지한다.
- 체크박스에 포커스한 상태의 Alt+위/아래로도 이동한다. 드래그 중·취소·키보드 이동 때 주변 행은 공통 `useReorderAnimation`의 180ms 곡선을 사용하고 `prefers-reduced-motion`에서는 애니메이션을 생략한다.
- 36px 공통 헤더·DockGrip·확대/복원·분할 경계·독·모바일 전면 스택·Esc/뒤로가기를 공유한다. 열림 상태는 계정별 `chrome.tasksOpen`, 위치는 `tasks` dock kind로 복원한다. 모바일에서는 입력칸을 자동 포커스하지 않는다.

## 하위 항목

- 삭제 버튼 왼쪽의 `+`는 부모의 마지막 하위 항목 뒤에 빈 자식을 만들고 즉시 입력칸을 포커스한다. 중첩은 들여쓰기로 표시하며 완료는 각 객체별로 독립적이다.
- 기존 항목의 Enter·여러 줄 붙여넣기는 같은 부모를 가진 다음 형제들을 만든다. 부모의 기존 하위 항목은 원래 부모 아래에 유지한다.
- 체크박스 드래그와 Alt+위/아래는 같은 부모를 가진 형제 사이에서 이동한다. 부모를 이동하면 모든 자손을 함께 옮긴다. 다른 부모 아래로 재배치하지 않는다.
- 부모 삭제는 해당 객체만 지우고 직접 자식을 한 단계 올린다. 자손의 내용·ID·완료를 보존한다.
- 배열은 부모 다음에 자손이 연속되는 전위 순서다. 서버는 중복·순환·없는 부모·분리된 자손을 거부하며 변경 묶음 전체에 대해 검증한다. `parentId` 변경도 독립 필드로 충돌 검사·재시도한다.

## 날짜 입력과 자체 달력

- 항목별 `startDate`는 시작일, 기존 `date`는 종료일이다. 둘 다 시간대 없는 `YYYY-MM-DD`이며 생략/null은 날짜 없음이다. 양 끝을 포함하고 하나만 지정하면 그날 하루 일정으로 표시한다. 시작일이 종료일보다 늦어지면 다른 끝도 선택한 날짜로 맞추며 서버는 역전된 기간을 거부한다. 기존 목록을 변환하지 않고 읽는다. 날짜는 부모/자식에 전파하지 않으며 이동·내용 분할에서도 원래 객체의 날짜를 유지한다. 목록의 새 형제/자식은 날짜 없이 시작하고 달력에서 생성·분할·붙여넣은 항목은 선택 날짜의 하루 일정으로 시작한다.
- `DateField`는 하나의 텍스트 입력에서 `0000-00-00` 마스크를 항상 유지하고 연·월·일 구간을 각각 선택한다. 선택한 구간의 숫자만 교체하며 연 4자리·월/일 2자리를 채우면 다음 구간으로 이동한다. 모바일은 숫자 키보드(`inputMode=numeric`)와 native beforeinput을 처리한다.
- 구간 클릭, 오른쪽/아래 방향키·Tab·Enter로 연→월→일을 이동한다. 왼쪽/위 방향키·Shift+Tab은 이전 구간, Home/End는 연/일을 선택한다. 일에서 Tab은 확정 후 다음 요소로, Enter/오른쪽/아래는 확정 후 달력 버튼으로 이동한다. 한 자리 월/일은 앞에 0을 붙인다. 탐색만으로 값이 바뀌지 않는다.
- 마지막 일 두 자리 입력·일 구간 확정·blur에 실제 날짜를 검증하고 자동 저장한다. 완성 전이나 없는 날짜는 입력과 오류를 남기며 기존 저장 날짜를 유지한다. Backspace/Delete는 현재 구간을 비우고, 빈 구간의 Backspace는 이전 구간을 비운다. 전체 선택 후 삭제는 모든 구간을 비우며 확정 시 날짜를 해제한다. Esc는 입력을 현재 저장 값으로 복원한다. IME 조합 중 구간 이동·확정은 무시한다.
- 전체 날짜 붙여넣기는 네 자리 연도를 포함한 `YYYY-MM-DD`·점/슬래시 구분·`YYYYMMDD`를 받아 고정 마스크로 표시한다. 숫자만의 구간 붙여넣기는 현재 구간부터 채운다. 구분자는 직접 수정하지 않으며 문자 입력은 받지 않는다.
- 달력 버튼 또는 입력칸 Alt+아래는 공용 자체 달력을 연다. 선택일의 월 또는 오늘의 월을 보여주고 이전/다음 달, 인접 달 날짜, 오늘/내일, 날짜 지우기를 지원한다. 선택일은 액센트 원으로, 오늘은 작은 점으로 구별한다. 요일/월/전체 날짜 접근성 이름은 선택 언어의 `Intl` 형식을 쓴다.
- 달력은 `dialog`·`grid`·`gridcell`과 날짜별 접근성 이름·선택·오늘 상태를 제공한다. 열 때 선택일/오늘 버튼에 포커스하며 방향키는 일/주, Home/End는 주의 처음/끝, PageUp/Down은 월, Shift+PageUp/Down은 연도를 이동한다. 이동만으로 저장하지 않고 Enter/Space/클릭으로 확정한다.
- 선택·닫기·Esc·뒤로가기 후 달력 버튼으로 포커스를 돌린다. 외부 클릭/Tab 이탈은 달력만 닫고 다음 요소 포커스를 유지한다. `useOverlayDismiss`로 패널보다 달력이 먼저 닫힌다. 달력은 body portal과 visual viewport 배치·내부 스크롤로 작은 화면과 키보드 변화에 대응한다. 모바일에서는 텍스트 입력을 자동 포커스하지 않는다.
- 달력은 기존 밝은/어두운 테마의 surface/ink/accent 토큰을 사용한다. 월 변경의 짧은 이동은 모션 감소 설정에서 생략한다. 태스크 행의 날짜 상태를 클릭하면 두 줄 일정 팝오버에서 날짜를 편집한다. 읽기 전용에서는 날짜 입력은 readonly이고 달력 버튼을 표시하지 않는다.
- 서버는 실제 달력 날짜와 네 자리 연도(0001–9999)를 검사한다. `startDate`·`date`는 각각 내용·완료·부모와 별개의 필드로 병합·충돌 검사·재시도한다. 별개 날짜 변경의 병합 결과가 역전된 기간이면 묶음 전체를 충돌로 처리한다. 날짜 저장 실패도 기존 초안/다시 저장 경로를 따른다. 유효하지 않은 텍스트 입력은 해당 입력칸의 편집 상태에만 남는다.

## 목록·달력·간트 보기

- 36px 타이틀바의 목록·달력·간트 탭으로 보기를 전환하며 같은 세션의 객체·완료 상태·기간을 편집한다. 보기 전환 시 입력 중인 새 태스크를 확정한다. 탭은 `tablist`·`tab`·`tabpanel`로 연결하고 좌우 방향키·Home/End로 선택과 포커스를 이동한다. 하단 독의 왼쪽 스와이프는 다음 보기, 오른쪽 스와이프는 이전 보기를 선택하며 양 끝에서 순환한다. App의 현재 작업 탭 전환 신호에 참여하고 패널은 열린 상태를 유지한다. 기존 날짜만 있는 목록은 변환 없이 하루 일정으로 표시한다.
- 달력은 위쪽에 일요일부터 시작하는 6주 월간 격자, 아래쪽에 선택 날짜의 일정을 표시한다. 시작일부터 종료일까지 매일 표시하고 완료 일정도 포함한다. 날짜 없는 항목과 간트의 부모 요약은 달력 일정에 추가하지 않는다. 날짜별 상태 점·일정 개수, 이전/다음 달·오늘, 선택·오늘 표시를 제공한다.
- 달력에서 방향키·Home/End·PageUp/Down으로 선택일과 월을 이동한다. 하단에서 내용·완료·시작일·종료일을 편집하거나 삭제하고 새 태스크를 입력할 수 있다. 새 태스크·형제·하위 항목·여러 줄 붙여넣기의 기간은 선택한 날짜 하루로 시작하며 선택일 목록 안에서 키보드 포커스를 이동한다.
- 간트의 UTC 일수 계산·눈금 간격·SVG 격자·44px 행·22px 막대·그라데이션·부모 합집합 색·포인터 조작은 워크스페이스 `gantt-maker/src/lib/date.ts`, `model.ts`, `rollup.ts`, `components/GanttSvg.tsx`, `App.tsx`에서 가져와 Mew 객체와 테마 토큰에 맞췄다. 별도 저장소나 새 패키지 의존성을 만들지 않는다.
- 간트의 왼쪽 고정 목록과 위쪽 고정 눈금은 본문과 함께 스크롤한다. 완료는 초록, 계획은 파랑, 종료일이 지난 미완료 일정은 빨강이다. 명시적 기간이 없는 부모는 여러 단계 자손의 일정 합집합을 색 평균으로 표시한다. 부모가 자체 기간을 가지면 그 기간을 표시하며 자손의 날짜를 바꾸지 않는다.
- 선택 모드의 막대 드래그는 기간 이동, 양 끝 손잡이는 하루 단위 길이 변경이다. 터치의 빈 공간 드래그는 스크롤이며 막대·손잡이·눈금·그리기 영역만 기본 터치 스크롤을 막는다. 그리기 모드에서는 기존 행에 기간을 설정하고 마지막 점선 행에 새 태스크를 만든다. 한 객체당 기간 하나를 유지한다.
- 드래그 미리보기는 화면에만 존재하고 놓을 때 최신 객체의 날짜만 저장한다. Esc·포인터 취소·캡처 해제·blur·크기 변경·화면 숨김·쓰기 권한 해제·대상 날짜의 외부 변경은 미리보기를 취소한다. 내용·완료 등 다른 필드는 보존한다.
- 막대 클릭·터치·우클릭·키보드 Enter/Space 또는 왼쪽 이름을 선택하면 화면 경계 안의 편집 카드에서 내용·완료·기간을 바꾸고 일정 날짜만 지울 수 있다. 키보드로 열면 카드의 닫기 버튼으로 포커스를 옮겨 터치 키보드를 자동으로 열지 않고, 닫기·Esc 후 원래 막대/이름 버튼으로 돌려준다. DateField 달력은 카드 위에서 먼저 닫힌다. 키보드 좌/우는 하루 이동, Shift+좌/우는 종료일, Alt+좌/우는 시작일 변경이다.
- 확대·축소·전체 기간·오늘 버튼과 Ctrl/Command+휠·트랙패드 핀치를 지원한다. 눈금을 좌우로 끌면 이동, 위로 끌면 축소, 아래로 끌면 확대한다. 읽기 전용은 세 뷰 모두 열람·날짜 탐색·확대만 허용한다.
- 네 언어의 라벨·월·요일·접근성 이름과 기존 밝은/어두운 테마를 사용한다. 원본 앱의 다중 기간·취소 상태·일정 분할·독립 JSON/이미지 내보내기는 Mew 태스크 모델에 추가하지 않는다.

## 저장과 동시 수정

- `DATA_DIR/task-list-<루트 절대경로 SHA-256>.json`에 `{version: 1, tasks}`를 원자 저장한다. 루트별로 공유하며 하위 프로젝트 탭을 바꿔도 같은 목록을 사용한다. 이전 `project-tasks-*.json`·개인 홈 todos·공통 메모 파일은 읽거나 변경하지 않는다. 2026-10-03 사용자 요청으로 새 단순 태스크 패널을 제공하며 [제거 전 기록](../history/project-tasks.md)은 이력으로 유지한다.
- `GET /api/task-list?workspace=<현재 루트>` → `{tasks, canEdit}`. `PATCH /api/task-list`는 `{workspace, changes}`를 받으며 같은 보드 형식을 반환한다. 요청의 `X-Mew-Task-Owner`는 URL 인코딩한 로그인 이메일로 세션과 일치해야 한다.
- 변경은 `{id, before, after, afterId, move?}`다. `before=null`은 생성, `after=null`은 삭제, 둘 다 객체이면 필드 변경이다. 생성 위치는 `afterId` 뒤이며 null이면 맨 앞이다. 기존 객체에 `move=true`이면 필드 변경과 별개로 해당 객체를 `afterId` 뒤로 이동한다. 객체를 재생성하지 않는다. 같은 PATCH에서 생성·삭제·이동·내용 변경을 함께 처리한다.
- 이동은 현재 서버의 객체 내용을 유지하고 앵커를 기준으로 적용한다. 다른 창의 내용·완료 수정과 병합하며 새 객체를 없애지 않는다. 동시에 순서를 바꾸면 나중에 저장된 이동의 앵커가 적용된다. 사라진 객체·앵커는 기존 충돌 경로를 따른다. 응답 유실 재시도는 같은 이동을 중복 생성하지 않는다.
- 서버는 현재 객체와 `before`를 비교한다. 다른 ID·다른 필드의 수정은 합치고, 변경할 필드가 이미 `after`이면 성공으로 취급한다. 같은 필드의 상충하는 수정·수정된 객체의 삭제·사라진 삽입 위치는 409다. 전체 변경 묶음을 검사한 뒤 한 번 저장해 일부만 반영하지 않는다. 저장 실패와 손상 파일을 빈 목록으로 덮어쓰지 않는다.
- 로그인과 루트 전체 파일 열람 권한이 필요하고, 쓰기는 전체 파일 편집 권한도 요구한다. 읽기만 허용된 계정은 목록만 볼 수 있다. 계정·현재 루트 불일치는 409, 권한 부족은 403, 잘못된 입력은 400, 저장/읽기 실패는 500이다. guest와 임시 비밀번호 계정은 기존 HTTP 인증 경계에서 차단한다.
- 최대 2,000개, 내용은 항목당 8,000자, ID는 영문·숫자·밑줄·하이픈 1–100자다. 빈 내용은 줄 나누기 도중의 독립 항목으로 허용하며 자동 생성하지 않는다. 중복 ID·형식 오류를 거부하고 저장 속성은 id/text/done/parentId/startDate/date만 유지한다. 부모가 없는 이전 평면 목록은 그대로 읽는다.

## 클라이언트 수명과 오류

- `useTaskList`는 App에서 루트·계정별 `TaskListSession`을 유지한다. 입력은 즉시 반영하고 마지막 입력 후 350ms 또는 기존 항목의 blur에 저장한다. 패널 닫기·도킹 재마운트는 세션과 대기 중 저장을 유지한다. 프로젝트가 바뀌면 이전 요청은 서버의 workspace 검사로 막고 이전 초안은 해당 세션에 남긴다.
- 쓰기 응답·조회 중 추가 입력은 로컬 변경으로 다시 합쳐 보존한다. 패널이 열린 동안 3초 간격과 브라우저 복귀 시 조회하며, 로컬 변경·진행 중 저장·오류가 있으면 주기 조회로 입력을 교체하지 않는다. 메모의 Yjs 공동 편집과 별개의 객체 API다.
- 미저장 변경과 마지막 입력 초안은 `mew:task-draft:<이메일>:<루트>:<창 ID>`로 브라우저에 보관한다. 창 ID는 sessionStorage에 유지해 같은 계정의 다른 창이 초안 보관값을 지우지 않게 한다. 서버 저장 후 해당 변경은 정리하며 새로고침 후 초안이 남으면 서버 조회 결과에 다시 합친다. 저장 공간이 부족해도 현재 페이지의 초안은 유지한다.
- 실패 시 입력과 오류·다시 저장 버튼을 유지한다. 사용자가 다시 저장하면 최신 서버 목록을 읽고 로컬에서 바꾼 필드만 다시 적용한다. 같은 필드의 충돌에서 다시 저장은 확인한 로컬 내용을 적용하는 명시적 동작이다. 계정 변경 시 이전 계정의 세션 타이머를 중지한다.

### 태스크 행 날짜 표시

목록·달력의 태스크 행은 + 버튼 왼쪽에 날짜 상태를 표시한다. 브라우저 현지 날짜보다 `startDate`가 미래이면 회색 `시작 전`을 우선 표시한다. 시작일이 오늘·과거이거나 없으면 `date`까지 남은 날짜 수를 `D-n`, 오늘은 `D-Day`, 지난 날짜 수는 빨간색 `D+n`으로 표시한다. 완료 체크 여부는 이 날짜 계산을 바꾸지 않는다. 완료일이 없으면 회색 `날짜 설정`으로 표시한다. 일수는 시간대 없는 달력 날짜 연산으로 계산하며 열린 화면도 30초마다, 창 포커스·가시성 변경 때 오늘을 갱신한다.

날짜 상태 버튼은 클릭·Enter·Space로 일정 편집 팝오버를 연다. `시작일 YYYY-MM-DD [달력]`, `완료일 YYYY-MM-DD [달력]` 두 줄에서 공용 DateField로 입력·선택·삭제한다. 저장 값은 기존 `startDate`·`date`를 유지한다. 팝오버는 body portal로 표시하고 스크롤·크기·visual viewport 변화에 위치를 맞춘다. 입력을 자동 포커스하지 않는다. 외부 클릭·Esc·뒤로가기로 닫으며 내부 포커스는 상태 버튼에 복원한다. 중첩된 날짜 달력은 먼저 닫힌다.

### 목록 기본 정렬

목록 보기의 형제 항목은 `날짜 설정 → D-Day → D-n → D+n → 시작 전` 순서로 표시한다. 같은 상태 그룹은 기존 저장 순서를 유지하고 숫자 n으로 추가 정렬하지 않는다. 부모·자손 블록을 보존하며 각 부모의 하위 항목에도 같은 순서를 적용한다. 완료 체크 여부는 순위를 바꾸지 않는다. 날짜 편집·현지 날짜 변경 때 표시 순서를 다시 계산하며 단순 정렬은 저장하지 않는다. 드래그·Alt+위/아래는 표시 순서를 기준으로 저장하며 같은 상태 그룹 안의 수동 순서를 유지한다. 서로 다른 상태 그룹은 기본 정렬 우선순위를 따른다. 입력칸 위/아래 이동도 표시 순서를 따른다. 달력·간트의 순서는 바꾸지 않는다.

---
title: "mewnager 폐기 안내"
description: "폐기한 Windows WSL 관리 앱의 기존 링크를 이력과 Windows 네이티브 실행 계약으로 연결한다."
updated: "2026-10-14"
---

mewnager는 2026-10-14 폐기했습니다. 앱 소스·빌드·CI를 제거하고 공통 mew CLI와 Windows 네이티브 실행 계층으로 방향을 통일합니다. 기존 PC의 WSL 배포판·프로젝트·계정은 삭제하지 않습니다.

현재 구현과 검증·발행 조건은 [Windows 네이티브](../development/windows-native.md)를 따릅니다. 전체 Windows 실기 검증과 첫 공개 발행은 아직 남아 있습니다.

이전 내용은 [역사 자료](../history/windows-manager-development.md), 결정은 [ADR 0210](../history/decisions/0210-mew-retire-mewnager.md)에 보존합니다.

# mew.saens.kr 계정 기반 P2P 원격 접속 설계

[진행 작업](_work.md) · [문서 지도](../MOC.md)

설계 본문과 구현·출시 확인 기준은 [mew 중계 기능 만들기](../tasks/mew%20%EC%A4%91%EA%B3%84%20%EA%B8%B0%EB%8A%A5%20%EB%A7%8C%EB%93%A4%EA%B8%B0.md)에서 관리한다. 서버의 최초 등록, 브라우저 계정 로그인, 중앙 인증·시그널링과 직접 WebRTC 데이터 전송, 보안 경계와 연결 실패 조건을 포함한다.

**상태: 핵심 P2P 전송·관리 UI 구현 및 로컬 자동 검증 완료 · 미배포·외부망 검증 대기.** 결정 근거는 [ADR 0195](../../../.mew/docs/decisions/0195-mew-account-based-p2p-remote-access.md)를 따른다.

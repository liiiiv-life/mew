## 요구사항

- 반복 사용하는 런타임·모델·노력도·역할을 프리셋으로 저장해 탭을 연다.
- 패널처럼 모델과 지원 노력도를 따로 선택한다. Codex는 정확한 모델·노력도 쌍을 모델 ID에 저장하고, 다른 런타임은 ACP 노력도 설정을 별도로 저장한다.
- 모델 이름·ID를 검색해 런타임별 후보 드롭다운에서 선택하고, 목록에 없는 ID도 직접 입력한다.

### 범위

- 에이전트셋 생성·편집·선택과 프로젝트별 탭·탭 이름 관리를 제공한다.
- `Ctrl/Cmd+1…9`와 이전·다음 탭 단축키로 전환하면 선택한 탭으로 키보드 포커스도 옮긴다. 이어서 `Ctrl/Cmd+W`를 누르면 같은 에이전트 그룹의 활성 탭을 닫는다. 닫기는 새 탭·복원과 같은 마지막 pointerdown·focusin 대상을 사용하므로, 에이전트 빈 영역을 선택한 뒤 에디터에 실제 포커스가 남아 있거나 body로 빠져도 에디터 탭을 닫지 않는다. 숨김·inert·제거된 대상과 모달·IME·반복 입력에서는 닫지 않는다.
- 에이전트 패널에서 `Ctrl/Cmd+N`·`Ctrl/Cmd+T`·`Alt+N`(설정에서 재지정한 새 파일 단축키 포함)을 누르면 해당 그룹의 `+`와 같은 런타임·에이전트셋 선택 화면을 연다. 대화 입력·탭 줄·분리된 패널과 CLI TUI에서도 동작하며, 에디터·사이드바에서는 기존 새 파일 이름 입력을 연다. 모달·IME 조합·키 반복 중에는 새 탭을 열지 않는다. 브라우저 예약키의 전체화면 조건은 [공통 단축키 계약](../../development/ui-contracts.md#포커스-기반-탭-단축키)을 따른다.
- `Ctrl/Cmd+Shift+T`는 현재 루트의 에이전트 패널에서 최근 닫은 탭부터 다시 연다. 이름·런타임·작업 폴더·에이전트셋·탭 순서와 ACP 대화 ID를 보존하며, 저장된 대화가 있으면 기존 복원 흐름으로 이어 쓴다. TUI는 같은 설정의 새 프로세스를 연다. 빈 패널·분리된 패널·대화 입력·탭 줄에서도 동작한다.
- 닫힌 기록이 없거나 모달·IME·키 반복 중이면 복원하지 않는다. 작업 중 닫기 확인을 취소하거나 패널만 숨긴 경우는 기록하지 않는다. 기록은 현재 화면의 메모리에 최대 50개를 보관하며 터미널과 별도로 최근 항목을 고른다. 새로고침·루트/계정 전환 시 비운다.
- 에이전트 탭이 없으면 `+` 선택 화면으로 바로 시작한다.
- 기존 탭은 복원하고 런타임·셋 선택 후에만 새 탭을 만든다.
- `+` 런타임 목록은 설치된 항목 자체를 눌러 연다. 설치 버튼은 오른쪽 설정 아이콘 바로 왼쪽에 둔다.
- Git의 AI Commit에서도 기존 셋을 선택하거나 새로 생성해 작업 단위 자동 커밋에 사용한다.

### 경계와 제한

- 셋은 런타임·모델·노력도·역할 프리셋이며 자동 작업 원장이나 기능 분류 규칙의 소유자가 아니다.
- 새 탭은 cwd 검증과 사용자 선택이 끝난 뒤 생성한다.
- AI Commit은 셋의 스냅샷을 별도 작업으로 실행하며 기존 대화·탭에 요청을 보내지 않는다.

## 구현 내용

- 닫기 완료 시 탭 스냅샷·도킹 그룹·순서를 기억한다. 복원은 원래 그룹이 남아 있으면 그 그룹에, 없으면 현재 같은 종류의 그룹에 삽입하고 활성화한다. 새 호스트 ID를 사용해 기존 세션 종료·비동기 캐시 삭제가 복원된 탭에 영향을 주지 않게 한다.

- 공통 `AgentTabBar`의 제목·아이콘·탭 여백을 더블클릭(모바일은 더블탭)하면 해당 탭 이름을 편집한다. F2도 같은 입력을 열며 닫기 버튼·이름 입력칸의 더블클릭은 편집을 다시 열지 않는다. 데스크톱 최대화·복귀는 패널 이동 손잡이 더블클릭으로 실행한다.

- 공통 `AgentTabBar`의 우클릭 또는 Shift+F10으로 이름 변경·탭 닫기·데스크톱 탭 최대화/원래 크기로 복귀 메뉴를 연다. 최대화는 대상 탭을 선택한 뒤 해당 패널을 확대하며, 닫기는 기존 세션 종료·확인 흐름을 사용한다. 모바일에는 최대화 항목을 표시하지 않는다. 메뉴 외형과 배치·닫기는 파일탐색기와 공유하는 `ActionMenu`를 사용하며 각 항목은 Iconoir 아이콘과 번역된 텍스트를 표시한다.

- `RuntimePicker`는 별도 사용 버튼 없이 행 전체의 네이티브 버튼으로 클릭·Enter·Space 선택을 제공한다. 설치·설정 버튼은 독립된 형제 요소로 처리해 탭 선택과 겹치지 않는다.
- 런타임 선택은 공통 자체 드롭다운으로 제공하고, 목록을 닫아도 생성·편집 폼을 유지한다.
- 모델은 공용 `SelectField`의 편집 모드로 검색·선택한다. 런타임을 바꾸면 모델 ID를 비우고 새 목록을 조회하며, 늦게 도착한 이전 런타임 응답은 반영하지 않는다. 조회 실패에는 번역된 오류·재시도를 제공하고 기존 값과 직접 입력을 보존한다. 빈 모델은 런타임 기본값을 사용한다.

- Codex 모델 후보는 패널과 같은 공통 분리 함수를 사용해 묶고, 선택 모델의 지원 노력도만 표시한다. 모델 변경 시 기존 노력도를 유지할 수 없으면 medium 또는 첫 후보를 선택한다. 다른 런타임은 ACP thought_level 선택지·설정 ID를 모델 조회와 함께 전달하고 탭·예약·기능 작업·AI Commit 실행 전에 적용한다. 런타임 변경은 모델과 노력도를 함께 초기화한다.
- 에이전트셋 생성·편집·선택과 프로젝트별 탭·탭 이름 관리를 제공한다.
- AI Commit에서도 같은 선택기와 생성 폼을 재사용하고 신규 셋 저장 후 바로 선택한다.
- 조작은 [Git 사용법](../../guides/projects.md#git-작업-패널)을 따른다.
- 생성·편집 폼은 공통 모달의 포커스·닫기 동작을 사용하고 저장 오류를 폼 안에서 표시한다.
- 저장 중 중복 제출을 막으며 일반 HTTP에서도 셋 ID를 생성한다.

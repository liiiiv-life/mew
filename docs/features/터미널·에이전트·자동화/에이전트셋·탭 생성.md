## 요구사항

- 반복 사용하는 런타임·모델·노력도·역할을 프리셋으로 저장해 탭을 연다.
- 패널처럼 모델과 지원 노력도를 따로 선택한다. Codex는 정확한 모델·노력도 쌍을 모델 ID에 저장하고, 다른 런타임은 ACP 노력도 설정을 별도로 저장한다.
- 모델 이름·ID를 검색해 런타임별 후보 드롭다운에서 선택하고, 목록에 없는 ID도 직접 입력한다.

### 범위

- 에이전트셋 생성·편집·선택과 프로젝트별 탭·탭 이름 관리를 제공한다.
- 에이전트 패널에서 `Alt+N`(설정에서 재지정한 새 파일 단축키 포함)을 누르면 해당 그룹의 `+`와 같은 런타임·에이전트셋 선택 화면을 연다. 대화 입력·탭 줄·분리된 패널과 CLI TUI에서도 동작하며, 에디터·사이드바에서는 기존 새 파일 이름 입력을 연다. 모달·IME 조합·키 반복 중에는 새 탭을 열지 않는다.
- 에이전트 탭이 없으면 `+` 선택 화면으로 바로 시작한다.
- 기존 탭은 복원하고 런타임·셋 선택 후에만 새 탭을 만든다.
- `+` 런타임 목록은 설치된 항목 자체를 눌러 연다. 설치 버튼은 오른쪽 설정 아이콘 바로 왼쪽에 둔다.
- Git의 AI Commit에서도 기존 셋을 선택하거나 새로 생성해 작업 단위 자동 커밋에 사용한다.

### 경계와 제한

- 셋은 런타임·모델·노력도·역할 프리셋이며 자동 작업 원장이나 기능 분류 규칙의 소유자가 아니다.
- 새 탭은 cwd 검증과 사용자 선택이 끝난 뒤 생성한다.
- AI Commit은 셋의 스냅샷을 별도 작업으로 실행하며 기존 대화·탭에 요청을 보내지 않는다.

## 구현 내용

- `RuntimePicker`는 별도 사용 버튼 없이 행 전체의 네이티브 버튼으로 클릭·Enter·Space 선택을 제공한다. 설치·설정 버튼은 독립된 형제 요소로 처리해 탭 선택과 겹치지 않는다.
- 런타임 선택은 공통 자체 드롭다운으로 제공하고, 목록을 닫아도 생성·편집 폼을 유지한다.
- 모델은 공용 `SelectField`의 편집 모드로 검색·선택한다. 런타임을 바꾸면 모델 ID를 비우고 새 목록을 조회하며, 늦게 도착한 이전 런타임 응답은 반영하지 않는다. 조회 실패에는 번역된 오류·재시도를 제공하고 기존 값과 직접 입력을 보존한다. 빈 모델은 런타임 기본값을 사용한다.

- Codex 모델 후보는 패널과 같은 공통 분리 함수를 사용해 묶고, 선택 모델의 지원 노력도만 표시한다. 모델 변경 시 기존 노력도를 유지할 수 없으면 medium 또는 첫 후보를 선택한다. 다른 런타임은 ACP thought_level 선택지·설정 ID를 모델 조회와 함께 전달하고 탭·예약·기능 작업·AI Commit 실행 전에 적용한다. 런타임 변경은 모델과 노력도를 함께 초기화한다.
- 에이전트셋 생성·편집·선택과 프로젝트별 탭·탭 이름 관리를 제공한다.
- AI Commit에서도 같은 선택기와 생성 폼을 재사용하고 신규 셋 저장 후 바로 선택한다.
- 조작은 [Git 사용법](../../guides/projects.md#git-작업-패널)을 따른다.
- 생성·편집 폼은 공통 모달의 포커스·닫기 동작을 사용하고 저장 오류를 폼 안에서 표시한다.
- 저장 중 중복 제출을 막으며 일반 HTTP에서도 셋 ID를 생성한다.

## 검증

- 아래 항목은 이번 정리에서 실행한 테스트 결과가 아닌 사용자 확인 기준이다:
  - 설치된 런타임 행의 클릭·Enter·Space로 탭이 열리고, 설치·설정 버튼은 각 동작만 실행하는지 확인한다.
  - Codex 모델·노력도 분리 선택, 지원 노력도 제한, 저장 후 재편집과 다른 런타임의 노력도 저장·적용을 확인한다.
  - 모델 이름·ID 검색, 키보드·터치 선택, 기본 모델·직접 입력, 런타임 변경과 조회 실패 후 재시도가 동작하는지 확인한다.
  - 셋을 수정해도 이미 접수한 기능 요청의 스냅샷이 바뀌지 않고 새 탭에만 원하는 설정이 적용되는지 확인한다.

- 2026-09-28: 격리 Chromium의 1100px 다크·390px 라이트에서 모델 이름·ID 검색, 키보드·클릭 선택, 기본 모델, 런타임 변경 시 초기화, 조회 실패·재시도 중 입력 보존과 정확한 모델 ID 저장을 확인했다. 모델 조회 권한·잘못된 런타임 거부, 모의 ACP 목록 조회 후 프로세스 종료·캐시 재사용, 타입·번역·문서 검사도 통과했다. 실제 공급자 계정의 목록 조회는 실행하지 않았다.

- 2026-09-30: 격리 Chromium의 1100px 다크·390px 라이트에서 Codex 모델·노력도 분리, 모델 변경에 따른 지원 노력도 전환, 정확한 쌍 저장·재편집, Claude ACP 노력도 저장을 확인했다. 셋 정규화와 예약 실행 전 모델·노력도 적용 순서 테스트를 추가했다. 실제 공급자 계정 연결은 실행하지 않았다.

- 2026-10-07: `server/agent-new-tab-ui.test.ts`의 격리 Chromium 1100px·390px, 밝은·어두운 테마에서 대화 입력·탭 줄·선택기의 새 탭 단축키, 재지정, 런타임 선택 후 탭 생성, 모달·키 반복·IME 차단과 에디터·사이드바 파일 생성 폴백을 확인했다. 기존 탭 닫기 UI와 중첩 단축키 표면 테스트, 타입·린트·문서 검사도 통과했다(린트는 기존 경고 포함).

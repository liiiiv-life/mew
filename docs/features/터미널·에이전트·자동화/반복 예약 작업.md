## 요구사항

- 설정한 폴더와 에이전트셋의 런타임·모델·역할로 프롬프트 작업을 주기적으로 실행한다.

### 범위

- 예약 작업 등록·수정·삭제·지금 실행과 전용 세션 출력 확인을 제공한다.
- 팝업 오른쪽 위 X 버튼으로 닫을 수 있다.

### 경계와 제한

- 에이전트 탭의 일회성 예약 메시지와 별개다.
- 실행 간격이 작업 시간보다 짧을 때 같은 세션에 입력되는 현재 제한과 로그 관리 규칙을 따른다.

### 상세 계약

- [명령·예약 작업](../../guides/commands.md)

- 상위: [분야 지도](MOC.md) · [상위 기능](_%ED%84%B0%EB%AF%B8%EB%84%90%C2%B7%EC%97%90%EC%9D%B4%EC%A0%84%ED%8A%B8%C2%B7%EC%9E%90%EB%8F%99%ED%99%94.md).

## 구현 내용

- 제목 오른쪽에 공통 X 아이콘·번역된 접근성 이름·툴팁을 제공하며, 저장 중에는 기존 닫기 경로와 같이 비활성화한다.
- 목록은 실행 시각을 제목 왼쪽에 크게 표시하고 반복 주기·에이전트셋·프로젝트·마지막 실행을 제목 아래에 배치한다. 고정 시각이 없는 예약은 왼쪽에 실행 주기 또는 크론식을 표시한다. 팝업·항목·편집 필드 사이 여백을 작게 유지한다.
- 실행 주기·에이전트셋·프로젝트 선택은 공통 자체 드롭다운이며 선택 결과는 저장 전까지 초안으로 유지한다.
- 입력·선택·요일·하단 버튼은 44px 높이를 사용한다. 이름과 작업 내용은 전체 너비, 셋·프로젝트는 데스크톱 2열·모바일 1열로 정렬한다.
- 실행 주기의 직접 입력 모드는 현재 크론식이 일반 주기와 같아도 유지한다.
- 예약 저장 시 서버의 에이전트셋을 스냅샷으로 보관해 반복 실행과 지금 실행에 같은 모델·역할을 적용한다. 셋 변경은 예약을 다시 저장할 때 반영하며, 삭제된 셋의 기존 스냅샷과 이전 런타임 전용 예약은 유지한다. 새 예약에는 에이전트셋 선택이 필수다.

- 예약 작업 등록·수정·삭제·지금 실행과 전용 세션 출력 확인을 제공한다.

## 검증

- 사용자 확인 기준: 오른쪽 위 X로 팝업이 닫히고 저장 중에는 비활성화되는지 확인한다.
- 사용자 확인 기준: PC·모바일에서 왼쪽 실행 시각과 제목 아래 정보가 읽히고 긴 프로젝트명·크론식이 화면 밖으로 넘치지 않는지 확인한다.
- 2026-10-03: 격리 Chromium의 1100px 다크·390/320px 라이트에서 목록·편집 화면을 확인하고, 기존 드롭다운·초안·저장 중 비활성화·모바일 넘침 회귀 검사를 통과했다. 대상 린트와 디자인 검출 검사도 통과했다.
- 아래 항목은 이번 정리에서 실행한 테스트 결과가 아닌 사용자 확인 기준이다:
  - 에이전트셋 선택·저장·재열기와 셋이 없는 상태, 긴 프로젝트 이름의 모바일 배치, 모든 실행 주기의 입력 높이를 확인한다.
  - 예약과 수동 실행이 같은 설정을 사용하고 무관한 사용자 crontab 항목을 보존하는지 확인한다.

- 2026-09-28: 격리 Chromium의 1100px 다크·390/320px 라이트에서 필드 높이, 키보드·터치 선택, 저장 전 초안, 저장 중 비활성화, 직접 입력, 셋이 없는 새 예약과 삭제된 셋의 표시를 확인했다. 서버 테스트로 스냅샷 저장·파일 정리·기존 예약 보존·모델과 역할 전달·모델 실패 시 실행 중단을 검증했다. 타입·번역·문서 검사를 통과했으며 실제 크론 등록·공급자 호출은 실행하지 않았다.

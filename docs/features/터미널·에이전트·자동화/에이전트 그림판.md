에이전트에게 도형·텍스트·스크린샷 위 주석으로 맥락을 설명하는 벡터 편집기다. 입력칸 안 오른쪽 아래의 **그림판 열기** 아이콘이나 입력칸의 `Ctrl/Cmd+Alt+D`로 연다. **저장**하면 재편집할 SVG 기록을 남기고, 같은 그림을 PNG 첨부로 현재 입력에 넣는다. 메시지 전송은 기존 전송 버튼으로 한다.

## 범위와 진입

그림판은 팝업 안에서 단독으로 편집한다. 실시간 공동 편집·다른 기기와의 편집 상태 동기화는 제공하지 않는다. 새 메시지와 대기 큐 편집에서 같은 그림판을 사용하며, 저장한 PNG는 그림판을 열었던 입력에 붙는다. CLI 명령 모드와 첨부 업로드 중에는 그림판을 열 수 없다.

저장하지 않은 변경이 있으면 닫기 전에 **계속 편집 / 닫기**를 고른다. 저장 중에는 중복 저장과 닫기를 막는다. 루트 프로젝트를 전환하거나 패널을 숨기면 그림판을 닫고, 늦게 끝난 저장·업로드를 다른 프로젝트나 다른 큐 메시지의 첨부로 연결하지 않는다. 일반 첨부의 미리보기·삭제·전송은 [입력·첨부 계약](에이전트%20입력·멘션·스킬·첨부.md)을 따른다.

## 작업 영역과 격자

캔버스의 너비·높이를 미리 정하지 않고 작업 영역을 이동하며 그린다. 원점 `(0, 0)`은 십자와 축으로 표시한다. X는 오른쪽, Y는 아래쪽이 양수이며 단위는 작업 좌표의 px다. 화면 확대는 이 좌표값을 바꾸지 않는다.

**원점으로** 또는 `0`은 현재 확대 비율로 원점을 화면 중앙에 놓는다. `Ctrl/Cmd+0`은 원점 중앙·100%로 복귀한다. `1`은 모든 개체, `2`는 선택한 개체에 화면을 맞춘다. 확대 범위는 5~1600%다. 휠은 화면 이동, `Ctrl/Cmd/Alt+휠`은 포인터를 기준으로 확대·축소한다. 이동 도구·Space+드래그·가운데 버튼 드래그와 두 손가락 이동·핀치도 사용한다.

격자는 기본 20px이며 표시와 스냅을 각각 켜고 끈다. **그리드 설정**에서 간격을 2~1000px로 바꾼다. 개체 생성·이동·크기 조절과 펜의 새 점을 격자에 맞추며, Alt를 누르는 동안 스냅을 해제한다. 축소했을 때 격자 점이 너무 촘촘하면 표시 간격만 넓힌다. 저장 이미지에는 격자·원점·선택 표시를 넣지 않는다.

## 그리기와 이미지

| 도구 | 조작 |
| --- | --- |
| 직사각형 `R` | 드래그로 두 꼭짓점을 정한다. Shift를 누르면 정사각형으로 만든다. |
| 타원 `O` | 드래그로 바깥 사각형을 정한다. Shift를 누르면 원으로 만든다. |
| 직선 `L` | 시작점에서 끝점까지 드래그한다. Shift를 누르면 45° 단위로 방향을 맞춘다. |
| 곡선 펜 `P` | 클릭으로 점을 추가하고, 누른 채 드래그해 곡선의 방향 핸들을 만든다. Enter·더블 클릭·**곡선 완성**으로 끝낸다. 세 점 이상에서 첫 점을 누르면 닫힌 경로로 완성한다. |
| 텍스트 `T` | 원하는 위치를 누르고 여러 줄을 입력한다. 바깥 클릭·Esc·Ctrl/Cmd+Enter로 입력을 마치고, 텍스트를 더블 클릭해 다시 편집한다. |

클립보드의 스크린샷·이미지를 붙여넣거나 파일을 캔버스로 드롭하면 이미지 개체를 만든다. PNG·JPEG·WebP·GIF·AVIF를 받고 파일 하나는 20 MiB까지 추가한다. 처음 놓을 때 긴 변의 표시 크기를 최대 1600px로 맞추며, 원본 바이트는 data URL로 보존한다. 이미지도 다른 개체와 함께 이동·변형·회전·그룹·레이어 작업을 한다. OS·브라우저가 이미지 클립보드를 전달하는 범위에서 동작한다.

## 선택·변형·레이어

선택 도구 `V`에서 개체를 누른다. Shift+클릭으로 선택을 추가하거나 빼며, 빈 영역을 드래그하면 상자 안에 완전히 들어온 개체를 함께 선택한다. 그룹의 한 개체를 고르면 같은 그룹을 함께 선택한다.

선택하면 바운딩 박스와 여덟 크기 핸들, 위쪽 회전 핸들을 표시한다. 꼭짓점으로 두 축을, 변 가운데로 한 축을 조절한다. Shift+크기 조절은 비율을 유지하고, Shift+회전은 15° 단위로 맞춘다. 회전된 단일 개체의 크기는 개체의 축에 맞춰 조절한다. 여러 개체는 공통 바운딩 박스를 기준으로 함께 변형한다.

텍스트의 가로·세로 늘리기는 글꼴 크기와 독립된 배율로 보존한다. 글자와 행간도 함께 늘어나며, 저장·재편집 때 크기가 되돌아가지 않는다.

`Ctrl/Cmd+G`로 그룹을 만들고 `Ctrl/Cmd+Shift+G`로 해제한다. 그룹은 하나의 선택·이동·레이어 단위다. 현재 문서 형식은 개체의 `groupId`로 그룹을 표현하며 중첩 그룹 트리를 만들지 않는다. `Ctrl/Cmd+[`·`]`는 한 단계 뒤·앞, Shift를 더하면 맨 뒤·맨 앞으로 보낸다. 같은 선택 안의 상대 순서는 유지한다.

## 우클릭 속성과 색상

개체를 우클릭하면 공통 `ActionMenu` 안에서 위치·너비·높이·회전·선 두께를 바로 입력하고 복사·붙여넣기·복제·그룹·레이어 변경·삭제를 실행한다. `Shift+F10`이나 키보드 메뉴 키로도 연다. X/Y 필드는 원점으로부터 **선택 바운딩 박스 중심**까지의 px 값이다. 단일 개체의 너비·높이는 회전 전 크기이며, 여러 개체는 공통 바운딩 박스의 크기다. 숫자 입력은 Enter·포커스 이동으로 반영하고 Esc로 입력 중 값을 취소한다.

채우기는 색상 원, 선은 색상 선 아이콘으로 구분한다. 아이콘이나 `F`·`X`로 팔레트를 연다. 기본 여덟 색은 짙은 회색·흰색·빨강·주황·초록·청록·파랑·보라 순서다. 팔레트가 열린 동안 `1~8`로 고르고, `0`은 투명, `9`는 기존 공용 `ColorPicker`를 연다. 개체를 선택하지 않은 상태에서 바꾼 색은 새 개체의 기본색이 된다.

여러 개체의 속성·색은 선택 전체에 적용한다. 텍스트와 도형을 함께 선택한 속성 메뉴에는 색상만 표시한다. 텍스트만 선택하면 글꼴·글자 크기·보통/굵게를 함께 편집한다. 선택·이동·변형 핸들은 혼합 선택에서도 사용할 수 있다.

글꼴은 공용 `SelectField`의 후보를 고르거나 Google Fonts의 글꼴 이름을 직접 입력한다. 시스템 글꼴은 로컬에서 쓰고, Google 글꼴은 이름·두께·사용 문자를 Google Fonts 요청에 포함해 필요한 글자만 내려받는다. 내려받은 폰트를 미리보기와 저장 SVG의 `@font-face`에 data URL로 넣어 완성한 SVG·PNG를 표시할 때 외부 요청이 필요 없게 한다. Google 글꼴의 새 선택·추가 문자·새 브라우저 세션에서 재저장하려면 다운로드가 필요하다. 글꼴을 내려받지 못하면 오류를 표시하고 저장을 완료하지 않는다.

## 저장·기록·첨부

**저장**은 개체 전체와 선 두께를 포함하는 바깥 영역에 24px 여백·흰색 배경을 더해 SVG를 만든다. 화면에 보이는 부분이나 원점 위치로 잘라내지 않는다. SVG의 `<metadata id="mew-drawing">`에 버전·개체·격자 설정을 XML 이스케이프한 JSON으로 넣고, 이미지와 다운로드한 폰트도 안에 포함한다. 화면 위치·선택·실행 취소 이력은 저장하지 않는다.

브라우저에서 같은 SVG를 PNG로 변환하고, SVG 저장 성공 후 기존 첨부 경로로 PNG를 업로드한다. PNG는 기본 2배 해상도로 만들되 한 변 8192px·약 16.8메가픽셀을 기준으로 축소한다. 저장·변환·첨부가 실패하면 그림과 오류를 남겨 재시도한다. SVG 저장 후 첨부만 실패한 경우 같은 그림·이름의 재시도에서 기존 내보내기를 재사용해 기록 중복을 줄인다.

| 데이터 | 위치·수명 |
| --- | --- |
| 재편집 원본 | 현재 루트 프로젝트의 `.mew/temp/drawings/<uuid>.svg` |
| 기록 이름·저장 시각·바이트 수 | 같은 폴더의 `<uuid>.json` |
| 에이전트 입력용 PNG | 현재 루트 프로젝트의 `.mew/temp/assets/`, 기존 첨부 수명 적용 |
| 미저장 문서·선택·화면 위치·undo/redo | 열린 그림판의 메모리 |

새 SVG·JSON·PNG는 `.mew/temp/` 아래에만 저장한다. 기존 `.mew/drawings/`의 기록과 `.mew/assets/` 첨부는 옮기거나 삭제하지 않고 계속 읽는다. Git에서 제외하려면 프로젝트의 `.gitignore`에 `.mew/temp`를 등록한다.

Mew 저장소는 기존 `.mew/drawings/`의 미추적 사용자 그림도 Git에서 제외해 원래 경로에 보존한다. 이미 추적하는 그림·첨부를 삭제하거나 저장 위치를 일괄 변경하지 않는다.

저장할 때마다 새 UUID 기록을 추가한다. 상단 **그림 기록**에서 이름·시각으로 고르면 SVG의 편집 메타데이터를 복원해 다시 편집한다. 목록은 작은 JSON만 읽으므로 스크린샷이 포함된 SVG 전체를 매번 파싱하지 않는다. Documents를 편집 중이어도 저장 위치는 `.workspace` 루트이며 Documents 아래에 `.mew`를 중첩 생성하지 않는다. 첨부 태그를 지워도 원본 SVG·PNG를 디스크에서 지우지 않는다.

## API와 접근 경계

| 요청 | 입력 | 응답 |
| --- | --- | --- |
| `GET /api/agent/drawings` | 선택적 `projectRoot` 쿼리 | `{ drawings, projectRoot }` |
| `GET /api/agent/drawings/:id` | UUID, 선택적 `projectRoot` 쿼리 | 기록 속성·`svg`·`projectRoot` |
| `POST /api/agent/drawings` | `{ svg, name, projectRoot? }` | HTTP 201, 기록 속성·`projectRoot` |

기록 속성은 `id`, `name`, `createdAt`, 프로젝트 상대 `path`, `bytes`다. 서버는 요청 계정의 활성 루트를 사용하며 전달한 `projectRoot`가 다르면 409로 거부한다. PNG의 기존 `POST /api/upload-into`도 선택적 `projectRoot`를 검사한다.

모든 그림 API는 로그인·에이전트 기능 권한과 `.mew/drawings`의 파일 권한을 요구한다. 목록·조회에는 열람, 저장에는 수정 권한을 적용하고 개별 SVG의 열람 제한도 검사한다. SVG는 32 MiB, 이름은 120자까지 받는다. 저장 폴더의 심볼릭 링크와 파일의 심볼릭 링크·하드 링크, 잘못된 UUID·경로 탈출을 거부한다.

서버는 편집기가 생성하는 SVG 태그·속성과 래스터 이미지 data URL, data 폰트만 허용한다. 스크립트·이벤트 속성·외부 참조·외부 CSS·임의 HTML은 저장하지 않는다. 재편집은 Mew의 편집 메타데이터만 읽으며 임의의 외부 SVG를 편집 문서로 실행하지 않는다. 공통 권한 정책은 [접근 제어](../../development/access-control.md)가 소유한다.

드래그 미리보기는 `requestAnimationFrame`으로 프레임당 한 번 반영하고, 제스처가 끝날 때 문서 스냅샷 하나를 확정한다. 실행 취소에 포인터 이동의 중간 상태를 쌓지 않는다. 문서의 개체 좌표와 뷰포트는 분리하며, 내부 개체 좌표의 X/Y는 회전 전 왼쪽 위를 나타낸다. 속성 메뉴의 중심 좌표는 선택 범위에서 계산한다. 새 개체 종류는 문서 모델·기하 계산·렌더러·SVG 변환의 대응 구현을 추가한다. 기술 선택의 근거는 [ADR 0008](../../decisions/0008-agent-vector-drawing.md)에 둔다.

드래그 중 실행 취소는 진행 중인 변경부터 취소하며 이미 확정한 직전 개체를 지우지 않는다. 문서 복원·내보내기의 정규화는 개체 5,000개와 개체별 경로 점 10,000개를 상한으로 둔다. 대규모 문서의 실제 편집 지연은 별도로 측정하지 않았다.

## 확인 기준과 검증

다음은 사용자 확인 기준이며 이 목록 자체가 검증 완료 판정은 아니다.

- 도형·직선·곡선·여러 줄 텍스트·스크린샷을 한 그림에서 편집하고 격자 표시·간격·스냅을 바꾼다.
- 원점 복귀·확대·이동 후에도 개체의 px 좌표가 유지되고, 회전된 개체·다중 선택의 크기 조절·회전·그룹·레이어 순서가 일관된다.
- 팔레트 숫자 키·투명·사용자 색상과 Google 글꼴이 선택 전체에 적용되며 혼합 선택 메뉴는 색상만 보여 준다.
- 실행 취소·다시 실행·복사·붙여넣기가 개체·이미지·그룹을 유지하고 한 번의 드래그를 한 번에 되돌린다.
- 저장한 SVG를 기록에서 재편집하고, PNG를 새 입력·큐 편집에 첨부하며, 프로젝트 전환·업로드 실패 후 다른 입력에 섞이지 않는다.
- 데스크톱·모바일에서 팝업·속성 메뉴·공용 선택·팔레트가 화면 안에 놓이고 텍스트 입력을 가리지 않는다.

2026-10-16: 그림판 모델·폰트·저장 API·실제 AgentPanel 브라우저 검사와 기존 에이전트 입력·큐 첨부·공용 번역 검사를 직렬 실행해 32개가 통과했다. `npx tsc -b`·변경 대상 린트·문서 description/링크·diff 검사도 통과했다.

격리 Chromium의 1100/390px 화면에서 도구·실제 베지어·스냅·다중 선택·그룹·레이어·회전·숫자 크기·텍스트 배율·팔레트·화면 이동과 확대를 확인했다. 모의 Google Fonts 응답의 폰트 임베딩, 합성 스크린샷 붙여넣기, SVG 재편집, PNG 첨부 실패 재시도·기록 중복 방지·프로젝트 전환 격리도 검사했다. 실제 Google Fonts 서비스 접속, 모바일 OS 클립보드·키보드, 운영 서버 반영은 확인하지 않았다. 빌드·서버 재시작은 수행하지 않았다.

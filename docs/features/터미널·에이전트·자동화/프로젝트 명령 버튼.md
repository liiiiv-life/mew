## 요구사항

- 현재 프로젝트의 반복 명령을 버튼으로 실행하고 출력을 본다.

### 범위

- 사이드바 ▶에서 프로젝트별 명령 등록·수정·실행·정지와 전용 터미널 팝업을 제공한다.

### 경계와 제한

- 하위 프로젝트 명령은 해당 프로젝트 탭에서 사용한다.
- 버튼 설정은 프로젝트별이며 현재 셸에 문자열을 넣는 전역 터미널 버튼과 다르다.

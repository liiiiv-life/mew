## 요구사항

- 에이전트 대화 안에서 셸 명령을 실행하고 결과를 확인한다.

### 범위

- 실행 전 큐에서 취소한 명령은 대화 버블·중단 상태를 남기지 않는다. 실제 실행 중단의 기록·출력은 보존한다.

- 입력 맨 앞의 `! `를 제거하며 일반/CLI 모드를 양방향 전환한다. 기존 버튼과 동일한 전환 제한을 따른다.
- CLI 입력 모드, 명령 상태·중단·터미널 열기, 완료 출력 보기·다운로드를 제공한다.
- 답변의 명령어 코드 블록에는 복사 버튼 왼쪽에 삼각형 실행 버튼을 제공한다. 누르면 같은 탭·세션·작업 폴더에서 CLI 명령으로 보내고 대화 안에 실행 기록을 표시한다.
- Linux에서 설치된 에이전트 합산 OS 메모리 한도를 셸과 자손에 적용하며, 메모리 부족 시 진행 명령을 중단하고 대기 명령을 보존한다([보호 범위](../../operations/agent-memory.md)).

### 경계와 제한

- AI 프롬프트와 CLI 명령은 공통 큐의 실행 순서를 따른다.
- 임의 셸 실행이므로 에이전트·터미널 관련 권한과 서버 실행 경계를 따른다.

### 상세 계약

### 답변 코드 블록에서 실행

`bash`·`sh`·`shell`·`zsh` 블록은 비어 있지 않은 명령 본문 전체를 한 번에 실행한다. 언어가 없거나 `text`·`plaintext`인 블록은 주석·빈 줄을 제외한 모든 줄이 `npm`·`npx`·`pnpm`·`yarn`·`bun`·`node`·`python`·`pip`·`uv`·`git`·`docker`·`make`·`cargo`·`go`·`curl`·`wget`·`cd`·`ls`·`pwd`·`mkdir`·`cp`·`mv`·`rm`·`echo`·`cat`·`sudo`·`chmod`·`export`·`source` 명령으로 시작할 때 실행 버튼을 표시한다(`python3`·`pip3`도 포함). 들여쓰기 코드 블록도 같은 판별을 사용한다. Python·C++ 등 소스 언어 블록은 셸 실행 버튼을 표시하지 않는다.

셸 블록과 `console`·`terminal`·`shellsession`, 언어 없는 블록에서 모든 명령 줄이 `$ `로 시작하면 프롬프트만 제거한다. 명령과 출력이 섞인 전사에는 실행 버튼을 표시하지 않는다. 복사 버튼은 프롬프트를 포함한 원문을 유지한다. 이 판별은 표시 기준이며 명령의 안전성을 검사하거나 실행할 셸을 변경하지 않는다. 실제 실행 환경은 기존 CLI 실행 경로를 따른다.

클릭한 명령은 AI 프롬프트로 보내지 않는다. 서버가 접수하면 CLI 입력 모드를 켜고 입력 기록에 남기되 작성 중인 초안을 덮어쓰거나 지우지 않는다. 작업 중이면 기존 공통 큐에 들어간다. 제출 중의 연속 클릭은 기존 제출 잠금으로 중복 실행하지 않는다. 실패 시 기존 오류 표시와 재시도 경로를 사용한다.

터미널 권한이 없으면 실행 버튼을 숨긴다. 답변 스트리밍 중, 연결·세션 준비/복원 중, 저장 전사 선표시, 큐 편집, 첨부 처리/보유 및 명령 제출 중에는 비활성화한다. 복사 버튼은 유지한다. 실행 버튼은 번역된 접근성 이름과 공통 툴팁, 키보드 포커스 표시를 제공한다.

## 구현 내용

- Windows 명령은 PowerShell로 실행하며 POSIX 셸 문법을 자동 변환하지 않는다. 사용자 `exit`는 내부 셸을 종료하고 별도 wrapper가 종료 코드·완료 파일·출력 drain을 기록한다. Job Object가 소유한 자손을 취소·부모 종료 시 함께 정리한다. 큐·출력 archive·대화 ID는 공통 구현을 사용한다. 정확한 보호 범위와 실제 Windows pty 검증은 [OS 실행 계약](../../development/windows-native.md)을 따른다.

- `! ` 접두사는 현재 모드의 반대 값을 지정한다. 편집기의 문서·커서 중복 알림으로 모드가 다시 돌아가는 것을 방지한다.

- 실행 전 취소는 서버 기록의 `cancelledBeforeStart` 표식으로 구분하고 대화 타임라인에서 제외한다. 기존 취소 기록도 조회 시 정규화하며, ID는 재전송 중복 실행 방지를 위해 유지한다.

- 입력 맨 앞의 `! `를 제거하며 일반/CLI 모드를 양방향 전환한다. 기존 버튼과 동일한 전환 제한을 따른다.
- CLI 입력 모드, 명령 상태·중단·터미널 열기, 완료 출력 보기·다운로드를 제공한다.

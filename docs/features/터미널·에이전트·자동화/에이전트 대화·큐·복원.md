## 요구사항

- 작업을 보내고 진행·중단·대기열·이전 대화를 관리한다. 작업 중인 에이전트 탭은 닫기 전에 확인한다.
- 브라우저 재시작 후 저장된 큐를 먼저 표시하고 서버의 최신 큐와 동기화한다.
- 히스토리 선택·자동 복원 때 유효한 저장 전사가 있으면 에이전트 준비를 기다리지 않고 먼저 읽을 수 있다. 복원 성공 전에는 전송·승인을 막는다.
- 진행 작업을 중단하면 대기열을 보존하고 종료 확인 뒤 맨 위 작업부터 실행한다.
- 빈 대화는 중앙의 번역된 안내 문구로 채팅 시작을 안내한다.
- 대화 영역에서 ↑/↓로 질문 사이를 이동한다. 긴 답변 중간의 ↑는 먼저 해당 질문으로 돌아간다.
- 버블·답변 본문을 클릭하면 질문 이동을 위해 대화 영역에 포커스를 두되 영역 전체의 테두리는 표시하지 않는다. 키보드 탐색에서는 포커스 테두리를 유지하며, 이미 포커스된 영역도 포인터로 누르면 테두리를 숨긴다. 자식 버튼·링크의 자체 포커스 표시는 유지한다. `server/agent-history-ui.test.ts`에서 입력칸 이후 답변 클릭, 키보드 탐색 이후 재클릭과 영역 밖으로 나갔다가 포커스 복귀를 검사한다.
- 접기/펴기 화살표 없이 버블을 눌러 내용을 열고 닫는다. 질문 복사는 버블 바깥 왼쪽에 두고 답변 복사는 펼친 상태에만 표시한다. 접힌 답변은 첫 줄 오른쪽에 중단 버튼만 배치하고 시간을 숨긴다. 펼친 답변의 작업시간은 하단 `접기` 버튼 옆에 표시한다.
- 펼친 답변의 상태·복사·중단 헤더는 자기 버블 안에서 대화 화면 상단에 붙는다. 하단 `접기` 버튼도 자기 버블 안에서 대화 화면 하단에 붙는다. 상하단이 겹치면 상단 헤더가 하단 영역을 덮는다. 상단 `질문으로` 버튼은 표시하지 않는다.

### 범위

- 메시지 전송·중단·작업 기록·대기 메시지 편집/순서 변경·/clear와 히스토리 복원을 제공한다.
- 독립 감독과 전사를 통해 브라우저·프로젝트 전환 뒤 대화를 이어 간다.
- 메모리 부족 시 진행 작업을 중단하고 오류를 표시하며 대기열을 보류한다.
- 회복과 취소 완료 후 중단된 AI 작업을 먼저 이어가고 대기열을 자동 재개한다. CLI는 재실행하지 않는다([OS 한도와 범위](../../operations/agent-memory.md)).

- 핸들 드래그 중 삽입될 빈자리와 주변 항목의 이동을 표시해 놓을 순서를 미리 확인한다.
- 큐 목록은 기본 접힌 아이템 약 3.5개 높이를 넘으면 자체 세로 스크롤을 제공한다.
- 대기 큐에서 첨부를 확인하고 편집 중 파일 추가·제거·사진 미리보기를 제공한다.
- 큐 본문은 누르면 전체 내용을 펼치고 항목 자체의 높이 제한이나 내부 스크롤 없이 표시한다. 긴 내용은 큐 목록의 세로 스크롤로 읽는다. 펼치면 본문 아래에 큐 등록 당시의 모델·노력·권한을 표시하고, 그 아래에 첨부 파일명 태그를 왼쪽부터 오른쪽으로 나열하며 폭이 부족하면 다음 줄로 이어진다. 삭제 X 왼쪽의 연필 버튼으로만 하단 메시지 입력칸 편집을 시작하며, 예약 버튼은 숨기고 편집 중인 큐 항목 오른쪽에 취소 텍스트 버튼을 제공한다.
- 큐 등록 당시의 모델·노력도·권한을 저장하고 편집 시 불러온다. 저장·취소 후에는 편집 직전 새 메시지용 설정을 복원한다.

### 경계와 제한

- 패널 닫기와 탭 세션 종료를 구분한다.
- 히스토리·외부 CLI 이어쓰기와 런타임별 복원 지원은 세션 계약을 따른다.

## 상세 동작

### 긴 대화와 스트리밍 갱신

같은 대화에서 새 답변 청크가 오면 프레임마다 새 이벤트만 조합한다. 완료된 질문·답변 버블은 기존 객체와 Markdown 결과를 재사용한다. 과거 도구·승인 상태의 늦은 갱신은 해당 항목에 반영하며, 펼침·복사·중단·키보드 질문 이동·스크롤 위치는 유지한다.

최근 20개 질문의 기기 캐시는 새 질문으로 범위가 이동해도 겹치는 기록을 재저장하지 않는다. 초기화·다른 전사 복원·과거 기록 불러오기는 전체 조합 규칙을 적용한다. 서버 기록·실제 에이전트 맥락은 유지하며, 저장·불변 스냅샷·캐시 예산·측정의 공통 계약은 [대화 저장과 구간 동기화](../../development/conversation-storage.md)를 따른다.

2026-10-07 검증: 관련 단위·서버 테스트 58개와 격리 Chromium의 대화 기록·연결·CLI/큐·예약 캐시·탭 닫기·새 탭 시나리오 6종을 통과했다. PC·모바일/양 테마에서 복원·스크롤·200개 순번 이벤트·중복 제외를 확인했고, 이동 캐시의 새 행 4개만 저장·기존 행 호환·저장 실패 rollback을 검사했다. 대상 lint·문서 설명/배치 검사도 통과했다. 합성 반복 처리 측정과 실행 명령은 공통 대화 저장 문서에 기록했다. 빌드·운영 서버 재시작·실제 공급자 호출은 수행하지 않았다.

### 히스토리 본문 먼저 읽기

히스토리 선택·현재 대화 새로고침과 자동 복원은 서버에 저장된 최근 질문·답변을 먼저 표시하고 에이전트 복원을 계속한다. 준비 중에도 질문·답변을 펼치고 복사하거나 스크롤할 수 있으며 입력 초안을 유지한다. 전송·승인·이전 구간 불러오기는 준비가 끝난 뒤 허용한다. 선표시가 있으면 로딩 말풍선으로 본문을 덮지 않으며, 대화의 `aria-busy`는 복원이 끝날 때까지 유지한다.

선표시는 탭의 세션 포인터나 기기 기록을 바꾸지 않는다. 복원에 성공하면 최신 대화로 교체하고 실패하면 이전 대화를 유지한다. 저장 전사가 없거나 손상·용량/조회 시간 제한에 걸리면 기존 로딩을 사용한다. 서버 읽기·프로토콜·구간과 측정의 기준은 [대화 저장 계약](../../development/conversation-storage.md#acp-복원-중-서버-전사-선표시)을 따른다.

### 작업 중 탭 닫기 확인

에이전트 탭의 `×`, `Alt+W`, 앱에 전달된 `Ctrl/Cmd+W`는 같은 닫기 경로를 사용한다. 탭별 `infos[id].busy`가 참이면 공통 확인창에서 대상 탭 이름과 진행 중 작업 종료를 알린다. ACP 응답과 에이전트 대화의 CLI 실행 모두 기존 busy 상태를 따른다. 일반 셸 탭은 기존 종료 동작을 유지하며 유휴 에이전트 탭은 즉시 닫는다.

탭을 제거한 뒤 같은 에이전트·터미널 그룹의 탭 줄에 포커스를 둔다. 마지막 탭을 닫아 런타임 선택기나 빈 패널이 나타나도 해당 패널에 포커스를 유지한다. `Alt+W`를 연속으로 누르면 같은 그룹의 남은 탭만 닫으며, 닫을 탭이 없으면 에디터 탭으로 넘어가지 않는다. 분리 그룹이 사라지면 같은 종류의 기본 패널 탭 줄로 포커스를 옮긴다.

확인창의 기본 포커스는 `취소`다. 취소·Esc·뒤로가기는 탭·세션·초안·대화·명령을 유지한다. 확인한 경우에만 해당 탭의 기존 세션·명령 종료와 초안·캐시 정리·탭 제거를 실행한다. 다른 탭으로 전환한 뒤 비활성 탭의 `×`를 눌러도 그 탭을 대상으로 확인한다. 확인창에서 닫기 단축키를 반복해도 배경 탭을 닫지 않는다. 패널 전체 닫기는 탭 세션 종료와 별개다.

검증: `server/agent-close-ui.test.ts`는 실제 AgentPanel과 공통 확인창을 격리 Chromium의 데스크톱·모바일, 밝은·어두운 테마에서 실행한다. 작업 중 단축키·비활성 탭 `×` 확인, 취소·Esc 보존, 취소 기본 포커스, 확인 전 세션·명령 비종료, 대상 탭만 종료, 유휴 탭 즉시 닫기와 모달에서 닫기 키 재입력을 확인한다. 서버·소켓은 fixture 응답으로 대체한다.

같은 검사에서 대화 입력칸의 포커스로 시작한 연속 `Alt+W`, 닫기 확인 뒤 남은 탭과 마지막 탭 닫기, 빈 패널의 추가 닫기 키가 에디터에 전달되지 않는지도 확인한다.

### 상태버블

에이전트 대화 헤더의 `i` 오른쪽에 책 모양 **Skills 관리**와 플러그 모양 **MCP 관리** 버튼을 둔다. 전역·프로젝트·하위 프로젝트를 런타임별로 탐색하고 원문 조회·추가·수정·이동·삭제한다. 기존 정보 팝업과 별개의 공통 전체 화면 모달이며 세부 동작·지원 범위는 [스킬·MCP 관리](../../configuration/agent-harness.md)를 따른다. 그 오른쪽 톱니 버튼은 **에이전트 기본 지침** 설정을 연다(`serverFiles` 권한). 커밋 방식·응답 언어·답변 길이와 파일 보기 동작은 [공통 지침 설정](../../guides/project-setup.md#공통-안내-파일-편집)을 따른다.

**에이전트**와 **터미널**은 별도 패널이다. 에이전트에는 ACP 채팅과 공식 에이전트 TUI를, 터미널에는 일반 셸 탭을 둔다. 에이전트의 `+`는 런타임 선택기를 열고 터미널의 `+`는 셸을 추가한다. 기존 `tmux` 탭은 ID·cwd를 유지한 채 터미널에 표시한다.

패널 이동과 탭 분리는 [ADR 0134](../../../../.mew/docs/decisions/0134-mew-dockable-workspace-panels.md)와 [UI 계약](../../development/ui-contracts.md#작업-패널-배치)을 따른다. 패널을 접거나 이동해도 세션은 종료하지 않는다. 패널의 닫기 버튼은 누른 칸만 닫고 탭을 같은 종류의 남은 패널로 모은다. 마지막 패널의 탭은 다시 열 때를 위해 보존한다. 남은 패널은 빈자리를 채우며 닫은 분할은 복원하지 않는다. 탭의 `×`만 해당 세션을 끝낸다.

### 새 에이전트 선택

`+` 런타임 목록에서 설치된 에이전트는 행 전체를 누르거나 키보드 Enter·Space로 연다. 행 클릭으로 열 수 있어 중복되는 `사용` 버튼은 제거했으며, 사용자 요청 전에는 다시 추가하지 않는다. 미설치·설치 중인 항목의 열기 동작은 비활성화한다. 미설치 항목의 `설치` 버튼은 맨 오른쪽 톱니 아이콘 바로 왼쪽에 둔다. 설치·설정은 행 선택과 독립적으로 동작하며, 설치 성공 후 해당 에이전트를 여는 기존 흐름은 유지한다.

### 모델·노력도 선택

입력칸의 기본값 저장 버튼은 모델·노력·권한 드롭다운과 같은 20px 높이의 투명 컨테이너에 넣고 아이콘을 가로·세로 중앙에 배치한다. 28px 설정 행 안에서도 중앙 정렬하며 음수 여백으로 위치를 보정하지 않는다.

Codex 모델 드롭다운은 노력도별 항목을 기본 모델 하나로 합친다. 예를 들어 `Astra (low)`·`Astra (medium)`·`Astra (high)`는 `Astra` 하나로 표시하고, 노력도는 바로 옆 사고 드롭다운에서 고른다. 모델 이름의 다른 괄호 설명은 유지한다. 기본 모델이 하나뿐이면 모델 선택만 비활성화하며, 지원 노력도가 여러 개면 사고 선택은 계속 사용할 수 있다.

모델을 바꿀 때 현재 노력도를 지원하면 유지하고, 지원하지 않으면 `medium` → 첫 지원 항목 순으로 선택한다. 사고 목록은 선택 모델이 광고한 지원 값으로 갱신한다. 노력도 변경 시 Codex의 실제 복합 모델 ID도 함께 동기화하여 기본값 저장·재접속과 표시가 어긋나지 않게 한다. 설정 실패 시 이전 값을 유지한다. 다른 런타임의 모델 목록과 기존 셋의 정확한 모델 ID는 유지한다. 실행·기본값 계약은 [런타임 설정](../../configuration/agent-runtimes.md#모델권한-기본값과-런타임-선택)을 따른다.

### 로그인 화면

제목은 `<에이전트 이름> 로그인`으로 표시한다. 로그인 방식은 설명 카드 대신 행 전체를 누르는 버튼으로 제공하며, Kimi의 `.com`·`.ai`처럼 선택에 필요한 구분은 이름에 남긴다. API 키는 이름이 연결된 입력란과 `연결` 버튼을 사용한다.

서버 실행 위치, CLI 자격증명 관리, 세션 재연결, 인증 코드 저장 방식 같은 내부 동작 설명은 화면에 표시하지 않는다. 인증 브라우저의 `SERVER OAUTH` 배지와 반복되는 하단 안내도 제거한다. 이 설명 문구는 다시 추가하지 않는다. 구현 정보는 [런타임 설정](../../configuration/agent-runtimes.md)에서 관리한다.

진행 상태, 승인 코드·복사, `로그인 계속하기`, 코드 입력, 오류와 재시도 안내는 필요한 상태에서만 표시한다. 로그인 사이트의 호스트와 공급자가 요청한 안내는 유지하며, 긴 OAuth URL은 본문에 나열하지 않는다. Prime의 `/login` 입력처럼 사용자가 직접 해야 하는 단계는 짧게 안내한다. 로그인 방식·인증 작업·브라우저 연결 계약은 유지한다.

내용은 최대 24rem 폭으로 배치하고, 짧은 패널에서는 위쪽으로 스크롤해 뒤로가기와 입력란에 접근할 수 있어야 한다. 버튼과 입력란은 키보드 포커스를 표시하며, 진행 상태는 `status`, 오류는 `alert`로 알린다.

### 빈 대화

연결·초기 준비·히스토리 로딩이 끝난 ACP 채팅에서 표시할 대화 버블이 없으면 본문 가로·세로 중앙에 `채팅을 시작하세요`를 보조 글자색으로 표시한다. 앱 언어에 따라 한국어·영어·일본어·중국어 간체로 번역하며, 메시지·명령·오류 버블이 생기면 숨긴다. 로그인 화면과 로딩 말풍선에는 이 문구를 겹쳐 표시하지 않는다.

### 패널 상태·오류 알림

일반 셸·공식 TUI의 연결·재연결 상태는 tmux 본문 상단 중앙에 작은 반투명 알림으로 띄운다. 터미널 열기 실패도 같은 알림에 재연결 버튼을 제공한다. ACP 채팅의 명령 조회·실행 오류와 런타임 열기 실패는 해당 본문 위에 같은 형태로 표시한다. 명령 버튼 바·대화·입력 영역의 높이는 변하지 않는다.

공통 `PanelNotice`는 테마 표면색의 85% 불투명도와 약한 배경 흐림을 사용한다. 본문 가장자리에서 8px 떨어뜨리고 최대 폭 22rem·최대 높이 6rem으로 제한한다. 긴 오류는 줄바꿈·내부 스크롤·텍스트 선택을 지원한다. 알림 바깥은 클릭·터치·스크롤을 가로채지 않고, 오류는 `alert`, 연결 상태는 `status`로 알린다. 작업 기록 속 오류·로그인 입력 검증·상세 오류 창은 기존 문맥을 유지한다.

### 연결 대기와 재연결

ACP 세션 연결·재연결, 인증 화면을 제외한 초기 준비, 히스토리 전환·현재 대화 새로고침 동안 대화 영역에 크기가 다른 빈 말풍선 네 개를 표시한다. 말풍선에는 빛이 순차적으로 좌우를 왕복하는 shimmer를 적용한다. 말풍선 너비 40%의 빛 띠가 각 방향 1.4초로 내부에서 왕복하며, 바깥으로 사라지거나 끝에서 처음으로 건너뛰지 않는다. 첫 프레임부터 띠를 표시하고 각 말풍선의 위상을 200ms씩 달리한다. 빛 띠는 수평 90도 그라데이션이며 0/25/50/75/100% 위치에 상대 강도 0/50/100/50/0(본문색 불투명도 0/11/22/11/0%)를 적용한다. 기울어진 그라데이션이 사각 레이어의 좌우 경계에서 잘리지 않도록 모든 높이에서 끝을 완전히 투명하게 연결한다. 히스토리 목록 조회에도 같은 컴포넌트의 작은 말풍선 세 개를 사용한다. 테마의 표면색·본문색을 사용하며, 로딩이 끝나면 실제 대화를 즉시 표시한다. 전체 mew 세션 인디케이터와 중복되던 패널 중앙 스피너·검정 덮개·상시 연결 문구는 제거했으며 사용자 요청 전 재도입하지 않는다.

대화·입력 초안은 유지한다. 같은 세션의 IndexedDB 기록이나 복원 대상의 서버 전사 선표시가 있으면 연결 대기에도 버블을 읽을 수 있다. 그 외 로딩 중 기존 대화 DOM은 숨기고 `inert`로 조작을 막되 스크롤 위치와 버블 상태를 보존한다. 연결이 끊기면 세션 도구 바도 `inert`로 잠근다. 입력 영역·탭 바·패널 닫기·다른 패널은 가리지 않으며 초안 작성·수정·첨부·높이 조절을 계속할 수 있다. 연결 끊김과 히스토리 전환·서버 전사 선표시 동안 버튼·`Ctrl+Enter` 전송은 막고 초안을 유지한다. 선표시가 없는 초기 준비 중 메시지를 서버 큐에 보내는 동작과 첨부·CLI 모드의 기존 제한은 유지한다.

기존 1초 간격 재연결을 유지한다. 기기 기록이 없으면 소켓이 열려도 초기 세션 준비 중에는 말풍선을 유지하며, 인증 화면·초기 오류는 숨기지 않는다. 히스토리는 `history`·기존 `replay`·`reset`·`error` 수신 시 로딩을 해제한다. 대화 영역은 `aria-busy`, 말풍선은 번역된 접근성 이름이 있는 `status`로 알린다. 모션 감소 설정에서는 띠를 중앙에 고정하고 2초마다 불투명도만 0.35~0.8로 부드럽게 왕복한다. 숨긴 탭에서는 두 애니메이션 모두 멈춘다. 표시 여부와 입력 포커스를 분리하여 다른 패널에 포커스가 있어도 화면에 보이는 말풍선은 계속 움직인다. 연결 끊김 뮤캣 알림은 사용자 요청 전 재도입하지 않으며 실제 작업 오류·완료·승인 알림은 유지한다.

검증: `server/agent-connection-ui.test.ts`는 실제 AgentPanel과 격리 Chromium에서 탭 원장 조회 중 캐시 줄글 미노출·소켓 미연결, 포커스 없는 복원 도킹 패널에서 빛의 실제 위치 변화·좌우 왕복과 양 끝 시점 스크린샷의 픽셀 대비(최소 25/255), 초기 연결·소켓 연결 후 준비 대기·장기 재연결의 알림 없음, 말풍선 영역과 입력칸의 비겹침, 초안 편집·높이 조절·전송 차단·복구, 탭별 격리, 모션 감소, 히스토리 목록·대화 로딩 및 replay/reset/error 후 해제를 데스크톱/모바일 양 테마로 검사한다. 소켓 전송은 fixture로 대체한다.

### 연결 계정·구독·사용량 제한

로그인에 성공해도 구독 권한이나 남은 사용량이 없을 수 있다. Claude·Kimi·Codex·Cursor의 ACP 채팅에서는
로그인 안내가 없는 상태에서 에이전트창의 **i(세션 정보)** 팝업을 열면 `연결 계정 · 구독`의 계정과 공급자 플랜을 바로 보여 준다. 화면의 항목명은 `계정`이며, 조회 방식에 대한 설명은 붙이지 않는다. 계정 조회는 팝업을 열 때 수행하며, 별도의 본문 카드와 추가 펼치기 단계는 두지 않는다. 지원 런타임 설정에서도 같은 계정 정보를 확인할 수 있다. Antigravity는 ACP 채팅·공식 Google 인증을 제공하지만 계정·플랜 정보 카드에는 포함하지 않는다. 공식 서버가 반환하지 않는 계정 정보는 추정하지 않는다.

구독 필요·사용량 소진·크레딧 부족은 인증 만료와 구분한다. 공급자가 Authentication required로 감싸 보내더라도
명시적 한도 오류이면 기존 대화와 로그인 상태를 유지한다. 대기 메시지를 보존하고 자동 전송은 멈춘다.
계정 재조회·패널 재연결·대기 메시지 편집은 실행 재개 신호가 아니다. 사용자가 새 메시지를 보내면 대기 순서대로 재개한다.

무료·미구독과 현재 요청 불가를 같은 상태로 보지 않는다. 무료 한도를 쓸 수 있는 상품은 구독 없이도 사용할 수 있다.
플랜 코드나 조회 실패만으로 미구독을 추정하지 않으며, Kimi의 VIP10처럼 유료 여부를 확인하지 못한 값은 그대로 표시하고 판단을 유보한다.

세션 도구 바의 히스토리·사용량 배터리·대화 비우기·정보·스킬/MCP·지침 버튼은 같은 세로 중심선에 정렬한다. 버튼 그룹은 `items-center`를 사용하고 배터리 버튼은 inline baseline 대신 flex로 배치한다.

Codex·Claude·Kimi Code는 세션 도구 바의 맨 오른쪽, 지침 버튼 다음에 폭 40px·높이 20px의 완전히 둥근 배터리를 표시한다. 공급자가 실제 반환한 유효 한도 중 집계 기간이 가장 짧은 것을 선택하고 남은 비율을 정수로 내림하여 숫자만 표시한다(예: 주별 28% 잔여는 `28`, 5시간 한도가 함께 있으면 5시간 잔여). 플랜명으로 기간을 추정하지 않는다. 배경 채움은 남은 비율을 따르며 25% 이하와 10% 이하를 구분한다. 공통 툴팁과 접근성 이름에는 기간·남은 %·제공된 초기화 시각을 표시한다. 조회 중·실패·미지원 CLI·API 키 연결은 `—`, 실제 소진은 `0`이다. 초기화 시각을 지난 데이터로 100% 회복을 가정하지 않는다. 표시 중인 연결 탭에서 최초 조회하고 이후 5분마다 갱신하며 숨겨진 문서/탭은 조회하지 않는다. 같은 Mew 계정·런타임의 여러 패널은 메모리에서 결과와 진행 중 요청을 공유하고 계정이 바뀌면 별도 조회한다. 배터리 숫자는 버튼이며 누르면 바로 아래에 전체 구독 한도 팝업을 연다. 반환된 모든 기간과 모델별 한도에 잔여율·채움 막대·제공된 초기화 시각을 표시한다. 모델별 추가 한도는 요약 배터리의 최단 기간 선택에 끼어들지 않는다. 팝업은 viewport 안으로 가로 위치를 보정하고 아래쪽 공간 안에서 스크롤한다. 다시 누르기·바깥 누르기·Esc·뒤로가기로 닫으며 키보드로 열고 닫을 수 있다. 조회되지 않은 한도를 추정해서 추가하지 않는다. 이 배터리는 한도 오류·큐 재개 판정을 바꾸지 않는다.

전체 구독 한도 팝업의 각 항목은 기간·게이지·잔여율을 한 줄에 배치한다(예: `1주 ━━━━━ 91%`). 게이지는 남는 가로 공간을 채우며 긴 기간·모델명은 말줄임과 전체 이름 툴팁을 제공한다. 초기화 시각은 해당 줄 아래에 표시한다.

세션 토큰 사용량 확인은 i 팝업의 기존 컨텍스트·입출력·캐시·전체 토큰·API 환산 비용 표시를 사용한다. 중복된 `구독 · 사용량 확인` 동선은 제거하고 `구독 관리`(무료 플랜 또는 구독 필요 시 `구독하기`) 버튼으로 내부 DOM 브라우저의 공식 페이지를 연다. 이 UI 통합은 재시도 금지 결정이 아니다. 팝업은 좁은 패널 폭에 맞추고 내용이 길면 내부에서 스크롤한다. 서버 CLI 계정과 웹 구독 페이지의 계정은 별개로 로그인되어 있을 수 있으므로
구독 창 안에서 같은 계정인지 확인하도록 안내한다. 계정 요약에는 무료 플랜 설명과 공급자 조회 메모를 반복 표시하지 않으며, API 키 연결은 별도 요금임을 표시한다. 구독 창을 닫으면 상태만 재조회하고 결제나 프롬프트 전송은 자동 수행하지 않는다.
계정 정보는 잠시 표시하며 대화 전사·브라우저 저장소에 남기지 않는다. 결정은 [ADR 0130](../../../../.mew/docs/decisions/0130-mew-agent-account-entitlement.md),
공급자별 조회 기능·실행 계약·API는 [런타임 설정](../../configuration/agent-runtimes.md)에 둔다.

### 새 탭 생성

런타임이나 에이전트셋의 `사용`을 누르면 현재 루트 프로젝트 경로를 서버의 `agent-cwd` 검증에 통과시킨 뒤 탭을 만든다. 검증 중에는 선택기를 그대로 두고 `여는 중…`을 표시한다. 검증 실패 시 이유를 같은 화면에 표시하고 탭은 만들지 않는다. 복원 호환 데이터의 cwd는 비어 있을 수 있지만 새 탭 생성 함수는 빈 cwd를 허용하지 않는다.

탭 목록의 SSoT는 계정 서버 원장이고 `localStorage`는 첫 화면용 fallback이다. 따라서 전사·본문 캐시가 브라우저 저장 한도를 채워 fallback 갱신이 `QuotaExceededError`로 실패해도 새 탭 렌더와 서버 원장 저장을 계속한다. 활성 탭과 최근 런타임·선택기 보기 저장도 같은 원칙으로 best effort 처리한다.

[대화 저장 계약](../../development/conversation-storage.md)에 따라 전사는 계정별 IndexedDB에 최근 20개 질문 단위로 저장한다. 서버는 SQLite 구간 조회·재접속 변경분을 제공하고, 위로 스크롤하면 과거 구간을 추가한다. 명시적 탭 종료 시 기기 전사를 제거한다. 설정·초안·레거시 캐시 정리는 [브라우저 저장 계약](../../development/browser-storage.md)을 따른다. 2026-09-08의 localStorage quota 문제는 전체 약 10.49MB 중 닫힌 Codex 탭 세 개가 약 89%를 차지했던 사례이며 새 IndexedDB 예산과는 별개다.

서버 탭 원장 조회 단계에는 기존 빈 말풍선을 표시하고, 확인 전에는 세션 연결·서버 원장 갱신을 하지 않는다. 2026-09-30 사용자 요청에 따라 원장 확인 뒤에는 같은 계정·세션의 검증된 IndexedDB 기록을 실제 대화 버블로 먼저 표시한다. 예전 localStorage 줄글 미리보기는 재도입하지 않는다. 캐시가 없거나 다른 히스토리를 선택한 경우에는 기존 로딩 말풍선을 사용한다.

ACP 에이전트 대화에서 사용자 메시지 바로 위에 보이는 `모델 · 노력 · 권한` 구분선을 **상태버블**이라 부른다.

- 첫 사용자 메시지에는 항상 보인다.
- 이후에는 직전 사용자 메시지와 모델·노력·권한 중 하나라도 달라진 경우에만 다시 보인다.
- 같은 대화를 한 시간 뒤 이어 가거나 유휴 종료 후 복원해도 조합이 같으면 새 상태버블을 추가하지 않는다. 복원된 답변의 표현·청크가 달라져도 같은 질문에 저장된 설정은 유지한다.
- 전송 시점의 값을 대화 전사에 남기므로, 재접속·세션 복원 뒤에도 당시 상태버블을 보인다.
- 상태버블은 사용자 메시지가 아니라 작업 버블과 같은 전체 폭을 쓴다. 사용자 메시지만 오른쪽으로 들여쓴다.

### 대기 큐 편집

대기 큐 순서 변경은 각 항목 맨 왼쪽의 전용 드래그 핸들로만 시작한다. 마우스·터치 모두 길게 누르지 않고 바로 끌며 핸들에만 `touch-action: none`을 적용한다. 핸들의 위·아래 방향키로도 인접 항목으로 이동한다. 항목이 하나뿐이거나 큐 편집 중이면 핸들을 비활성화한다. 본문 길게 누르기로 이동하는 동작은 제거한다. 드래그 중에는 잡은 행이 포인터를 따라 떠 있고, 삽입할 위치에 점선 빈자리를 표시한다. 그 사이의 다른 행은 실제 높이와 간격에 맞춰 위·아래로 이동해 놓은 뒤의 순서를 미리 보여준다. 원래 슬롯으로 대상을 판정해 미리보기 이동 때문에 위치가 왕복하지 않게 한다. 순서 변경은 손을 놓을 때 한 번 전송하며, 포인터 취소·Esc·창 포커스 이탈은 미리보기를 되돌린다. 모션 감소 설정에서는 주변 행·빈자리 이동 애니메이션을 생략한다.

대기·예약 큐 컨테이너는 대화 영역보다 위 레이어에 표시하고 높이가 눌리지 않도록 유지한다. 컨테이너는 기본 접힌 항목 약 3.5개 높이(행 24px·간격 4px·상하 패딩과 경계 포함 109px)를 상한으로 두고, 초과하면 큐 안에서 세로 스크롤한다. 스크롤 경계에서는 대화 영역으로 스크롤을 전달하지 않는다. 대화 내부 레이어는 분리해 버블이나 새 메시지 표시가 큐의 상단 경계와 내용을 덮지 않도록 한다.

대기 큐 본문을 누르면 접힘·펼침을 전환한다. 펼친 본문은 줄바꿈을 보존해 전체 내용을 표시하며 항목 자체의 높이 제한이나 내부 스크롤 없이 표시한다. 긴 내용은 큐 목록의 세로 스크롤로 읽는다. 펼치면 본문 아래에 큐 등록 당시의 모델·노력·권한을 표시하고, 그 아래에 첨부 파일명 태그를 왼쪽부터 오른쪽으로 나열하며 폭이 부족하면 다음 줄로 이어진다. 본문을 눌러도 편집 잠금을 걸거나 입력 초안을 바꾸지 않는다. 오른쪽 삭제 X 바로 왼쪽의 연필 아이콘(편집)을 눌렀을 때만 기존 하단 메시지 입력칸에서 본문과 첨부를 편집한다. `/clear`·CLI 명령에는 편집 버튼을 표시하지 않는다. 편집 중인 큐 행은 배경으로 구분하며 큐 순서 변경·삭제·다른 항목 편집을 막는다. 하단 입력칸의 멘션·스킬·첨부·이미지 붙여넣기·높이 조절을 그대로 사용한다.

편집 중에는 전송 버튼을 저장 아이콘으로 바꾸고 예약 버튼은 숨긴다. 편집 중인 큐 항목 오른쪽에 번역된 `취소` 텍스트 버튼을 표시한다. 저장 버튼은 번역된 접근성 이름과 툴팁을 제공한다. CLI 모드 전환·새 메시지 예약·전송 기록 탐색은 편집 중 사용하지 않는다.

작성 중이던 새 메시지 본문·첨부·CLI 모드는 큐 편집 상태와 분리해 보존하고 저장·취소 후 복원한다. 모델·노력도·권한도 큐 등록 시점의 표시 이름과 실제 설정 ID를 항목별로 저장한다. 큐 편집을 열면 해당 스냅샷을 드롭다운에 불러오고 변경은 편집 중인 항목에만 보관한다. 저장하면 본문·첨부와 함께 반영하며, 저장·취소 후에는 편집 직전 새 메시지용 모델·노력도·권한으로 돌아간다. 큐를 등록한 뒤 바꾼 설정을 과거 큐 설정으로 덮어쓰지 않는다. 편집 중 기본값 저장은 비활성화한다. 취소는 큐 원본을 유지하며 Esc·브라우저/기기 뒤로가기로도 취소한다. 뒤로가기는 공통 오버레이 스택에서 편집 한 겹만 닫고 패널을 유지한다. 멘션 후보·사진 미리보기가 열렸으면 Esc는 해당 화면부터 닫는다. Ctrl/Cmd+Enter는 새 메시지를 보내지 않고 수정한 큐 항목을 저장한다. 연결 끊김·첨부 업로드 중·본문과 첨부가 모두 빈 항목은 저장하지 않는다.

### 질문 단위 키보드 스크롤

대화 영역을 클릭하거나 Tab으로 포커스를 옮긴 뒤 위·아래 방향키를 누르면 사용자 질문 단위로 이동한다. 질문의 시작을 대화 영역 상단 여백 아래에 맞추며, 첨부·실행 설정이 있는 질문은 그 묶음의 시작을 기준으로 한다. 답변·도구·오류·CLI 버블은 이동 대상에서 제외한다.

- 답변 중간에서 ↑를 누르면 해당 답변의 질문으로 먼저 올라간다. 질문 시작에 맞춰진 상태에서 다시 ↑를 누르면 이전 질문으로 이동한다.
- ↓는 현재 상단 위치 다음에 있는 질문으로 이동한다. 답변 중간에서도 다음 질문으로 넘어간다.
- 첫·마지막 질문에서 순환하지 않는다. 하단 공간이 부족해 마지막 질문을 상단에 맞추지 못해도 연속 키 입력은 질문 순서를 유지한다.
- 마우스·터치 등으로 스크롤 위치를 바꾸면 바뀐 위치를 기준으로 이동 대상을 다시 고른다. 위쪽 이전 구간 로딩과 기존 스크롤 보존을 유지한다.
- 입력칸·편집 가능한 내용·선택 위젯의 키 입력과 조합키·IME 입력은 가로채지 않는다. 대화 밖 입력칸의 커서 이동·전송 기록 탐색, 큐 핸들의 순서 변경은 유지한다. 질문 이동 자체는 버블 접힘 상태와 키보드 포커스를 바꾸지 않는다.

검증: `server/agent-history-ui.test.ts`는 격리 Chromium에서 데스크톱·모바일 양 테마의 긴 답변 중간 ↑/↓, 연속 질문 이동, 하단 정렬 제한·첫/마지막 경계, 수동 스크롤 후 재탐색, 입력칸·조합키·버튼 포커스와 기존 구간 로딩·캐시 복원을 함께 검사한다.

### 작업 버블 상태

사용자 채팅 버블은 오른쪽 위, 에이전트 답변 작업 버블은 왼쪽 위 모서리의 라운딩을 0으로 표시한다. 나머지 모서리는 기존 라운딩을 유지하며 접힘·펼침 상태에 동일하게 적용한다.

질문·답변·작업 묶음에서 접기/펴기 화살표 아이콘을 표시하지 않는다. 본문·헤더를 누르거나 포커스된 버튼에서 Enter·Space로 기존 접힘 상태를 전환하며 `aria-expanded`로 상태를 알린다. 펼친 답변은 따라오는 상단 헤더 또는 하단의 `접기` 버튼으로 접는다. 하단 버튼은 긴 답변을 읽는 동안 대화 화면 하단 경계에 붙고 자기 답변 버블의 상단을 넘지 않는다. 본문이 버튼 뒤로 비치지 않도록 배경과 구분선을 유지하며 접힌 답변에서는 숨긴다.

질문 복사 버튼은 접힘·펼침 상태 모두 질문 버블 배경 바깥 왼쪽에 둔다. 복사는 질문 전체를 복사하며 접힘 상태를 바꾸지 않는다. 답변 복사 버튼은 펼친 헤더에만 표시하고 접힌 상태에서는 숨긴다.

접힌 답변의 요약은 마지막 답변 원문을 패널 폭에 맞춰 최대 두 줄로 표시하고 넘치는 끝에 말줄임표를 붙인다. 고정 80자 제한은 사용하지 않는다. 진행 중 중단 버튼은 첫 줄 오른쪽에 두며 첫 줄에서 버튼에 필요한 폭만 비운다. 접힌 답변에서는 작업시간을 표시하지 않고 시간 자리나 추가 줄을 만들지 않는다. 펼친 답변은 요약을 숨기고 상단의 상태 점·복사·중단 버튼을 동일한 세로 중심선에 정렬한다. 작업시간은 하단 `접기` 버튼 바로 왼쪽에 같은 세로 중심선으로 표시하며 버튼과 함께 스크롤을 따라온다. 진행 중에는 경과 시간을 갱신하고 시간이 없는 옛 전사에서는 시간 자리를 만들지 않는다. 복사는 전체 답변을 복사하며 접힘 상태를 바꾸지 않는다.

펼친 답변의 헤더는 해당 대화 영역을 스크롤해 원래 위치가 위로 넘어가면 대화 화면 상단 경계에 붙는다. 상태 점·복사·진행 중 중단 버튼을 함께 표시하며, 본문이 헤더 뒤로 비치지 않도록 배경과 구분선을 유지한다. 헤더는 자기 답변 버블의 하단을 넘지 않으며 다음 버블로 넘어가면 함께 위로 밀려난다. 접힌 답변의 헤더는 따라오지 않는다. 같은 답변 버블의 상단 헤더와 하단 접기 영역이 겹치면 상단 헤더가 하단 영역을 덮는다. 펼친 상하단 바는 높이 26px(기존 약 37px의 70%)로 맞추고, 복사·중단·접기 버튼은 높이 20px, 복사 아이콘은 10px, 중단 표시는 8px, 상태 점은 5px로 표시한다. 시간·접기 글자는 11px로 맞춘다.

상단 헤더의 `질문으로` 버튼은 사용자 요청으로 제거했다. 명시적 후속 요청 없이 다시 추가하지 않는다. 대화 영역의 ↑/↓ 질문 이동은 유지한다.

검증: `server/agent-history-ui.test.ts`는 PC·모바일 양 테마에서 질문 복사의 버블 바깥 배치, 펼친 답변에서만 복사 노출, 접힌 답변의 시간 미표시·펼친 하단의 시간과 접기 버튼 정렬, 완료·진행 헤더의 세로 중심 일치와 긴 답변 중간의 상단 고정, 버블 하단에서의 밀려남, 완료·진행 헤더의 복사·중단과 질문 이동 버튼 미표시, 기존 키보드 질문 이동·구간 복원을 검사한다.

작업 버블의 점 색은 실행 상태를 뜻한다: 파랑은 진행 중, 초록은 완료, 회색은 중단, 빨강은 실패다. ACP 히스토리에 마지막 종료 이벤트가 없더라도 현재 세션이 유휴면 마지막 작업은 완료로 본다.

완료된 작업은 종료 순간의 전체 전사를 보존한다. 따라서 감독 프로세스가 유휴 종료된 뒤에도 다시 불러온 화면에는 사용자 질문, 답변과 작업 내역 전체, 완료 상태와 경과 시간이 남는다. 이벤트 수가 많다는 이유로 한 턴의 앞부분을 자르지 않는다.

## 구현 내용

- 질문 복사를 버블 배경 밖으로 옮기고 답변 복사는 펼친 헤더에서만 표시한다. 펼친 헤더의 상태 점·복사·중단 버튼을 같은 세로 중심선으로 정렬한다([버블 표시 계약](#작업-버블-상태)).

- 명령 조회·실행 및 런타임 열기 오류는 본문 위의 작은 반투명 플로팅 알림으로 표시한다. 긴 오류는 알림 안에서 스크롤하고 기존 작업 오류 기록·상세 창은 유지한다.

- 펼친 답변 헤더를 자기 버블 안의 sticky 영역으로 두고 대화 화면 상단 여백을 보정해 경계에 붙인다. 하단 `접기` 버튼도 sticky 영역으로 두고 대화 화면 하단 여백을 보정한다. 상단 헤더의 겹침 우선순위를 하단 영역보다 높게 둔다. 펼친 상하단 바 높이는 26px로 줄이고 버튼·아이콘·상태 점·시간 글자를 함께 축소한다. 사용자 요청으로 상단 `질문으로` 버튼을 제거하고 명시적 후속 요청 없이 다시 추가하지 않는다. ↑/↓ 질문 이동은 유지한다. 접힘 상태와 복사·중단·입력 동작을 유지한다([버블 표시 계약](#작업-버블-상태)).

- 질문·답변·작업 묶음의 접기/펴기 아이콘을 제거하고 클릭·Enter·Space와 접근성 상태를 유지한다. 답변 요약의 고정 80자 제한을 없애 두 줄 말줄임을 적용하고, 첫 줄에서 중단 버튼에 필요한 폭만 비우고 접힌 답변의 작업시간을 숨긴다([버블 표시 계약](#작업-버블-상태)).

- 대화 영역에 클릭·Tab 포커스와 질문 기준 방향키 스크롤을 연결한다. 수동 스크롤 후에는 현재 위치에서 대상을 다시 계산하고, 맨 아래 정렬 제한에도 연속 질문 순서를 유지한다([키보드 스크롤 계약](#질문-단위-키보드-스크롤)).

- 메모리 보호 중에도 2초마다 회복을 확인하고 AI 이어가기와 큐를 자동 재개한다. 원래 설정·편집 잠금을 유지하며 사용자 중단은 이어가기를 제거한다.

- 큐 본문·종류·첨부·설정을 계정별 IndexedDB에 비동기 저장한다. 같은 탭·세션의 큐를 연결 전에 표시하고 서버 스냅샷으로 교체한다. 재연결 중 표시는 유지하며 서버 상태 확인 전 수정은 차단한다([대화 저장 계약](../../development/conversation-storage.md)).

- AI·CLI 중단은 진행 작업과 승인 요청만 취소한다. 종료 처리 후 공통 FIFO 큐를 이어 실행하며 편집 잠금·보호 보류는 유지한다. 탭 종료·대화 전환은 대기 작업도 정리한다.

- 드래그 재배열 시 주변 항목은 180ms의 공통 이동 애니메이션으로 새 자리를 찾아간다. 잡은 아이템은 포인터를 바로 따라가며, 연속 재배열과 모션 감소 설정은 [공통 모션 계약](../../development/ui-contracts.md#드래그-재배열-모션)을 따른다.

- 유휴 상태에서 히스토리의 새 대화를 누르면 UI를 먼저 비우고 서버 종료·재연결·준비는 뒤에서 진행한다. 빈 화면에 연결 로딩을 덮지 않으며 입력 초안과 연결 전 전송 차단을 유지한다([세션 계약](../../development/agent-sessions.md#메시지재접속큐)).

- 서버 전사를 SQLite에 증분 저장하고, 계정별 IndexedDB에 최근 대화를 비동기 보관한다. 최근 20개 질문·이전 구간·재접속 변경분을 순번으로 동기화한다. 기존 JSON은 비파괴 이전하며 구 감독 replay와 자동 복원 실패 보호를 유지한다([대화 저장 계약](../../development/conversation-storage.md)).
- 이전 구간을 읽을 때 스크롤·버블 키·CLI의 전체 질문 순서를 보존한다. 원장 확인 뒤 동일 계정·세션의 기기 기록을 먼저 표시한다.

- 큐 항목의 설정 표시 이름·실행 ID를 `settings`로 저장하고 `meta.queuedSettings`로 복원한다. 편집 중 설정은 로컬 초안에만 반영하고 저장할 때 서버 큐를 갱신한다. 실제 실행도 저장된 설정을 사용하며 턴 뒤 최신 새 메시지 설정으로 복원한다.

- 대기 큐 항목 맨 왼쪽의 전용 핸들로 순서를 바꾼다. 마우스·터치 모두 길게 누르지 않고 바로 끌며, 핸들에서 위·아래 방향키로도 이동한다. 본문은 접힘·펼침만 전환하고 편집 중에는 모든 핸들을 비활성화한다. 세로 목록 미리보기는 높이가 다른 행을 실제 크기로 밀어내며 점선 삽입 자리와 포인터를 따라가는 행을 표시한다. 서버 순서는 드롭할 때 한 번 갱신한다.

- 대기·예약 큐의 높이와 상위 레이어를 확보하고 대화 내부 레이어를 분리해 큐 상단이 버블에 가려지지 않도록 한다.
- 대기·예약 큐 컨테이너의 최대 높이를 109px로 제한하고 내부 세로 스크롤과 overscroll containment를 적용한다([큐 표시 계약](#대기-큐-편집)).
- 펼친 큐 본문의 높이 제한과 내부 스크롤을 제거해 전체 내용을 배치한다. 긴 본문은 기존 큐 목록 스크롤로 읽는다.
- 큐 인라인 편집칸 대신 하단 입력 UI를 재사용한다. 전송은 저장 아이콘으로, 예약은 숨기고 큐 항목 오른쪽에 취소를 배치하며 새 메시지 초안·첨부·CLI 모드는 저장·취소 후 복원한다([큐 편집 표시](#대기-큐-편집)).
- 사용자 버블의 오른쪽 위와 에이전트 답변 버블의 왼쪽 위 라운딩을 0으로 표시한다([대화 표시 명세](#작업-버블-상태)).
- 준비가 끝난 빈 대화 본문 중앙에 네 언어의 채팅 시작 문구를 표시한다([빈 대화 표시 계약](#빈-대화)).
- 서버 탭 원장 조회부터 연결·초기 준비·히스토리 로딩까지 빈 말풍선의 좌우 왕복 shimmer로 알린다. 레거시 줄글 캐시 미리보기는 표시하지 않는다. 동일 세션의 IndexedDB 버블 선표시는 아래 저장 계약을 따른다. 히스토리 목록 조회에도 같은 효과를 사용하며 중복된 중앙 스피너·검정 덮개는 제거한다.
- 빛 띠는 수평으로 양 끝 0%·¼/¾ 지점 50%·중앙 100%의 상대 강도로 이어지며 경계에서 끊기지 않는다.
- 대화·초안을 보존하고 준비가 끝나면 실제 대화를 표시한다. 연결·히스토리 로딩 중에도 입력칸 작성은 유지하고 전송만 막는다. 화면에 보이는 탭은 입력 포커스와 관계없이 빛 띠를 말풍선 안에서 왕복시킨다. 모션 감소 시에는 중앙에서 밝기만 변화시키며 숨긴 탭에서는 멈춘다.
- 탭 전환은 계속 가능하며 연결 끊김 뮤캣 알림은 보내지 않는다.

- 메시지 전송·중단·작업 기록·대기 메시지 편집/순서 변경·/clear와 히스토리 복원을 제공한다.

- 기존 대화 복원은 지원 런타임에서 임시 빈 세션 생성을 생략하고, 새로고침의 전사 캐시 병합은 긴 반복 청크를 선형 비교한다. 복원·인증 실패 시 기존 폴백을 유지한다([실행 계약](../../development/agent-sessions.md#메시지재접속큐)).

- 대기 큐에 첨부 태그와 별도 첨부 버튼을 연결한다. 저장 시 첨부를 함께 반영하고 취소 시 원본을 유지하며, 업로드 중 저장과 늦은 업로드의 다른 초안 혼입을 막는다([입력 계약](%EC%97%90%EC%9D%B4%EC%A0%84%ED%8A%B8%20%EC%9E%85%EB%A0%A5%C2%B7%EB%A9%98%EC%85%98%C2%B7%EC%8A%A4%ED%82%AC%C2%B7%EC%B2%A8%EB%B6%80.md), [큐 전달 계약](../../development/agent-sessions.md#메시지재접속큐)).

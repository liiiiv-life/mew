## 요구사항

- 작업을 보내고 진행·중단·대기열·이전 대화를 관리한다.
- 브라우저 재시작 후 저장된 큐를 먼저 표시하고 서버의 최신 큐와 동기화한다.
- 진행 작업을 중단하면 대기열을 보존하고 종료 확인 뒤 맨 위 작업부터 실행한다.
- 빈 대화는 중앙의 번역된 안내 문구로 채팅 시작을 안내한다.
- 대화 영역에서 ↑/↓로 질문 사이를 이동한다. 긴 답변 중간의 ↑는 먼저 해당 질문으로 돌아간다.
- 접기/펴기 화살표 없이 버블을 눌러 내용을 열고 닫는다. 질문 복사는 버블 바깥 오른쪽에 두고 답변 복사는 펼친 상태에만 표시한다. 접힌 답변은 첫 줄 오른쪽에 중단 버튼만 배치하고 시간을 숨긴다. 펼친 답변의 작업시간은 하단 `접기` 버튼 옆에 표시한다.
- 펼친 답변의 상태·복사·중단 헤더는 자기 버블 안에서 대화 화면 상단에 붙는다. 하단 `접기` 버튼도 자기 버블 안에서 대화 화면 하단에 붙는다. 상단 `질문으로` 버튼은 표시하지 않는다.

### 범위

- 메시지 전송·중단·작업 기록·대기 메시지 편집/순서 변경·/clear와 히스토리 복원을 제공한다.
- 독립 감독과 전사를 통해 브라우저·프로젝트 전환 뒤 대화를 이어 간다.
- 메모리 부족 시 진행 작업을 중단하고 오류를 표시하며 대기열을 보류한다.
- 회복과 취소 완료 후 중단된 AI 작업을 먼저 이어가고 대기열을 자동 재개한다. CLI는 재실행하지 않는다([OS 한도와 범위](../../operations/agent-memory.md)).

- 핸들 드래그 중 삽입될 빈자리와 주변 항목의 이동을 표시해 놓을 순서를 미리 확인한다.
- 큐 목록은 기본 접힌 아이템 약 3.5개 높이를 넘으면 자체 세로 스크롤을 제공한다.
- 대기 큐에서 첨부를 확인하고 편집 중 파일 추가·제거·사진 미리보기를 제공한다.
- 큐 본문은 누르면 전체 내용을 펼치고 항목 자체의 높이 제한이나 내부 스크롤 없이 표시한다. 긴 내용은 큐 목록의 세로 스크롤로 읽는다. 펼치면 본문 아래에 큐 등록 당시의 모델·노력·권한을 표시하고, 그 아래에 첨부 파일명 태그를 왼쪽부터 오른쪽으로 나열하며 폭이 부족하면 다음 줄로 이어진다. 삭제 X 왼쪽의 연필 버튼으로만 하단 메시지 입력칸 편집을 시작하며, 예약 버튼은 숨기고 편집 중인 큐 항목 오른쪽에 취소 텍스트 버튼을 제공한다.
- 큐 등록 당시의 모델·노력도·권한을 저장하고 편집 시 불러온다. 저장·취소 후에는 편집 직전 새 메시지용 설정을 복원한다.

### 경계와 제한

- 패널 닫기와 탭 세션 종료를 구분한다.
- 히스토리·외부 CLI 이어쓰기와 런타임별 복원 지원은 세션 계약을 따른다.

## 구현 내용

- 질문 복사를 버블 배경 밖으로 옮기고 답변 복사는 펼친 헤더에서만 표시한다. 펼친 헤더의 상태 점·복사·중단 버튼을 같은 세로 중심선으로 정렬한다([버블 표시 계약](../../specs/agent-panel.md#작업-버블-상태)).

- 명령 조회·실행 및 런타임 열기 오류는 본문 위의 작은 반투명 플로팅 알림으로 표시한다. 긴 오류는 알림 안에서 스크롤하고 기존 작업 오류 기록·상세 창은 유지한다.

- 펼친 답변 헤더를 자기 버블 안의 sticky 영역으로 두고 대화 화면 상단 여백을 보정해 경계에 붙인다. 하단 `접기` 버튼도 sticky 영역으로 두고 대화 화면 하단 여백을 보정한다. 사용자 요청으로 상단 `질문으로` 버튼을 제거하고 명시적 후속 요청 없이 다시 추가하지 않는다. ↑/↓ 질문 이동은 유지한다. 접힘 상태와 복사·중단·입력 동작을 유지한다([버블 표시 계약](../../specs/agent-panel.md#작업-버블-상태)).

- 질문·답변·작업 묶음의 접기/펴기 아이콘을 제거하고 클릭·Enter·Space와 접근성 상태를 유지한다. 답변 요약의 고정 80자 제한을 없애 두 줄 말줄임을 적용하고, 첫 줄에서 중단 버튼에 필요한 폭만 비우고 접힌 답변의 작업시간을 숨긴다([버블 표시 계약](../../specs/agent-panel.md#작업-버블-상태)).

- 대화 영역에 클릭·Tab 포커스와 질문 기준 방향키 스크롤을 연결한다. 수동 스크롤 후에는 현재 위치에서 대상을 다시 계산하고, 맨 아래 정렬 제한에도 연속 질문 순서를 유지한다([키보드 스크롤 계약](../../specs/agent-panel.md#질문-단위-키보드-스크롤)).

- 메모리 보호 중에도 2초마다 회복을 확인하고 AI 이어가기와 큐를 자동 재개한다. 원래 설정·편집 잠금을 유지하며 사용자 중단은 이어가기를 제거한다.

- 큐 본문·종류·첨부·설정을 계정별 IndexedDB에 비동기 저장한다. 같은 탭·세션의 큐를 연결 전에 표시하고 서버 스냅샷으로 교체한다. 재연결 중 표시는 유지하며 서버 상태 확인 전 수정은 차단한다([대화 저장 계약](../../development/conversation-storage.md)).

- AI·CLI 중단은 진행 작업과 승인 요청만 취소한다. 종료 처리 후 공통 FIFO 큐를 이어 실행하며 편집 잠금·보호 보류는 유지한다. 탭 종료·대화 전환은 대기 작업도 정리한다.

- 드래그 재배열 시 주변 항목은 180ms의 공통 이동 애니메이션으로 새 자리를 찾아간다. 잡은 아이템은 포인터를 바로 따라가며, 연속 재배열과 모션 감소 설정은 [공통 모션 계약](../../development/ui-contracts.md#드래그-재배열-모션)을 따른다.

- 유휴 상태에서 히스토리의 새 대화를 누르면 UI를 먼저 비우고 서버 종료·재연결·준비는 뒤에서 진행한다. 빈 화면에 연결 로딩을 덮지 않으며 입력 초안과 연결 전 전송 차단을 유지한다([세션 계약](../../development/agent-sessions.md#메시지재접속큐)).

- 서버 전사를 SQLite에 증분 저장하고, 계정별 IndexedDB에 최근 대화를 비동기 보관한다. 최근 20개 질문·이전 구간·재접속 변경분을 순번으로 동기화한다. 기존 JSON은 비파괴 이전하며 구 감독 replay와 자동 복원 실패 보호를 유지한다([대화 저장 계약](../../development/conversation-storage.md)).
- 이전 구간을 읽을 때 스크롤·버블 키·CLI의 전체 질문 순서를 보존한다. 원장 확인 뒤 동일 계정·세션의 기기 기록을 먼저 표시한다.

- 큐 항목의 설정 표시 이름·실행 ID를 `settings`로 저장하고 `meta.queuedSettings`로 복원한다. 편집 중 설정은 로컬 초안에만 반영하고 저장할 때 서버 큐를 갱신한다. 실제 실행도 저장된 설정을 사용하며 턴 뒤 최신 새 메시지 설정으로 복원한다.

- 대기 큐 항목 맨 왼쪽의 전용 핸들로 순서를 바꾼다. 마우스·터치 모두 길게 누르지 않고 바로 끌며, 핸들에서 위·아래 방향키로도 이동한다. 본문은 접힘·펼침만 전환하고 편집 중에는 모든 핸들을 비활성화한다. 세로 목록 미리보기는 높이가 다른 행을 실제 크기로 밀어내며 점선 삽입 자리와 포인터를 따라가는 행을 표시한다. 서버 순서는 드롭할 때 한 번 갱신한다.

- 대기·예약 큐의 높이와 상위 레이어를 확보하고 대화 내부 레이어를 분리해 큐 상단이 버블에 가려지지 않도록 한다.
- 대기·예약 큐 컨테이너의 최대 높이를 109px로 제한하고 내부 세로 스크롤과 overscroll containment를 적용한다([큐 표시 계약](../../specs/agent-panel.md#대기-큐-편집)).
- 펼친 큐 본문의 높이 제한과 내부 스크롤을 제거해 전체 내용을 배치한다. 긴 본문은 기존 큐 목록 스크롤로 읽는다.
- 큐 인라인 편집칸 대신 하단 입력 UI를 재사용한다. 전송은 저장 아이콘으로, 예약은 숨기고 큐 항목 오른쪽에 취소를 배치하며 새 메시지 초안·첨부·CLI 모드는 저장·취소 후 복원한다([큐 편집 표시](../../specs/agent-panel.md#대기-큐-편집)).
- 사용자 버블의 오른쪽 위와 에이전트 답변 버블의 왼쪽 위 라운딩을 0으로 표시한다([대화 표시 명세](../../specs/agent-panel.md#작업-버블-상태)).
- 준비가 끝난 빈 대화 본문 중앙에 네 언어의 채팅 시작 문구를 표시한다([빈 대화 표시 계약](../../specs/agent-panel.md#빈-대화)).
- 서버 탭 원장 조회부터 연결·초기 준비·히스토리 로딩까지 빈 말풍선의 좌우 왕복 shimmer로 알린다. 레거시 줄글 캐시 미리보기는 표시하지 않는다. 동일 세션의 IndexedDB 버블 선표시는 아래 저장 계약을 따른다. 히스토리 목록 조회에도 같은 효과를 사용하며 중복된 중앙 스피너·검정 덮개는 제거한다.
- 빛 띠는 수평으로 양 끝 0%·¼/¾ 지점 50%·중앙 100%의 상대 강도로 이어지며 경계에서 끊기지 않는다.
- 대화·초안을 보존하고 준비가 끝나면 실제 대화를 표시한다. 연결·히스토리 로딩 중에도 입력칸 작성은 유지하고 전송만 막는다. 화면에 보이는 탭은 입력 포커스와 관계없이 빛 띠를 말풍선 안에서 왕복시킨다. 모션 감소 시에는 중앙에서 밝기만 변화시키며 숨긴 탭에서는 멈춘다.
- 탭 전환은 계속 가능하며 연결 끊김 뮤캣 알림은 보내지 않는다.

- 메시지 전송·중단·작업 기록·대기 메시지 편집/순서 변경·/clear와 히스토리 복원을 제공한다.

- 기존 대화 복원은 지원 런타임에서 임시 빈 세션 생성을 생략하고, 새로고침의 전사 캐시 병합은 긴 반복 청크를 선형 비교한다. 복원·인증 실패 시 기존 폴백을 유지한다([실행 계약](../../development/agent-sessions.md#메시지재접속큐)).

- 대기 큐에 첨부 태그와 별도 첨부 버튼을 연결한다. 저장 시 첨부를 함께 반영하고 취소 시 원본을 유지하며, 업로드 중 저장과 늦은 업로드의 다른 초안 혼입을 막는다([입력 계약](../../specs/agent-input-mentions.md), [큐 전달 계약](../../development/agent-sessions.md#메시지재접속큐)).

## 요구사항

- 테마는 같은 Mew 인스턴스의 계정에 저장하고 모든 기기에 반영한다. 언어·글꼴·키 조합 등 기기별 설정은 기존 범위를 유지한다.
- 계정 테마와 이관할 브라우저 설정이 없으면 애니메이션 그라데이션이 있는 미드나이트를 기본으로 사용한다. 기존에 저장한 프리셋·커스텀·이전 모드와 테마색은 유지한다.
- 앱 첫 로딩·인증 확인·작업 화면 준비 동안 선택한 테마의 전체 배경과 중앙의 **접속 중…** 문구만 표시한다. 다크·라이트·커스텀 단색과 그라데이션 배경을 따르며 헤더·사이드바·패널 뼈대는 표시하지 않는다. 브라우저 팝업의 첫 로딩에도 같은 화면을 사용한다.
- 탭 닫기 키는 포커스된 파일·에이전트·터미널 등의 내부 탭에 적용하고, 닫을 탭이 없으면 다른 창의 탭을 닫지 않는다.

### 범위

- 배경색·글씨색·주요색을 한 테마로 선택하고, 단색·그라데이션 프리셋과 커스텀 테마를 제공한다. 그라데이션은 두 색·방향·배경 애니메이션을 설정한다. 언어·글꼴·단축키 설정·초기화도 제공한다.

- **Dock** 카테고리에서 항목 표시·순서·실시간 미리보기·기본값 복원을 제공한다.

### 경계와 제한

- 테마 선택·커스텀 목록은 계정별이다. 다른 기기의 변경은 실시간 신호와 화면 복귀·재연결 때 반영한다. 언어·글꼴 등 나머지 화면 설정은 브라우저별이다.
- 고정 편집 단축키는 바꿀 수 없고, 웹폰트로 로드되지 않고 기기에도 설치되지 않은 글꼴은 시스템 폴백을 사용한다.

## 구현 내용


- `shared/theme.ts`의 팔레트·정규화를 서버와 브라우저가 공유한다. `useAccountTheme`는 로그인 계정의 선택·커스텀 목록을 서버에 저장하고, 같은 계정의 presence 변경 신호·화면 복귀·재연결 때 최신 테마를 적용한다. 기존 브라우저 선택은 서버에 계정 테마가 없을 때만 이관한다. 오래된 사본과 늦은 응답은 최신 선택을 덮어쓰지 않으며, 저장 실패 시 선택을 유지하고 오류를 알린 뒤 다음 복귀·재접속·변경에 재시도한다. 계정 전환과 브라우저 캐시·데모 경계는 [계정 테마 계약](../../development/browser-storage.md#계정-테마)을 따른다.

- `Ctrl/Cmd+,`는 설정 팝업을 연다. 이미 열려 있으면 열린 상태를 유지한다. 편집기·터미널·입력칸에서도 앱이 먼저 처리하며, 로그인 영상·원격 데스크톱 입력 중에는 원격 전달을 우선한다. Shift·Alt 추가 조합과 IME 조합 입력은 처리하지 않으며 키 반복은 소비만 한다.

- `DockSettingsPanel`과 `useDockPreferences`가 독 표시·순서를 공유한다. 사용 가능한 항목만 표시하고 숨겨도 열린 패널은 유지한다. 모바일·PC와 밝은/어두운 테마·네 언어를 지원한다. 저장·권한·초기화 범위는 [Dock 설정](../../configuration/appearance.md#dock-설정)을 따른다.

- `Ctrl/Cmd+N/T`는 포커스된 에이전트·터미널의 새 탭을 열고 에디터·사이드바에서는 새 파일 이름 입력을 연다. `Ctrl/Cmd+Shift+N`은 기존 새 폴더 흐름(문서 트리는 새 문서)을 사용한다. 기존 Alt 조합과 사용자 재지정도 유지한다.
- `Ctrl/Cmd+Tab/Shift+Tab/PageUp/PageDown`과 기존 `Alt+Q/E`는 포커스된 패널의 이전·다음 탭으로 순환한다. `Ctrl/Cmd+1…9`는 표시 순서의 내부 탭을 선택하며 없는 번호는 무시한다. 분할 에디터·포털 터미널·브라우저 iframe·사이드바·태스크에 같은 경계를 적용한다.
- `Alt+1…9`는 헤더의 표시 순서에 따른 프로젝트 탭을 선택한다. 그룹·재배열 순서를 따르며 포커스된 패널과 무관하다. 현재 프로젝트·없는 번호·모달·반복·owner 권한 없음은 전환하지 않는다. 원격 화면 포커스에서는 원격으로 전달한다.
- `Ctrl/Cmd+W/Shift+W`는 포커스된 내부 탭 하나를 닫는다. 표준 Ctrl/Cmd 조합은 고정 별칭이며 사용자 지정 단축키를 바꿔도 유지한다. 생성·닫기의 반복·IME·모달 입력은 소비하고 배경 탭을 조작하지 않는다.
- mew 버튼의 JavaScript 전체화면에서 생성·닫기·번호·이동 키와 R을 잠그고 원격 화면은 더 높은 우선순위로 전체 키를 받는다. 에이전트 패널의 `Ctrl/Cmd+R`은 [대화 비우기](../터미널·에이전트·자동화/에이전트%20대화·큐·복원.md#대화-비우기-단축키)에 사용한다. 원격에서 돌아오면 앱 잠금을 복원한다. 일반 Chrome 창의 예약키 제한·Chrome 앱 창 선택 경로와 검증은 [포커스 계약](../../development/ui-contracts.md#포커스-기반-탭-단축키)을 따른다.

- 언어·글꼴 선택은 공통 `SelectField`의 자체 드롭다운을 사용한다. 글꼴 이름 직접 입력·초기화와 브라우저별 저장을 유지한다.

- 한국어·영어·중국어 간체·일본어 설정을 에이전트·편집기·검색·Git·예약·원격 데스크톱·공용 패키지의 상태 문구와 접근성 이름에도 적용한다. 언어 전환 때 초안·검색어·본문을 유지하며 [UI 번역 계약](../../development/ui-contracts.md#ui-번역)의 누락 검사를 따른다.

- `ThemeButton`은 선택한 단색·그라데이션 배경의 둥근 사각형에 글씨색 `A`와 주요색 `a`를 표시한다. 선택 상태는 테두리·체크와 `aria-pressed`로 구분한다. 화면 너비에 따라 3~4열 그리드로 배치한다.
- 다크·라이트·미드나이트·포레스트·페이퍼·로즈·오션 프리셋 7개와 저장한 커스텀 테마를 표시한다. 미드나이트·로즈·오션은 두 색이 부드럽게 섞이고 천천히 움직이는 그라데이션을 사용한다. 프리셋은 즉시 적용하고 마지막 `+` 버튼은 현재 테마를 복사한 편집 영역을 연다.
- 커스텀 편집은 배경색·글씨색·주요색을 작은 색상 버튼으로 표시하며, 버튼을 누르면 최대 288px 너비의 공통 `ColorPicker` 안에서 HEX 입력·초기화·색상 영역·슬라이더를 조작한다. HEX 입력 옆에 초기화·닫기 아이콘을 모으고 별도 하단 버튼 행을 없앤다. 내부 여백은 8px, 색상 영역 높이는 112px이며 입력·아이콘은 28px, 슬라이더 행은 24px를 기본으로 쓴다. 터치 포인터에서는 입력·아이콘을 44px, 슬라이더 조작 영역을 36px로 늘린다. 배경색 옆에 **그라데이션** 체크와 두 색상 버튼을 모으고, 켜진 동안 방향 슬라이더·**배경 애니메이션**을 바로 아래에 표시한다. 좁은 화면에서는 같은 배경색 영역 안에서 줄을 바꾼다. `Aa` 미리보기에서 확인한 뒤 **테마 추가**로 저장·적용한다. 그라데이션 유무·두 색·방향·애니메이션까지 같은 조합은 중복으로 추가하지 않는다.
- 저장한 커스텀 테마 카드를 누르면 해당 테마를 적용하고 그리드 아래의 편집 영역을 바로 연다. 편집 후 **테마 저장**은 해당 항목을 교체한다. 편집 영역 안의 **커스텀 테마 삭제**를 누르면 해당 항목을 삭제하고 기본 다크 테마를 적용한다. **취소**는 초안을 버리고 선택한 테마의 저장된 상태를 유지하며, 편집을 시작한 카드나 `+` 버튼으로 포커스를 돌려준다. Esc·뒤로가기는 열린 색 선택기 → 커스텀 편집 영역 → 설정창 순서로 한 겹씩 닫는다. 저장 전 닫으면 초안을 버린다.
- 단색 라이트·페이퍼와 그라데이션 없는 밝은 커스텀 테마는 버블·중립 버튼·입력창·팝업의 공통 배경을 밝게 표시한다. 그라데이션이 있는 테마에서는 공통 표면의 색조를 더 진하게 파생하고 기본·raised·hover를 각각 48%·58%·72% 불투명도로 표시해 전체 배경이 비치게 한다. 원본 팔레트·전체 작업 배경·그라데이션·주요색·본문 글씨·테두리와 터미널 기본 배경은 유지하며 저장 항목이나 초안 형식은 바꾸지 않는다.
- Git·태스크·기능·디버거·메모 등 작업 패널의 큰 바탕과 탭바·데스크톱 독은 공통 그라데이션을 그대로 보여 준다. Git diff·SVG·미디어·스프레드시트·PDF 미리보기와 패널 로딩·커밋 작성 영역도 같은 바탕을 쓰며 활성 탭·버튼·입력창은 반투명 색조를 유지한다. 간트 격자와 주말 음영도 그라데이션을 비치게 한다. 실제 문서·미디어 콘텐츠의 배경과 팝업 내부·고정 영역의 가독성은 유지하고, 단색 테마로 바꾸면 기존 배경을 복원한다.

- 전역 그라데이션은 실제 `DockWorkspace`의 `[data-dock-workspace]` 포털 호스트까지 투명한 작업 배경을 통해 표시해 기본 경계색 배경이 에이전트 본문을 덮지 않게 한다. 부유창·대화상자·메뉴·선택 목록·툴팁은 라이트 모드에서 그라데이션 유무와 관계없이 바깥 배경 면에 75% 불투명도와 6px 배경 블러를 적용한다. 라이트·페이퍼·로즈·오션과 밝은 커스텀 테마에 모두 적용하며, 테마 배경색 70%와 기존 팝업 표면색 30%를 섞어 밝은 색조로 표시한다. 라이트 모달의 검은 덮개는 둥근 패널 바깥에만 표시해 반투명 패널 아래로 비치지 않게 한다. 다크 모드의 그라데이션 팝업은 기존 75% 배경·6px 블러를, 단색 팝업은 불투명 배경·블러 없음을 유지한다. 사이드바 명령어 버튼 추가·수정 창과 CSS·인라인 위치를 쓰는 에디터·날짜·태스크·그림판·원격 화면의 팝업, 뮤펫 대화·알림도 햄버거 메뉴와 같은 기준을 사용한다. 뮤펫 꼬리는 본체와 같은 불투명도를 사용한다. `src/components/overlay-layers.css`가 공통 배경·블러·바깥 덮개 규칙을 소유한다. 글씨·아이콘은 선명하게, 안쪽 컨트롤·트리 고정 행·로딩 덮개는 단색으로 유지한다. 바깥 누름·Esc·뒤로가기와 기존 레이어 순서는 보존한다.

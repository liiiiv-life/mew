## 요구사항

- 뮤펫 스킨이 없거나 고양이를 숨겨도 알림을 수집하고, 앱 내 알림이 켜져 있고 미확인 알림이 있으면 상단 전체화면 버튼 오른쪽, 햄버거 버튼 왼쪽에 종 아이콘과 개수를 표시한다. 누르면 같은 알림 목록에서 해당 화면 이동·개별 닫기·모두 확인을 제공한다.
- 알림 채널·자원 감시·테스트는 설정의 독립 **알림** 탭으로 옮긴다. 뮤펫 스킨이 켜진 경우 **뮤펫으로도 알림 표시** 옵션을 추가하며 이 옵션을 꺼도 헤더·OS 알림·소리를 유지한다. 뮤펫 탭은 스킨·기본 크기·원격 뷰어 숨김·휴식 설정을 소유한다.

- 화면 하단의 고양이와 상호작용하고, 에이전트 작업·오류·서버 과부하를 시각 알림과 선택적인 PC 데스크톱 알림·소리로 확인한다.
- 원하면 사용 시간 뒤 뮤펫 자체가 거대하게 커져 작업 화면을 가리고 휴식을 유도한다.

### 범위

- 대표 캐릭터 **뮤펫(Mewpet)**의 기본값이자 유일한 내장 스킨은 **카피바라**다. 사용자가 등록한 파일 스킨도 유지한다.
- 스프라이트 고양이의 걷기·달리기·클릭·끌기·던지기와 설정에서 숨기기·스킨 선택을 제공한다.
- 설정 → 뮤펫에서 가만히 있기·걷기·뛰기·공중 상승·공중 하강·쓰다듬기·목덜미 잡기 동작의 스프라이트 이미지·프레임 수·재생 시간·활성화 여부와 이동 속도를 등록하고 이름별로 저장·수정·삭제한다. 동작별 전체 재생 시간은 프레임 수와 독립적으로 설정하며, 공중 상승·하강은 독립 이미지를 사용하고 착지는 하강 이미지의 후반 프레임을 재사용한다.
- 작업 완료·오류·승인과 지속적인 서버 자원 과부하를 토스트로 알리고, 알림 목록에서 해당 화면으로 이동한다.
- 현재 보고 있는 에이전트 탭의 작업 완료 알림은 생략한다. 다른 탭·패널·브라우저 창에 있을 때의 완료 알림과 오류·승인 요청 알림은 유지한다.
- 클릭 목록·토스트의 문구와 접근성 이름은 화면 언어 설정을 따르며, 열린 상태에서도 언어 변경을 즉시 반영한다.
- 알림 채널·자원 감시를 설정하고 비활성 PC 창의 OS 알림·소리를 테스트한다.
- 기본 꺼짐인 강제 휴식을 제공한다.
- 사용·휴식 시간을 시/분으로 설정하고 사용 시간이 차면 큰 뮤펫이 휴식 종료까지 작업 화면을 가린다.
- 타이머만 표시하며 큰 뮤펫도 평소처럼 돌아다니고 잡아 끌거나 던질 수 있다.
- 그림 밖 화면·키보드 조작은 유지한다.

### 경계와 제한

- 현재 프로젝트의 연결된 ACP 채팅 탭만 감시한다.
- 터미널 전용 에이전트·닫힌 브라우저의 푸시는 포함하지 않는다.
- OS 알림은 브라우저 권한과 지원 환경이 필요하다.
- 일반 표시 모드는 바닥에서만 움직인다.
- 데스크톱·모바일 모두 독과 관계없이 현재 visual viewport의 맨 아래를 바닥으로 삼는다. 모바일에서는 고양이가 하단 독 위를 덮으며, 독 높이·숨김·safe area를 이유로 고양이를 위로 띄우지 않는다. 전체화면 전환·창 크기 변경·키보드·확대/스크롤 때 바닥과 이동 범위를 다시 계산한다.
- 강제 휴식은 거대 고양이의 시각·포인터 방해이며 전체 화면 덮개·입력 잠금·실제 시선 감지는 하지 않는다.
- 재배포 권한이 불명확한 외부 마스코트 자산은 재도입하지 않으며 현재 자체 기본 스킨을 사용한다.

### 관련 문서

- 팝업의 대화 기능은 [뮤펫 도우미](%EB%AE%A4%ED%8E%AB%20%EB%8F%84%EC%9A%B0%EB%AF%B8%C2%B7%EB%8C%80%ED%99%94%C2%B7Mew%20%EC%A1%B0%EC%9E%91.md)가 소유한다.

## 상세 동작

### 시작 시 전체화면 안내

mew를 열거나 새로고침할 때 전체화면이 아니면 뮤펫 말풍선으로 **전체화면으로 사용하면 mew 단축키가 안정적으로 작동해요.**와 **전체화면으로 전환 (Alt+Enter)** 버튼을 표시한다. 클라이언트가 Mac이면 `Option+Enter`로 표기하며 서버 OS와 무관하다. 사용자가 전체화면 단축키를 재지정하면 버튼도 실제 바인딩을 표시한다. 문구는 앱의 네 언어 설정을 따르고 열린 상태에서도 변경한다.

버튼은 클릭 제스처에서 앱 루트의 Fullscreen API를 호출한다. 기존 전체화면 단축키나 다른 화면의 버튼으로 진입해도 안내를 닫는다. 실패하면 안내를 유지하고 오류와 재시도를 제공한다. 닫기 또는 전체화면 진입 후 같은 앱 수명에서는 반복하지 않으며, 다음 로드에서 다시 표시한다. 영구 숨김 설정이나 자동 전체화면 진입은 하지 않는다.

기존 뮤펫 말풍선 위치·테마를 재사용하고 안내 중에는 고양이를 멈춘다. 스킨이 없으면 하단의 같은 안내를 표시한다. 일반 알림 채널 설정과 독립된 시작 안내이며, 원격 뷰어의 뮤펫 숨김·휴식 표시 계약은 유지한다. Fullscreen API를 지원하지 않거나 문서의 전체화면 사용이 금지된 클라이언트에서는 표시하지 않는다.

`server/mewcat-fullscreen-guide-ui.test.ts`는 격리 Chromium의 PC 다크·모바일 라이트에서 말풍선의 화면 경계·넘침, 클라이언트 OS 표기·언어 변경, 실패 후 재시도·닫기·새로고침·전체화면 종료 뒤 반복 없음·스킨 없음·미지원 상태를 검증한다. Fullscreen API는 성공·실패와 이벤트를 대역하며 실제 OS 키 선점이나 기기별 전체화면 동작을 검증하지 않는다.

설정 → 뮤펫의 **원격 데스크톱에서 뮤펫 숨기기**를 켜면 원격 뷰어가 열린 동안 고양이·말풍선·휴식 표시를 숨기고 닫으면 복원한다. 기본값은 꺼짐이며 브라우저별 `mew:mewcat-hide-desktop`에 저장한다. 알림 수집·OS 알림과 휴식 타이머는 계속 동작한다.

원격 데스크톱에서 표시하는 뮤펫·말풍선은 뷰어 내부 호스트에 portal하여 배경 `inert`의 영향을 받지 않는다. 클릭·드래그·키보드 조작은 뮤펫에서 처리하고 원격 입력으로 전달하지 않는다.

모바일(768px 미만)에서 설정을 열면 뮤펫·말풍선을 설정 내부 전용 호스트로 옮겨 설정창 위에 표시한다. 스킨·기본 크기를 바꾸면서 실제 뮤펫을 바로 확인하고 클릭·끌기·놓기를 할 수 있다. 그림 밖의 설정 입력·스크롤은 유지하며 뮤펫을 조작해도 설정을 닫지 않는다. 말풍선이 열려 있으면 Esc·뒤로가기로 말풍선을 먼저 닫고 다음 입력에서 설정을 닫는다. 설정 종료·데스크톱 폭 전환 시 원래 작업 영역 또는 원격 뷰어 호스트로 돌아가며, 원격 뷰어 숨김 설정은 계속 적용한다. 데스크톱에서는 설정이 일반 뮤펫보다 앞에 표시된다.

기능 항목: [Mewpet](Mewpet%20%EB%A7%88%EC%8A%A4%EC%BD%94%ED%8A%B8%C2%B7%EC%95%8C%EB%A6%BC%C2%B7%ED%9C%B4%EC%8B%9D.md). 이 문서는 해당 기능의 세부 동작·표시 계약을 소유한다.

일반 표시 모드의 Mewpet은 화면 **맨 아래**를 바닥으로 삼아 움직이며, 벽·천장을 타지 않는다. 데스크톱·모바일·전체화면 모두 현재 visual viewport의 화면 아래를 바닥으로 삼는다. 독의 위치·높이·표시 여부와 관계없이 같은 바닥을 유지하며, 모바일에서는 독 위에 겹쳐 표시한다. 기본 행동은 idle, walk, run과 가끔 하는 자동 점프 중 하나를 무작위로 골라 수행한다. 시스템 모션 감소 설정에서는 자동 점프와 선택 전환 재생을 생략하지만 걷기·뛰기·상승·하강·쓰다듬기·잡힌 상태를 나타내는 기본 프레임은 계속 재생한다. 스프라이트의 동작별 프레임과 좌우 반전으로 표현하며 0번 프레임에 강제로 고정하지 않는다.
기본 48px 정사각형 안에 비율을 유지해 카피바라를 표시한다. 카피바라는 작은 점눈과 굵고 투박한 갈색 선·면을 사용한다. 그림의 색은 테마·강조색과 무관하게 유지하며 설정 미리보기·휴식용 큰 고양이·원격 뷰어에도 같은 스킨을 적용한다.
Idle 스프라이트의 하단 투명 여백을 스킨의 공통 바닥 앵커로 사용한다. 공중·준비·착지 모션의 개별 여백으로 바닥을 다시 계산하지 않아 동작 변경 때 몸 위치가 튀지 않는다.

설정 → 뮤펫의 **기본 크기** 슬라이더는 24–144px 범위를 1px씩 조절하며 현재 크기를 표시한다. 되돌리기 버튼은 48px로 복원한다. 변경은 내장·커스텀 스킨과 원격 뷰어에 즉시 적용하며 기존 위치·동작·잡힌 상태를 유지한다. 바닥·벽 경계·투명 여백 보정·그림의 포인터 경로도 새 크기에 맞춘다. 스킨 미리보기는 기존 크기를 유지하며 휴식용 거대 뮤펫의 크기는 visual viewport에서 계산한다.

일반 크기는 scoped localStorage `mew:mewcat-size`에 브라우저별로 저장하며 P2P의 중앙 계정·인스턴스별 범위를 따른다. 다른 창에서 같은 범위의 값을 바꾸면 반영하고 새로고침 후 복원한다. 저장된 값이 없거나 숫자가 아니면 48px, 유효한 숫자가 범위를 벗어나면 가장 가까운 경계값을 사용한다. 저장 실패 시 현재 화면에는 적용하고 설정에 오류를 표시한다. 사용자 설정이므로 자동 캐시 정리 대상이 아니다.

마우스·터치로 끌 수 있고, 그동안 struggle 모션을 반복한다.
놓으면 마지막 포인터 이동의 수평·수직 속도를 운동량으로 이어 받아 중력이 적용된 궤적으로 날아간다.
일반·휴식용 뮤펫 모두 놓는 순간 실제 수평 운동량의 방향을 바라본다. 잡기 전 바라보던 방향과 관계없이 왼쪽으로 던지면 왼쪽, 오른쪽으로 던지면 오른쪽을 본다. 수평 운동량이 없으면 기존 바라보는 방향을 유지한다. 마지막 이동 뒤 120ms를 넘겨 놓거나 포인터 입력이 취소되면 운동량 없이 떨어지고 기존 바라보는 방향을 유지한다.
공중에 떠 있는 중에도 다시 눌러 붙잡을 수 있으며, 이때 기존 운동량은 멈춘다. 마우스·터치 모두
잡은 순간의 포인터와 캐릭터 사이 간격을 유지하며, 포인터를 움직이지 않아도 잡힌 위치에 머문다.
포인터를 잡고 있는 프레임은 마지막 포인터 좌표만 반영하고 이동·중력·바닥 보정을 건너뛴다.
수직 속도가 음수인 상승 중에는 jump, 0 이상인 하강 중에는 fall 모션을 반복하며, 양쪽 벽에 닿으면 진행 방향을 반대로 바꾸고 속도는
50%로 줄어든다. 정점 또는 천장 충돌에서 하강 동작으로 전환한다. 바닥에 닿을 때는 선택 착지 모션을 한 번 재생한다. 착지 이미지가 없으면 기존 fall의 후반 프레임을 사용한 뒤 다시 기본 행동을 무작위로 고른다.

일반·휴식용 Mewpet 모두 실제 그림 부분만 포인터 입력을 받는다. 프레임별 알파에서 추출한 48×48 포인터 경로를 사용한다. 그림 밖이나 사각형 경계
안의 투명한 부분을 누르면 뒤쪽 버튼·편집기로 입력이 전달된다. 던지거나 놓은 직후 포인터 캡처를
해제하며, 낙하 중에도 배경 조작을 막는 덮개를 두지 않는다. 그림에서 시작한 `touchstart`는
비수동 리스너에서 기본 동작을 취소해 브라우저의 터치 제스처가 던진 뒤 첫 배경 탭의 클릭을
삼키지 않게 한다. 터치 취소는 고양이 요소에만 적용하며, 탭·끌기·던지기는 기존 pointer 이벤트로 처리한다. 공중에서 다시 잡으려면 그림을 직접 누른다.

공개 레포에는 외부 마스코트 원본·가공본을 넣지 않는다. 재배포 권한이 불명확한 Oreo Cat 계열 자산은
재도입하지 않는다.

### 스킨별 모션 설정

스킨 편집기에서 기본 모션과 전환별 **재생 시간 (초)**을 0.05–60초(저장은 정수 ms)로 설정한다. 프레임 수를 바꿔도 한 주기 길이는 유지한다. 전환은 설정 시간에 한 번 재생하고, 미리보기는 같은 길이로 반복한다. Idle·걷기 등의 행동 선택 간격과 점프·낙하의 실제 비행 시간은 프레임 재생 시간과 독립적이다.

**이동 속도 (배)**는 0.1–5배이며 기본은 1배다. 걷기 48px/s·뛰기 115px/s·자동 점프 수평 90px/s에 배율을 적용한다. 전환 중 속도 보간, 일반·거대·원격 뷰어 뮤펫에도 같은 설정을 사용한다. 손으로 던지는 속도·중력은 기존 입력 물리를 유지한다.

Idle·걷기·Struggle은 체크된 비활성 컨트롤로 표시하며 서버도 끄기를 거부한다. 나머지는 활성화 체크로 켜고 끈다. 끈 기본 행동은 자동 선택에서 제외하고 연결된 전환도 재생하지 않는다. 점프를 끄면 자동 점프와 이륙·정점 전환을 하지 않는다. 공중 상승·하강을 끈 상태에서 직접 끌어 놓거나 던질 때는 물리 이동을 유지하면서 해당 그림을 Idle로 표시한다. 쓰다듬기를 꺼도 클릭으로 말풍선을 여는 동작은 유지한다.

`motion.stride`가 있으면 `walk`·`run`의 한 주기 보폭을 원본 프레임 px로 저장한다. 두 값 모두 유한한 0 초과·4096 이하 숫자여야 한다. 화면 크기/원본 셀 폭과 보폭·재생 시간으로 이동 속도를 계산하므로 기본 크기·거대 휴식에서도 접지발이 같은 바닥을 짚는다. 이 스킨은 이동 배율에 맞춰 걷기·달리기와 여섯 지상 전환의 재생 시간도 함께 바꾼다. 예를 들어 0.5배면 해당 재생 시간은 2배다. 보폭이 없는 기존 스킨은 위 기본 속도·재생 동작을 유지한다. 설정에서 이름·시간 등을 수정해도 기존 보폭 메타데이터를 보존한다.

`skin.json`과 업로드 manifest의 `motion`은 `durations`(모션별 ms), `enabled`(모션별 boolean), `movementSpeed`(배율)를 저장한다. 목록 응답·새로고침·수정·내장 덮어쓰기에서도 유지한다. 설정이 없는 기존 스킨은 기존 시간·1배·모션 활성화를 기본값으로 사용한다. 필수/활성 기본 이미지 누락과 잘못된 시간·배율·필수 모션 끄기를 저장 전에 거부하며 이전 정상 스킨을 보존한다.

업로드는 모션 이미지 최대 16개와 manifest 하나를 함께 허용한다. multipart 파서가 제한값에 도달하는 순간 오류를 내는 경계를 고려해 parts 상한은 18로 설정하고, 파일 16개·일반 필드 1개 제한은 유지한다. 파일 크기/개수 초과만 파일 제한 오류로 표시하며, 다른 업로드 형식 오류는 스킨 입력 오류로 구분한다.

### 선택 전환 모션과 자동 점프

`idle`·`walk`·`struggle` 세 모션은 필수이며 항상 활성화한다. `run`·`jump`·`fall`·`love`와 전환 모션은 각각 끌 수 있고, 비활성 모션의 이미지는 생략할 수 있다. 아래 아홉 전환 모션은 각각 선택 사항이며, 일부 또는 전부 생략한 기존 스킨도 계속 사용할 수 있다. 설정의 **기본 모션** 아래 **전환 모션 (선택)**을 펼쳐 이미지·프레임 수·미리보기·예제 다운로드를 사용하며, 등록한 전환만 제거할 수 있다. 새 입력의 기본 프레임 수는 기본 모션 8, 전환 모션 2이며 이미 저장한 스킨의 프레임 수는 보존한다. 필수 이미지 검증과 이미지·프레임 제한은 동일하다.

| 전환 | 이미지 키 | 기본 한 번 재생 시간 |
| --- | --- | --- |
| 뛰기 → 걷기 | `run-walk` | 220ms |
| 걷기 → 뛰기 | `walk-run` | 180ms |
| 뛰기 → Idle | `run-idle` | 260ms |
| Idle → 뛰기 | `idle-run` | 220ms |
| 걷기 → Idle | `walk-idle` | 240ms |
| Idle → 걷기 | `idle-walk` | 240ms |
| 바닥 → 점프 | `takeoff` | 240ms |
| 낙하 → 착지 | `landing` | 240ms |
| 공중 상승 → 하강 | `apex` | 180ms |

자발적인 Idle·걷기·달리기 변경은 현재 반복 주기의 끝에서 전환을 시작한다. 전환은 한 번 재생한 뒤 다음 기본 모션의 0번 프레임부터 새 주기를 시작하며, 전환에 쓴 시간을 다음 모션의 경과 시간에 더하지 않는다. 착지는 Idle 자세를 회복한다. 누르기·끌기·주의 알림은 주기 경계를 기다리지 않는다. 프레임 수와 무관하게 모션별 설정 시간을 사용하며(표는 기본값) 반복 미리보기만 순환한다. 걷기·뛰기·Idle 사이에는 전환 시간 동안 수평 속도를 이전 속도에서 다음 속도로 연결한다. 누르기·끌기는 전환을 즉시 취소하며 포인터가 잡힌 동안 위치·중력·자동 행동을 멈춘다.

자유 행동을 다시 고를 때 10% 확률로 자동 점프를 선택한다. 알림·전체화면 안내·열린 말풍선 등 주의 상태와 모션 감소 설정에서는 자동 점프를 시작하지 않는다. 걷기·달리기에서 자동 점프를 선택하고 정지 전환이 있으면 먼저 Idle로 멈춘다. `takeoff`가 있으면 바닥에서 준비 모션을 재생한 뒤 현재 방향으로 이륙하고, 없으면 기존 `jump`를 사용한다. 실행 직전에도 주의 알림과 점프 활성화를 다시 확인한다. 이륙 뒤 수평 90px/s·수직 −640px/s에서 기존 중력·벽·천장·바닥 규칙을 적용한다. `apex`는 수직 속도가 음수에서 0 이상으로 바뀔 때 재생하며 그동안 비행 물리는 계속 진행한다. 보폭 메타데이터가 있는 스킨은 남은 하강 시간과 실제 중력 적분 간격에 맞춰 정점 시간을 줄여 착지 전에 하강 준비 자세를 표시한다. 두 프레임보다 짧은 비행에서는 정점을 생략한다. 이 시간 보정은 해당 전환에만 적용하며 다음 점프의 설정 시간은 유지한다. `landing`은 실제 바닥 접촉 때 재생한다. 손으로 던질 때는 바닥 준비 모션 없이 즉시 상승·하강을 시작한다. 이 규칙은 일반 크기와 휴식용 거대 펫이 공유한다.

여섯 내장 스킨은 각각 아홉 전환을 **2프레임·256×128** 투명 PNG와 무손실 WebP로 제공한다. 기본 모션은 **8프레임·1024×128**을 유지한다. 두 전환 프레임은 시작 자세에서 다음 상태로 이어지는 서로 다른 핵심 자세다. 내장 image_gen으로 캐릭터를 참조해 6열×3행 아틀라스의 연속 두 셀을 하나의 전환으로 생성한 뒤 같은 128px 셀·127px 발바닥 기준선으로 정렬했다. 카피바라의 이전 8프레임 전환 생성 기록은 `transitions-source.json`의 `previousSources`에 보존한다. 프롬프트·실제 참조·원본 아틀라스·정렬 규격은 각 스킨 폴더에 보존한다.

`src/utils/mewcat-sprites.ts`는 선택 모션 타입·상태 대응·설정 가능한 재생 시간과 한 번 재생을, `src/components/Mewcat.tsx`는 전환 수명·자동 점프와 물리를, 스킨 저장·설정은 이미지 등록·제거·복원을 소유한다. `server/mewcat-transitions-ui.test.ts`는 여섯 내장 스킨의 PC·모바일에서 두 전환 프레임의 실제 진행과 여섯 방향 전환·이륙·정점·착지·준비 중 잡기·던지는 방향 유지와 이미지 없는 스킨·모션 감소의 폴백을 검사한다. 설정 회귀 테스트는 일곱 기본 모션만으로 저장, 선택 전환 등록·잘못된 프레임 거부·제거·저장 후 복원을 검사한다.

### 클릭으로 최근 알림 확인

일반 Mewpet을 클릭·탭하면 현재 위치에 폭 260px의 작은 말풍선을 연다. 본문은 최근 알림을
최신순으로 보여 주며 제목·본문은 12px, 출처는 11px로 표시한다. 항목별 × 버튼으로
해당 알림만 지울 수 있다. 목록은 기존 페이지 메모리의 최대 30개 알림을 사용하고, 이미 확인·삭제한
항목을 다시 가져오지 않는다. 알림이 없으면 빈 상태 안내를 표시한다. 목록이 길면 본문만 스크롤한다.
헤더·목록의 좌우 여백은 12px로 맞춘다. 헤더는 위아래 8px, 알림 행과 빈 상태는 위아래 12px를 두고 본문 안쪽 패딩을 중복하지 않는다. 본문과 출처 사이는 2px, 16px 상태 아이콘·본문·닫기 사이 간격은 8px다. 행의 본문과 닫기 버튼은 세로 가운데에 정렬하고 상태 아이콘은 첫 줄에 맞춘다.

- 제목·빈 상태·모든 알림 종류·버튼·접근성 이름·자원 툴팁은 화면 언어 설정(한국어·영어·일본어·중국어 간체)을 따른다. 열린 말풍선과 기존 알림도 언어 변경 즉시 다시 번역한다. CPU·GPU 약어와 사용자 지정 에이전트 이름은 유지하며, 테스트 알림의 뮤펫 이름은 번역한다.
- 대상이 있는 알림 본문은 기존 대화·시스템 자원·업데이트 화면을 열고 해당 알림을 확인 처리한다.
- 시스템 자원 권한이 있으면 최상단 바에 작은 자원 버튼을 표시한다. 버튼은 모바일·데스크톱 모두 36×36px이며, 높이 24px·같은 폭의 세로 게이지를 2px 간격으로 나란히 표시한다. 각 게이지는 모서리를 4px로 둥글게 하고 CPU·RAM·GPU를 뜻하는 `C`·`R`·`G`를 가로·세로 중앙에 Mono 글꼴로 표시한다. 수치는 툴팁과 스크린 리더용 설명에 제공한다. 게이지는 테마 주요색(`accent` 토큰)으로 아래에서 위로 채우며, 채움 높이는 0~100% 범위로 제한한다. 라벨은 빈 배경에서는 테마 글씨색(`ink`), 채움 위에서는 주요색 위 글씨색(`ink-on-accent`)을 사용해 밝은·어두운 테마에서 읽을 수 있게 한다. 값이 없으면 게이지를 비운다. 게이지 그림은 접근성 트리에서 제외하고 버튼의 번역된 이름과 별도의 수치 설명을 연결한다. 갱신 애니메이션은 추가하지 않는다. 약어는 모든 언어에서 유지하고 툴팁 제목·접근성 이름은 화면 언어를 따른다.
- CPU는 서버 전체 사용률, RAM은 사용량/총량, GPU는 여러 GPU의 최대 연산 사용률이다. 미지원 값은 툴팁·접근성 설명에서 `—`로 표시한다. 조회 실패·로딩 중에는 막대를 비우고 상태 툴팁을 표시하며 접근성 설명의 수치를 `—`로 바꾼다. 브라우저 기기가 아니라 **mew 서버 기계**의 자원이다.
- 헤더를 표시할 때 즉시 조회하고 500ms 간격으로 갱신한다. 이전 요청이 진행 중이면 해당 주기를 건너뛰며 10초 타임아웃을 둔다. 실패하면 이전 값을 비우고 다음 주기에 재시도한다.
- 자원 버튼을 누르면 기존 시스템 자원 팝업을 연다. 뮤펫 스킨·말풍선·알림 설정과 독립적으로 표시·갱신한다. 권한 해제·계정 변경·헤더 해제 시 요청과 타이머를 정리한다. 뮤펫 최근 알림 목록에는 자원 줄과 별도 조회를 두지 않는다.
- 닫기·Mewpet 재클릭·Esc·뒤로가기·끌기 시작·스킨 숨기기·강제 휴식 진입 시 목록을 닫는다. Enter·Space로도 열 수 있다. 큰 휴식용 고양이는 기존 상호작용만 유지한다.
- 수동 목록은 토스트·자원 감시 설정과 독립적이다. 목록이 열려 있어도 새 알림은 토스트로 표시한다. 단순 목록 열기·닫기는 알림을 삭제하지 않는다.
- 자원 점유율을 큰 가로 카드로 보여 주던 본문은 알림 목록으로 대체했다. 사용자 요청 전 재도입하지 않는다.

`src/components/header-resources.tsx`가 상단 자원 표시·조회 수명을, `src/components/mewcat-resources.tsx`가 클릭 목록을, `Mewcat.tsx`가 클릭/드래그
구분과 표시 상태를 소유한다. `App`은 시스템 자원 권한이 있을 때만 헤더 자원 버튼을 표시하고 기존 팝업 콜백을 전달한다.

말풍선은 `src/hooks/use-mewcat-bubble.ts`에서 현재 고양이 위치와 visual viewport를 따라 배치한다.
기본은 고양이 위쪽 가운데이며, 화면 양 끝에서는 본체를 화면 안으로 보정하고 아래 꼬리를 고양이
중심 쪽으로 움직인다. 알림 중 끌기·던지기에도 위치를 따라가며, 위쪽 공간이 부족하면 아래쪽에
배치하고 꼬리를 위로 돌린다. 창 크기·키보드·확대/스크롤·목록 펼침에 맞춰 너비·높이도 보정한다.
클릭·알림 도착을 이유로 고양이를 오른쪽 끝으로 보내던 동작은 제거했으며 재도입하지 않는다.
고양이를 숨긴 알림 패널은 기존 오른쪽 아래 위치를 유지한다.

### 스킨 선택

설정 창의 **뮤펫** 카테고리에서 화면별 스킨을 고른다. 첫 카드는 **없음**이며, 선택하면 Mewpet을
렌더링하지 않는다. 유일한 내장 스킨인 **카피바라**와 사용자가 등록한 스킨을 실제 그림의 정적 미리보기로 선택한다. 목록·편집기 미리보기는 공통 `surface-hover` 배경을 사용한다. 카피바라(`capybara`)가 기본값이다. 제거된 내장 스킨의 `mew`·`oreo`·`kitten`·`russian-blue`·`black-cat`·`korean-shorthair`·`siamese`·`penguin` 선택은 카피바라로 복원한다. 없음·그 외 파일 스킨 선택은 유지한다. 선택 ID는 scoped localStorage의 `mew:mewcat-skin`에 저장한다. scoped 선택이 아직 없으면 기존 origin 공통 설정의 없음·카피바라·제거된 내장 선택을 이어받으며 커스텀 ID는 다른 인스턴스로 이관하지 않는다.

카피바라(`capybara`)는 넓고 둔한 주둥이·둥근 귀·큰 갈색 몸통에 작은 가로 점눈과 멍한 표정을 유지한다. 일곱 동작 모두 굵고 조금 삐뚤한 선과 단순한 갈색 면으로 대충 그린 듯한 그림체를 사용하며 눈 반짝임·광택·세밀한 털 묘사를 넣지 않는다. 일곱 동작·상승과 하강 분리·좌우 반전·끌기·휴식·원격 표시를 지원한다.

러시안블루·까만 고양이·코리안 숏헤어·샴·펭귄은 사용자의 디자인 판단에 따라 내장 제공을 제거했다. 카피바라의 이미지·프레임·재생 시간은 유지한다. 명시적인 후속 요청 전 이 다섯 내장 스킨을 재생성하거나 다시 등록하지 않는다.

이전 기본 SVG 고양이와 전용 털색 선택기·HEX·초기화는 사용자 요청으로 제거했다. 기존 `mew:mewcat-fur-color` 값은 사용하지 않으며 사용자 요청 전 이전 캐릭터·털색 설정을 재도입하지 않는다. 내장·업로드 스킨의 색은 이미지 그대로 표시한다.

**스킨 추가**에서 이름과 활성화한 기본 동작의 이미지를 넣고 프레임 수·재생 시간을 입력한다. 저장하면 새 스킨을 바로 적용한다. 이름별 수정·삭제를 제공하며 활성 스킨을 삭제하면 카피바라로 복귀한다. 입력 중에는 동작별 미리보기를 재생하고, 예제 다운로드 버튼으로 현재 고른 스킨의 이미지를 받을 수 있다. 없음 선택에서는 기본 뮤펫 예제를 제공한다. 스킨 목록은 서버 전역으로 공유하며 등록·수정·삭제는 owner만 사용할 수 있다. 내장 스킨을 수정하면 전역 폴더에 같은 ID의 사용자 버전을 저장하고, 이를 삭제하면 내장 원본으로 돌아온다.

| 동작 | 이미지 키 | 정방향 재생 시간 |
| --- | --- | --- |
| 가만히 있기 | `idle` | 880ms |
| 걷기 · 한 방향 | `walk` | 880ms |
| 뛰기 · 한 방향 | `run` | 340ms |
| 공중 상승 | `jump` | 560ms |
| 공중 하강 | `fall` | 560ms |
| 쓰다듬기 | `love` | 560ms |
| 목덜미 잡기 | `struggle` | 600ms |

- 같은 크기의 프레임을 **가로 한 줄**로 나열한 PNG·WebP를 받는다. 이미지 하나당 4MiB, 스킨 전체 합계 24MiB, 16메가픽셀 이하이며 너비 최대 32768px·높이 최대 4096px다. 프레임 수는 1~256인 정수이고 이미지 너비를 균등하게 나눌 수 있어야 한다. 투명한 배경을 권장한다. 손상되거나 전체가 투명한 이미지는 저장하지 않고 오류를 표시한다.
- 걷기가 10프레임이면 각 프레임을 88ms씩 표시해 모두 재생한다. 5프레임이면 각 176ms이며 같은 880ms에 한 바퀴를 마친다. 걷기·뛰기의 이동 속도는 기존 48px/s·115px/s를 유지하고 반대 방향은 좌우 반전한다.
- 낙하는 전체 재생 시간마다 정방향으로 순환한다. 내장 카피바라의 8프레임은 560ms 동안 45·44·42.5·41·40·41·42.5·44도 부근의 자세를 재생해 마지막→첫 프레임에서도 기울기가 이어진다. 실제 펫과 설정 미리보기에 동일하게 적용한다. 원본 atlas와 생성·정규화 정보는 `public/mewcat/capybara/fall-source-atlas.png`와 `fall-source.json`에 보관한다. 착지는 기존 하강 후반 240ms 또는 등록된 별도 착지 전환을 한 번 재생한다.
- 공중 상승·하강 이미지를 별도로 등록한다. 상승·하강은 처음 560ms에 모든 프레임을 순서대로 재생하며 하강도 이후 같은 순서로 반복한다. 착지는 하강 이미지의 후반 프레임을 240ms에 재생한다. 1프레임 이미지도 지원한다. 기존 다섯 동작만 저장한 커스텀 스킨은 목덜미 잡기의 첫 프레임을 위·아래 방향으로 기울인 독립 1프레임 이미지로 보완해 계속 사용할 수 있다. 설정에서 전용 이미지를 넣어 교체할 수 있고 다음 수정 저장 시 일곱 동작을 보관한다.
- 스프라이트는 비율을 유지해 48px 정사각형 안에 표시한다. 모든 프레임의 공통 하단 투명 여백을 바닥 위치에 보정하며, 그림 밖 포인터 입력은 배경으로 통과시킨다. 거대 휴식용 뮤펫과 원격 뷰어에도 같은 선택을 적용한다. 시스템 모션 감소에서도 기본 동작의 프레임 재생은 유지한다. 스킨 목록 카드는 정적이고 편집기의 동작 미리보기는 시스템 설정과 관계없이 등록한 모든 프레임을 반복 재생한다.
- 이미지·프레임 수·이름은 `DATA_DIR/mewpet/skins/<스킨 폴더>/`의 파일에 저장한다. 목록은 같은 Mew 인스턴스의 모든 프로젝트·워크스페이스·계정·기기에서 공유하며 P2P도 같은 API를 사용한다. 선택 ID·크기·숨김 취향은 기존 브라우저 범위를 유지한다. 저장 실패 시 입력과 이전 스킨을 유지한다. [브라우저 저장 계약](../../development/browser-storage.md)을 따른다.

`src/utils/mewcat-sprites.ts`가 프레임·재생 주기 계약을, `mewcat-sprite-storage.ts`가 이미지 검사·전역 API·옛 IndexedDB 이관·포인터 알파 경로를, `mewcat-skin-settings.tsx`가 등록·수정 UI를 소유한다. `Mewcat.tsx`의 기존 물리·포인터 처리에서 상태별 프레임을 진행한다.

`mewcat-sprite.tsx`는 `playing`이 켜진 편집기 미리보기를 반복 재생하고 꺼진 목록 카드를 첫 프레임으로 유지한다. 실제 펫은 `Mewcat.tsx`가 동작 시간에 맞춰 `mewcat-sprite-render.ts`로 이미지의 가로 위치와 해당 프레임의 포인터 경로를 함께 바꾼다. `server/mewcat-animation-ui.test.ts`는 PC·모바일의 일반/모션 감소 환경에서 카피바라의 필수·전환 미리보기 진행, WebP 걷기의 실제 표시 픽셀 변경, 화면 아래 펫의 걷기 프레임과 정적 카드 유지, 긴 낙하와 낙하 미리보기의 마지막 프레임 이후 역순 진행을 확인한다.

내장 이미지는 `public/mewcat/capybara/`에 보관한다. 카피바라의 필수 일곱 동작은 동작당 8프레임·1024×128, 선택 아홉 전환은 2프레임·256×128이며 상승·하강도 독립 이미지다. 생성 기록은 `source.json`과 `transitions-source.json`, 이전 기록은 각 `previousSources`에 보존한다. ID·번역 이름·순서·이미지와 프레임 수는 `skin.json`이 소유해 미리보기·실제 렌더링·예제 다운로드가 같은 스킨을 사용한다. 외부 오레오캣 자산은 사용하지 않는다.

### 첫 표시와 비동기 로딩

새로고침 직후 선택 스킨이 준비되기 전에는 뮤펫을 숨긴다. 예비 그림·로딩 문구·포커스 대상·포인터 입력 영역을 표시하지 않는다. 이때도 새 알림은 토스트로 표시하며, 전체화면 시작 안내는 펫에 연결하지 않고 화면 하단에 표시한다. 스킨 없음·화면 숨김 취향은 그대로 따른다. 실제 이미지가 준비되면 바닥 위치에서 표시하고 정상 이동·상호작용을 시작한다. 같은 동작을 다시 선택해도 프레임 재생 주기를 끊지 않는다.

스킨 목록을 받은 뒤 설정된 ID를 가장 먼저, 기본 `capybara`를 다음으로 가져온다. 한 펫 안의 이미지는 최대 네 개씩 비동기로 받고, 한 펫이 모두 준비될 때마다 바로 게시한 뒤 다음 펫을 가져온다. 선택 펫의 표시는 다른 펫·미리보기·옛 IndexedDB 이관 완료를 기다리지 않는다. 나머지 로딩 중에는 이미 표시한 그림을 유지하고 최종 목록 순서는 서버 순서로 복원한다. 선택 ID의 파일 교체가 실패하면 이전 정상 그림을 계속 사용한다. 선택 ID를 아직 로드하는 동안 다른 기본 펫을 잠깐 표시하지 않는다.

여섯 내장 스킨의 필수·전환 96개 이미지는 필수 1024×128·전환 256×128 규격의 무손실 WebP로 전송하며 `skin.json`의 파일명을 해당 `.webp`로 연결한다. 생성 원본 PNG와 프롬프트는 보존한다. 기존 변환은 FFmpeg의 `libwebp`, `lossless=1`, `quality=100`, `compression_level=6`으로 수행했다. API·프레임 검사·예제 다운로드·사용자 PNG·WebP 업로드 규칙은 유지한다.

`server/mewpet-loading-ui.test.ts`는 PC 다크·모바일 라이트에서 목록 응답을 지연시켜 뮤펫·예비 그림·로딩 문구 숨김과 독립 토스트 표시·자동 종료를 확인한다. 선택 펫의 표시 후 끌기, 다른 네 펫의 응답을 막아도 선택 펫이 먼저 표시되는지, 네 이미지 동시 요청 상한과 최종 목록 순서·교체 실패 시 이전 그림 유지도 검사한다.

### 파일로 스킨 등록

에이전트 채팅에서 캐릭터 설명·참조 이미지로 스프라이트를 만들 때는 별도 설치한 [외부 생성 MCP](../../configuration/local-sprites.md)를 선택적으로 연결한다. 생성 도구·모델·Python 의존성은 Mew 배포에 포함하지 않는다. 도구의 출력 경로를 아래 전역 폴더로 지정하고 사용자가 등록을 요청한 결과만 추가하며, 스킨 선택은 설정에서 한다.

설치마다 하나인 `DATA_DIR/mewpet/skins/` 아래에 스킨 폴더를 만든다. 현재 설치는 기존 `.data/`를 DATA_DIR로 사용하며, 다른 설치의 기본 위치·`MEW_DATA_DIR`는 [서버 상태 계약](../../development/architecture.md#서버-상태-파일-data)을 따른다. 프로젝트의 Documents·작업 폴더에는 스킨을 저장하지 않는다.

폴더에 일곱 동작의 PNG·WebP와 아래 `skin.json`을 넣는다. `id`는 영문·숫자로 시작하는 1~80자 ID이며 영문·숫자·밑줄·하이픈을 받는다. 옛 `custom:<id>`도 호환한다. `name`은 1~40자이고 `frames`는 이미지별 실제 프레임 수다. 파일 경로는 해당 스킨 폴더 안의 상대 경로를 사용한다.

```json
{
  "id": "my-pet",
  "name": "내 동물",
  "sprites": {
    "idle": { "file": "idle.png", "frames": 8 },
    "walk": { "file": "walk.png", "frames": 8 },
    "run": { "file": "run.png", "frames": 8 },
    "jump": { "file": "jump.png", "frames": 8 },
    "fall": { "file": "fall.png", "frames": 8 },
    "love": { "file": "love.png", "frames": 8 },
    "struggle": { "file": "struggle.png", "frames": 8 }
  }
}
```

선택 전환 모션도 같은 `sprites` 객체에 추가한다. 내장 폴더와 전역 폴더는 매 목록 조회에서 읽으며 전역의 같은 ID가 내장을 덮는다. 유효하지 않은 폴더·중복 ID·심볼릭 링크·폴더 밖 경로는 등록하지 않고 부분 로드 오류로 알린다. 파일을 다 넣은 뒤 `skin.json`을 마지막에 저장한다. API 업로드는 새 버전의 이미지 전체를 먼저 쓴 뒤 manifest를 원자적으로 교체해 이전 정상 스킨을 보존한다. 이전 이미지 버전은 스킨 삭제 전까지 보관해 파일 복구에 사용할 수 있다.

설정 열기·새로고침 버튼·창 포커스 복귀와 활성 창의 30초 주기로 목록을 다시 읽는다. 선택 중인 ID의 파일이 바뀌면 그림도 갱신된다. 이후 스킨 추가·교체에는 앱 빌드·서버 재시작이 필요 없다. 이 저장 기능 자체를 처음 적용하는 코드 업데이트는 사용자가 기존 실행 규칙에 따라 적용한다.

이전 scoped IndexedDB `mewcat-sprite-skins`에 남은 커스텀 스킨은 owner가 열 때 전역 파일로 이관한다. 일곱 동작이 없던 스킨의 상승·하강을 보완하며 성공한 항목만 이관 표시를 남긴다. 원본 Blob은 보존한다. 실패나 owner 이외의 계정에서는 기존 로컬 스킨을 계속 보여 주고 이관 안내를 표시한다. 한 번 이관한 스킨을 삭제해도 옛 브라우저 복사본으로 되살리지 않는다. 기존 코드 파일명·저장 키·MCP 식별자의 `mewcat`은 호환을 위해 유지한다.

`server/mewpet-skins.ts`가 파일 목록·검사·원자적 저장을, `server/mewpet-skin-routes.ts`가 프로젝트와 독립된 `/api/mewpet/skins`와 owner 쓰기 경계를 소유한다. 목록과 이미지 응답은 `private, no-store`이며 새 그림을 빌드 산출물에서 찾지 않는다.

### 작업·오류·자원 알림

작업 완료·오류·승인·서버 자원·업데이트 알림은 공용 `Toast`로 화면 하단에 표시한다. 제목과 출처를 한 줄로 보여 주며 긴 내용은 말줄임한다. 토스트는 2.6초 뒤 사라지고, 그 사이 새 알림이 오면 최신 알림으로 교체해 시간을 다시 센다. 포커스를 옮기거나 포인터 입력·뒤로가기를 가로채지 않으며 화면 판독기에는 polite 상태 알림을 제공한다. 스킨 로딩 중에도 같은 방식으로 표시한다.

토스트의 종료는 알림 확인 처리가 아니다. 미확인 항목은 헤더의 종 버튼과 뮤펫 클릭 목록에 남고, 목록에서 해당 대화·시스템 자원·업데이트 화면으로 이동하거나 개별 확인할 수 있다. 대상 에이전트 탭이 이미 닫혔으면 새로 만들지 않는다. 승인 요청은 화면 이동 후에도 처리되거나 사용자가 확인할 때까지 목록에 남는다. 새 승인 요청은 열린 뮤펫 도우미·최근 목록을 닫고, 전체화면 시작 안내보다 먼저 토스트로 표시한다. 요청 처리 후 시작 안내를 복원한다.

뮤펫은 추가 알림 표시가 켜진 미확인 알림이나 클릭 목록이 있으면 현재 위치에서 멈춘다. 알림을 모두 확인하면 다시 돌아다닌다. 새 알림에는 그림이 3도 기울었다 돌아오는 420ms 동작을 한 번 재생하며, 모션 감소에서는 생략한다. 끌기·던지기는 유지한다. 스킨 없음에서는 토스트를 표시하지 않고 상단 종 버튼에서 알림을 확인한다.

수동 최근 목록·도우미·전체화면 시작 안내는 기존 말풍선 위치와 테마를 유지한다. 본체와 꼬리에는 `drop-shadow(0 4px 10px rgb(0 0 0 / 24%))` 그림자를 적용한다. 고양이 그림의 색상은 유지하며, 말풍선에 크림색·갈색을 고정하던 스타일은 재도입하지 않는다.

- **작업 완료**: 실시간 `turn_end(end_turn)` 뒤 대기 큐가 비고 실행이 멈춘 `meta`를 받았을 때.
  큐 중간 턴·사용자 취소·과거 기록 재생·히스토리 복원은 완료 알림을 보내지 않는다.
- **오류·승인**: 에이전트 오류·인증 실패·실패 종료·승인 요청, 토큰 한도 등 비정상 중단을 알린다.
  같은 실패의 error/turn_end는 한 번만 알리고 승인 처리가 끝나면 해당 알림을 제거한다.
- **연결 끊김**: 뮤펫 말풍선·목록·소리·데스크톱 알림을 보내지 않는다. 반복적인 연결 끊김 알림은 사용자 요청으로 제거했으며 요청 전 재도입하지 않는다. 해당 에이전트 패널 안의 반투명 어두운 덮개와 로딩 표시로만 알린다([패널 연결 표시](../%ED%84%B0%EB%AF%B8%EB%84%90%C2%B7%EC%97%90%EC%9D%B4%EC%A0%84%ED%8A%B8%C2%B7%EC%9E%90%EB%8F%99%ED%99%94/%EC%97%90%EC%9D%B4%EC%A0%84%ED%8A%B8%20%EB%8C%80%ED%99%94%C2%B7%ED%81%90%C2%B7%EB%B3%B5%EC%9B%90.md#연결-대기와-재연결)).
- **업데이트**: 시스템 권한이 있는 계정이 앱에 접속할 때 설치된 관련 항목을 조회하고 업데이트가 있으면 개수·대표 항목을 알린다. **업데이트 보기**는 통합 업데이트 화면을 연다. 조회 실패를 최신 상태로 알리지 않는다. 상세 대상·실행 제한은 [통합 업데이트](../../deployment/native.md#설치된-의존성에이전트-통합-업데이트)를 따른다.
- **과부하**: 시스템 자원 권한이 있는 계정만 기존 `/api/system-stats`로 **서버 기계**를 감시한다.
  브라우저를 실행하는 PC의 메모리나 JS heap 감시가 아니다. 요청 완료 후 15초 간격으로 겹치지 않게
  조회하며 10초 타임아웃을 둔다. 3회 연속 높은 값일 때 알리고 정상 회복 전에는 반복하지 않는다.
  조회 실패·알 수 없는 값은 높은 표본으로 세지 않는다.

| 자원 | 알림 기준 | 다시 알릴 수 있는 회복 기준 |
| --- | --- | --- |
| CPU 사용률 | 90% 이상 | 75% 미만 |
| 메모리 (`total - available`) | 90% 이상 | 80% 미만 |
| GPU 메모리 (GPU 중 최대 사용률) | 95% 이상 | 85% 미만 |
| CPU·GPU 중 최고 온도 | 90°C 이상 | 80°C 미만 |

이 임계값은 일반적인 주의 알림 기준이며, 하드웨어별 안전 한계 판정이나 강제 작업 종료가 아니다.
알림은 현재 페이지 메모리에 최근 30개까지 유지하고 새로고침·로그인 계정 변경 시 비운다.
같은 식별자의 이벤트는 확인 후에도 30초 동안 재전송을 억제한다. 여러 mew 브라우저 탭 사이의
알림 통합·중복 제거는 하지 않는다.

### 알림 설정과 PC 데스크톱 알림

**설정 → 알림** 맨 위의 **승인 요청 시 에이전트 탭 열기**는 기본 켜짐이다. 새 실시간 승인 요청을 받으면 다른 작업 중에도 해당 프로젝트·에이전트 탭을 전면에 연다. 자동 이동은 앱 내·뮤펫 알림 표시 설정과 독립적이며, 이 옵션만 끄면 현재 화면을 유지하면서 다른 알림은 계속 받을 수 있다. 같은 요청의 중복 이벤트와 과거 대화 재생으로 반복 이동하지 않는다. 기존 저장값에 `autoOpenApproval`이 없으면 켜짐으로 읽는다. 상세 이동·버블 펼침은 [에이전트 승인 대기 계약](../터미널·에이전트·자동화/에이전트%20대화·큐·복원.md#승인-대기-상태)을 따른다.

앱 내 알림, 데스크톱 알림, 소리, 서버 자원 감시도 각각 켜고 끈다.
앱 내 알림·자원 감시는 기본 켜짐, 데스크톱·소리는 기본 꺼짐이다. 뮤펫 스킨이 활성화되어 있으면 **토스트 알림**을 추가로 설정하며 기본 켜짐이다. 설정은 이 브라우저의
`mew:notification-preferences`에 저장하며 저장소를 쓸 수 없으면 현재 페이지에서만 적용한다.
스킨 **없음**은 고양이·토스트를 숨기며 헤더 알림·OS 알림·소리 수집과 전달은 유지한다. 헤더의 종은 앱 내 알림(`visual`)이 켜지고 큐에 항목이 있을 때만 표시한다. 기존 저장값은 그대로 이어받고 추가 `mewcat` 필드가 없으면 기본 켜짐으로 읽는다. 앱 내 알림을 꺼도 큐를 삭제하지 않아 다시 켜면 확인할 수 있다.

1. **데스크톱 알림 허용**을 눌러 브라우저 권한을 허용한다. 이때 데스크톱 옵션도 켜진다.
2. 필요하면 **알림 소리**를 켠다. 켜는 동작에서 미리듣기를 하고 브라우저 오디오를 활성화한다.
3. **테스트 알림 보내기**를 누른 뒤 3초 안에 다른 PC 창으로 전환해 확인한다.

OS 알림은 페이지가 숨겨졌거나 창에 포커스가 없을 때 Web Notifications API로 전달한다.
Windows에서는 지원 브라우저의 Windows 알림으로 나타나며 클릭하면 mew를 포커스하고 해당 화면을
연다. 알림 권한은 HTTPS 또는 localhost의 지원 브라우저에서 사용자가 버튼을 눌렀을 때만 요청한다.
차단·미지원 상태는 설정에 설명한다. OS 알림에는 작업 종류만 표시하며 프로젝트명·대화·오류 원문을
싣지 않는다. 시스템 기본 소리는 끄고 mew 소리 설정을 따르며, mew 소리는 전경·배경 모두 적용하고
3초 안의 연속 알림은 한 번만 울린다. 새로고침 뒤 소리는 페이지에서 클릭·키 입력이 있어야 재개될 수
있다. OS 방해 금지·브라우저 음소거·절전 정책은 전달이나 소리 재생을 막을 수 있다.

#### 지원 범위

현재 프로젝트에서 **한 번 열어 연결한 ACP 채팅 탭**의 실시간 이벤트를 감시한다. 에이전트 패널을
접거나 다른 에이전트 탭·PC 창으로 이동해도 연결이 살아 있으면 알림을 받는다. 루트 프로젝트를
전환해 연결이 해제된 이전 프로젝트, 터미널 전용 에이전트·독립 셸·cron 작업은 감시하지 않는다.
브라우저 탭 종료·휴면·네트워크 단절 중 발생한 이벤트의 푸시·영구 알림함은 제공하지 않는다.
이는 서버 감독 프로세스의 작업 생존 계약을 바꾸지 않으며, 전역 서버 알림은 추후 별도 확장할 수 있다.

작업 완료 시 브라우저 문서가 보이고 창에 포커스가 있으며, 현재 작업 패널과 선택된 에이전트 탭이 완료된 탭이면 완료 알림을 생성하지 않는다. 분할 화면에서는 포커스된 에이전트 그룹의 선택 탭만 해당한다. 패널을 닫았거나 다른 탭·패널·브라우저 창을 보고 있으면 기존 완료 알림을 유지한다. 생략한 완료는 이후 탭을 떠나도 다시 알리지 않으며 오류·승인 요청·비정상 중단 알림은 그대로 제공한다.

#### 구현·검증

`src/utils/mewcat-notification-rules.ts`가 에이전트·자원 판단, `src/utils/mewcat-notifications.ts`가
한 페이지의 큐·설정·소리, `src/hooks/use-mewcat-notifications.ts`가 자원 조회·OS 전달을 맡는다.
`AgentPanel.tsx`는 실시간 이벤트만 연결하고 UI·설정은 `src/components/mewcat-notifications.tsx`가
담당한다. `src/components/header-notifications.tsx`는 뮤펫과 독립적으로 같은 큐를 표시하고 위험·경고·완료 순서와 최신 우선 정렬을 공유한다. 목록은 Esc·뒤로가기·닫기로 닫고 해당 화면 이동이나 마지막 항목 확인 때 종을 비운다. `mewcat-notification-copy.ts`의 네 언어 문구를 `i18n.tsx`에 `mewcat.*` 키로 등록하고, 클릭·자동 말풍선·설정·OS 알림 모두 공통 `t()`를 사용한다.

```bash
node --test src/utils/mewcat-notifications.test.ts src/components/mewcat-notifications.test.ts server/header-notifications-ui.test.ts server/mewcat-ui.test.ts
node --test server/mewcat-grab-ui.test.ts
npx tsc -b
npm run lint
```

`server/mewcat-ui.test.ts`는 Node용 TypeScript 설정으로 검사한다. Playwright 콜백에서 브라우저 fixture를 호출할 때는 `globalThis`를 명시적 fixture 타입으로 좁혀 사용하며, 서버 검사에 DOM 전역 타입을 추가하지 않는다.

테스트는 큐 완료·취소·오류 중복·과부하 회복·권한/비활성 조건·설정·목록 조작과 Chromium의
데스크톱/모바일 밝은·어두운 테마 레이아웃 및 확인 후 이동 재개를 검사한다. 열린 빈 목록·모든 알림 종류·자동 말풍선을 네 언어로 전환해 즉시 반영과 사용자 출처 보존도 검사한다. 클릭 목록은 클릭·터치·키보드 진입, 최신순·항목별 삭제·빈 상태, 상단 C/R/G 게이지의 작은 크기·같은 폭·둥근 모서리·중앙 라벨·아래부터 채움·테마색 표시·툴팁과 접근성 설명의 수치·0.5초 갱신, GPU 정보 없음·조회 실패 시 비우기, 기존 자원 팝업 연결, 뮤펫 목록을 닫아도 헤더 조회 유지·권한 해제 시 조회 중단도 검사한다. 실제 Windows 알림
센터·OS 방해 금지·스피커 출력은 지원 PC에서 위 테스트 알림으로 확인한다.
`mewcat-grab-ui.test.ts`는 시간을 고정한 Chromium에서 일반 크기 고양이를 던지고 마우스·실제
터치 입력으로 반복해서 붙잡아, 누르는 순간·정지 유지 중 좌표와 움직인 뒤 잡은 간격을 검사한다.
카피바라의 일반·원격 portal에서 마우스·터치로 좌우로 던질 때 놓는 순간부터 비행 방향을 바라보는지, 오래 잡았다가 놓으면 수평 운동량 없이 기존 방향으로 떨어지는지도 검사한다.
낙하 중 고양이 밖·투명한 부분의 배경 버튼 클릭/터치와 그림 부분의 재잡기도 함께 검사한다.
390px 모바일 뷰포트·실제 터치 입력에서 시간을 다시 흐르게 한 뒤 빠르게 던지고, 공중에 있는 동안
첫 배경 탭으로 버튼이 즉시 작동하는 회귀 조건도 검사한다.


### 강제 휴식 — 기본 꺼짐

**설정 → 뮤펫 → 뮤펫과 쉬기**에서 **강제 휴식 사용**을 선택하고 사용 시간·쉬는 시간을 각각
**시간 / 분** 입력으로 설정한 뒤 **휴식 설정 저장**을 누른다. 초기값은 **꺼짐**, 사용 **0시간
50분**, 휴식 **0시간 10분**이다. 각 기간은 1분~23시간 59분이며, 시간·분은 각각 0~23·0~59의
정수만 받는다. 두 입력 합계가 0이면 저장하지 않고 안내한다. 이 기본 시간은 제품 초기값이며
의학적 권장 주기를 뜻하지 않는다.

사용 시간은 **이 mew 브라우저 탭이 표시되고 포커스된 동안** 누적한다. 마우스를 움직이지 않고
읽고 있는 시간도 포함한다. 다른 탭·창으로 이동하면 누적을 멈추고 돌아오면 이어간다. 실제 시선이나
사용자의 자리 비움을 감지하지 않으며 카메라·시선 추적·PC 전체 사용시간 권한을 요청하지 않는다.
절전·탭 정지로 5초를 초과한 타이머 공백은 사용 증거로 세지 않는다.

정해진 사용 시간에 도달하면 **기존 SVG 뮤펫 자체가 작업 화면 위에서 거대하게 확대**된다.
전체 화면 배경·딤은 없다. SVG 너비는 뷰포트 너비의 118%와 높이의 108% 중 작은 값으로 정한다.
큰 고양이도 평소처럼 바닥을 좌우로 걷거나 달리고 잠시 멈춘다. 좁은 화면에서도 오갈 수 있도록
몸체 너비의 18%까지 양쪽 화면 밖으로 나갈 수 있다. 큰 고양이가 작업 내용을 가려 휴식을 유도하고,
고양이 주변에는 원래 작업 화면이 그대로 보인다. 하단에는 남은 시간만 분:초(1시간 이상은 시:분:초)로
표시하며 종료 시 일반 크기·표시 설정으로 돌아간다. 사용자 요청에 따라 휴식 안내 문구는 제거했으며
현재 모드에는 다시 넣지 않는다.

- SVG의 실제 그려진 몸체만 포인터 입력을 가로막는다. 사각형 영역 전체를 막지 않으며 귀 사이·
  그림 밖 투명 영역과 타이머 뒤쪽은 아래 화면을 클릭할 수 있다. 키보드 입력·단축키·기존 포커스는 유지한다.
- 큰 고양이도 마우스·터치로 잡고 어느 방향으로든 끌 수 있다. 잡은 위치를 유지하고, 잡고 있는 동안
  이동·낙하를 멈춘다. 빠르게 끌어 놓으면 던져지고, 멈춰 잡고 있다 놓거나 포인터 입력이 취소되면
  그대로 떨어진다. 벽 반사·중력·공중에서 다시 잡기·착지 후 이동 재개는 평소 고양이와 같은 동작을 쓴다.
- 수동 popover의 top layer로 패널·포털 위에 표시하지만 modal dialog·inert·포커스 이동·오버레이
  뒤로가기 가드를 사용하지 않는다. Esc로 큰 고양이를 닫지는 않으며, 앱의 원래 Esc 동작은 유지한다.
  초 단위 카운트다운은 스크린 리더에 매번 발화하지 않는다.
- 불투명 전체 화면과 앱 전체 입력 잠금은 사용자가 요청한 **그림 자체의 방해**와 달라 제거했다.
  현재 휴식 모드에는 재도입하지 않는다. 화면 전체를 잠그는 별도 동작은 새로운 명시적 요청이 필요하다.
- 휴식은 창을 비활성화하거나 다른 일을 해도 실제 경과 시간으로 진행한다. 끝나면 사용 누적을
  0으로 비우고 다음 주기를 시작한다. 사용 도중의 백그라운드 시간은 누적을 일시정지할 뿐 리셋하지 않는다.
- 스킨 **없음**이나 말풍선 알림 끄기와 독립적이다. 강제 휴식을 켰다면 휴식 중 큰 뮤펫은 표시한다.
  휴식 중 작은 고양이와 말풍선은 숨기고, 진행 중인 에이전트·자동저장·알림 수집은 유지한다.
- 한국어·영어·일본어·중국어와 밝은/어두운 테마를 지원한다. 모션 감소 설정에서는 등장 확대를 끈다.

설정은 브라우저 localStorage의 `mew:break-preferences`, 진행 중인 사용 누적·휴식 종료 시각은
탭별 sessionStorage의 `mew:break-progress`에 저장한다. **새로고침·프로젝트 전환으로 진행 중인
휴식 시간을 초기화하지 않는다.** 설정을 실제로 변경해 저장하면 새 주기를 시작한다. 설정은 같은 사이트의
다른 탭에도 반영하지만 사용 누적은 탭별이고, 계정/기기간 동기화나 새 탭·브라우저 재실행을 가로지르는
통합 타이머는 제공하지 않는다. 저장소 접근이 제한되면 현재 페이지 메모리에서만 동작한다.

구현은 `src/utils/mewcat-break-rules.ts`의 상태 전이·복원, `src/utils/mewcat-break-preferences.ts`의
설정, `src/hooks/use-mewcat-break.ts`의 포커스·타이머, `src/components/mewcat-break.tsx`의 설정과
거대 뮤펫 표시가 소유한다. 일반·거대 뮤펫의 이동·잡기·던지기는 `src/components/Mewcat.tsx`의
같은 상호작용 구현을 사용한다.

```bash
node --test src/utils/mewcat-break-rules.test.ts server/mewcat-break-ui.test.ts
```

기본 꺼짐·시간 검증·활성 시간만 누적·절전 제외·휴식 종료·설정 변경·저장 복원은 단위 테스트로,
실제 Chromium의 기본 비활성·설정 저장·배경 일시정지·타이머만 표시·거대 뮤펫의 이동/끌기/놓기/공중에서 잡기·그림의 클릭 가로막기·투명 영역 클릭 통과·키보드/포커스 유지·새로고침·자동 복귀 및
데스크톱/모바일 밝은·어두운 테마는 독립 브라우저 fixture로 확인한다. 실행 중인 mew를 빌드하거나
재시작하지 않는다.

## 구현 내용

- 헤더 활성 세션 왼쪽의 `HeaderNotifications`는 스킨 유무와 관계없이 미확인 큐를 표시한다. 설정에 알림 탭을 추가하고 기존 알림 설정을 이동했다. 선택적 `mewcat` 채널은 고양이 자동 말풍선·주의 동작만 제어하며 헤더와 OS 전달·소리를 바꾸지 않는다. 동일 큐의 확인 처리는 모든 표시에서 공유한다.

- 업데이트를 포함한 자동 알림 본문은 높이 제한·자체 스크롤 없이 전체 내용을 표시한다. 고양이 주변 공간이 부족하면 말풍선 위치를 화면 안으로 보정한다. 펼친 알림 목록의 스크롤은 유지한다.

- 원격 데스크톱에서 표시하는 뮤펫·말풍선은 뷰어 내부 호스트에 portal하여 배경 `inert`의 영향을 받지 않는다. 클릭·드래그·키보드 조작은 뮤펫에서 처리하고 원격 입력으로 전달하지 않는다.

- 설정 → 뮤펫의 **원격 데스크톱에서 뮤펫 숨기기**를 켜면 원격 뷰어가 열린 동안 고양이·말풍선·휴식 표시를 숨기고 닫으면 복원한다. 기본값은 꺼짐이며 브라우저별 `mew:mewcat-hide-desktop`에 저장한다. 알림 수집·OS 알림과 휴식 타이머는 계속 동작한다.

- 이전에는 검정 몸통·흰 눈만 있는 실루엣을 기본값으로 바꾸고 기본 SVG·털색 설정을 제거했다. 2026-10-09 최종 후속 요청에 따라 내장 스킨은 카피바라만 남기고 러시안블루·까만 고양이·코리안 숏헤어·샴·펭귄을 제거했다. 제거된 내장 선택은 카피바라로 복원한다. 미리보기·휴식용 큰 뮤펫·원격 뷰어에도 같은 스프라이트를 사용한다.
- 연결 끊김 알림은 반복 방해를 줄이려는 사용자 요청으로 제거했으며 요청 전 재도입하지 않는다.
- 해당 에이전트 패널 내부의 연결 대기 표시로 대체한다.

- 모바일·전체화면에서도 발이 화면 맨 아래에 붙고 하단 독 위에 겹쳐 표시된다. 독 높이 변경·숨김은 바닥 위치에 영향을 주지 않는다.
- 뮤펫에서 시작한 터치의 브라우저 기본 제스처를 취소하여 던진 직후 다른 요소를 첫 탭부터 조작할 수 있다.

- 자동 말풍선 폭을 300px로 줄이고 본문·목록의 좌우 여백을 12px로 통일했다.
- 본문·출처 사이는 2px로 묶고 중첩 패딩·음수 마진을 제거한다. 최근 알림과 펼친 목록은 공통 행 간격·정렬을 사용하며 헤더는 상하 8px, 알림 행·빈 상태는 상하 12px로 맞춘다.
- 터치 버튼 크기는 유지한다.
- 자동 알림은 버튼 내부의 빈 공간을 보정해 실제 콘텐츠 끝 기준으로 상하좌우 여백을 가장 좁은 12px에 맞추고 제목·출처·이동 버튼의 시작선을 맞춘다.
- 대화·시스템 자원 열기는 배경 없는 작은 글자·화살표로 표시한다. 데스크톱 높이는 28px로 줄이고 모바일 터치 영역은 44px로 유지한다. 알림 개수·펼침 및 닫기는 오른쪽 보조 조작으로 구분한다.
- 상태·닫기 아이콘은 16px로 맞추고 행 본문과 닫기 버튼은 세로 가운데에 정렬한다. 자동 알림의 본문과 조작 줄 사이는 8px를 둔다.
- 세부 간격·터치 크기는 연결된 명세를 따른다.

- 공통 번역 함수로 말풍선·알림 설정·OS 알림을 연결하고 메모리 표기·뮤펫 접근성 이름도 현지화했다.
- 일반 Mewpet 클릭으로 작은 최근 알림 목록을 최신순으로 표시하고 항목별 ×로 삭제한다.
- CPU·RAM·GPU는 최상단 바의 36×36px 버튼 안에 작고 둥근 C·R·G 세로 게이지로 나란히 표시하며 라벨을 중앙에 놓고 테마 주요색으로 아래부터 채운다. 수치는 툴팁·접근성 설명으로 제공하고 권한이 있을 때만 0.5초 주기로 갱신하며 클릭하면 기존 시스템 자원 팝업을 연다.
- 뮤펫 목록을 닫아도 헤더 자원 조회는 유지하며 권한 해제·계정 변경·헤더 해제 시 정리한다.
- 기존 SVG 상호작용에 우선순위 말풍선·30개 알림 목록·화면 이동을 연결했다.
- 실시간 ACP 이벤트와 권한이 있는 서버 자원 조회를 사용하며 설정·OS 알림·합성 알림음·테스트 버튼을 제공한다.
- 자원·알림 말풍선은 고양이의 현재 위치에 뜨며, 화면 가장자리에서는 본체를 보정하고 꼬리가 고양이를 가리키도록 움직인다.
- 클릭·알림으로 고양이를 오른쪽으로 순간이동시키지 않는다.
- 말풍선 본체·꼬리·글자·버튼은 앱의 라이트·다크 테마를 따르고, 새 알림마다 한 번 고개를 까딱한다.
- 탭의 활성 사용 시간과 새로고침에도 이어지는 휴식 타이머·투명 배경의 거대 뮤펫을 추가했다.
- 휴식 중에는 타이머만 표시하고, 큰 고양이도 같은 이동·끌기·던지기 동작을 사용한다.
- 기본 꺼짐이며 시간을 설정하고 저장해 켠다.
- 상세 조건과 한계는 연결된 명세를 따른다.

- 앱 접속 시 설치된 관련 항목의 업데이트 알림을 제공하고 통합 업데이트 화면으로 연결한다([업데이트 계약](../../deployment/native.md#설치된-의존성에이전트-통합-업데이트)).

## 요구사항

- 원격 데스크톱 밖에서도 앱 헤더의 활성 세션 왼쪽에 누적 네트워크 데이터 사용량을 표시한다.
- 사용량을 누르면 원격 데스크톱에서 쓴 양과 그 외 기능에서 쓴 양을 자세히 비교할 수 있다.

## 상세 동작

- 현재 Mew 탭을 연 뒤의 수신·송신 합계를 B·KB·MB·GB 단위로 표시한다.
- 팝업은 원격 데스크톱·그 외·전체 행과 수신·송신·합계 열을 제공하고, 사용량이 증가하면 헤더와 함께 약 1초마다 갱신한다.
- 원격 연결을 종료하거나 다른 프로젝트로 이동해도 합계를 유지한다. 원격 세션의 상단 표시는 접속별 값이며 앱 헤더는 모든 원격 세션을 합산한다.
- 새로고침하면 초기화하며 다른 탭·기기·계정의 트래픽을 합치지 않는다. 팝업에 현재 탭의 추정치라는 범위를 표시한다.
- 기본 0 B에서도 팝업을 열 수 있고 PC·모바일·양 테마·네 언어를 지원한다. 닫기·바깥 클릭·Esc·뒤로가기와 포커스 복원은 공통 DialogFrame을 사용한다.
- 일반 Mew HTTP·협업·터미널·에이전트 등의 WebSocket과 원격 영상·입력을 포함한다. 전송 계층 헤더·브라우저가 제공하지 않는 바이트 등은 제외하며 OS·통신사의 청구량과 다를 수 있다. [집계·중복 방지와 한계](../../development/network-usage.md)를 따른다.

## 구현 진입점

`main.tsx`의 공통 추적기가 저장소를 갱신하고 `NetworkUsageButton`이 구독한다. 원격 연결은 접속별 집계의 증분만 같은 저장소에 추가한다. 팝업을 열기 위한 서버 요청·새 권한·영구 데이터 파일은 없다.

## 확인 기준

- 일반 통신과 원격 연결이 각각 올바른 행에 반영되고 합계가 두 행의 합과 일치한다.
- 여러 원격 세션을 열고 닫아도 이전 사용량이 남고 같은 표본은 중복 집계되지 않는다.
- 업로드·WebSocket·지속 SSE 데이터가 갱신되고 정상 응답·입력·취소 동작이 유지된다.
- 320px 모바일과 데스크톱에서 헤더·팝업이 넘치지 않으며 언어 전환·키보드·뒤로가기·포커스 복원을 확인한다.

2026-10-07: 관련 단위·공용 번역 검사 10개와 격리 Chromium의 네트워크 팝업 1개·WebRTC 뷰어 2개 시나리오를 통과했다. 실제 HTTP·WebSocket·SSE와 취소·clone·중복 집계 방지, 원격 뷰어 종료 후 합계 보존, 320/390/1100px·양 테마·네 언어·Esc·포커스 복원을 확인했고 PC·모바일 캡처를 검토했다. 대상 린트·문서 description·문서 경계 검사가 통과했다. 프런트엔드 타입 검사는 초기에 통과했으나 최종 재확인에서 작업 밖 Git UI 변경의 타입 오류가 발생했고 전체 타입 검사는 작업 밖 `server/remote-access-agent.ts` 오류로 실패했다. 운영 빌드·서버 재시작·실제 원격 기기 검증은 수행하지 않았다.

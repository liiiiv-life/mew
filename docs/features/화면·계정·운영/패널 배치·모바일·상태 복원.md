## 요구사항

- 모바일 패널 전환 시 에디터를 포함한 이전 패널 이력을 최대 20개 저장하고 뒤로가기로 역순 복원한다.

- 화면 크기와 작업 흐름에 맞춰 문서·도구 패널을 배치한다.
- 독을 오른쪽으로 스와이프하면 현재 패널의 왼쪽 탭, 왼쪽으로 스와이프하면 오른쪽 탭을 연다.

### 범위

- 모바일에서 드롭다운·창·검색 패널을 열어도 입력칸에 자동 포커스를 주어 키보드를 띄우지 않는다.

- 문서 탭·분할·도킹·크기 조절·계정별 복원과 모바일 하단 독·전체화면·뒤로가기를 제공한다.
- Documents·일반 파일을 오가도 같은 탭 목록·편집 칸·도킹 배치를 유지한다.
- 데스크톱 에디터 탭 바 오른쪽에 다른 패널과 같은 닫기(X) 버튼을 제공한다.
- PC·모바일의 패널 조작은 독·상단 메뉴를 사용한다. PC 사이드바는 왼쪽에 고정하고 오른쪽 경계 중앙 버튼으로 접고 펼친다. 메모·태스크 팝업에는 이동·크기 조절 손잡이를 제공한다.
- 데스크톱에서 모든 작업 패널 탭의 더블클릭으로 본문 확대·원래 배치 복귀를 제공한다.
- 프로젝트·패널 탭 바와 독은 덮지 않으며 Esc로도 복귀한다.

### 경계와 제한

- 브라우저 패널은 좌우 배치만 지원한다.
- 패널 닫기와 작업 세션 종료를 구분하며 기기별 설정과 계정별 화면 상태의 소유권을 유지한다.

## 구현 내용

- 열린 패널의 전면 순서와 별도로 전환 이력을 관리한다. 같은 패널 재선택은 기록하지 않고 뒤로가기 복원은 이력을 추가하지 않는다. 이력은 앱 메모리에만 두며 계정·루트 프로젝트 변경 시 초기화한다.

- 내부 브라우저·원격 데스크톱은 PC·모바일 햄버거 메뉴에 표시하고 Dock에서는 제외한다. 저장된 순서에 남은 두 항목도 표시하지 않는다.

- 드래그 재배열 시 주변 항목은 180ms의 공통 이동 애니메이션으로 새 자리를 찾아간다. 잡은 아이템은 포인터를 바로 따라가며, 연속 재배열과 모션 감소 설정은 [공통 모션 계약](../../development/ui-contracts.md#드래그-재배열-모션)을 따른다.

- 입력칸 자동 포커스는 공통 `canAutoFocusInput()` 조건을 사용한다. 모바일의 공통 대화상자는 입력칸 대신 창 자체에 포커스를 둔다. 상세 기준은 [모바일 입력 포커스](../../development/ui-contracts.md#모바일-입력-포커스)를 따른다.

- Documents는 독립 편집 화면으로 전환하지 않는다. 현재 루트의 공통 탭 상태를 사용해 파일 종류에 따라 `DockPanel` 등록과 패널 위치가 초기화되지 않는다.

- 독에 있는 작업 패널은 PC·모바일 햄버거 메뉴에서 제거해 진입점 중복을 줄인다. 독·단축키와 나머지 메뉴 항목의 권한 조건은 유지한다.

- 모바일에서 여러 편집 칸을 전환하는 선택기는 공통 자체 드롭다운이며 기존 칸·문서 상태를 유지한다.

- 문서 탭·분할·도킹·크기 조절·계정별 복원과 모바일 하단 독·전체화면·뒤로가기를 제공한다.

- 문서·에이전트·터미널·브라우저 탭을 드래그하면 잡은 탭이 포인터를 따라 움직이고 원래 탭은 빈 자리로 표시한다.
- 가로 스크롤 영역 밖에서도 미리보기가 보이며 순서 이동·가장자리 자동 스크롤·다른 칸으로 분할/합치기를 유지한다.

- 패널 이동 손잡이는 데스크톱에서만 표시한다.
- 실제 탭이 없는 패널의 탭 바에는 독과 같은 아이콘·번역된 제목을 표시한다. 에이전트 선택기를 연 상태도 포함하며 실제 탭이 생기면 제목을 숨긴다. 고정 제목을 쓰는 기능·Git 패널은 기존 표시를 유지한다.
- 에이전트·터미널·브라우저에 실제 탭이 없으면 `+`를 숨기고 본문에 각각 에이전트 선택기·새 터미널 시작 버튼·브라우저 시작 화면을 표시한다. 첫 탭 생성 후 `+`를 다시 표시한다.
- 기능·메모·태스크 패널도 공통 도킹 영역에서 위치·폭·높이를 조절하고 계정·프로젝트별 배치를 복원한다. 타이틀바는 다른 패널과 같은 36px다.
- 2026-10-03: 사용자 요청으로 [텍스트 입력 중심의 태스크 패널](../%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B8%C2%B7%ED%8C%8C%EC%9D%BC%C2%B7%EA%B2%80%EC%83%89/%ED%83%9C%EC%8A%A4%ED%81%AC%20%ED%8C%A8%EB%84%90%C2%B7%EB%AA%A9%EB%A1%9D%C2%B7%EB%8B%AC%EB%A0%A5%C2%B7%EA%B0%84%ED%8A%B8.md)을 독·도킹·모바일 스택에 다시 등록했다. 메모와 별도의 객체 목록이며 과거 계층형 태스크 저장 파일은 사용하지 않는다.
- 2026-10-01: 태스크 패널을 제거하고 메모 팝업을 공통 패널로 대체했다. 이전 태스크 독·배치 항목은 정규화에서 제외한다. 메모는 모바일 전면 스택·Esc/뒤로가기·PC 확대/복원에 참여한다. 상세 저장·협업 상태는 [공통 메모](../%ED%98%91%EC%97%85%C2%B7%EB%8C%93%EA%B8%80%C2%B7%EC%B1%84%ED%8C%85/%EA%B3%B5%ED%86%B5%20%EB%A9%94%EB%AA%A8.md)를 따른다.
- 모바일에서는 에디터·에이전트·터미널·브라우저·Git·기능·메모·태스크 상단의 손잡이와 해당 여백을 제거한다.

- 데스크톱 탭 더블클릭 확대는 임시 표시 상태로 처리하며 저장된 분할 배치를 변경하지 않는다.
- 사이드바를 포함한 작업 영역에 선택한 패널의 탭 바·본문을 함께 펼치고, 다른 패널의 탭 바는 숨기고 조작을 막는다.
- 선택한 탭 바는 작업 영역 맨 위에서 전체 너비를 차지하며 프로젝트 헤더·독은 유지한다.
- 확대·복귀·대상 전환은 세션을 다시 마운트하지 않는다.
- 상세 해제 조건과 모바일 경계는 [작업 패널 배치](../../development/ui-contracts.md#작업-패널-배치)를 따른다.

- 데스크톱에서는 상단 햄버거 메뉴 바로 왼쪽에 독을 고정 배치한다.

- 아이콘을 누르면 닫힌 패널을 열고, 열려 있지만 포커스되지 않은 패널은 닫지 않고 포커스를 옮긴다. 다른 패널은 유지한다.
- 열린 패널은 옅게 하이라이트하고, 현재 포커스가 있는 작업 패널 하나는 더 진하게 표시한다.
- 포커스된 아이콘을 다시 누를 때만 해당 패널을 닫고 하이라이트도 없앤다.
- 다른 열린 패널로 이동할 때 마지막 입력 요소의 포커스와 작성 중인 초안을 보존한다.
- 이미 열린 패널의 본문·탭을 클릭하거나 키보드·내부 브라우저 iframe으로 포커스를 옮기면 즉시 갱신한다.
- 에디터는 탭·본문·분할 배치를 보존한 채 숨기고 다시 표시하며, 기능 패널은 닫기 전 미저장 확인을 유지한다.
- 에디터의 닫기(X)는 독의 에디터 숨김과 같은 동작을 사용하며, 열린 탭이 없어도 표시한다.
- 자유 이동 손잡이·위치 저장은 제거하고 기존 저장 위치는 무시한다. 사용자 요청 전 플로팅 배치를 재도입하지 않는다.
- PC·모바일 모두 아이콘을 꾹 누르면 마우스·손가락을 따라 움직이며 순서를 바꾼다.
- 빈 자리 표시로 들어갈 위치를 보여주고, 놓으면 저장하며 Esc·터치 취소 시 원래 순서로 돌아간다.

- 모바일 하단에 화면 너비를 채우는 직사각형 독을 제공한다.
- 아이콘은 패널을 열거나 전면으로 전환하며 같은 아이콘을 다시 눌러도 닫지 않는다.
- 높이는 48px + 하단 안전 여백이고, 기능 버튼은 기능 작업 패널을 연다.
- 기능 패널도 독 버튼·스와이프로 오가며 선택 항목과 초안을 유지한다.
- 둥근 외곽선·아이콘 배경 없이 위쪽 구분선과 선택된 아이콘의 밝기·굵기로 구분한다.
- 기본 순서는 사이드바·에디터·에이전트 패널·터미널·Git·내부 브라우저·기능·메모·태스크이며 권한에 맞춰 표시한다.
- 길게 눌러 순서를 변경하고 브라우저에 기억한다.

- 독으로 다른 패널을 선택하면 원격 연결을 종료하고 이동하며, 뷰어를 닫으면 이전 작업 화면으로 돌아온다.

### 기기별 배치와 메모·태스크 팝업 (2026-10-06)

저장 소유권은 [ADR 0197](../../../../.mew/docs/decisions/0197-mew-device-local-workspace-layout.md)을 따른다.

설정 → 화면에서 PC 메모와 태스크 각각의 탭/팝업 표시를 선택한다. 팝업은 문서 위에서 이동·크기 조절할 수 있고, 방식 전환 시 같은 컴포넌트와 입력 상태를 유지한다. 모바일은 선택과 관계없이 기존 전면 패널을 사용한다.

도킹 위치·분할 비율·문서 탭·패널 여닫힘은 브라우저 기기별로 계정/루트 프로젝트 키에 저장한다. 계정 복원값은 로컬 기록이 없는 기기의 초기값으로 사용한다. 팝업 크기·위치와 표시 설정도 브라우저에 저장하며 다른 기기와 서로 덮어쓰지 않는다. 브라우저 저장 공간을 지우면 해당 기기의 기억도 초기화된다.

검증 (2026-10-06): 관련 서버·격리 Chromium 테스트와 TypeScript·대상 lint를 실행했다. 실제 업데이트 설치·빌드·서버 재시작은 실행하지 않았다.

## 요구사항

- 메모·태스크의 PC 팝업/패널 전환은 각 탭 헤더의 아이콘 버튼에서 수행하며 화면 설정의 선택 항목은 제거한다. 방식·좌표·내용을 유지하고 도구마다 독립적으로 전환한다. 모바일은 버튼을 숨기고 패널을 표시한다.
- 설정 창은 팝업·다른 작업 창·뮤캣보다 위의 최상단 앱 레이어에 표시한다. 설정 안의 언어·글꼴 드롭다운을 계속 조작할 수 있어야 하고 Esc는 목록부터 닫아야 한다. 확인 기준은 높은 팝업 레이어·PC/모바일·읽기/입력 내용 보존·새로고침 복원이다.

- PC·모바일 전체화면 버튼은 햄버거 바로 왼쪽에 표시하고 메뉴 내부 항목은 제거한다. 기존 표시 조건과 토글·단축키는 유지한다.

- 모바일 패널 전환 시 에디터를 포함한 이전 패널 이력을 최대 20개 저장하고 뒤로가기로 역순 복원한다.

- 화면 크기와 작업 흐름에 맞춰 문서·도구 패널을 배치한다.
- 저장 배치가 없는 데스크톱은 에디터 위·터미널 아래, 오른쪽 Git 위·에이전트 아래로 시작한다. 기능·태스크의 탭 표시는 맨 오른쪽 열에 위아래로 배치한다.
- 독을 오른쪽으로 스와이프하면 현재 패널의 왼쪽 탭, 왼쪽으로 스와이프하면 오른쪽 탭을 연다.

### 범위

- 열린 파일이 없는 편집 칸에는 사이드바 열기·문서 검색·문서 파일 검색 단축키만 세로로 표시한다.

- 모바일에서 드롭다운·창·검색 패널을 열어도 입력칸에 자동 포커스를 주어 키보드를 띄우지 않는다.

- 문서 탭·분할·도킹·크기 조절·계정별 복원과 모바일 하단 독·전체화면·뒤로가기를 제공한다.
- Documents·일반 파일을 오가도 같은 탭 목록·편집 칸·도킹 배치를 유지한다.
- 데스크톱 에디터 탭 바 오른쪽에 다른 패널과 같은 닫기(X) 버튼을 제공한다.
- PC·모바일의 패널 조작은 독·상단 메뉴를 사용한다. PC 사이드바는 왼쪽에 고정하고 오른쪽 경계 중앙 버튼으로 접고 펼친다. 메모·태스크 팝업에는 이동·크기 조절 손잡이를 제공한다.
- 데스크톱에서 모든 작업 패널 탭의 더블클릭으로 본문 확대·원래 배치 복귀를 제공한다.
- 프로젝트·패널 탭 바와 독은 덮지 않으며 Esc로도 복귀한다.

### 경계와 제한

- 브라우저 패널은 좌우 배치만 지원한다.
- 패널 닫기와 작업 세션 종료를 구분하며 기기별 설정과 계정별 화면 상태의 소유권을 유지한다.

## 구현 내용

- `ToolPresentationToggle`이 메모·태스크 헤더에서 기존 표시 방식 저장을 토글한다. `SettingsModal`은 body 포털의 최상단 레이어를 사용하고 언어·글꼴 선택 목록도 설정 포털 내부에 표시한다. [UI 계약](../../development/ui-contracts.md#설정-창-레이어)을 따른다.

- 기본 도킹 트리는 `src/utils/dock-layout.ts`의 `defaultDockTree`로 구성한다. 숨긴 패널의 자리는 가시 영역에서 접고, 늦게 마운트한 패널은 `addDockGroup`으로 해당 이웃에 추가한다. 기존 저장 배치·편집 칸 내부 분할·모바일 전면 표시를 유지한다. 비율과 복원 우선순위는 [작업 패널 배치 계약](../../development/ui-contracts.md#작업-패널-배치)을 따른다.
- 2026-10-06 기본 배치 검증: 도킹 단위 검사 12개와 `dockWorkspaceUi.test.ts`의 실제 Chromium 기본 위치·드래그·경계 크기 조절·닫기·재열기·복원 검사, 타입·대상 lint·문서 허용목록 검사를 통과했다. `dock-maximize-ui.test.ts`는 Git 커밋 제목 입력칸을 찾지 못해 실패했고 변경 전 `DockWorkspace`에서도 같은 실패를 확인했다. 워크스페이스 링크 검사는 작업 밖 태스크 문서 3개의 MOC 미등록으로 실패했다. 빌드·서버 재시작은 실행하지 않았다.

- **설정 → Dock**에서 표시 여부와 순서를 조절한다. 기존 독 재정렬과 같은 상태를 공유하며 숨긴 항목은 스와이프 대상에서도 제외한다. 권한으로 숨겨진 항목의 순서·표시 설정과 열린 작업 패널은 보존한다. 상세는 [Dock 설정](../../configuration/environment.md#dock-설정)을 따른다.

- 빈 편집 칸은 `useShortcutBindings`로 현재 설정의 세 단축키를 표시한다. 기존 문서 선택·새 파일·자동 저장 안내는 사용자 요청으로 제거했으며 명시적 후속 요청 없이 재도입하지 않는다. 상세 동작은 [편집 안내](../../guides/editor.md#기본-편집)를 따른다.

- 공통 오버레이는 뒤로가기를 처리할 때마다 남은 스택의 History 가드를 다시 설치한다. 전면 패널만 바뀌어 등록이 유지되는 경우도 보호하며, 뒤로가기로 닫은 패널을 새 방문으로 기록하지 않는다.

- 열린 패널의 전면 순서와 별도로 전환 이력을 관리한다. 같은 패널 재선택은 기록하지 않고 뒤로가기 복원은 이력을 추가하지 않는다. 이력은 앱 메모리에만 두며 계정·루트 프로젝트 변경 시 초기화한다.

- 내부 브라우저·원격 데스크톱은 PC·모바일 햄버거 메뉴에 표시하고 Dock에서는 제외한다. 저장된 순서에 남은 두 항목도 표시하지 않는다.

- 드래그 재배열 시 주변 항목은 180ms의 공통 이동 애니메이션으로 새 자리를 찾아간다. 잡은 아이템은 포인터를 바로 따라가며, 연속 재배열과 모션 감소 설정은 [공통 모션 계약](../../development/ui-contracts.md#드래그-재배열-모션)을 따른다.

- 입력칸 자동 포커스는 공통 `canAutoFocusInput()` 조건을 사용한다. 모바일의 공통 대화상자는 입력칸 대신 창 자체에 포커스를 둔다. 상세 기준은 [모바일 입력 포커스](../../development/ui-contracts.md#모바일-입력-포커스)를 따른다.

- Documents는 독립 편집 화면으로 전환하지 않는다. 현재 루트의 공통 탭 상태를 사용해 파일 종류에 따라 `DockPanel` 등록과 패널 위치가 초기화되지 않는다.

- 독에 있는 작업 패널은 PC·모바일 햄버거 메뉴에서 제거해 진입점 중복을 줄인다. 독·단축키와 나머지 메뉴 항목의 권한 조건은 유지한다.

- 모바일에서 여러 편집 칸을 전환하는 선택기는 공통 자체 드롭다운이며 기존 칸·문서 상태를 유지한다.

- 문서 탭·분할·도킹·크기 조절·계정별 복원과 모바일 하단 독·전체화면·뒤로가기를 제공한다.

- 문서·에이전트·터미널·브라우저 탭을 드래그하면 잡은 탭이 포인터를 따라 움직이고 원래 탭은 빈 자리로 표시한다.
- 가로 스크롤 영역 밖에서도 미리보기가 보이며 순서 이동·가장자리 자동 스크롤·다른 칸으로 분할/합치기를 유지한다.

- 패널 이동 손잡이는 데스크톱에서만 표시한다.
- 실제 탭이 없는 패널의 탭 바에는 독과 같은 아이콘·번역된 제목을 표시한다. 에이전트 선택기를 연 상태도 포함하며 실제 탭이 생기면 제목을 숨긴다. 고정 제목을 쓰는 기능·Git 패널은 기존 표시를 유지한다.
- 에이전트·터미널·브라우저에 실제 탭이 없으면 `+`를 숨기고 본문에 각각 에이전트 선택기·새 터미널 시작 버튼·브라우저 시작 화면을 표시한다. 첫 탭 생성 후 `+`를 다시 표시한다.
- 기능·메모·태스크 패널도 공통 도킹 영역에서 위치·폭·높이를 조절하고 계정·프로젝트별 배치를 복원한다. 타이틀바는 다른 패널과 같은 36px다.
- 2026-10-03: 사용자 요청으로 [텍스트 입력 중심의 태스크 패널](../%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B8%C2%B7%ED%8C%8C%EC%9D%BC%C2%B7%EA%B2%80%EC%83%89/%ED%83%9C%EC%8A%A4%ED%81%AC%20%ED%8C%A8%EB%84%90%C2%B7%EB%AA%A9%EB%A1%9D%C2%B7%EB%8B%AC%EB%A0%A5%C2%B7%EA%B0%84%ED%8A%B8.md)을 독·도킹·모바일 스택에 다시 등록했다. 메모와 별도의 객체 목록이며 과거 계층형 태스크 저장 파일은 사용하지 않는다.
- 2026-10-01: 태스크 패널을 제거하고 메모 팝업을 공통 패널로 대체했다. 이전 태스크 독·배치 항목은 정규화에서 제외한다. 메모는 모바일 전면 스택·Esc/뒤로가기·PC 확대/복원에 참여한다. 상세 저장·협업 상태는 [공통 메모](../%ED%98%91%EC%97%85%C2%B7%EB%8C%93%EA%B8%80%C2%B7%EC%B1%84%ED%8C%85/%EA%B3%B5%ED%86%B5%20%EB%A9%94%EB%AA%A8.md)를 따른다.
- 모바일에서는 에디터·에이전트·터미널·브라우저·Git·기능·메모·태스크 상단의 손잡이와 해당 여백을 제거한다.

- 데스크톱 탭 더블클릭 확대는 임시 표시 상태로 처리하며 저장된 분할 배치를 변경하지 않는다.
- 사이드바를 포함한 작업 영역에 선택한 패널의 탭 바·본문을 함께 펼치고, 다른 패널의 탭 바는 숨기고 조작을 막는다.
- 선택한 탭 바는 작업 영역 맨 위에서 전체 너비를 차지하며 프로젝트 헤더·독은 유지한다.
- 확대·복귀·대상 전환은 세션을 다시 마운트하지 않는다.
- 상세 해제 조건과 모바일 경계는 [작업 패널 배치](../../development/ui-contracts.md#작업-패널-배치)를 따른다.

- 데스크톱에서는 헤더 아래 작업 영역의 맨 왼쪽, 사이드바 왼쪽에 독을 세로로 고정 배치한다. 사이드바를 접어도 독을 유지하며 아이콘은 세로 드래그·Alt+위아래로 재정렬한다. 모바일 하단 독과 원격 뷰어 도구 모음 배치는 유지한다.
- 독 아이콘의 hover 툴팁은 아래로 표시하며 원격 뷰어에서도 가려지지 않게 한다.
- 아이콘을 누르면 닫힌 패널을 열고, 열려 있지만 포커스되지 않은 패널은 닫지 않고 포커스를 옮긴다. 다른 패널은 유지한다.
- 열린 패널은 옅게 하이라이트하고, 현재 포커스가 있는 작업 패널 하나는 더 진하게 표시한다.
- 포커스된 아이콘을 다시 누를 때만 해당 패널을 닫고 하이라이트도 없앤다.
- 다른 열린 패널로 이동할 때 마지막 입력 요소의 포커스와 작성 중인 초안을 보존한다.
- 이미 열린 패널의 본문·탭을 클릭하거나 키보드·내부 브라우저 iframe으로 포커스를 옮기면 즉시 갱신한다.
- 에디터는 탭·본문·분할 배치를 보존한 채 숨기고 다시 표시하며, 기능 패널은 닫기 전 미저장 확인을 유지한다.
- 에디터의 닫기(X)는 독의 에디터 숨김과 같은 동작을 사용하며, 열린 탭이 없어도 표시한다.
- 자유 이동 손잡이·위치 저장은 제거하고 기존 저장 위치는 무시한다. 사용자 요청 전 플로팅 배치를 재도입하지 않는다.

### 데스크톱 레이아웃 프리셋

- 768px 이상에서 햄버거 메뉴 왼쪽에 **레이아웃** 버튼을 표시한다. 모바일에는 표시하지 않는다. 패널과 문서 탭 복원이 끝난 뒤 사용할 수 있다.
- 처음 열면 **기본값**, **프리셋 1**, **프리셋 2**, **+**를 제공한다. 기본값은 mew의 기본 도킹(에디터 위/터미널 아래, Git 위/에이전트 아래, 기능 위/태스크 아래), 프리셋 1은 문서 집중, 프리셋 2는 에디터·터미널 구성이다. 권한 제한으로 같은 배치가 되면 서로 다른 편집 칸 분할을 사용해 초기 프리셋 중복도 피한다.
- 프리셋 클릭은 해당 배치를 적용한다. **+**는 현재 배치를 다음 번호의 프리셋으로 저장한다. 기존 프리셋은 생성·수정 시 중복 배치를 허용하지 않으며, 중복이면 기존 값을 유지하고 결과를 알린다.
- 프리셋 우클릭 또는 `Shift+F10`/메뉴 키는 **이름 변경**, **mew 자체 기본값**, **현재 상태로 설정**, **프리셋 삭제** 메뉴를 연다. 기본값·현재 상태 설정은 선택한 프리셋만 대체한다. 이름 변경은 목록 안에서 입력해 저장하며 최대 60자, 앞뒤 공백을 제거한다. 빈 이름은 기본값/프리셋 번호 표기로 돌아간다. 이름은 배치 중복 판정에 영향을 주지 않고 배치를 대체해도 유지한다. Enter는 저장, 취소·Esc는 이름 입력만 닫고 해당 프리셋으로 포커스를 돌린다. 자기 자신의 같은 배치는 허용하지만 다른 프리셋과의 중복은 막는다. 기본값 항목도 수정·삭제할 수 있다. 삭제 후 번호를 다시 매기지 않는다.
- 메뉴는 방향키·Home/End·Enter로 조작한다. Esc는 우클릭 메뉴부터 닫고 해당 프리셋으로 포커스를 돌리며, 다시 누르면 목록을 닫고 레이아웃 버튼으로 돌아온다. 목록·메뉴는 화면 경계 안에 배치하며, 추가 프리셋이 많으면 목록 안에서 스크롤한다.
- 저장 범위는 도킹 트리·분할 비율·편집 칸 구성·패널 표시 상태·사이드바/Android 폭·메모/태스크의 탭/팝업 표시와 팝업 위치·크기다. 파일 본문·실행 세션·활성 탭은 프리셋에 복제하지 않는다. 적용 시 현재 문서와 미저장 내용을 보존하며 줄어든 편집 칸의 문서는 첫 칸으로 모은다. 실행 세션은 종료하지 않고 현재 탭 배정을 살아 있는 같은 종류의 패널로 연결한다. 임시 확대는 해제한다. 기능 패널 초안을 숨기는 전환은 기존 미저장 확인을 거친다.
- 중복 판정은 숨겨진 도킹 가지를 접은 뒤 패널 종류와 정규화한 사각형 좌표/크기(1/1000 단위), 표시 상태, 보이는 사이드 패널 폭, 열린 팝업의 위치·크기를 비교한다. 내부 그룹 ID·활성 탭·숨긴 패널의 폭은 제외하며, 다른 트리 구조로 같은 화면 배치를 만든 경우도 중복으로 처리한다.
- 프리셋은 브라우저의 `mew:layout-presets:<계정>` 키에 기억하며 계정 식별자는 URI 인코딩한다. 같은 계정은 프로젝트를 바꾸어도 같은 목록과 이름을 사용하고 같은 브라우저의 다른 탭 변경도 반영한다. 다른 계정·브라우저의 목록은 별개이며 서버 동기화는 하지 않는다. 프로젝트별 실제 작업 배치·열린 파일·실행 세션의 저장 키는 기존 계약을 유지한다. 최초 계정 공용 목록을 읽을 때 기존 같은 계정의 프로젝트별 키를 현재 프로젝트 우선으로 합친다. 중복 배치는 한 번만 가져오고 ID·번호 충돌은 새 값으로 구분한다. 기존 키는 보존하며 공용 목록이 이미 있으면 다시 가져오지 않아 삭제한 프리셋이 되살아나지 않는다. 기존 빈 배열만 있으면 빈 상태도 승계한다. 잘못된 저장값은 정규화하고 중복 항목은 제외한다. 빈 배열은 사용자가 모두 삭제한 상태로 보존한다. 저장 실패 시 현재 세션에 유지하고 결과를 알린다.

#### 레이아웃 SVG 생성

`src/utils/layout-presets.ts`의 `layoutIconRects`는 64×48 viewBox에서 헤더·왼쪽 독·사이드 패널·중첩 분할·팝업을 축소한다. 숨긴 패널은 그리지 않으며 분할 비율과 팝업 위치·크기를 반영한다. React `LayoutIcon`과 `layoutIconSvg`가 같은 사각형 계산을 사용하므로 추가·현재 상태 설정·기본값 설정 직후 미리보기가 자동으로 갱신된다. 색상은 `currentColor`와 기존 표면 토큰을 사용한다.

독립 스크립트는 버전 1 `LayoutSnapshot` JSON을 표준 입력에서 읽고 SVG를 표준 출력으로 쓴다. 저장된 프리셋 객체에서는 `layout` 값이 입력이다.

```bash
node server/layout-icon-cli.ts < layout-snapshot.json > layout.svg
```

입력에는 `version`, `dock`(기존 DockState), `open`(패널별 boolean), `sidebarWidth`, `androidWidth`, `tools`(memo/tasks의 tab 또는 popup), `popups`(x/y/width/height)가 포함된다. 생성기는 숫자를 검증·제한하고 SVG에 임의 입력 문자열을 삽입하지 않는다. 잘못된 JSON이나 버전·dock 없는 입력은 오류 종료하며 출력 SVG를 만들지 않는다.

### 기기별 배치와 메모·태스크 팝업 (2026-10-06)

저장 소유권은 [ADR 0197](../../../../.mew/docs/decisions/0197-mew-device-local-workspace-layout.md)을 따른다.

설정 → 화면에서 PC 메모와 태스크 각각의 탭/팝업 표시를 선택한다. 팝업은 문서 위에서 이동·크기 조절할 수 있고, 방식 전환 시 같은 컴포넌트와 입력 상태를 유지한다. 모바일은 선택과 관계없이 기존 전면 패널을 사용한다.

도킹 위치·분할 비율·문서 탭·패널 여닫힘은 브라우저 기기별로 계정/루트 프로젝트 키에 저장한다. 계정 복원값은 로컬 기록이 없는 기기의 초기값으로 사용한다. 팝업 크기·위치와 표시 설정도 브라우저에 저장하며 다른 기기와 서로 덮어쓰지 않는다. 브라우저 저장 공간을 지우면 해당 기기의 기억도 초기화된다.

검증 (2026-10-06): 관련 서버·격리 Chromium 테스트와 TypeScript·대상 lint를 실행했다. 실제 업데이트 설치·빌드·서버 재시작은 실행하지 않았다.

- 2026-10-07 계정 공용 프리셋 검증: 기존 프로젝트 목록 병합·중복/ID 충돌 처리·빈 목록 보존·계정 격리, 이름 저장·취소·재시작·프로젝트 전환 공유를 단위 및 격리 Chromium UI 테스트로 확인한다.

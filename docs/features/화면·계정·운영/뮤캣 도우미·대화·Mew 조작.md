## 요구사항

- 뮤캣 팝업의 최근 알림과 시스템 리소스 사이에서 궁금한 점을 묻고 Mew 기능을 실제로 실행한다.
- 사용자에게 별도 MCP 연결을 요구하지 않고 선택한 에이전트에 Mew 내장 MCP를 자동 주입한다.
- UI와 이후 AI 응답 안내·새 문서 생성에 현재 언어를 적용한다.

### 범위

- 런타임 선택·인증 안내, 도우미 전용 대화, 스트리밍 답변·중지·대화 기록 지우기·복원을 제공한다.
- 알림·대화·입력·리소스를 팝업 전체의 단일 스크롤로 탐색한다. 대화 기록 지우기는 표시 기록과 현재 대화 맥락을 초기화한다.
- 현재 맥락·제품 도움말, 프로젝트 생성·열기, Documents 준비, 파일·패널 열기, 프로젝트 작업 대화의 요청 초안을 제공한다.
- 기존 알림·리소스·계정 권한과 문서를 보존한다.

### 경계와 제한

- 프로젝트 관리 작업은 owner 전용이고 agent 권한이 없는 계정은 대화 영역을 사용하지 않는다.
- 기존 런타임 MCP 설정을 수정하지 않는다. 도구 실패·연결 종료를 완료로 표시하지 않는다.
- 삭제·배포·앱 빌드·업데이트는 도구 범위 밖이다. 프로젝트 작업 초안은 사용자가 전송한다.
- 세션 복원과 실제 도구 연결은 ACP 런타임 지원에 의존하며 실제 공급자 계정 검증은 별도다.

## 구현 내용

- 뮤캣 팝업에 도우미 대화·입력·전송·톱니 선택 목록을 통합하고 기존 에이전트 패널의 런타임 선택·인증을 연결했다.
- 대화·알림의 내부 스크롤을 제거하고 팝업 하단에서만 스트리밍 답변을 따라간다. 헤더의 대화 기록 지우기를 기존 새 대화 동작에 연결했다.
- 독립 감독·ACP 대화를 재사용하고 세션 생성·복원에 내장 stdio MCP를 자동 주입한다.
- 로컬 소켓의 각 호출에서 원래 계정 권한을 확인하고 화면 이동을 작업 ID로 요청·응답한다.
- 네 언어 UI·AI 응답 언어 안내·문서 템플릿을 제공하고 기존 문서·대화를 보존한다.

- 2026-10-02: 데스크톱·모바일 Chromium에서 긴 대화의 팝업 단일 스크롤, 진행 중 지우기 비활성화, 기록 초기화를 확인했다. 타입 검사·린트·문서 링크 검사가 통과했다(기존 lint 경고 유지). 워크스페이스 문서 배치 검사는 이번 변경 밖의 `todo/docs` 미등록 문서 3개를 보고했다.

- 실제 연결한 공급자에서 “메모 앱을 만들고 싶어”를 요청해 프로젝트 탭·Documents·작업용 대화 초안을 확인해야 한다. 사용자 확인 전 상태는 `changed`다.

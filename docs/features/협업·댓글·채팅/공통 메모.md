## 요구사항

- PC 메모 타이틀바의 아이콘으로 팝업/패널을 전환하고 내용·협업 세션·브라우저 표시 방식 저장을 유지한다. 화면 설정의 표시 선택 항목은 제거한다. 모바일은 전환 버튼 없이 공통 패널로 표시한다. 팝업 위에서 설정을 열면 설정 창과 내부 드롭다운이 앞에 표시된다.

- 서버 공통 Markdown 메모 하나를 실시간으로 함께 편집한다.
- PC·모바일 독의 메모 아이콘으로 도킹 패널을 열고 기존 독 재정렬·권한 표시를 따른다.
- 기능·Git 패널과 같은 36px 타이틀바·메모 아이콘·참여자 색 점·닫기 버튼과 Hotview·Markdown 원문(Plain) 보기 토글과 입력칸을 제공한다. 글자 수는 표시하지 않는다.
- 본문 첫 줄 위 여백은 PC·모바일 모두 16px로 유지하고 첫 제목·목록의 추가 위쪽 여백을 제거한다.
- PC에서는 공통 DockGrip으로 패널을 이동하고 분할 경계로 크기를 조절하며 제목 탭의 더블클릭으로 확대/복원한다. 배치와 열림 상태를 프로젝트별 계정 UI 원장에 저장한다.
- 모바일에서는 공통 전면 패널 스택·독 전환·Esc/뒤로가기 경로를 따른다.
- 패널 열기·독 전환·협업 연결 완료·보기 전환 시 본문에 자동 포커스하지 않는다. 모바일 키보드는 본문을 직접 눌러 편집할 때 연다.
- `Ctrl/Cmd+M`은 닫혀 있으면 열고, 외부에 포커스가 있으면 메모를 전면으로 가져와 본문에 포커스하고, 내부에 포커스가 있으면 닫는다.
- 패널을 닫아도 협업 문서·미전송 변경을 유지하고 참여자 표시에서 빠진다. 프로젝트를 전환해도 같은 서버 공통 메모를 사용한다.
- 모바일 보조키는 소프트 키보드가 열린 동안에만 표시하며 키보드가 닫히면 Ctrl·Shift 토글을 해제한다.

## 구현 내용

- 메모 열기·독 포커스 신호는 비편집 패널 루트에 포커스한다. 연결 완료와 Hotview/Plain 전환은 편집기 포커스를 요청하지 않는다. 이미 열린 메모로 이동하는 명시적 키보드 단축키는 본문 포커스를 유지한다.

- Hotview·Yjs·PresenceDots와 서버 예약 방·원자 저장 파일을 유지한다. 로그인과 협업 권한이 필요하다.
- App 소유 `useSharedMemo`가 프로젝트별 DockWorkspace 바깥에서 협업 세션·포커스·단축키를 유지하며 SharedMemo는 도킹 헤더·본문을 렌더링한다.
- 2026-10-01 사용자 요청으로 태스크 패널·API를 제거하고 메모 팝업을 패널로 대체했다. 기존 태스크 저장 파일은 보존하고 별도 요청 없이 기능을 재도입하지 않는다. [제거된 태스크 기록](../../history/project-tasks.md).
- 2026-10-03 사용자 요청으로 메모와 별도의 [태스크 패널](../%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B8%C2%B7%ED%8C%8C%EC%9D%BC%C2%B7%EA%B2%80%EC%83%89/%ED%83%9C%EC%8A%A4%ED%81%AC%20%ED%8C%A8%EB%84%90%C2%B7%EB%AA%A9%EB%A1%9D%C2%B7%EB%8B%AC%EB%A0%A5%C2%B7%EA%B0%84%ED%8A%B8.md)을 새로 제공한다. 메모에는 태스크 전환 버튼을 두지 않는다.
- 독·도킹·모바일 전면 상태·Esc/뒤로가기·배치 복원을 공통 패널 경로에 통합했다. 기존 팝업 이동·8방향 크기 조절·viewport 위치 보정은 제거했다.

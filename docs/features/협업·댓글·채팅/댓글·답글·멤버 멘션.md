## 요구사항

- 본문 선택 위치에 의견을 남기고 스레드로 대화한다.

### 범위

- 선택 위치 댓글·답글·멘션·수정·삭제와 댓글 목록을 제공한다.

### 경계와 제한

- 댓글은 본문과 별도로 관리한다.
- 원문이 바뀌어 앵커를 못 찾는 댓글도 목록에 남기며 작성자·owner의 관리 권한을 구분한다.

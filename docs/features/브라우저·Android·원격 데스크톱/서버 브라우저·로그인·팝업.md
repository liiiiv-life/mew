## 요구사항

로그인 중 다른 사용자가 호스트의 게임·작업 포커스를 빼앗지 않아야 한다. OAuth는 패널 크기에 맞는 독립 가상 화면의 일반 Chrome에서 진행하고 그 영상과 입력을 패널에 연결한다. 닫으면 가상 세션을 정리하며 완료된 공식 CLI 인증은 유지한다.

개발 앱은 도메인·Tailscale·Mewlink 접속 주소 뒤의 `/포트번호`로 연다. Mew 로그인과 계정별 권한을 확인한 뒤 호스트의 해당 localhost 앱을 접속한 기기에서 실행한다. 일반 내부 브라우저 메뉴·패널·주소창·바로가기·DOM 중계는 제공하지 않는다.

## 인수 기준과 검증 경계

- 로그인 영상과 클릭·키·붙여넣기·팝업이 같은 전용 X 서버에서 동작한다.
- 닫기·재접속·시작 중 취소·권한 회수에서 키·버튼과 소유 자식을 정리한다.
- `/3333` 비로그인은 인증 후 원래 앱으로 돌아오고 guest·다른 계정·다른 포트·Mew 자체 포트는 우회하지 못한다.
- 프론트의 루트 자산·API·POST·WebSocket/HMR을 전달하고 앱에 Mew 쿠키·전체 API 권한을 주지 않는다.
- 격리 자동 검사와 실제 OAuth·게임 동시 사용·운영 도메인·Tailscale·Mewlink 외부망 검증은 구분한다. 운영 반영은 사용자가 수행한다.

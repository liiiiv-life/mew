## 요구사항

- Git 변경 목록은 현재 접속 IP에서 Mew로 저장한 내용과 일치하는 파일만 기본 선택한다. 다른 IP와 출처가 확인되지 않는 변경은 수동으로 선택한다.

- 현재 프로젝트 저장소의 변경과 커밋을 검토하고 Git 작업을 수행한다.

### 범위

- 커밋 그래프·변경 파일·diff, 체크한 파일의 작업트리 내용 커밋을 제공한다.
- 변경 파일 마크는 추가·새 파일(`A`·`?`) 초록, 삭제(`D`) 빨강, 변경·타입 변경(`M`·`T`) 노랑, 이름 변경·복사(`R`·`C`) 보라, 충돌(`U`) 빨강으로 구분한다. 복합 상태는 문자마다 색상을 적용하며 상태 문자와 원본 상태 툴팁을 유지한다.
- diff 헤더에서 파일명을 작게 표시하고 문서 아이콘으로 해당 파일을 에디터에서 연다.
- 모바일 뒤로가기는 패널과 내부 화면을 함께 복원한다. `Git 목록 → diff → 에디터` 이동 후 두 번 뒤로가면 같은 파일의 `diff → Git 목록` 순서로 돌아간다. 커밋 상세·과거 커밋 diff도 방문 순서로 복원하며, 화면 안의 뒤로가기 버튼은 같은 이력을 소비한다.
- 처음 불러온 미커밋 변경 파일은 현재 IP 저장 기록과 현재 내용이 일치하는 파일만 기본 선택한다.
- 변경사항 바의 커밋 아이콘 왼쪽에 선택 변경 취소 아이콘을 둔다. 선택이 없거나 처리 중이면 비활성화하며 확인 팝업에서 파일 목록·복구 불가·새 파일 삭제를 안내한다. 확인 후에만 선택 파일의 staged·unstaged 변경을 HEAD로 되돌리고 새 파일을 삭제하며 선택 밖 변경과 커밋 초안을 유지한다.
- 커밋 제목·설명 입력란은 기본으로 숨기고 변경사항 바 맨 오른쪽의 커밋 아이콘을 누르면 하단에 표시한다. 입력란에는 제목·설명과 제목 오른쪽 종이비행기 전송 아이콘을 두며, 전송 버튼·같은 커밋 아이콘·제목 Enter로 수동 커밋하고 로봇 아이콘으로 AI 자동 커밋을 연다.
- 파일 체크박스 영역에서 터치·마우스 드래그를 시작하면 시작 항목이 미선택이면 지나간 항목을 모두 선택하고, 이미 선택돼 있으면 모두 해제한다. 같은 항목을 다시 지나가도 상태를 유지하며, 단일 탭·클릭과 키보드는 선택을 토글한다.
- 체크박스 드래그 중 변경 목록의 위·아래 가장자리에 머무르면 자동 스크롤하며 새로 나타나는 항목에도 선택·해제를 이어간다. 손을 떼거나 취소하면 스크롤을 멈춘다.
- 패널을 보는 동안 외부 편집·Git 작업으로 바뀐 커밋 기록·브랜치 정보·미커밋 변경 목록과 열린 작업트리 diff를 자동 갱신한다.
- AI 자동 커밋에서 기존 에이전트셋을 선택하거나 새로 만들고 Mew 커밋 스킬을 사용하는 전용 작업으로 선택 변경을 작업 단위로 나눠 실제 커밋한다.
- 큰 변경은 전체 diff를 로컬 색인한 뒤 변경 근거로 커밋을 구성하고, 불확실한 부분의 원본은 묶어서 추가 분석한다. 실제 커밋은 원본 전체를 사용한다.
- 진행 로그·취소·재접속을 제공한다.
- 브랜치·태그 생성·detached checkout·cherry-pick·revert를 제공한다.
- 타이틀바의 브랜치 드롭다운에서 현재 브랜치를 확인하고 로컬·원격 브랜치를 검색·선택해 전환한다.
- 같은 드롭다운에서 이름과 base(현재 HEAD·로컬/원격 브랜치·태그·커밋 해시)를 지정해 새 브랜치를 만들고 전환한다.
- 타이틀바의 origin 버튼으로 원격 저장소를 새 탭에서 연다. GitHub는 GitHub 아이콘, 다른 호스트는 외부 링크 아이콘을 표시한다.
- 타이틀바의 아래 화살표 Pull·위 화살표 Push로 현재 브랜치와 upstream을 동기화한다.
- 원격 작업 버튼 안에 실제 Git 진행 단계·퍼센트를 간결하게 표시하고 성공 후 `완료`를 잠깐 표시한 뒤 기본 아이콘으로 되돌린다.
- Mew 계정별 GitHub OAuth 연결·계정 표시·승인 코드·외부/내부 승인·취소·연결 해제를 제공한다.
- 기본 OAuth 앱을 포함해 설치자의 앱 등록 없이 연결하며 자체 Client ID 설정도 지원한다.
- 미연결 상태의 커밋·AI 커밋·Pull/Push는 로그인 창을 열고 성공 후 원래 요청만 한 번 실행한다. 취소 시 초안을 유지한다.

### 경계와 제한

- 하위 저장소 목록은 표시하지 않는다.
- 하위 프로젝트의 Git은 해당 프로젝트 탭에서 연다.
- AI 자동 커밋 실행은 선택 파일의 실제 분할 커밋을 승인하는 동작이다.
- AI 자동 커밋은 선택 범위 밖 변경을 포함하거나 push하지 않는다.
- AI 자동 커밋은 Git과 에이전트 기능 권한이 모두 필요하다.
- 브랜치 생성·전환은 Git 권한과 프로젝트 전체 파일 접근이 필요하다. 로컬 작업이라 GitHub 연결·fetch를 요구하지 않는다. 강제 전환·자동 stash·변경 폐기는 하지 않으며 Git이 전환을 거부하면 작업 내용과 입력을 유지하고 오류를 표시한다.
- Pull/Push는 Git 권한과 프로젝트 전체 파일 접근, 원격 추적 브랜치가 필요하다. Pull은 fast-forward만 허용하며 Push는 현재 브랜치만 강제 덮어쓰기 없이 보낸다.

## 구현 내용

- App이 루트 프로젝트별 현재 Git 화면을 관리하고 `useWorkspacePanelDismissals`의 공통 화면 등록 계약에 연결한다. `src/utils/git-workbench-navigation.ts`에서 목록·커밋 해시·diff 출처와 경로의 화면 식별자를 만든다. 방문 이력은 가벼운 화면 상태의 복원 콜백만 보관하며 diff 내용은 기존 요청으로 다시 읽는다. 이력 소진·PC 화면에서는 기존 상위 단계 이동을 유지한다.

- `GitWorkbench.tsx`의 공통 변경 파일 목록에서 상태 문자별 색상을 적용한다. 기존 테마별 의미 색상 토큰을 사용하므로 밝은·어두운 테마와 사용자 액센트 색상에 관계없이 타입 구분을 유지한다.

- `POST /api/git/discard`는 Git·파일 쓰기·프로젝트 전체 접근 권한과 현재 workspace를 검증한다. 선택 경로와 현재 변경 목록을 먼저 확인하고 이름 변경의 원래 파일도 함께 복원한다. 최초 커밋 전 새 파일 취소를 지원하며 폴더·서브모듈·심볼릭 링크 하위 경로는 거부한다. GitHub 연결이나 원격 작업 없이 실행한다. 공용 위험 작업 확인창은 취소 버튼에 초기 포커스를 두고 취소·Esc 시 요청을 보내지 않는다.

- 체크박스 영역의 포인터 캡처로 드래그 선택을 처리한다. 5px 이상 움직이면 시작 행의 반대 선택 상태를 드래그 전체에 고정해 시작 행과 현재 행 사이에 적용하고, 종료 클릭이 체크박스를 다시 토글하거나 diff를 열지 않도록 막는다. 체크박스 밖에서 시작한 터치는 목록 스크롤을 유지한다. 목록 가장자리 40px 안에서는 포인터 위치에 비례해 프레임마다 스크롤하며 새로 드러난 행에 같은 선택 상태를 적용한다. 종료·취소·목록 변경·비활성화·언마운트 시 프레임을 취소한다.

- 저장소 조회의 origin fetch URL을 자격 증명 없는 HTTP(S) 링크로 변환해 Pull·Push 오른쪽에 표시한다. SSH·SCP·Git 주소는 HTTPS로 변환하고 `.git` 접미사를 제거한다. origin이 없거나 웹 주소로 변환할 수 없으면 버튼을 숨긴다. GitHub 연결 없이 새 탭에서 열 수 있다.

- Pull·Push 앞의 브랜치 드롭다운은 현재 이름(또는 detached HEAD)을 표시한다. 열 때 로컬·캐시된 원격 브랜치와 base용 태그를 조회하고 브랜치 검색은 대소문자를 구분하지 않는다. 검색 입력·목록은 키보드 방향키와 Enter를 지원하고 Esc·뒤로가기는 최상위 팝업만 닫는다. 모바일에서는 화면 안에 배치하며 긴 이름은 말줄임한다.
- 새 브랜치 폼은 이름과 검색 가능한 공통 `SelectField`의 base를 받는다. 커밋 해시도 직접 입력할 수 있다. 생성하면 즉시 전환한다. 원격 브랜치를 직접 선택하면 원격 추적 로컬 브랜치를 만들고 전환하며, 새 이름으로 base만 지정한 생성에는 upstream을 자동 설정하지 않는다. 커밋 초안과 남아 있는 변경 파일 선택은 유지한다.

- 커밋 기록의 작성자 칸은 이름 길이만큼만 차지하고 긴 이름에만 최대 너비·말줄임을 적용한다. 행 오른쪽 여백은 8px이다.
- 변경 파일의 상태 마크(M·A·D 등)는 고정 너비 없이 글자 너비와 좌우 4px 패딩에 맞춘다. 체크박스와 마크 사이 간격은 기본 목록 10px, 상세 목록 14px로 기존의 약 2/3로 줄인다.

- 변경사항 바 제목은 `변경사항`으로 표시하며 수동 새로고침 버튼을 제거하고 기존 자동 갱신을 유지한다. 바 맨 오른쪽에 Git 커밋 아이콘과 AI 자동 커밋 로봇 아이콘 버튼을 순서대로 표시한다. 제목 입력칸과 버튼 높이는 28px로 통일하며 두 버튼은 28×28px 정사각형, 내부 아이콘은 14px이다. 모바일에서도 같은 크기를 유지한다. 마우스를 올리면 기존 번역 문구를 즉시 툴팁으로 보여주고 접근성 이름도 유지한다.
- 다른 패널 탭 바와 같은 36px 상단 바에 Git 아이콘·제목·닫기 버튼을 표시하며 데스크톱에는 공통 이동 손잡이를 둔다.
- 상단 바는 상세·diff·로딩·저장소 없음 상태에서도 유지하며, 본문은 그 아래에서 시작한다.
- GitHub 로그인 버튼·연결 계정 정보는 패널 헤더의 닫기 버튼 왼쪽에서 제공하고 하위 저장소 선택은 제공하지 않는다.
- Pull·Push 버튼은 기본 24×24px, 아이콘 14px로 표시한다. 진행 중에도 높이 24px을 유지하며 진행 문구는 10px과 좌우 4px 패딩으로 표시한다.
- Git 타이틀바는 화면이 아닌 실제 패널 너비를 기준으로 400px 미만일 때 Git 아이콘·제목을 숨기고 나머지 메뉴를 유지한다.
- GitHub 계정 왼쪽에 Pull·Push 아이콘 버튼을 순서대로 표시한다. 실행 중 중복 요청을 막고 완료 후 목록을 갱신하며 커밋 초안과 파일 선택을 유지한다. 실패는 패널의 기존 오류 영역에 표시한다.
- 실행한 원격 버튼 안에 `Push 중…`·`압축 42%`·`전송 68%` 등 단계별 실제 진행률을 한 줄로 표시한다. 전송 100% 뒤에는 원격 결과를 기다리며 `확인 중…`을 표시한다. Git 성공 종료를 확인한 뒤 체크 아이콘과 `완료`를 3초간 표시하고 원래 아이콘으로 돌아온다. 별도 전역 토스트·로그 패널은 띄우지 않는다. 패널 너비 400px 미만에서는 Git 아이콘·제목을 숨겨 메뉴 공간을 확보하고 최소 브랜치 조작 영역을 유지하며 계정·긴 브랜치 이름을 말줄임해 진행 텍스트가 겹치지 않게 한다. 실패·연결 중단을 완료로 표시하거나 자동 재실행하지 않는다. 프로젝트 전환·컴포넌트 해제 뒤 오래된 진행 이벤트는 적용하지 않는다.

### 현재 IP 기본 선택 (2026-10-06)

## 요구사항

- 열린 파일의 변경을 커밋하고 과거 내용을 확인·복원한다.

### 범위

- 현재 파일 Commit과 파일별 Git 이력 조회·되돌리기를 제공한다.

### 경계와 제한

- 현재 파일 커밋과 Git 패널의 선택 파일 커밋은 범위가 다르다.
- 자동저장만으로 Git 이력이 생긴다고 가정하지 않는다.

### 상세 계약

- [편집 사용법](../../guides/editor.md)

- 상위: [분야 지도](MOC.md) · [상위 기능](_Git%C2%B7%EB%B3%80%EA%B2%BD%20%EC%9D%B4%EB%A0%A5.md).

## 구현 내용

- 명시적 커밋·이력 복원은 쓰기 전에 계정별 Git 연결을 확인한다. 미연결이면 OAuth 창을 열고 성공 후 재실행하며 취소 시 초안을 유지한다. 다른 staged 파일은 함께 커밋하지 않는다. [Git 연결 계약](../../development/git-connections.md)을 따른다.

- 현재 파일 Commit과 파일별 Git 이력 조회·되돌리기를 제공한다.

## 검증

- 2026-09-29: HTTP/실제 임시 Git으로 미연결 시 파일·index 미변경, 일반 저장 허용, 계정별 작성자·커미터, 다른 staged 파일 보존을 확인했다. 브라우저에서 파일 커밋의 로그인 취소·초안 유지·성공 후 한 번만 재시도를 검증했다.

- 아래 항목은 이번 정리에서 실행한 테스트 결과가 아닌 사용자 확인 기준이다:
  - 선택 파일의 커밋·이력·복원이 다른 파일의 미커밋 변경을 의도 없이 포함하지 않는지 확인한다.

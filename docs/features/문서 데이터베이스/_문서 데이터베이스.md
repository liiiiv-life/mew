## 요구사항

- 프로젝트별 표 데이터를 문서에 연결하고 공동으로 다룬다.

- 하위 기능에서 작업 범위와 관련 구현을 고른다.
- 여러 하위 기능을 바꿀 때도 각각의 상세 계약을 확인한다.

## 요구사항

- 기능 단위로 요구사항을 관리하고 에이전트 구현과 사용자 검토를 연결한다.

### 범위

- 다른 작업 패널과 일관된 타이틀바·데스크톱 이동 및 크기 조절을 제공하며 제목 앞에 독과 같은 기능 아이콘을 표시한다.
- 기능 패널은 모든 계정에서 읽기 전용이며, 기능 계층 안에서 요구사항·구현 내용·검증을 목록 항목으로 읽는다.
- 제목 왼쪽 아이콘으로 해당 가지를 접고 펼치며, 제목과 본문은 선택·복사할 수 있는 텍스트로 표시한다.
- 원본 문서는 제목 오른쪽 문서 아이콘으로 열며, 접힌 상태에서도 제공하고 본문의 문서 열기 버튼은 제거한다.
- 본문은 Markdown 서식을 적용해 읽는다. 요구사항은 12px·20px 줄 높이와 `ink-secondary` 색상으로 다른 본문보다 작고 어두운 톤을 사용한다. 중복 제목·상위 기능 표시는 생략한다.
- 요구사항·구현 내용·검증·관련 파일·커밋은 제목 다음 줄부터 내용을 표시하는 한 열 배치를 사용한다. 섹션 사이의 별도 세로 여백 없이 32px 제목 행을 촘촘하게 배치하고 펼친 기능 아래에는 4px 여백을 둔다.
- 기능 상태는 제목 옆 색상 표시와 접근성 이름·툴팁으로 제공하고, 펼친 본문에는 중복 상태 설명·수정 날짜를 표시하지 않는다.
- 하위 기능은 파일 링크 대신 부모 안의 실제 기능 행으로 표시하며, 같은 패널에서 상태 확인·접기를 제공한다.
- 기능을 펼치면 요구사항과 하위 기능을 바로 표시하며 해당 묶음에는 접기·펼치기 버튼을 두지 않는다. 각 하위 기능 자체와 구현 내용·검증·관련 파일·커밋 섹션은 접고 펼칠 수 있다. 편집 입력과 미저장 초안은 제공하지 않는다.
- 처음에는 기능과 접을 수 있는 내부 섹션을 접어 두고, 이후에는 계정·프로젝트별 펼침 상태·정렬·스크롤 위치를 저장해 다시 연다. 새로 추가된 항목은 접힌 상태로 시작한다.
- 에이전트셋 선택과 조회, 제목·본문 편집, 항목·기능 추가, 요청·재위임·재시도, 상태 판정·실행 중단 UI는 제공하지 않는다.
- 사용자 요청으로 기능 패널의 조회와 변경을 분리했다. 명시적 후속 요청 없이 제거한 변경 UI를 재도입하지 않는다.
- 제목·부모 관계·관련 파일·커밋·상태·작업 이력을 같은 계층에서 조회한다. 원본 문서·파일·커밋·기존 대화 열기는 유지한다.
- Markdown 프론트매터와 본문을 기준본으로 사용하고 관련 파일·커밋·구현 결과를 연결한다.

### 경계와 제한

- 실행 큐·대화·요청 이력은 서버 소유다. 문서 편집기·외부 Markdown 편집과 기존 API·CLI는 유지한다.
- 외부 문서 편집만으로 작업을 실행하지 않으며 사용자 승인 상태를 에이전트가 임의 설정하지 않는다.

## 구현 내용

- 기능 패널의 변경 API 호출·에이전트셋 조회 및 편집·요청 상태를 제거하고 조회·탐색·화면 상태 복원을 유지한다.

- 타이틀바 제목 앞의 14px 기능 아이콘은 독과 공통 `FeatureIcon`을 사용하며 PC·모바일 모두 표시한다.
- PC·모바일 독의 기능 버튼으로 작업 패널을 연다. 다른 작업 패널과 같은 36px 타이틀바·배경·아이콘 버튼을 사용한다.
- 데스크톱에서는 공통 도킹 손잡이로 위치를 옮기고 경계선 드래그·키보드로 폭과 높이를 조절한다. 계정·프로젝트별 배치와 조회 상태를 복원한다. 모바일에서는 손잡이 없이 독 위 본문을 채운다.
- 펼침 상태와 스크롤은 사이드바와 같은 계정의 프로젝트 화면 상태에 저장하고, 기능 목록을 불러온 뒤 복원한다.
- 독 전환 시 펼침 상태를 유지하며 닫기·Esc·뒤로가기는 즉시 닫는다.
- 현재 프로젝트·에이전트 권한을 따르고 모바일도 동일한 인라인 계층을 사용한다.
- 기능 전체 팝업은 사용자 요청으로 제거했으며 요청 전 재도입하지 않는다.

- 관련 파일·커밋과 과거 실행 결과는 보존한다.
- 제목과 본문은 읽기 전용이다. 중복된 제목·부모 편집 행은 사용자 요청으로 제거했고 요청 전 재도입하지 않는다.
- 본문의 제목·불렛·강조·코드·링크·표를 렌더링하고, 문서의 중복 제목·상위 탐색 링크는 원문을 보존한 채 패널에서 숨긴다.
- 파일 링크는 기능 문서 기준으로 열며 링크 클릭은 편집을 시작하지 않는다. 정렬은 공용 자체 선택기를 사용한다.
- `parent`로 연결된 자식은 요구사항 다음의 하위 기능 묶음에 한 번만 표시한다. 요구사항·하위 기능 묶음은 부모 기능을 펼치면 즉시 표시하며 과거 섹션 펼침 상태에 영향을 받지 않는다. 본문의 자식 링크 목록은 원문을 보존한 채 생략하고, 등록된 기능으로 향하는 링크는 GUI의 해당 기능으로 이동한다.

## 요구사항

- 작업을 보내고 진행·중단·대기열·이전 대화를 관리한다.

### 범위

- 메시지 전송·중단·작업 기록·대기 메시지 편집/순서 변경·/clear와 히스토리 복원을 제공한다.
- 독립 감독과 전사를 통해 브라우저·프로젝트 전환 뒤 대화를 이어 간다.
- 메모리 부족 시 진행 작업을 중단하고 오류를 표시하며 대기열을 보류한다.
- 회복 후 명시적 전송으로 재개한다([OS 한도와 범위](../../operations/agent-memory.md)).

### 경계와 제한

- 패널 닫기와 탭 세션 종료를 구분한다.
- 히스토리·외부 CLI 이어쓰기와 런타임별 복원 지원은 세션 계약을 따른다.

### 상세 계약

## 구현 내용

- 연결·초기 준비·히스토리 로딩은 대화 영역의 빈 말풍선 shimmer로 알린다. 히스토리 목록 조회에도 같은 효과를 사용하며 중복된 중앙 스피너·검정 덮개는 제거한다.
- 대화·초안을 보존하고 준비가 끝나면 실제 대화를 표시한다. 연결·히스토리 로딩 중에도 입력칸 작성은 유지하고 전송만 막는다. 모션 감소와 비활성 탭에서는 애니메이션을 멈춘다.
- 탭 전환은 계속 가능하며 연결 끊김 뮤캣 알림은 보내지 않는다.

- 메시지 전송·중단·작업 기록·대기 메시지 편집/순서 변경·/clear와 히스토리 복원을 제공한다.

- 기존 대화 복원은 지원 런타임에서 임시 빈 세션 생성을 생략하고, 새로고침의 전사 캐시 병합은 긴 반복 청크를 선형 비교한다. 복원·인증 실패 시 기존 폴백을 유지한다([실행 계약](../../development/agent-sessions.md#메시지재접속큐)).

## 검증

- 아래 항목은 이번 정리에서 실행한 테스트 결과가 아닌 사용자 확인 기준이다:
  - 작업 중 화면 전환·재접속 시 중복 전송 없이 전사와 대기 순서가 보존되는지 확인한다.

- 2026-09-25: 격리 Chromium에서 데스크톱·모바일 양 테마의 오버레이 경계, 연결 중 초안 편집·높이 조절, 전송 차단, 탭 전환·재연결 후 초안 보존과 전송을 확인했다.

- 2026-09-25: `agent-startup.test.ts`·`agentHost.test.ts`·ACP/인증/전사/WS·캐시·연결 UI 관련 테스트 75개가 통과했다. 모의 stdio ACP에서 복원 전 빈 세션·중복 기본값 호출 제거, load 미지원·인증 만료·복구 실패·writer 반납을 확인했다. 반복 청크 캐시 병합은 모든 짧은 조합과 긴 전사에서 보존을 확인했다. 실제 공급자의 응답 시간과 배포 후 체감 시간은 미측정이다.

- 2026-09-25: 빈 말풍선 shimmer 전환 후 연결 UI·전사 캐시·대화 접기 테스트 27개가 통과했다. 격리 Chromium의 390/1100px 양 테마에서 초기 준비·재연결·히스토리 목록과 본문 로딩·성공/실패 후 해제·초안 보존·모션 감소를 확인했다. 타입 검사와 문서 경계·링크 검사도 통과했다.

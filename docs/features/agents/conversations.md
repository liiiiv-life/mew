## 요구사항

- 작업을 보내고 진행·중단·대기열·이전 대화를 관리한다.
- 빈 대화는 중앙의 번역된 안내 문구로 채팅 시작을 안내한다.

### 범위

- 메시지 전송·중단·작업 기록·대기 메시지 편집/순서 변경·/clear와 히스토리 복원을 제공한다.
- 독립 감독과 전사를 통해 브라우저·프로젝트 전환 뒤 대화를 이어 간다.
- 메모리 부족 시 진행 작업을 중단하고 오류를 표시하며 대기열을 보류한다.
- 회복 후 명시적 전송으로 재개한다([OS 한도와 범위](../../operations/agent-memory.md)).

- 대기 큐에서 첨부를 확인하고 편집 중 파일 추가·제거·사진 미리보기를 제공한다.
- 큐 항목은 하단 메시지 입력칸에서 편집하며, 저장 버튼 바로 위에 취소 X를 제공한다.
- 큐 등록 당시의 모델·노력도·권한을 저장하고 편집 시 불러온다. 저장·취소 후에는 편집 직전 새 메시지용 설정을 복원한다.

### 경계와 제한

- 패널 닫기와 탭 세션 종료를 구분한다.
- 히스토리·외부 CLI 이어쓰기와 런타임별 복원 지원은 세션 계약을 따른다.

## 구현 내용

- 서버 전사를 SQLite에 증분 저장하고, 계정별 IndexedDB에 최근 대화를 비동기 보관한다. 최근 20개 질문·이전 구간·재접속 변경분을 순번으로 동기화한다. 기존 JSON은 비파괴 이전하며 구 감독 replay와 자동 복원 실패 보호를 유지한다([대화 저장 계약](../../development/conversation-storage.md)).
- 이전 구간을 읽을 때 스크롤·버블 키·CLI의 전체 질문 순서를 보존한다. 원장 확인 뒤 동일 계정·세션의 기기 기록을 먼저 표시한다.

- 큐 항목의 설정 표시 이름·실행 ID를 `settings`로 저장하고 `meta.queuedSettings`로 복원한다. 편집 중 설정은 로컬 초안에만 반영하고 저장할 때 서버 큐를 갱신한다. 실제 실행도 저장된 설정을 사용하며 턴 뒤 최신 새 메시지 설정으로 복원한다.

- 대기 큐 항목 맨 왼쪽의 전용 핸들로 순서를 바꾼다. 마우스·터치 모두 길게 누르지 않고 바로 끌며, 핸들에서 위·아래 방향키로도 이동한다. 본문은 편집만 열고 편집 중에는 모든 핸들을 비활성화한다.

- 대기·예약 큐의 높이와 상위 레이어를 확보하고 대화 내부 레이어를 분리해 큐 상단이 버블에 가려지지 않도록 한다.
- 큐 인라인 편집칸 대신 하단 입력 UI를 재사용한다. 전송은 저장 아이콘으로, 예약은 저장 바로 위의 취소 X로 바꾸고 새 메시지 초안·첨부·CLI 모드는 저장·취소 후 복원한다([큐 편집 표시](../../specs/agent-panel.md#대기-큐-편집)).
- 사용자 버블의 오른쪽 위와 에이전트 답변 버블의 왼쪽 위 라운딩을 0으로 표시한다([대화 표시 명세](../../specs/agent-panel.md#작업-버블-상태)).
- 준비가 끝난 빈 대화 본문 중앙에 네 언어의 채팅 시작 문구를 표시한다([빈 대화 표시 계약](../../specs/agent-panel.md#빈-대화)).
- 서버 탭 원장 조회부터 연결·초기 준비·히스토리 로딩까지 빈 말풍선의 좌우 왕복 shimmer로 알린다. 레거시 줄글 캐시 미리보기는 표시하지 않는다. 동일 세션의 IndexedDB 버블 선표시는 아래 저장 계약을 따른다. 히스토리 목록 조회에도 같은 효과를 사용하며 중복된 중앙 스피너·검정 덮개는 제거한다.
- 빛 띠는 수평으로 양 끝 0%·¼/¾ 지점 50%·중앙 100%의 상대 강도로 이어지며 경계에서 끊기지 않는다.
- 대화·초안을 보존하고 준비가 끝나면 실제 대화를 표시한다. 연결·히스토리 로딩 중에도 입력칸 작성은 유지하고 전송만 막는다. 화면에 보이는 탭은 입력 포커스와 관계없이 빛 띠를 말풍선 안에서 왕복시킨다. 모션 감소 시에는 중앙에서 밝기만 변화시키며 숨긴 탭에서는 멈춘다.
- 탭 전환은 계속 가능하며 연결 끊김 뮤캣 알림은 보내지 않는다.

- 메시지 전송·중단·작업 기록·대기 메시지 편집/순서 변경·/clear와 히스토리 복원을 제공한다.

- 기존 대화 복원은 지원 런타임에서 임시 빈 세션 생성을 생략하고, 새로고침의 전사 캐시 병합은 긴 반복 청크를 선형 비교한다. 복원·인증 실패 시 기존 폴백을 유지한다([실행 계약](../../development/agent-sessions.md#메시지재접속큐)).

- 대기 큐에 첨부 태그와 별도 첨부 버튼을 연결한다. 저장 시 첨부를 함께 반영하고 취소 시 원본을 유지하며, 업로드 중 저장과 늦은 업로드의 다른 초안 혼입을 막는다([입력 계약](../../specs/agent-input-mentions.md), [큐 전달 계약](../../development/agent-sessions.md#메시지재접속큐)).

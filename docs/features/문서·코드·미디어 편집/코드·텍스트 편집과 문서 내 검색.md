## 요구사항

- 코드와 일반 텍스트를 편집하고 열린 문서 안을 탐색한다.

### 범위

- 줄 번호·구문 강조·지원 형식의 진단을 표시한다.
- 문서 안 찾기·바꾸기와 실행 취소·다시 실행을 제공한다.
- 모바일에서 코드·일반 텍스트를 두 손가락으로 벌리거나 오므려 글자와 줄 번호를 확대·축소한다. 읽기 전용 파일에도 적용한다.

- 모바일 키보드가 열릴 때 편집기 높이를 줄여 터치한 커서 줄과 선택 글자 수·파일 크기 상태줄을 키보드 위에 유지한다.

### 경계와 제한

- 언어별 지원은 실제 등록된 확장에 한정한다.
- 프로젝트 전체 검색은 프로젝트·검색 기능에서 다룬다.

### 상세 계약

- [편집 사용법](../../guides/editor.md)

### 코드·일반 텍스트의 문서 내 검색

- `Ctrl+F`·`Cmd+F`로 편집기 상단에 찾기 행을 연다. 검색어, 현재 결과·전체 결과 수, 대소문자 구분·단어 단위·정규식 옵션과 이전·다음·모두 선택·닫기 동작을 모아 표시한다.
- 바꾸기 행은 기본으로 접고 필요할 때 펼친다. 읽기 전용 파일에서는 바꾸기 입력과 동작을 숨긴다. 폭 480px 이하에서는 검색 옵션을 입력 안에 유지하고 결과 수·이전·다음·모두 선택·닫기를 다음 행에 배치한다.
- 검색 옵션은 눌림 상태를 표시하는 버튼으로 제공한다. 아이콘 버튼에는 번역된 접근성 이름과 공통 툴팁을 적용한다.
- 검색 결과는 최대 10,000개까지 세며, 이를 넘으면 전체 결과 수 뒤에 `+`를 붙인다. 검색 이동·모두 선택·바꾸기·실행 취소와 검색 입력 안의 키보드 처리는 기존 CodeMirror 검색 동작을 유지한다.
- 모두 선택은 최대 1,000개의 일치 항목을 각각 선택하며, 이를 넘으면 버튼을 비활성화하고 툴팁에 한도를 표시한다. 화면 언어를 바꿔도 검색어·바꿀 문자열과 바꾸기 행의 펼침 상태를 유지한다.

### 터치 확대·축소

- `.md`·`.mdx`를 제외한 CodeMirror 파일 본문과 줄 번호 영역에서 두 손가락의 거리 비율에 따라 글자 크기를 8~40px로 조절한다. 도구 모음과 브라우저 전체 배율은 그대로 유지한다.
- 손가락 사이에서 읽던 위치를 기준으로 스크롤을 보정한다. 한 손가락 스크롤·텍스트 선택과 키보드 편집은 기존 동작을 따른다.
- 핀치는 본문·선택 영역·실행 취소 이력을 바꾸거나 자동저장을 일으키지 않는다. 핀치 뒤 남은 손가락을 뗄 때도 커서를 옮기지 않는다.
- 크기는 열린 편집기에서만 유지한다. 파일 전환·읽기 전용 전환 등으로 편집기가 다시 만들어지면 기본 14px로 돌아간다.

## 구현 내용

- 모바일 viewport·편집기 높이 변경 뒤 포커스된 커서를 다시 맞추고 키보드를 닫으면 높이를 복원한다. 상세 계약은 [모바일 에디터와 키보드](../../development/ui-contracts.md#모바일-에디터와-키보드)를 따른다.

- 줄 번호·구문 강조·지원 형식의 진단을 표시한다.
- `src/utils/codeSearch.ts`가 CodeMirror 검색 확장에 `src/utils/code-search-panel.ts`의 전용 패널을 연결한다. 검색·바꾸기 명령과 상태는 CodeMirror를 사용하고 패널의 배치·옵션·결과 수를 Mew UI로 표시한다.
- `src/utils/code-pinch-zoom.ts`의 CodeMirror 확장이 스크롤 영역의 터치 이벤트와 글자 크기를 처리한다. 기본 한 손가락 스크롤을 허용하고 핀치만 에디터에서 처리하며, 편집기를 제거할 때 이벤트와 대기 중인 프레임을 정리한다.

- 본문 로딩 중에는 에디터 영역에 반투명 검정 덮개와 중앙 인디케이터를 표시하고 편집을 막는다.
- 탭 전환은 유지하며 성공·실패 시 해제한다.
- 상세 계약은 [에디터 본문 로딩](../../development/ui-contracts.md#에디터-본문-로딩)을 따른다.

## 검증

- `server/code-search-ui.test.ts`를 680px·미드나이트·한국어, 390px·로즈·영어, 320px·오션·일본어 조건에서 실행해 통과했다. 찾기·바꾸기 펼침, 결과 수·검색 옵션·정규식 오류 회복, 이전·다음·모두 선택, IME 입력과 키보드 이동·닫기, 단일·전체 바꾸기와 실행 취소, 읽기 전용, 언어 변경 후 입력·펼침 상태 보존을 확인했다. 가로 넘침·24px 이상 버튼 높이·공통 툴팁·Esc 전파 차단과 10,001개 결과의 `10000+` 표시·모두 선택 한도·계속 탐색도 검증했다.

- `server/code-pinch-zoom-ui.test.ts`에서 모바일 터치 확대·축소, 크기 제한, 읽던 위치·브라우저 배율·본문·선택 영역·실행 취소 이력 보존, 읽기 전용·일반 텍스트 지원과 Markdown 제외를 검증한다. 한 손가락 입력·취소·편집기 제거 뒤 이벤트 정리와 데스크톱 스크롤도 확인한다. 실제 휴대폰의 Safari·Chrome 동작은 실기기 확인 대상이다.

- `server/editor-keyboard-ui.test.ts`에서 키보드로 줄어든 화면의 28번 줄 유지·반복 크기 변경·상태줄과 보조키의 비겹침·입력·높이 복원·데스크톱과 읽기 스크롤 보존을 확인한다. OS 키보드 자체는 실기기 확인 대상이다.

- 아래 항목은 이번 정리에서 실행한 테스트 결과가 아닌 사용자 확인 기준이다:
  - 지원 파일의 강조·진단·찾기 위치와 수정 후 실행 취소를 확인한다.

- `server/editor-pane-ui.test.ts`로 데스크톱·모바일 로딩 표시, 캐시 재조회, 연속 전환, 빈 문서·실패 후 해제를 검증한다.

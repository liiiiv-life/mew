## 요구사항

- 문서의 각주를 삽입하고 번호와 참조를 정리한다.
- 커서 위치나 선택한 글 뒤에 주석(Annotation)을 달고, 팝업과 전체 목록에서 읽고 고친다.

### 범위

- 각주 추가·자동 번호 정리·본문 마커와 References 사이 이동을 제공한다.
- 주석 추가·수정·삭제, 위첨자 마커와 전체 주석 목록을 제공한다.

### 경계와 제한

- 각주 구문과 정리 규칙은 편집기의 지원 형식을 따른다.
- 주석은 Markdown 파일에 저장하며, 댓글·답글이나 기존 `Alt+E` 각주와 별도로 관리한다.
- 인용 출처의 사실 검증을 자동 수행하지 않는다.

### 주석 추가와 편집

Markdown의 Hotview와 Plain에서 `Ctrl+'`를 누르면 현재 커서 위치에 주석 마커를 넣는다. 글자를 선택했다면 선택한 글은 유지하고 그 뒤에 마커를 넣는다. Hotview는 마커를 작은 위첨자 `1)`, `2)`로 표시한다.

본문 우클릭 메뉴의 **주석 추가**도 같은 삽입·편집 경로를 사용한다. 기존 선택 안을 우클릭하면 선택 뒤에, 선택 밖을 우클릭하면 옮긴 커서 위치에 마커를 넣는다. Markdown 이외의 파일이나 수정할 수 없는 위치에서는 항목을 비활성화한다. 메뉴 공통 동작은 [에디터 우클릭 계약](../../development/ui-contracts.md#에디터-본문-우클릭-메뉴)을 따른다.

마커를 추가하면 텍스트 입력창 하나가 있는 작은 팝업을 연다. 입력한 내용은 문서 자동저장에 반영한다. Hotview의 위첨자 마커를 누르면 같은 팝업을 다시 열어 내용을 고치거나 주석을 삭제한다.

댓글 플로팅 버튼 바로 옆에 닫는 쌍따옴표 모양의 **주석** 버튼을 둔다. 이 버튼으로 현재 문서의 전체 주석을 보고, 항목을 골라 편집 팝업을 연다.

### 주석 저장과 표시

본문의 주석 마커는 `^[1]`, `^[2]`로 저장하고, 내용은 파일 하단의 `# $Annotations$` 아래 순서 목록으로 저장한다.

```markdown
선택한 구절^[1]과 다른 구절^[2].

# $Annotations$

1. 첫 번째 주석
2. 두 번째 주석
```

Hotview는 본문의 위첨자 마커만 표시하고 주석 저장 구역은 숨긴다. Plain에서는 마커·제목·목록을 포함한 원문을 볼 수 있다. 주석을 모두 삭제하면 `# $Annotations$` 제목과 목록도 제거한다. 기존 `# References` 각주 구역의 삭제 규칙과는 별개다.

주석 저장 구역은 문서 최상위의 레벨 1 제목 `$Annotations$`부터 다음 최상위 제목 직전까지다. 뒤에 다른 제목과 본문이 있으면 보존한다. 코드 블록·인라인 코드·프론트매터와 이스케이프한 `\^[1]`은 주석 마커로 읽지 않는다.

번호는 본문 마커 순서에 맞추되 기존 번호와 연결된 내용을 함께 이동한다. 수동으로 작성한 목록 항목에 대응하는 마커가 없어도 내용을 자동 삭제하지 않는다. 저장 구역에 알 수 없는 본문이 남아 있으면 마지막 마커를 삭제한 뒤에도 그 본문을 보존한다.

공동 편집 중에는 문서 모델 내부의 안정된 식별자로 마커와 목록 항목을 연결해, 동시 삽입으로 화면 번호가 바뀌어도 각 내용을 유지한다. 식별자는 Markdown에 추가하지 않는다. 다른 참여자의 편집으로 열어 둔 주석의 번호가 바뀌거나 주석이 삭제되면 입력 팝업을 닫아 다른 주석을 잘못 고치지 않게 한다.

입력창의 Markdown·HTML 기호는 서식으로 실행하지 않고 글자로 저장한다. 여러 줄은 목록 항목 안의 문단으로, 빈 줄은 기존 편집기의 `<br/>` 형식으로 보존한다. Plain의 주석 조작은 필요한 마커·목록 구간만 바꾸며 본문 전체를 Hotview로 변환하지 않는다.

## 구현 내용

- 각주 추가·자동 번호 정리·본문 마커와 References 사이 이동을 제공한다.
- 주석은 본문 마커와 파일 하단 목록을 같은 Markdown에 저장하고, Hotview에서 저장 구역을 숨긴다.

## 검증

- 아래 항목은 실행 결과가 아닌 사용자 확인 기준이다:
  - 각주 추가·삭제·이동 뒤 마커와 참고문헌 번호가 맞는지 확인한다.
  - Hotview·Plain에서 `Ctrl+'`로 커서 위치와 선택한 글 뒤에 주석을 달고, 입력한 내용이 다시 열어도 유지되는지 확인한다.
  - Hotview 마커와 전체 주석 목록에서 같은 내용을 열어 고치고 삭제할 수 있는지 확인한다.
  - Hotview에 `$Annotations$` 저장 구역이 보이지 않고 Plain에는 원문이 보이는지 확인한다.
  - 마지막 주석을 삭제하면 마커·목록·`# $Annotations$` 제목이 함께 없어지고, 기존 각주와 본문은 유지되는지 확인한다.

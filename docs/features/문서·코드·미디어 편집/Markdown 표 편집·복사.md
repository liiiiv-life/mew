## 요구사항

- 문서의 표를 편집하고 다른 형식으로 복사한다.

### 범위

- 행·열 조작·열 너비 조절과 Markdown·CSV·이미지 복사, 문서 DB로의 전환을 제공한다.

### 경계와 제한

- Markdown 표는 문서 본문에, 문서 DB의 행·열은 Postgres에 저장한다. 전환은 문서 블록을 교체하며 DB를 삭제하지 않는다.
- 열 너비 보조 저장 형식은 편집 사용법을 따른다.

### 상세 계약

- 표 우클릭은 기본 본문 메뉴의 주석·댓글·복사·잘라내기·붙여넣기·삭제·전체 선택 아래에 기존 표 전용 항목을 함께 표시한다. 모든 항목은 왼쪽 아이콘과 오른쪽 이름을 사용하며, 기본 항목의 선택·권한·클립보드 동작은 [에디터 우클릭 계약](../../development/ui-contracts.md#에디터-본문-우클릭-메뉴)을 따른다.
- 편집 가능한 표의 셀을 우클릭하면 `행 추가`와 `열 추가`가 표 형식 복사 항목 위에 표시된다. 기존 커서 위치와 관계없이 우클릭한 셀의 바로 아래에 행을, 바로 오른쪽에 열을 추가한다. 헤더 셀과 마지막 행·열에서도 사용할 수 있다.
- 편집 가능한 문서에서는 우클릭 메뉴의 `데이터베이스로 전환`으로 표 전체를 DB로 바꾼다. 모든 열은 텍스트이며 숫자·날짜·불리언처럼 보이는 문자열도 그대로 저장한다. 첫 행이 헤더면 열 이름으로 사용하고, 헤더가 없으면 열 이름을 만들고 첫 행부터 데이터로 저장한다. 빈 이름·중복 이름·예약된 열 이름은 구분되는 이름으로 정리한다. 첫 열의 값이 비어 있거나 중복되면 원본 값을 유지하고 맨 앞에 텍스트 대표열을 추가한다.
- 셀의 문단·강제 줄바꿈을 텍스트 줄바꿈으로 저장하며 굵게·링크 같은 서식은 DB 값에 포함하지 않는다. 병합 셀의 텍스트는 시작 칸에만 두고 나머지 칸은 비운다. 헤더만 있는 표는 행 없는 DB를 만들며 예시 행을 넣지 않는다. 가져오기는 최대 200열·10,000행이며 잘못된 입력이나 저장 실패 시 원본 표를 유지한다.
- 전환은 일반 이력과 Yjs 협업 이력 모두 한 단계의 실행 취소·다시 실행을 제공한다. 실행 취소는 원래 표의 서식을 복원하고, 다시 실행은 이미 생성한 같은 DB를 재사용한다. 전환 대기 중 원본을 수정·삭제하거나 문서를 읽기 전용으로 바꾸면 교체를 취소한다. 자세한 저장 경계는 [DB 기능 계약](../문서%20데이터베이스/문서%20데이터베이스·전체%20목록.md#markdown-표와-전환)과 [전환 결정](../../decisions/0035-table-database-conversion.md)을 따른다.
- 읽기 전용에서는 행·열 추가와 DB 전환을 표시하지 않고 표 전용 항목으로 Markdown·CSV·이미지 복사만 제공한다. 셀이 아닌 표 영역에서도 편집 권한이 있으면 DB 전환과 복사를 제공한다.
- 헤더·본문의 한 셀 안에서 텍스트를 선택해 복사하면 선택한 글자만 일반 텍스트로 복사한다. 표 HTML 태그·Markdown 서식은 붙이지 않으며 셀 안의 문단과 강제 줄바꿈은 줄바꿈으로 보존한다.
- 여러 셀 선택·표 전체 선택과 표 복사 메뉴는 기존 복사 형식을 유지한다.
- [편집 사용법](../../guides/editor.md)

## 구현 내용

- `packages/editor/src/utils/clipboardTable.ts`가 같은 셀 안의 텍스트 선택을 판별하고, `Editor.tsx`의 클립보드 텍스트 직렬화기가 Markdown 직렬화 전에 선택 텍스트를 반환한다.
- 행·열 조작·열 너비 조절과 Markdown·CSV·이미지 복사를 제공한다.
- `Editor.tsx`가 우클릭한 셀을 메뉴에 전달하고, `TableCopyMenu.tsx`가 추가 버튼을 누를 때 그 셀의 현재 문서 위치로 선택을 옮겨 행·열을 삽입한다.
- `TableCopyMenu.tsx`는 DB 확장에 주입된 API를 사용해 `database/tableConversion.ts`의 전환을 실행한다. 요청 대기 중 문서 위치를 매핑하고 원본 노드가 유지된 경우에만 교체한다. ProseMirror·Yjs 이력의 앞뒤 그룹을 끊어 다른 입력과 묶이지 않게 한다.
- 표 컨테이너는 줄번호 오른쪽의 본문 시작선에 맞추며 표 앞의 내부 여백을 두지 않는다. 넓은 표의 가로 스크롤에서도 줄번호를 거터에 유지한다([패키지 계약](../../development/packages.md)).

## 검증

- `server/editor-table-menu-ui.test.ts`에서 데스크톱·모바일 화면 폭의 우클릭 셀 기준 행·열 삽입, 헤더·마지막 행·열, 다른 표의 커서 위치, 키보드 실행·Esc 취소와 읽기 전용 메뉴를 검증한다.
- `server/editor-table-database-ui.test.ts`는 실제 Hotview의 양방향 메뉴·일반/Yjs 실행 취소·다시 실행, 실패 시 표 보존·읽기 전용 제어를 검사한다. 순수 전환·입력 정규화·요청 대기 중 변경 경계는 `packages/editor/src/database/tableConversion.test.ts`가 검사한다.
- `packages/editor/src/editor/markdownBehavior.test.ts`에서 헤더·본문의 부분·전체 텍스트 복사, 여러 문단·강제 줄바꿈, 셀 간 선택·셀 선택·표 전체 선택·일반 본문의 기존 복사 경계를 검증한다.
- `server/editor-line-numbers-ui.test.ts`에서 PC·모바일의 컨테이너·표·줄번호 정렬과 가로 스크롤을 검증한다.
- 아래 항목은 이번 정리에서 실행한 테스트 결과가 아닌 사용자 확인 기준이다:
  - 행·열 수정과 너비가 재열기 후 유지되고 복사 결과가 표 내용과 일치하는지 확인한다.

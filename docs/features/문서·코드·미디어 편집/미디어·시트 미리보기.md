## 요구사항

- 이미지·음성·영상·스프레드시트를 파일 형식에 맞게 본다.

### 범위

- 이미지·오디오·영상, SVG 이미지/텍스트 전환, XLSX·CSV·TSV 보기를 제공한다.
- `.html`·`.htm` 파일은 코드 편집기로 열며, 우상단의 **브라우저 새 탭에서 열기** 아이콘으로 서버에 저장된 HTML을 별도 브라우저 탭에서 연다. 대소문자 확장자와 프로젝트 파일·외부 파일 경로를 지원한다.
- 실행 파일(EXE·APK·AAB 등)·압축 파일·DB·기타 미지원 형식은 새 에디터 탭을 만들거나 본문을 읽지 않는다. 이미 열린 탭은 새로고침 후에도 순서·활성 선택과 함께 유지하며 미리보기 불가 안내를 표시한다. 파일 메뉴의 다운로드를 사용한다.

### 경계와 제한

- 시트 보기는 완전한 스프레드시트 편집기를 뜻하지 않는다.
- PDF 읽기·필기는 별도 하위 기능이다.
- HTML 새 탭은 기존 원문 파일 응답의 접근 권한과 sandbox·CSP를 적용한다. 스크립트는 실행하지 않으며, 편집기의 미저장 본문 대신 서버에 저장된 파일을 표시한다.
- 파일 크기 확인창 대신 형식별 열기 제한을 적용한다. 지원 문서·코드·미디어는 기존대로 열리며, 5MB 이상 파일에 별도 확인창은 표시하지 않는다.

## 구현 내용

- `src/utils/editor-open-policy.ts`에서 지원 텍스트 확장자·설정 파일명과 미디어 뷰어 형식을 판별한다. 새로 여는 미지원 형식은 선택 시 안내만 표시하고 현재 에디터를 유지한다. 기존 미지원 탭은 다시 선택할 수 있으며 본문 대신 안내를 표시한다. 프로젝트 간 링크·외부 파일에도 같은 기준을 적용한다.
- 계정 및 로컬에 저장된 탭을 복원할 때 미지원 탭도 순서·배치·활성 선택을 그대로 보존한다. 미지원 탭의 캐시 조회·본문 및 규칙 요청·편집·협업은 시작하지 않고 로딩 표시도 띄우지 않는다. 로딩 지연을 만드는 바이너리의 UTF-8 열기를 다시 도입하지 않는다.

- 이미지·오디오·영상, SVG 이미지/텍스트 전환, XLSX·CSV·TSV 보기를 제공한다.

## 검증

- `src/utils/editor-open-policy.test.ts`는 문서·코드·미디어 허용과 실행 파일·압축·알 수 없는 형식 차단, 프로젝트 및 외부 파일 경로를 검사한다.
- `server/editor-pane-ui.test.ts`는 기존 EXE·ZIP 탭과 활성 선택 복원 보존·기존 EXE 재선택, 새 EXE·BIN 선택 시 현재 편집기 보존, 미지원 본문 요청이 발생하지 않는지 검사한다.
- 같은 브라우저 검사는 HTML·대문자 HTM의 경로와 프로젝트를 보존하는 새 탭 열기, 데스크톱·모바일 버튼 표시, 새 탭의 opener 분리와 스크립트 차단 유지, 일반 텍스트에서 버튼 숨김을 확인한다.

- 아래 항목은 이번 정리에서 실행한 테스트 결과가 아닌 사용자 확인 기준이다:
  - 지원 형식별 뷰어·다운로드가 열리고 원본이 뜻하지 않게 변경되지 않는지 확인한다.

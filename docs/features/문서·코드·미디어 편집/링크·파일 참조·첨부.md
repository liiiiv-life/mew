## 요구사항

- 문서에 링크·프로젝트 파일·이미지와 첨부를 연결한다.

### 범위

- 링크 삽입·수정, 파일 멘션, 파일 업로드·드롭·이미지 붙여넣기와 크기 조절을 제공한다.
- 내부 파일 링크는 아이콘과 배경을 갖춘 인라인 항목으로 구분한다. 현재 문서의 하위문서는 테두리 없이 표시하고, 그 밖의 내부문서는 기존 테두리를 유지한다. 설정된 Docs 폴더 밖 파일은 기존 항목 오른쪽에 대각선 화살표를 표시한다. 외부 URL은 밑줄 하이퍼링크로 유지한다.
- Hotview 내부 파일 링크의 표시 텍스트는 직접 편집할 수 없으며, 클릭하면 툴팁 없이 대상 파일로 이동한다.
- 선택한 파일 경로·줄 범위를 Ctrl+L로 대상 입력창에 전달한다.

### 경계와 제한

- YouTube 노드 삽입과 실제 재생 허용은 다르며 배포 CSP 제한이 남아 있다.
- 첨부 열람은 첨부 자체의 파일 권한도 필요하다.

## 구현 내용

- 링크 삽입·수정, 파일 멘션, 파일 업로드·드롭·이미지 붙여넣기와 크기 조절을 제공한다.
- 내부 파일 링크는 세로 패딩 없이 낮은 높이로 표시하며, 글자·아이콘 크기와 본문 줄 높이를 유지하고 문장 흐름 안에서 줄바꿈한다. Hotview 표시만 바꾸며 기존 Markdown 형식을 유지한다.
- 내부 파일 링크는 편집 불가 영역으로 렌더링하고, 커서·부분 선택을 링크 경계로 맞춘다. 링크 전체 삭제와 주변 텍스트 편집은 유지한다. 원문 모드에서 링크 이름과 대상을 수정할 수 있다.
- 내부 파일 링크만 있는 문단에서도 링크 양옆과 같은 줄의 오른쪽 빈 공간을 클릭하면 링크 바깥에 보이는 커서를 두고 입력할 수 있다. 앞뒤의 작은 커서 자리는 Hotview 장식이며, Markdown에는 공백·숨은 문자·HTML을 추가하지 않는다.
- 내부 파일 링크 경계에서 왼쪽·오른쪽 방향키를 누르면 링크 전체를 한 번에 건너뛰며, 브라우저 커서도 편집 불가 링크 바깥에 배치한다. Shift+방향키는 링크 전체를 선택한다.
- 호스트가 현재 파일의 절대 경로와 설정된 Docs 루트를 주입한다. 상대 경로·URL 인코딩·쿼리·앵커를 해석한 대상이 Docs 밖이면 오른쪽 위 화살표를 표시한다. Docs 안의 Markdown 대상이 현재 문서의 하위 경로이면 테두리를 제거한다. `_폴더이름.md`·`MOC.md`·`_MOC.md`는 해당 폴더를, 단일 `name.md`는 `name/`을 하위 경로 기준으로 삼는다. 자기 자신·형제·상위 문서와 첨부는 기존 테두리를 유지한다. 이 표시는 링크 대상·문서 경로·Docs 설정 변경에 따라 갱신하며 Markdown에는 저장하지 않는다.
- 내부 링크 뒤에 2px 바깥 여백을 둔다. 줄바꿈된 링크는 전체 시작·끝에만 좌우 테두리와 둥근 모서리를 표시하고, 줄이 이어지는 중간 경계는 열어 둔다.
- 상세 표시는 [편집 사용법](../../guides/editor.md#링크와-첨부)을 따른다.

## 검증

- 아래 항목은 이번 정리에서 실행한 테스트 결과가 아닌 사용자 확인 기준이다:
  - 참조가 올바른 파일·줄로 열리고 이미지 조절·첨부 저장과 권한 차단이 유지되는지 확인한다.
- `packages/editor/src/editor/markdownBehavior.test.ts`와 `server/editor-line-numbers-ui.test.ts`로 하위문서·일반 내부문서·Docs 밖 파일 구분과 PC·모바일 양 테마의 테두리·화살표·Markdown 보존을 검증한다.
- `packages/editor/src/editor/markdownBehavior.test.ts`로 내부 링크 커서 진입 차단·전체 선택과 삭제·주변 입력, 외부 링크 텍스트 편집과 Markdown 왕복 저장을 검증한다.
- `server/editor-line-numbers-ui.test.ts`에서 PC·모바일의 단독 링크·본문 안 링크·인접한 링크를 양쪽 방향키로 건너뛴 뒤 커서가 링크 밖에 있고 주변 입력이 링크 이름을 바꾸지 않는지 확인한다.
- 같은 브라우저 테스트에서 PC·모바일의 단독 링크 양옆·오른쪽 빈 공간 클릭 후 보이는 커서와 영문·한글 입력, 링크 이름·Markdown 보존을 확인한다.
- `server/editor-line-numbers-ui.test.ts`는 PC·모바일 양 테마에서 내부 링크가 목록 줄 높이를 늘리지 않는지, 긴 이름의 줄바꿈과 중첩 목록 줄번호 정렬, 원문 보존을 확인한다.
- 내부 파일 링크의 인라인 배경·긴 이름 줄바꿈·밝은/어두운 테마를 확인하고, 외부 링크의 밑줄과 Markdown 왕복 저장·링크 수정 동작이 유지되는지 확인한다.

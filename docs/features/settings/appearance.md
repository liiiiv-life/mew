## 요구사항

- 기기에서 쓰기 편한 외형과 키 조합을 설정한다.

### 범위

- 밝은/어두운 테마·언어·단일 테마색·글꼴과 변경 가능한 단축키 설정·초기화를 제공한다.

### 경계와 제한

- 화면 설정은 브라우저별이다.
- 고정 편집 단축키는 바꿀 수 없고, 웹폰트로 로드되지 않고 기기에도 설치되지 않은 글꼴은 시스템 폴백을 사용한다.

### 상세 계약

- [계정·화면 설정](../../configuration/environment.md) · [포커스 기반 단축키](../../development/ui-contracts.md)

- 상위: [분야 지도](MOC.md) · [상위 기능](../settings.md).

## 구현 내용

- 언어·글꼴 선택은 공통 `SelectField`의 자체 드롭다운을 사용한다. 글꼴 이름 직접 입력·초기화와 브라우저별 저장을 유지한다.

- 한국어·영어·중국어 간체·일본어 설정을 에이전트·편집기·검색·Git·예약·원격 데스크톱·공용 패키지의 상태 문구와 접근성 이름에도 적용한다. 언어 전환 때 초안·검색어·본문을 유지하며 [UI 번역 계약](../../development/ui-contracts.md#ui-번역)의 누락 검사를 따른다.

- 밝은/어두운 테마·언어·단일 테마색·글꼴과 변경 가능한 단축키 설정·초기화를 제공한다.

- 테마색 입력은 공통 `ColorPicker`를 사용한다.
- 설정 안에서 색상 영역 드래그·색조/채도/밝기 슬라이더·HEX 입력·초기화를 제공하고, 키보드·터치·Esc·뒤로가기를 지원한다.

- 테마색 하나에서 액센트·강한 액센트·링크를 자동 계산하며 원본의 색상·채도를 유지한다.
- HSL 색상·채도를 유지한 채 명도만 조절한다. 다크에서는 단계적으로 밝게, 라이트에서는 단계적으로 어둡게 보정하고 버튼 글자 대비를 유지한다.
- 다크 테마의 기본 버튼이 지나치게 밝아지지 않도록 액센트/hover 목표 휘도를 0.27/0.35로 낮춘다. 에이전트·터미널 전송 아이콘은 버튼 전용 대비색을 사용한다.
- 기존 액센트 설정을 테마색으로 이어받는다.
- 저장·계산·검증은 [테마색 계약](../../development/ui-contracts.md#테마색과-파생-액센트)을 따른다.

- 기본 IBM Plex Sans KR·IBM Plex Mono의 일반체·굵은체를 앱에 포함해 외부 인터넷 연결 없이 제공한다.
- Noto Serif KR을 위한 Google Fonts의 스타일시트·폰트 파일 출처는 프로덕션 CSP에 계속 허용한다.
- 출처·라이선스와 폴백 범위는 [화면 설정](../../configuration/environment.md#화면-설정)을 따른다.

## 검증

- 아래 항목은 이번 정리에서 실행한 테스트 결과가 아닌 사용자 확인 기준이다:
  - 설정 재열기·초기화·포커스별 단축키가 맞고 다른 기기의 화면 설정을 덮어쓰지 않는지 확인한다.
  - 밝은 하이라이트에서도 지정한 테마색의 채도가 유지되고 양 테마의 링크·버튼 글자를 읽을 수 있는지 확인한다.

- 2026-09-23:
  - 프로덕션 CSP를 적용한 격리 Chromium에서 모든 외부 요청을 차단하고, 로컬 IBM Plex 두 글꼴의 400·700 네 파일이 실제 웹폰트로 렌더되는지 확인했다(한글·영문, 캐시 없는 새 브라우저).
  - 폰트 설정 테스트 5개와 문서 검사도 통과했다.
  - 실제 배포 빌드·서버 재시작과 Windows 화면 확인은 별도다.

- 2026-09-24:
  - 격리 Chromium에서 공통 컬러피커의 HEX 입력·초기화·마우스/터치 드래그·키보드 슬라이더·검정/회색 편집·Esc/뒤로가기/바깥 누름과 320/390/1100px 양 테마 배치를 검증했다.
  - 기존 테마 저장·복원·파생 대비 테스트를 포함해 5개 테스트, 타입 검사와 문서 검사가 통과했다.
  - 린트는 기존 경고만 있으며 실제 배포 빌드·서버 재시작은 수행하지 않았다.

- 2026-09-25:
  - 격리 Chromium에서 언어·글꼴의 자체 목록, 글꼴 직접 입력·IME·저장 복원·초기화, 키보드·터치·바깥 누름·Esc·뒤로가기와 320/390/1100px 양 테마 목록 경계를 검증했다.
  - 설정 화면과 기존 에이전트 기본 지침 UI 테스트 2개, 타입 검사, 변경 파일 린트와 문서 검사가 통과했다.
  - 실제 배포 빌드·서버 재시작은 수행하지 않았다.

- 2026-09-25 번역 누락 정리:
  - 클라이언트·공용 패키지 테스트 368개를 통과했다. 사전의 네 언어·자리표시자와 한국어 UI 리터럴 누락 방지 검사를 포함한다.
  - 격리 Chromium의 390/1100px에서 네 언어를 전환해 히스토리·대화 새로고침·찾기·코드 복사·공용 확인창과 초안·검색어·사용자 본문 보존을 확인했다.
  - 기존 에이전트 연결·Skills/MCP·Git·GitHub·편집기·예약·파일 생성·터미널·원격 데스크톱 UI 회귀 검사도 통과했다. 영어 화면에서 한국어 placeholder를 찾던 파일 생성 테스트는 번역된 이름으로 갱신했다.
  - 실제 배포 빌드·서버 재시작은 수행하지 않았다.

- 2026-09-29: 테마색 파생의 HSL 색상·채도 보존, RGB 격자·무채색 대비 4.5:1 이상, 밝기 순서와 초기 CSS 일치 단위 테스트 5개를 통과했다. 기존 설정 UI 테스트에서 320/390/1100px 양 테마의 색 변경·복원·초기화·hover를 확인했고 타입·대상 린트·문서 검사도 통과했다. 빌드·서버 재시작은 수행하지 않았다.

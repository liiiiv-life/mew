## 요구사항

화면 크기와 작업 흐름에 맞춰 문서·도구 패널을 배치한다.

### 범위

- 문서 탭·분할·도킹·크기 조절·계정별 복원과 모바일 하단 독·전체화면·뒤로가기를 제공한다.

### 경계와 제한

브라우저 패널은 좌우 배치만 지원한다. 패널 닫기와 작업 세션 종료를 구분하며 기기별 설정과 계정별 화면 상태의 소유권을 유지한다.

## 구현 내용

문서 탭·분할·도킹·크기 조절·계정별 복원과 모바일 하단 독·전체화면·뒤로가기를 제공한다.

모바일 하단에 화면 너비를 채우는 직사각형 독을 제공한다. 높이는 48px + 하단 안전 여백이고, 기능 버튼은 메뉴와 같은 작업 패널을 연다. 기능 패널도 독 버튼·스와이프로 오가며 선택 항목과 초안을 유지한다. 둥근 외곽선·아이콘 배경 없이 위쪽 구분선과 선택된 아이콘의 밝기·굵기로 구분한다. 기본 순서는 사이드바·에디터·에이전트 패널·터미널·Git·내부 브라우저·기능·원격 데스크톱·RAG이며 권한에 맞춰 표시한다. 길게 눌러 순서를 변경하고 브라우저에 기억한다. 독 스와이프는 탭 선택을 유지하고 인접 패널로 바로 이동한다. 원격 데스크톱 뷰어에서도 독을 표시하며 전체화면을 켜면 숨긴다. 독으로 다른 패널을 선택하면 원격 연결을 종료하고 이동하며, 뷰어를 닫으면 이전 작업 화면으로 돌아온다. 탭 우선 스와이프는 사용자 요청으로 제거했으며 요청 전 재도입하지 않는다. 마우스 호버에는 아이콘 이름 툴팁을 표시하고, 터치 탭에는 독 바로 위 중앙에서 이름 토스트가 0.5초 뒤 사라진다. 모바일 키보드가 열리면 숨긴다. 모바일 플로팅 핸들과 왼쪽 사이드바 버튼은 대체했으며 사용자 요청 전 재도입하지 않는다. 상세 제스처·배치·저장 계약은 연결된 개발 문서를 따른다.

## 검증

독의 선택·스와이프·재정렬·취소·저장 복원·키보드 숨김·모바일 양 테마는 연결된 개발 계약의 격리 Chromium 테스트로 검사한다.

아래 항목은 이번 정리에서 실행한 테스트 결과가 아닌 사용자 확인 기준이다: 데스크톱 분할·모바일 전환·닫기·재열기 뒤 탭과 실행 중 작업이 올바르게 유지되는지 확인한다.

# Mew 기능 문서 관리

[기능 홈](MOC.md)에서 분야를 고른다. Mew 프로젝트 독의 **기능** 패널은 같은 문서를 간단한 계층 목록으로 보여 준다. Mew의 Documents 연결은 `docs`다.

## 파일과 계층

- 기능 항목 하나는 Markdown 파일 하나다. 제목은 실제 파일명에서 `.md`를 뺀 이름이다. 상위 대표 파일의 접두 `_`는 표시하지 않는다. 프론트매터의 `title`과 `parent`는 제목·계층의 기준본이 아니다.
- 자식 없는 항목은 `이름.md`다. 첫 하위 항목을 만들거나 이동해 넣으면 `이름/_이름.md`로 옮기고, 하위 항목은 같은 폴더에 둔다. 마지막 자식이 삭제되거나 이동하면 대표를 다시 `이름.md`로 옮기고 빈 폴더를 제거한다. 첨부·숨김 파일이 남으면 Documents와 같이 폴더를 유지한다.
- Documents의 생성·개명·이동·삭제를 사용하면 본문과 링크도 함께 보정한다. 상위 이름 변경은 폴더와 대표 이름을 함께 바꾼다. 일반 파일 도구로 직접 옮기면 링크도 직접 확인한다.
- 기존 `MOC.md`·`_MOC.md`는 해당 폴더의 대표로 호환한다. `_폴더이름.md`가 있으면 MOC는 별도 기능 행으로 중복 표시하지 않는다. 루트 MOC·README와 숨김 파일은 기능 항목에서 제외한다.
- 기존 ID는 API·CLI와 실행 이력 연결을 위해 유지한다. 일반 Markdown은 프론트매터나 전용 구분자가 없어도 읽으며, 본문 제목·불렛 형식을 강제하지 않는다.

## 탐색과 내용 소유권

- 패널에는 제목·상태 표시·문서 열기와 하위 항목만 둔다. 제목은 수정 권한이 있으면 직접 입력해 수정하며 Enter·포커스 이동으로 저장하고 Esc로 취소한다. 오른쪽 문서 아이콘만 원본 파일을 열고, 화살표는 자식 목록만 접고 펼친다. 요구사항·구현 내용·검증·관련 파일·커밋·작업 이력 섹션은 패널에서 표시하지 않는다.
- 기능 패널의 계층은 세로선으로 연결하고 펼친 상위 항목은 목록 상단에 틈 없이 쌓는다. 각 하위 목록 끝을 지나면 해당 고정 행은 사라지고, 하위 항목이 없는 행은 꺾쇠 자리에 불렛을 표시한다.
- 기존 타이틀바·정렬·새로고침·계정별 펼침 및 스크롤 복원과 읽기 전용 경계는 유지한다. 제목 수정을 제외하고 사용자 요청으로 제거한 상세 표시·변경 조작은 명시적 후속 요청 없이 재도입하지 않는다.
- 기능 문서는 제품 범위·구현 진입점·확인 기준을 소유한다. 기능을 맡길 때 연결한 상세 계약도 읽는다. `guides/`, `configuration/`, `development/`, `specs/`의 본문을 기능 파일에 복제하지 않는다.
- 코드·기능이 바뀌면 소유 기능 파일과 상세 계약을 같은 작업에서 고친다. 문서를 이동하면 해당 MOC와 들어오는 링크도 갱신한다. 상태 판정과 확인 해시는 형식 정리만으로 다시 승인하지 않는다.

## 상태와 실행

2026-09-18 최초 목록화에서는 8개 분야와 44개 하위 기능을 등록했다. `created`는 등록일이며 실제 최초 구현일이 아니다. 이후 추가·제거한 기능은 현재 파일 목록을 따른다.

- `implemented`는 제공 범위를 문서·코드에서 확인한 상태이며 모든 환경의 검증 완료를 뜻하지 않는다. `verified`·`needs-fix`는 사용자 판정이다.
- `status_hash`는 현재 제목·본문 요구사항·부모 관계에 상태를 연결한다. 외부 내용·경로 변경으로 달라지면 패널에서 `changed`로 읽으며 원본 판정을 자동 갱신하지 않는다.
- `files`는 대표 구현 진입점이며 변경 파일 전체 목록이 아니다. 실제 수행하지 않은 실행·커밋·검증을 추정해 쓰지 않는다.
- 문서 편집만으로 에이전트 실행이나 Git 커밋은 발생하지 않는다. 기존 API·CLI·실행 큐·보고 형식·이전과 복구는 [기능 기반 개발](../specs/feature-development.md)이 소유한다.

## 목록에 넣지 않은 것

옛 홈의 할 일·달력, 미구현 AI 커밋 메시지 생성, 실현되지 않은 계획을 현재 기능으로 만들지 않았다. Android는 환경 준비와 기존 gateway 연결 범위다. 최초 등록했던 RAG는 2026-09-28 제거해 [과거 기능 기록](../history/rag-feature.md)으로 옮겼다. 설치·HTTPS·백업·라이선스·연구·과거 계획은 기존 소유 문서에 유지한다.

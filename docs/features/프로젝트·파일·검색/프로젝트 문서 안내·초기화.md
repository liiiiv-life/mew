## 요구사항

- 에이전트가 현재 프로젝트의 문서와 지침부터 찾아 읽도록 안내한다.

### 범위

- 에이전트 패널 Skills·MCP 옆 기본 지침에서 커밋 방식·응답 언어·답변 길이·서브에이전트 위임·디버거 활용을 설정하고 파일 보기로 MD를 직접 편집한다.
- 저장은 로그인한 Mew 계정의 모든 프로젝트에서 다음 ACP 요청에 반영하며 다른 계정에는 영향을 주지 않는다.
- Documents 설정에서 자동 안내·진입 문서·추가 지침을 편집하고 미리 본다.
- 없는 문서를 생성하는 프로젝트 초기화 GUI와 CLI를 제공한다.

### 경계와 제한

- 공통 자동 안내는 사용자 요청이나 프로젝트 지침을 대체하지 않는다.
- 서브에이전트 위임 설정은 런타임 기능 활성화나 강제 차단이 아니며 상위 지침·지원 범위 안에서 적용한다.
- 문서 진입점·description 탐색 안내를 전달하며 새 문서의 MOC 등록 의무를 두지 않는다. 제거된 RAG 검색 명령은 전달하지 않는다.
- 초기화는 기존 문서·사용자 설정을 보존하는 계약을 따른다.

## 구현 내용

- 에이전트 패널의 기본 지침 설정은 MD 원문에서 선택값을 읽고 변경한 항목만 저장한다.
- 파일 보기로 기존 에디터에서 직접 수정한다.
- 기존 TXT와 자유 지침을 보존하며 동시 수정 충돌을 알린다.
- 세션 시작 계정의 원문을 모든 프로젝트의 다음 ACP 요청에서 다시 읽는다. 기존 공용 원문·모델 기본값·런타임 설정은 최초 owner 계정에만 한 번 이전하며 다른 계정에는 복제하지 않는다.
- 서브에이전트 위임은 별도 지정 안 함·필요할 때 자동 위임·요청할 때만 위임·사용 안 함을 제공한다. 기존 지침은 선택을 강제하지 않으며 지원 런타임에 전달할 문장만 저장한다.
- 자동 위임은 독립적인 작업에 한정하고 공유 파일 수정 조율·결과 검토 및 통합을 지시한다.
- 디버거 활용은 활성화·비활성화를 제공하며 기본값은 활성화다. 설정 구간 없는 기존 지침에는 읽을 때만 영어 안내를 보충하고 저장 원문을 보존한다. 직접 편집한 구간과 명시적인 비활성화는 덮어쓰지 않는다.
- 활성화는 로그·테스트로 설명이 부족할 때 디버거 활용과 변수·호출 스택 확인, 기존 실행·권한 제한 준수 및 임시 연결·프로세스 정리를 지시한다. 비활성화는 사용자 명시 요청 시에만 사용하도록 안내하며, 어느 값도 디버거를 자동 설치·실행하지 않는다.

- Documents 설정에서 자동 안내·진입 문서·추가 지침을 편집하고 미리 본다.

- 로컬 RAG CLI·설정 조회와 자동 검색 안내를 제거했다.

## 검증

- 2026-10-07: 계정별 지침·모델 기본값·런타임 환경변수 분리, 최초 owner로만 기존 공용 설정 이전, 초기화 후 재이전 방지, 프로젝트 전환·동시 실행·실행 중 ACP의 시작 계정 유지와 다음 요청 반영을 검사했다. 에이전트·예약·Git AI 실행의 대상 회귀 테스트와 대상 린트·description·문서 경계 검사를 통과했다. 전체 타입 검사는 다른 작업의 공용 UI 저장소 DOM 타입과 원격 접속 테스트 오류로 실패했다. 빌드·운영 서버 재시작·커밋은 수행하지 않았다.

- 2026-10-07: 디버거 기본 활성화·기존 MD/TXT 보존·명시적 비활성화·직접 편집·손상 구간·두 프로젝트 다음 요청 반영을 검증했다. 격리 Chromium에서 데스크톱/모바일의 활성화·비활성화 저장과 재열기, 양 테마의 메뉴 경계, 기존 충돌·에디터 동기화 회귀를 확인했다. 타입·대상 린트·description·문서 경계 검사와 UI 기계 검사를 통과했다. 앱 빌드·서버 재시작은 수행하지 않았다.

- 아래 항목은 이번 정리에서 실행한 테스트 결과가 아닌 사용자 확인 기준이다:
  - 현재 프로젝트와 Documents 경로가 안내에 반영되고 기존 문서가 덮어써지지 않는지 확인한다.

- 2026-09-28: ACP 실제 전송 컨텍스트에서 RAG 안내가 빠지고 프로젝트별 안내·큐·재접속이 유지되는지 검사했다.

- 2026-09-29: 서브에이전트 네 가지 선택값의 저장·다른 지침 보존·직접 편집·초기화와 두 프로젝트의 컨텍스트 반영을 검사했다. 격리 ACP 세션에서 재시작 없이 다음 요청으로 위임 지침이 전달되고 화면 전사에서는 숨겨지는 것을 확인했다. 데스크톱·모바일 선택/재열기·양 테마 메뉴 경계, 에디터 동기화·충돌 회귀와 타입·대상 린트·문서 검사를 통과했다.

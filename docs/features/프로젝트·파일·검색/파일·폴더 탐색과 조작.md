## 요구사항

- 파일을 탐색하고 생성·이동·업로드·다운로드한다.

### 범위

- 펼친 폴더·상위 문서 행은 스크롤 목록 상단에 단계별로 쌓이며 각 하위 목록 끝에서 밀려난다. 고정 행 사이에 틈을 두지 않고 조상 계층 세로선도 계속 표시한다.

- 펼친 폴더와 상위 문서의 하위 목록에 세로 가이드선을 표시한다. 중첩된 조상마다 한 줄씩 이어져 세 단계 아래 항목에는 세 줄이 보이며 접으면 해당 선도 사라진다.

- 프로젝트 추가·서버 파일 탐색기의 맨 위에 OS/클라우드 기본 폴더와 계정별 즐겨찾기를 제공한다.
- 상단 전체 너비 문서/Documents·파일/Files 토글로 탐색 목록을 분리한다. 선택한 보기와 각 트리의 펼침·스크롤을 프로젝트별로 보존한다.
- 사이드바에서 현재 활성 파일은 기존 선택 배경으로, 다른 탭·분할 창에 열린 비활성 파일은 그보다 옅은 배경으로 구분한다. 탭을 닫으면 열린 파일 배경을 제거하며 테마 색 테두리를 표시하지 않는다.
- 상위 문서·폴더를 펼치거나 접은 뒤 내부 포커스 상태만으로 배경 강조를 남기지 않는다. 현재 열린 문서의 선택 배경과 hover·키보드 포커스 표시는 유지한다.
- 사이드바에서 생성·개명·복제·복사·잘라내기·붙여넣기·삭제와 드래그 이동을 제공한다.
- 파일·문서 이동이 반영될 때 이동 항목과 주변 행을 탭·Dock과 같은 180ms 모션으로 연결하고 모션 감소 설정에서는 즉시 배치한다.
- 에디터 파일 탭을 한 번 클릭하면 사이드바에서 해당 파일의 위치를 표시한다.
- 모바일에서 다른 파일 탭 선택은 에디터를 유지하고, 현재 활성 파일 탭을 다시 선택할 때만 사이드바로 전환한다.
- 권한이 있는 계정은 서버 전체 파일 탐색기에서 프로젝트 밖 경로를 다룰 수 있다.
- 숨김 목록과 파일 권한을 트리·검색에 적용한다.

### 경계와 제한

- 확장자를 생략해도 .md를 자동 추가하지 않는다.
- 서버 전체 탐색기는 OS 권한의 서버 제어 기능이며 일반 파일 권한의 샌드박스가 아니다.

## 구현 내용

- 하위 목록은 폴더 경로별 진행 중 Promise를 공유한다. 첫 펼치기와 복원 효과, Documents 이름·화살표가 같은 요청을 중복 실행하지 않는다. 복원한 열린 폴더는 기존 행을 먼저 보여주고 한 번 재검증하며, 접힌 조상 아래는 조회하지 않는다.
- 루트 배열 갱신만으로 하위 캐시를 지우지 않는다. App의 명시적 전체 새로고침·생성/조작 완료는 별도 `refreshSignal`로 현재 열린 목록을 재검증하므로 watcher 수신에만 의존하지 않는다. 변경된 부모의 열린 목록은 기존 행을 유지한 채 재조회하고, 닫힌 목록은 다음 펼침에 재검증한다. 요청 도중 무효화되면 오래된 응답을 적용하지 않고 최신 목록을 다시 조회한다. 사라진 폴더의 하위 캐시·진행 중 결과는 제거한다.
- `virtual-tree-rows.tsx`는 연속된 파일·닫힌 폴더 200개 이상을 화면 주변 행과 앞뒤 12행으로 가상화한다. 펼친 폴더·상위 문서의 래퍼는 유지해 고정 행·조상선·드롭 대상을 보존한다. 실제 행 높이를 측정하고 포커스·메뉴·드래그 항목은 유지하며, 이름 변경·하위 생성 입력이 있는 묶음은 전체 표시한다. Tab/Shift+Tab은 화면 밖 이웃 행도 순서대로 이동한다.
- 파일 탭 위치 표시와 중앙 앵커 복원은 화면 밖 행을 먼저 생성한 뒤 스크롤한다. 저장 경로와 전체 하위 목록 캐시는 기존 형식이며 가상 행 범위는 저장하지 않는다.
- 서버 탐색기의 `/api/fs/entries?size=0`은 표시하지 않는 일반 파일 크기의 개별 stat을 생략한다. 기본 API 요청은 크기를 계속 반환하고, 심볼릭 링크 종류 확인은 유지한다. 원격 응답의 수신 창은 [P2P 계약](../../development/remote-access.md#프로토콜과-자원-수명)을 따른다.

- 에디터·사이드바의 Ctrl/Cmd+N·T와 기존 Alt+N은 새 파일 이름 입력, Ctrl/Cmd+Shift+N은 기존 새 폴더 흐름을 연다. 문서 트리는 기존 문서 생성 규칙을 사용한다. 사이드바에서는 선택한 디렉터리, 에디터에서는 활성 문서의 폴더를 사용한다. App은 파일 읽기·쓰기 권한을 확인하고 `useSidebarCreate`의 프로젝트별 일회성 요청을 공유한다. 처리된 요청은 소비하며 트리 재마운트·프로젝트 전환에서 오래된 입력을 다시 열지 않는다. 에이전트·터미널·브라우저의 새 탭은 각 표면이 먼저 소유한다.

- 공통 파일 우클릭 메뉴의 각 항목은 16px Iconoir 아이콘과 텍스트를 나란히 표시한다. 모서리를 직각으로 하고 그림자를 제거하며 항목 여백은 좌우 8px·상하 4px, 아이콘 간격은 6px로 줄인다. 다운로드도 같은 아이콘 열에 맞추고, 아이콘은 접근성 이름에 포함하지 않는다. 사이드바·프로젝트 추가·서버 파일 탐색기에 동일하게 적용한다.

- 2026-10-06 사용자 재요청에 따라 상위 항목 스크롤 고정을 다시 제공한다. `TreeHeader`는 상단 여백을 보정해 틈 없이 쌓이고, 노드별 `isolate`로 조상 가이드선이 하위 고정 행 위에 이어지게 한다. 접기·하위 목록 끝에서 고정 해제와 파일 위치 표시를 유지한다. [상위 행 고정 계약](../../development/ui-contracts.md#사이드바-트리의-상위-행-고정)을 따른다.

- `FileTree.tsx`의 공통 `TreeChildren`은 각 하위 목록에 1px 테마 구분선을 겹쳐 표시한다. 선은 폴더 아이콘·문서 펼침 버튼 중심에서 2px 왼쪽에 놓는다. 기존 14px 들여쓰기를 유지하고 생성 입력·로딩 행에도 선을 이어 표시하며 클릭·드래그와 접근성 탐색에는 관여하지 않는다.

- 파일 보기 맨 위의 문서 폴더는 실제 프로젝트 상대경로로 일반 폴더처럼 펼치고 접으며, 같은 폴더 아이콘·파일 조작·지연 로딩·상태 보존을 사용한다. 이름 옆 대각선 화살표만 문서 보기로 전환한다. 내부의 대표 문서·MOC도 파일명과 확장자를 그대로 표시하고 Documents 페이지 구조로 변환하지 않는다. 설정 경로가 `.mew/docs`처럼 중첩되어도 맨 위의 행에서 실제 하위 파일을 탐색한다. 서버는 루트 목록에서만 기존 위치의 중복을 제외하며 하위 경로에는 일반 파일 가시성·권한·차단 규칙을 적용한다.

- 선택한 범위의 트리만 마운트하고 기존 상단 Documents 펼침 행은 제거한다. 토글은 스크롤과 무관하게 위쪽 독립 행에 있으며 키보드 방향키·Home/End를 지원한다. 새 파일·폴더와 Alt+N은 현재 보기를 대상으로 한다. `sidebar.explorerScope`를 계정·로컬 상태에 저장하고 기존 `docsExpanded`에서 이관한다.

- `App.tsx`는 파일 탭 선택 시 사이드바의 파일 보기를 열고 선택한 파일의 문서/파일 보기로 전환한다. `FileTree.tsx`는 부모 폴더를 열고 지연 로딩된 파일 행이 표시된 뒤 스크롤한다. 같은 탭 재선택에도 동작하며 프로젝트 밖 파일은 제외한다.
- 모바일의 비활성 탭 선택은 전면 패널을 유지하며 위치 표시 요청만 갱신한다. 닫혔거나 숨겨진 사이드바는 이후 표시될 때 선택한 파일로 스크롤한다.
- 초기 화면 복원은 저장된 펼침·스크롤을 유지하고, 사용자가 탭을 선택한 경우에만 닫힌 트리의 복원보다 위치 표시를 우선한다.

- 두 탐색기의 항목 우클릭은 사이드바와 같은 메뉴 컴포넌트로 복사·잘라내기·붙여넣기·이름 변경·삭제를 제공하고 폴더에 즐겨찾기 추가를 표시한다.
- 모바일 길게 누르기도 지원한다. 탭·Dock과 같은 350ms부터 끌기를 준비하고 움직이면 즉시 이동하며, 움직이지 않고 500ms 이상 누른 뒤 놓으면 메뉴를 연다.
- 사이드바에서는 500ms부터 누른 항목을 배경으로 강조하며 메뉴가 열린 동안 유지하고, 메뉴 닫기·터치 취소 시 임시 강조를 해제한다.
- 모바일 메뉴는 하단 독 위로 위치를 보정하며, 높이가 부족하면 메뉴 안에서 스크롤해 마지막 항목까지 선택할 수 있다.

- 두 탐색기 맨 위의 즐겨찾기는 접힌 자체 드롭다운이며, 펼쳐서 폴더 이동·제거를 실행한다.
- 키보드·터치·Esc·뒤로가기를 지원한다.
- 목록은 서버 OS 기본 폴더·감지된 클라우드 폴더와 직접 추가한 경로를 제공한다.
- 추가·제거는 계정별로 저장한다.

- 프로젝트 추가와 서버 파일 탐색기는 프로젝트 추가 창의 디자인을 기준으로 공통 탐색 컴포넌트를 사용한다.
- 주소창·필터·목록 행·하단 경로를 공유하고 각 화면의 기존 작업을 유지한다.

- 사이드바에서 생성·개명·복제·복사·잘라내기·붙여넣기·삭제와 드래그 이동을 제공한다.

- 사이드바 파일 목록 위에 2px 여백을, 끝에 300px의 스크롤 여백을 제공한다.
- PC·모바일의 문서/파일 트리 각각에 동일하게 적용한다.

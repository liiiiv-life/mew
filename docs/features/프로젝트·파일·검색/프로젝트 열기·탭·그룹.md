## 요구사항

- `Ctrl/Cmd+O`는 서버 파일 권한이 있는 계정의 서버 파일 탐색기를 연다. 파일을 열어도 현재 프로젝트를 유지하며 모바일에서는 에디터를 앞으로 가져온다. `Ctrl/Cmd+Shift+O`는 owner의 프로젝트 열기 창을 연다. Alt 병용·IME 조합은 처리하지 않는다.

- 서버 폴더를 프로젝트로 열고 헤더의 현재 프로젝트 선택기로 작업 공간을 오간다.

### 범위

- 프로젝트의 `.mew/project-icon.json` 하나를 사이드바·프로젝트 선택기의 공통 아이콘으로 사용한다.
- 선택기 목록의 프로젝트 아이콘은 16×16px 영역 안에서 가로·세로 중앙 정렬한다. 라인 아이콘·사용자 SVG·이모지 모두 같은 영역을 사용해 제목과의 세로 정렬을 유지한다.

- 프로젝트 추가·서버 파일 탐색기의 맨 위에 OS/클라우드 기본 폴더와 계정별 즐겨찾기를 제공한다.
- 폴더 탐색·클라우드 바로가기·새 폴더·Git clone·Git 초기화를 프로젝트 선택 창에서 제공한다.
- 헤더 왼쪽에는 현재 프로젝트의 아이콘·이름만 표시한다. 누르면 저장된 프로젝트 목록이 열리고 마지막 항목은 **프로젝트 추가**다. 탭 나열·닫기·재배열·그룹 UI는 제공하지 않는다.
- 프로젝트 선택·아이콘 변경과 계정별 화면 복원을 제공한다. `Alt+1…9`는 드롭다운의 목록 순서대로 프로젝트를 선택한다.

### 경계와 제한

- 프로젝트 전환은 owner 전용이며 자기 계정의 활성 프로젝트만 바꾼다. 같은 계정의 다른 접속에는 전환을 알리고, 다른 계정과 guest의 화면·파일 요청 경로는 유지한다.
- 기존 프로젝트 경로 목록과 순서는 유지하며 저장된 그룹 정보는 선택기에서 표시하지 않는다.
- 실행 중 에이전트의 기존 작업 경로는 유지한다.

## 구현 내용

- 직계·중첩 하위 프로젝트는 일반 파일 트리의 실제 위치·정렬로 표시하며, 폴더 클릭은 펼침·접기만 수행한다. 옆 화살표는 기존 프로젝트 열기 API로 해당 프로젝트를 선택하고, 목록에 없는 경로만 추가한다. owner 권한·중복 경로 재사용·계정별 복원과 실행 중 에이전트의 작업 경로는 유지한다. 폴더 탐색은 [하위 프로젝트 탐색 결정](../../decisions/0004-subproject-folder-exploration.md), 헤더는 [프로젝트 선택기 결정](../../decisions/0019-project-selector.md)을 따른다.

- 프로젝트 선택기의 전역 capture 리스너는 Alt+1…9를 저장된 목록 순서의 프로젝트에 연결한다. 일반 패널 입력에서도 기존 클릭과 같은 전환 경로를 사용한다. 숫자패드와 macOS Option 물리 키를 지원하고, 현재 프로젝트·없는 번호·모달·반복·owner 권한 없음은 전환하지 않는다. Ctrl/Cmd+숫자는 내부 패널 탭에 남기며 로그인 영상·원격 화면 포커스에서는 Alt+숫자도 원격에 전달한다.

- 활성 프로젝트는 계정 UI 원장의 `activeWorkspace`에 저장한다. HTTP·프로젝트 WebSocket 요청은 계정의 루트를 비동기 컨텍스트에 고정하며, 전환은 서버 시작 루트·환경 설정과 다른 계정의 watcher·공동 편집 방을 바꾸지 않는다. 파일 목록·검색·감시자·협업 방은 루트 경로로 분리한다. 저장값이 없거나 폴더가 사라졌으면 서버 기본 루트를 사용한다. [계정별 경로 계약](../../development/architecture.md#계정별-활성-프로젝트)을 따른다.

- `server/projectIcons.ts`가 프로젝트별 아이콘 읽기·저장·기존 값 이관을 맡는다. 직계·중첩 트리와 프로젝트 선택기는 같은 값을 표시하고, 선택기에서 변경하면 프로젝트 파일을 갱신한다.

- 두 탐색기의 항목 우클릭은 사이드바와 같은 메뉴 컴포넌트로 복사·잘라내기·붙여넣기·이름 변경·삭제를 제공하고 폴더에 즐겨찾기 추가를 표시한다.
- 모바일 길게 누르기도 지원한다.

- 두 탐색기 맨 위의 즐겨찾기는 접힌 자체 드롭다운이며, 펼쳐서 폴더 이동·제거를 실행한다.
- 키보드·터치·Esc·뒤로가기를 지원한다.
- 목록은 서버 OS 기본 폴더·감지된 클라우드 폴더와 직접 추가한 경로를 제공한다.
- 추가·제거는 계정별로 저장한다.

- 프로젝트 추가와 서버 파일 탐색기는 프로젝트 추가 창의 디자인을 기준으로 공통 탐색 컴포넌트를 사용한다.
- 주소창·필터·목록 행·하단 경로를 공유하고 각 화면의 기존 작업을 유지한다.

- 프로젝트 추가 창은 처음 열 때 제목에 포커스를 둔다.
- 없는 경로를 입력하면 기존 부모·첫 누락 이름·전체 생성 경로를 네 언어로 확인받고, 확인 시 중간 폴더까지 만든 뒤 해당 위치로 이동한다.
- [경로 생성 계약](../../development/ui-contracts.md#없는-프로젝트-경로-확인생성)을 따른다.

- 폴더 탐색·클라우드 바로가기·새 폴더·Git clone·Git 초기화를 프로젝트 선택 창에서 제공한다.

- 프로젝트 선택기는 공용 메뉴의 테마·키보드 이동·화면 경계·Esc/뒤로가기 닫기·포커스 복원 규칙을 따른다. 목록 항목의 hover·focus는 화면 상태만 미리 준비하고 실제 선택 시 같은 요청을 재사용한다. 파일·트리·에이전트 점유는 미리 조회하지 않으며 [빠른 전환 계약](../../development/ui-contracts.md#루트-프로젝트-빠른-전환)을 따른다.
- 프로젝트 전환 중에는 중앙 로딩 인디케이터를 표시하고, 완료·실패 후 닫는다.
- 검정 덮개 없이 클릭·터치·키보드 조작을 유지한다.

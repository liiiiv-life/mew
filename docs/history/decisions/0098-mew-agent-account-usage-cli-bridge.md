## 배경

에이전트 창의 세션 정보는 현재 탭에서 쓴 토큰과 API 환산 비용만 보여 준다. Codex와 Claude Code를
구독 로그인으로 쓸 때는 실제 계정의 남은 한도·리셋 시각·크레딧을 해당 CLI의 상태 화면에서 따로 확인해야 했다.

Mew가 공급자 토큰이나 비공개 CLI 세션 파일을 읽으면 0072의 자격증명 소유 경계를 깨고, OpenAI 조직 Usage
API를 함께 붙이면 관리자 API 키를 새로 보관해야 한다.

## 선택지

1. 세션 토큰 정보만 둔다.
2. 로컬 인증 저장소·세션 파일을 파싱한다.
3. 로그인된 CLI의 고정 상태 명령을 짧은 터미널에서 실행하고 화면 텍스트만 중계한다.
4. Mew가 공급자 API 키를 저장해 조직 사용량 API를 직접 호출한다.

## 결정

3번을 채택한다.

- Info 팝업에서 Codex는 `/status`, Claude Code는 `/usage`를 사용자가 눌러 조회한다.
- 서버는 런타임 등록표에 선언한 실행 파일·환경·슬래시 명령만 실행한다. 브라우저 요청은 runtime id 하나뿐이며
  명령, 인자, 계정 정보, API 키를 보낼 수 없다.
- 서버는 임시 tmux 세션을 열어 출력의 제어문자와 길이를 제한한 뒤 회수하고 즉시 종료한다. 결과는 브라우저에만
  표시하며 Mew 데이터·이벤트·로그에는 저장하지 않는다.
- CLI 시작 화면에 업데이트 안내가 떠도 조회가 막히지 않게, 상태 명령 전에 이 **임시 조회 세션에서만** `Esc`를
  보낸다. 일반 에이전트 세션의 업데이트 확인·설치 정책은 건드리지 않는다.
- CLI가 비대화형 상태 명령을 제공하지 않거나 로그인되지 않았으면 오류를 보여 주며, 인증 파일을 파싱해 우회하지 않는다.
- 조직 API 사용량·비용은 관리자 키와 보존 정책이 필요한 별도 기능으로 남긴다. 이 기능은 연결된 CLI 계정이
  자체 화면에 표시하는 구독 한도와 크레딧만 중계한다.

## 결과

계정 사용량은 현재 세션 비용과 혼동되지 않고, Mew가 장기 자격증명이나 공급자 청구 데이터의 새 소유자가 되지 않는다.

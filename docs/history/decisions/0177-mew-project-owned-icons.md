## 배경

사이드바와 독립 프로젝트 탭이 서로 다른 아이콘 원장을 읽어 같은 프로젝트를 다르게 표시했다. 사용자는 하위 프로젝트의 `.mew` 안에 아이콘 정보를 두고 양쪽에서 공유하도록 요청했다.

## 결정

- 프로젝트 루트의 `.mew/project-icon.json`이 SVG·이모지·라인 아이콘 선택값의 단일 기준본이다. 사이드바와 프로젝트 탭은 같은 파일을 읽는다. 중첩 프로젝트도 자기 파일을 가진다.
- 아이콘 변경은 프로젝트 파일에 저장한다. 열린 탭 목록·순서·그룹의 계정별 저장은 유지하되 아이콘 복사본을 새로 저장하지 않는다.
- 기존 사이드바 원장 값을 프로젝트 파일로 이관한다. 파일이 없을 때만 기존 계정 탭 아이콘을 보충 원본으로 사용하고, 프로젝트 파일이 있으면 항상 우선한다. 명시적 초기화는 null로 기록해 옛 아이콘이 부활하지 않게 한다.
- 기존 SVG 검증과 owner의 절대경로 접근 권한을 유지한다. 이름 변경은 폴더 안 아이콘 파일을 함께 이동한다.
- 별도 사이드바·탭 아이콘 원장은 다시 도입하지 않는다. 변경하려면 후속 결정을 작성한다.

## 근거

프로젝트 자체에 기준본을 두면 탭을 여는 방법·계정·상위 프로젝트에 관계없이 같은 아이콘을 표시하며 폴더 이동에도 아이콘이 따라간다.

## 배경

새 프로젝트에서도 별도의 AGENTS.md 준비 없이 Documents를 탐색하고 작업 결과를 문서에 반영해야 한다. 프로젝트 전환 중 실행하는 에이전트에 다른 프로젝트의 문서가 전달되어서는 안 된다.

## 선택지

1. 프로젝트마다 에이전트 지침 파일 생성 — 외부 도구에도 유효하지만 초기 설정과 중복 관리가 필요하다.
2. mew가 공통 지침과 문서 진입 경로를 요청마다 전달 — 앱 안에서 자동으로 작동하며 외부 도구는 선택적으로 연결한다.

## 결정

- 모든 ACP 요청의 공통 실행 지점에서 짧은 mew 안내를 별도 텍스트 블록으로 전달한다. 대화 표시와 사용자 원문에는 넣지 않는다. 시스템 역할을 가장하지 않으며 문서 읽기의 강제 실행을 보장하지 않는다.
- 프로젝트 루트·Documents 연결은 세션별로 고정하고 세션 ID와 함께 저장한다. 화면 전환, 복원, 큐와 예약 실행에서도 같은 연결을 쓴다. 새 대화는 현재 프로젝트 설정을 다시 해석한다.
- `.mew/agent-context.json`은 프로젝트별 Documents 경로, 자동 전달 여부, 추가 문서 진입점과 지침의 기준본이다. Documents 선택은 이 값을 우선하며 기존 환경 설정과 기본 경로는 호환용으로 유지한다.
- Liiiiv의 회사·브랜드·ADR 배치를 다른 프로젝트에 강제하지 않는다. 기존 에이전트 지침과 문서 구조를 보존하고 탐색·write-back 원칙만 기본 제공한다. 문서 본문을 일괄 주입하지 않는다.
- GUI와 CLI는 같은 계획·적용 모듈을 사용한다. 초기화는 없는 파일만 생성하고 기존 문서는 덮어쓰지 않는다. 외부 CLI용 AGENTS.md 연결 파일 생성은 명시적 선택이다.
- 터미널 직접 입력은 ACP 경로가 아니므로 자동 주입 대상이 아니다. 외부 지침 파일을 쓰는 도구의 고유 동작을 따른다.

## 근거

짧은 공통 지침으로 설정 부담과 컨텍스트 비용을 줄인다. 세션에 경로를 귀속시켜 전역 화면 상태와 실행 수명을 분리한다. 하나의 초기화 모듈을 사용해 CLI와 GUI의 동작이 갈라지지 않게 한다.

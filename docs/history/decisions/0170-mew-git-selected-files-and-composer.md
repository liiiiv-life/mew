## 결정

Git 기본 화면은 커밋 작성·변경 파일·커밋 기록 순서로 배치하며 초기 높이는 약 30:50:20이다. 제목과 커밋 버튼 아래에 세로 크기를 조절할 수 있는 설명을 둔다. 파일 체크박스와 전체 선택으로 커밋 범위를 정한다. 체크하지 않은 파일은 stage 여부와 무관하게 커밋에서 제외하고 기존 stage 상태를 보존한다. 새 변경 파일은 자동 선택하지 않는다.

AI 자동 커밋 버튼은 선택한 파일의 제목·설명 초안을 생성한다. [0166](0166-mew-git-ai-commit-drafts.md)의 에이전트셋·독립 작업·사용자 초안 적용과 명시적 커밋 확정 경계를 유지한다. 선택 범위 또는 해당 변경이 달라지면 기존 결과를 적용하지 않는다.

## 근거

현재 변경을 선택하고 메시지를 작성하는 작업을 한 화면에서 마치려는 사용자 요청이다. 상세 동작은 [Git 사용법](../../guides/projects.md#git-작업-패널)에 둔다.

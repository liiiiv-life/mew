## 결정

- 사이드바 파일 탐색기는 하단에 떠 있는 Documents(문서)·Files(파일) 전환으로 선택한 목록만 표시한다. 상단 Documents 펼침 행은 제거한다.
- 문서와 일반 파일의 펼침·스크롤은 각자 보존하고 선택한 보기는 계정·루트 프로젝트별로 저장한다. 이전 Documents 펼침 상태는 문서 보기 선택으로 이관한다. 저장값이 없으면 파일 보기로 시작한다.
- 파일 탭에서 위치를 표시하거나 새 파일을 만들 때 해당 목록으로 전환한다. 탐색 보기 전환은 열린 편집기 탭·패널 배치를 바꾸지 않는다. Files의 하위 프로젝트는 기존처럼 별도 프로젝트 탭으로 연다.
- 토글은 스크롤과 무관하게 탐색기 아래에 유지하며 검색·명령 화면에는 표시하지 않는다. 게스트는 기존 문서 범위를 유지한다. Documents 설정은 문서 토글의 우클릭과 기존 설정 진입점을 유지한다.

## 근거

두 파일 영역을 한 목록에 섞지 않고 현재 작업의 탐색 범위를 명확히 한다. 기존 API 스코프·권한·에디터 통합은 유지한다. 현행 사용법은 [프로젝트 안내](../../guides/projects.md#사이드바의-프로젝트--하위-프로젝트--documents)에 둔다.

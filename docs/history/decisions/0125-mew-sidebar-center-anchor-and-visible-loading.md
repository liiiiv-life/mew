## 배경

픽셀 위치만 복원하면 화면 높이와 지연 로딩에 따라 보던 항목이 달라진다. 닫힌 폴더 예열은 복원에 필요한 요청과 경쟁한다.

## 결정

- 루트별 계정 상태에 Docs·하위 프로젝트·일반 폴더 펼침과 세로 중앙 항목의 트리 식별자·경로·항목 내 상대 위치를 저장한다.
- 복원은 중앙 항목을 우선하며, 없어진 항목이나 옛 저장값에는 기존 스크롤 위치를 사용한다. 첫 활성 문서가 복원 위치나 펼침을 덮어쓰지 않는다.
- 루트와 열린 경로의 직접 자식을 먼저 표시한다. 저장된 자식 목록은 즉시 표시 후 갱신한다. 닫힌 조상 아래의 경로와 접힌 최상위 폴더는 열 때 읽는다.
- 사용자 스크롤·클릭·키 입력이 시작되면 초기 위치 보정을 끝낸다. 이미 받은 자식 목록과 진행 중 요청은 재사용한다.

## 결과

최상위 전체 예열은 재도입하지 않는다. 탐색 상태는 기존 계정 UI 원장에 저장하며 별도 저장소를 만들지 않는다.

## 결정

- 메뉴 Git·Alt+G는 현재 프로젝트 루트의 Git 워크벤치를 바로 연다. 하위 프로젝트는 [0158](0158-mew-subprojects-open-root-tabs.md)의 독립 프로젝트 탭에서 작업한다.
- 중첩 저장소·별도 Documents 저장소 선택기와 새 Git 탭 버튼을 제거한다. 현재 프로젝트 루트가 Git 저장소가 아니면 빈 상태를 표시하며 상위·하위 저장소를 대신 열지 않는다.
- 이전에 저장된 Git 탭은 현재 프로젝트 루트 하나로 정규화한다. 저장소 목록 API도 요청 스코프의 루트만 확인하고 재귀 탐색하지 않는다. 파일 이력·기능 결과의 커밋 조회 등 기존 경로 기반 Git API는 유지한다.
- 공통 작업 패널·도킹 이동·크기 조절·프로젝트별 배치·숨김 중 초안 유지·모바일 닫기는 유지한다. 패널의 단일 탭 닫기·Ctrl+W는 Git 패널을 접는다. 새로고침은 커밋 초안을 복원하지 않는다.

## 근거

사용자가 프로젝트 탭에서 작업 범위를 정했으므로 Git 패널에서 다시 저장소를 고르게 할 필요가 없다. 프로젝트별 Git 작업 경계를 일치시키고 불필요한 하위 저장소 탐색을 없앤다. 제거한 통합 선택기를 같은 형태로 재도입하려면 후속 결정을 기록한다.

현행 기준은 [Git 사용법](../../guides/projects.md#git-작업-패널)과 [UI 계약](../../development/ui-contracts.md#git-저장소-탭)에 둔다.

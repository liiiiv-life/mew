## 배경

mew의 루트 README에 설치, 기능별 사용법, 개발 규칙이 함께 들어 있었다. 사용자는 첫 화면에 짧은 영어 소개와 한국어·영어·중국어·일본어 사용법 링크만 두도록 요청했다.

## 결정

- mew 루트 README는 영어 소개와 네 언어의 사용법 링크를 담는다.
- 설치·사용·업데이트 안내는 `mew/docs/guides/getting-started-{ko,en,zh,ja}.md`에 둔다. 중국어는 간체를 사용한다. 네 문서는 같은 사용법의 언어판이며, 절차가 바뀌면 함께 갱신한다.
- 개발 명령, 에이전트 실행 제한, 필수 UI 규칙은 `mew/docs/development/getting-started.md`로 옮긴다. 프로젝트 AGENTS에서 이 문서를 직접 연결한다.
- 각 언어판에서 프로젝트 문서 지도와 개발 문서로 이어진다. 문서 검사는 README에서 같은 프로젝트 docs 안의 안내 문서를 한 번 거쳐 MOC에 도달하는 경로도 인정한다.
- 프로젝트 문서 소유권, 중앙 ADR 위치, current/history 구분과 write-back 규칙은 0132를 따른다.

## 근거

처음 방문한 사람이 언어를 고른 뒤 설치와 사용법을 읽을 수 있다. 개발 규칙은 번역본마다 복제하지 않고 에이전트 진입점에서 바로 찾도록 한다.

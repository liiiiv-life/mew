## 배경

사용자가 에이전트 패널의 진행 작업을 취소했을 때 대기열까지 취소되는 동작을 변경하도록 요청했다.

## 선택지

1. 진행 작업과 대기열을 함께 취소한다.
2. 진행 작업만 취소하고 종료 확인 뒤 대기열을 FIFO로 계속 실행한다.

## 결정

패널의 작업 중단은 진행 중인 AI 또는 CLI 작업과 해당 승인 요청만 취소한다. 대기 항목은 보존하고 진행 작업의 종료 처리가 완료된 뒤 맨 위 항목부터 실행한다. 큐 편집 잠금·메모리 보호·인증 및 사용량 오류의 기존 보류는 유지한다. 개별 큐 삭제는 해당 항목만 취소하며 탭 종료와 대화 전환은 대기 작업도 정리한다.

## 근거

현재 작업을 중단해도 사용자가 등록한 다음 작업과 순서를 보존한다. 종료 확인 전 다음 작업을 시작하지 않아 같은 탭의 AI와 CLI가 동시에 실행되지 않는다.

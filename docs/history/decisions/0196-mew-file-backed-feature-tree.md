## 결정

- 기능 항목 하나는 Documents의 `features/` 아래 Markdown 파일 하나다. 제목은 파일명에서 `.md`와 대표 파일의 접두 `_`를 뺀 이름이며, 프론트매터의 제목·부모가 화면 계층을 결정하지 않는다.
- 계층은 [0191](0191-mew-documents-parent-and-child-pages.md)의 `이름.md` ↔ `이름/_이름.md` 규칙을 따른다. 첫 자식 생성·이동으로 승격하고 마지막 자식 제거·이동으로 단일 파일에 복귀한다. 남은 첨부 파일과 숨김 파일은 Documents와 같이 보존한다.
- 패널의 기존 타이틀바·상태 표시·정렬·새로고침·화면 상태 복원은 유지한다. 행에는 제목과 문서 열기만 제공하며 화살표는 하위 항목만 펼친다. 요구사항·구현·검증·파일·커밋·작업 이력은 원본 문서와 기존 에이전트·Git 화면에서 확인한다. 명시적 요청 없이 상세 섹션 UI를 재도입하지 않는다.
- 일반 Markdown은 별도 ID나 전용 결과 구분자 없이 읽는다. 기존 ID·상태·결과 메타데이터와 API·CLI 실행 큐는 호환하며 본문 형식 때문에 전체 목록을 막지 않는다. 문서 변경만으로 실행하지 않는다.
- 구조 변경은 본문과 링크를 보존하고, 충돌한 문서는 덮어쓰지 않는다. 현재 제품·저장·검증 계약은 [기능 기반 개발](../../specs/feature-development.md)이 소유한다.

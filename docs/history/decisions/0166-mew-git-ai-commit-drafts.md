- 결정자: 사용자 (에이전트셋 선택·생성과 전용 작업 실행 승인)

## 결정

- AI Commit은 저장된 에이전트셋을 선택하거나 새로 만들어 커밋 제목·설명을 생성한다. 실제 stage·commit은 기존 커밋 버튼으로 확정한다.
- 현재 프로젝트 루트 저장소만 대상으로 삼는다([0160](0160-mew-git-current-project-only.md)). 생성 전 변경 파일·diff를 캡처하고 에이전트셋의 런타임·모델·역할도 작업별로 고정한다.
- [0060](0060-mew-shared-agent-runtime-registry.md)의 등록표와 일회성 ACP 경로를 재사용한다. 작업별 tmux에서 별도 세션을 실행하며 기존 대화·탭·큐에는 요청하지 않는다.
- 계정·저장소별 작업 상태와 결과를 서버에 저장해 재접속 시 조회한다. 중복 실행을 막고 취소·시간 초과·실패를 구분한다. 사용자가 편집한 초안을 늦게 도착한 결과로 덮어쓰지 않는다.
- 생성 요청은 Git과 에이전트 기능 권한을 모두 요구한다. tmux는 내부 실행 수단이며 임의 셸 입력을 노출하지 않는다. 에이전트에는 제공된 변경만 읽고 JSON 초안만 반환하도록 지시하며 승인 요청은 거절한다. 이는 OS 파일 격리를 추가하는 결정이 아니며 기존 에이전트 실행 권한 경계는 유지한다.

## 근거

tmux는 작업 수명과 출력을 맡고 ACP는 공통 런타임·모델 선택과 완료 판정을 맡는다. 대화형 TUI 화면을 파싱하거나 런타임별 CLI 명령을 별도로 구현하지 않는다.

현행 조작과 한계는 [Git 사용법](../../guides/projects.md#git-작업-패널)에 둔다.

## 결정

에이전트 입력줄의 모델 선택 왼쪽에 기본 해제인 CLI 토글을 둔다. 켠 상태의 입력은 AI 프롬프트가 아니라 해당 cwd의 셸 명령이다. 명령마다 전용 tmux를 즉시 생성한다. ACP 큐·모델·스킬·첨부 합성은 적용하지 않는다.

ADR 0046의 탭별 ACP 대화 소유권은 유지하되, 대화에 여러 독립 CLI 작업을 연결할 수 있다. 계정·런타임·cwd·대화 ID를 저장 경계로 삼고 AI 전사와 명령 기록을 분리한다. `/clear`와 히스토리 이동은 명령을 새 대화에 섞지 않는다. 탭 닫기는 그 탭이 시작한 실행 중 명령도 중단한다. 팝업·패널·브라우저 닫기는 실행에 영향을 주지 않는다.

명령 버블은 고정폭 글꼴과 `$`로, 응답은 상태색이 있는 터미널 열기 버튼으로 표시한다. 실행 중에는 tmux에 연결한다. 서버와 독립된 실행기가 출력을 gzip으로 스트리밍 저장하고 완료 상태를 원자적으로 저장한 뒤 tmux를 종료한다. 완료 뒤에는 저장 출력 미리보기와 전체 압축 기록 다운로드를 제공한다.

에이전트와 터미널 기능 권한을 모두 요구한다(ADR 0150). 기록 HTTP API는 계정 소유권을 검사한다. 일반 tmux 접근의 서버 제어 경계는 바꾸지 않는다.

## 근거와 결과

브라우저 연결과 AI 턴 수명에 명령을 묶지 않고, 빠르게 끝나는 명령도 출력을 잃지 않게 한다. 대용량 출력은 대화 전사·localStorage에 복제하지 않는다. 기록과 실행 계약의 기준본은 [mew 세션 문서](../../development/agent-sessions.md)다.

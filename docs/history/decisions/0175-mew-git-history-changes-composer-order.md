## 결정

Git 기본 화면은 위에서부터 커밋 기록, 변경사항 목록, 커밋 입력 순서로 배치한다. 초기 높이는 약 20:50:30이며 기존 독립 스크롤·목록 경계 조절·입력 영역 크기 조절·선택 파일·초안 보존을 유지한다. 탭 바를 다시 만들지 않는다.

최근 기록을 위에서 확인하고 가운데에서 파일을 선택한 뒤 아래에서 커밋하는 사용자 요청을 반영한다. [0174](0174-mew-commit-skill-and-automatic-commits.md)의 실제 자동 커밋 계약은 유지한다. 현행 조작은 [Git 사용법](../../guides/projects.md#git-작업-패널)에 둔다.

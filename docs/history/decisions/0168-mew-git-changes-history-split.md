## 결정

현재 프로젝트 Git 패널의 기본 화면은 위쪽 변경 파일 목록과 아래쪽 커밋 그래프로 나눈다. 두 목록은 독립적으로 스크롤하고 중간 경계 드래그·키보드로 높이 비율을 조절한다. 변경 파일에서 바로 diff를 열 수 있고, 커밋 작성과 과거 커밋 상세는 기존 화면을 유지한다.

커밋 행은 작은 그래프와 제목·상대 시간·짧은 해시·작성자를 한 줄로 표시한다. 분·시간·일 중 가장 큰 단위 하나를 쓴다. 기본 화면의 빈 상단 바와 중복된 프로젝트 루트 문구는 제거한다. 현재 프로젝트 범위·도킹·초안·Git 작업 권한은 바꾸지 않는다.

## 근거

현재 변경과 과거 기록을 바로 비교하고 좁은 패널에서도 더 많은 커밋을 확인하려는 사용자 요청이다. 상세 계약은 [Git 사용법](../../guides/projects.md#git-작업-패널)에 둔다.

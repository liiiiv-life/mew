## 결정

- 기능 패널은 모든 계정에서 읽기 전용으로 제공한다. 에이전트셋 선택, 제목·본문 편집, 항목·기능 추가, 요청·재위임·재시도, 상태 판정, 실행 중단 UI를 제거한다.
- 계층·섹션 접기와 펼치기, 정렬·새로고침, 원본 문서·관련 파일·커밋·기존 대화 열기, 작업 이력 조회와 화면 상태 복원은 유지한다.
- 문서 편집기·외부 Markdown 편집과 기존 API·CLI·실행 큐는 유지한다. 패널에서는 변경 API나 에이전트셋 조회를 호출하지 않는다.
- 사용자 요청에 따라 조회와 변경을 분리한다. 명시적 후속 요청 없이 제거한 패널 조작을 재도입하지 않는다.

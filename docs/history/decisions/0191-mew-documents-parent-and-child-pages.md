## 결정

- Docs의 폴더는 상위 문서로 표시한다. 이름 클릭은 대표 파일을 열고 화살표는 하위를 펼친다. 대표 파일은 자식 목록에 중복 표시하지 않는다.
- 자식 없는 문서는 `name.md`, 자식 있는 문서는 `name/_name.md`로 저장한다. 첫 자식을 추가할 때 승격하고 마지막 자식을 제거할 때 다시 단일 파일로 내린다. 이름 변경은 폴더와 대표 파일을 함께 바꾼다.
- 일반 클릭은 현재 편집기 탭에서 문서를 바꾸며 Ctrl/Cmd+클릭은 별도 탭을 유지한다. 저장 전 내용은 버리지 않는다.
- 기존 MOC.md·_MOC.md는 폴더 대표 문서로 읽는다. 실제 기존 문서를 일괄 이전하지 않으며 해당 상위 문서의 자식 생성·개명 때 새 대표 이름으로 전환한다. Docs 루트 진입점은 기존 MOC를 호환한다. archives는 변경하지 않는다.
- 구조 전환은 경로·본문·내부 링크를 함께 보정하고 충돌 또는 권한 오류에서 기존 파일을 보존한다. Docs API·에디터 스코프와 일반 파일 탐색은 유지한다.

## 근거

문서를 파일과 폴더로 구분해 탐색하는 부담을 줄이고, 문서 내용을 유지하면서 하위 문서를 묶을 수 있게 한다. 저장 방식과 현행 사용법은 [문서 페이지 계약](../../development/document-pages.md)에 둔다.

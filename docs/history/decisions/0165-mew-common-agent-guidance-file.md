## 결정

- 서버 전체 공통 안내의 기준본은 `DATA_DIR/agent-guidance.txt`다. 저장소의 `server/prompts/agent-guidance.txt`는 최초 생성용 기본값이며 기존 사용자 파일을 업데이트로 덮어쓰지 않는다.
- 사이드바 Documents 위에 공통 안내 파일을 표시하고 기존 서버 파일 편집기로 연다. 노출·편집 권한은 서버 파일 탐색기와 같은 `serverFiles`다.
- ACP 실행 직전에 파일을 읽는다. 저장한 안내는 프로젝트·세션에 관계없이 다음 요청부터 적용한다. 프로젝트 경로·문서 진입점·추가 지침은 별도로 조합한다.
- 파일이 없으면 실행 또는 파일 열기 때 기본 파일을 생성한다. 설정 미리보기는 생성하지 않고 기본값을 읽는다. 빈 파일은 공통 문구만 비우며, 읽기 오류는 숨기지 않는다.
- 안내는 기존처럼 별도 ACP 텍스트 블록이며 시스템 역할을 가장하지 않는다. 프로젝트별 자동 안내 끄기와 터미널 직접 입력의 경계는 유지한다.

## 근거

공통 문구를 코드 수정 없이 편집하면서 프로젝트별 사본과 배포 시 사용자 수정 손실을 피한다. 현재 파일 편집기의 저장·탭 동작을 재사용한다.

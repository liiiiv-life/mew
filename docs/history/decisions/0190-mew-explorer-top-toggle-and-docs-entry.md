## 결정

- 문서/파일 토글은 탐색기 맨 위에 전체 너비의 독립 행으로 배치한다. 목록 스크롤에 포함하지 않는다.
- 파일 보기에는 연결된 문서 폴더의 이름으로 진입점을 표시한다. 클릭하면 폴더를 펼치거나 프로젝트를 열지 않고 문서 보기로 전환한다. `.mew/docs`도 같은 방식으로 진입점을 제공한다.
- 문서 API 스코프와 파일 목록 분리, 보기별 펼침·스크롤, 편집기 탭 보존, 키보드 전환, 게스트 범위와 문서 설정 진입점은 유지한다.

## 근거

탐색 범위를 즉시 찾고 파일 보기에서도 문서 폴더에 접근할 수 있게 한다. 실제 사용법은 [프로젝트 안내](../../guides/projects.md#사이드바의-프로젝트--하위-프로젝트--documents)에 둔다.

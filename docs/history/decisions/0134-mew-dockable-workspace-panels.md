## 배경

에디터는 분할 배치, 에이전트는 오른쪽 고정 패널, 웹 브라우저는 별도 창을 사용한다. 에이전트와 일반 셸을 동시에 보면서 작업하려면 별도 패널이 필요하다. 사용자는 이 패널들을 같은 방법으로 끌어서 다른 구역에 붙이기를 요청했다.

## 결정

- 에디터·에이전트·일반 터미널·웹 브라우저를 공통 작업 영역의 분할 배치로 관리한다. 헤더를 끌면 패널을 이동하고, 탭을 끌면 해당 탭을 이동하거나 별도 패널로 분리한다.
- 좌우·상하 가장자리에는 배치 미리보기를 표시한다. 같은 종류의 패널 가운데에 탭을 놓으면 합치고, 다른 종류의 패널과는 나란히 배치한다.
- 웹 브라우저는 좌우 도킹만 허용한다. 상하 분할 안에 넣어 납작해지는 배치는 만들지 않는다. 다른 패널을 브라우저 위아래에 붙여 같은 제약을 우회하지 못한다.
- 탭을 옮기거나 패널을 접는 동작으로 ACP 세션·tmux 프로세스를 종료하지 않는다. 에이전트의 모든 탭은 기존 계정 원장 하나를 계속 사용한다. 일반 셸 탭은 터미널 패널로 분류하며 ID·cwd·세션 연결을 보존한다. Claude·Antigravity 등 에이전트 TUI는 에이전트 패널에 남는다.
- 배치와 탭의 패널 배정은 계정·루트 프로젝트별 작업 화면 상태에 저장한다. 기존 에디터 분할과 에이전트 탭을 처음 배치에 반영하며, 새 형식은 독립된 버전 필드로 구분한다.
- 모바일에서는 패널 전면 전환과 뒤로가기 계약을 유지한다. 데스크톱 도킹 배치가 모바일에서 작은 여러 칸을 강제하지 않는다.
- 로그인·구독·브라우저 네트워크·셸 권한은 변경하지 않는다. 패널 배치 때문에 실행 정보를 설명하는 문구를 추가하지 않는다.

## 근거

분할 배치와 탭 수명주기를 분리하면 패널 위치를 바꾸는 동작이 실행 중인 작업에 영향을 주지 않는다. 위치만 다른 별도 패널 구현을 늘리지 않고 배치·드롭 판정·크기 조절을 공통으로 관리한다.

구현·검증 계약은 [UI 계약](../../development/ui-contracts.md)에서 관리한다.
